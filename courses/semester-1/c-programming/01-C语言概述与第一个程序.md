## 1. 程序与程序设计语言

**程序**：按特定顺序组织的指令集合，告诉计算机做什么。

**程序设计语言**：人与计算机沟通的语言。
- 机器语言：二进制，机器直接执行，难读难写
- 汇编语言：助记符，需汇编程序翻译
- **高级语言**：接近自然语言/数学符号，需编译器/解释器翻译 → **C 语言属于高级语言**

> 💡 C 语言 = 高级语言的表达力 + 低级语言的硬件操作能力

## 2. C 语言简史与特点

| 年份 | 里程碑 |
|------|--------|
| 1972 | 丹尼斯·里奇在贝尔实验室开发 C，用于重写 UNIX |
| 1978 | K&R C（《C 程序设计语言》出版， facto 标准） |
| 1989 | ANSI C (C89) —— 首个国际标准 |
| 1999 | C99 标准（`//`注释、`long long`、变量声明位置灵活等） |
| 2011 | C11 标准（多线程、泛型选择、原子操作等） |

**C 语言特点**（考试常考简答）：
1. 简练、紧凑、功能强大（32 个关键字、丰富运算符）
2. 结构化控制语句（if/for/while，无 goto 也能写清晰程序）
3. 数据类型丰富，且允许直接操作内存（指针）
4. 编译高效，生成代码质量高，执行速度快
5. 可移植性强（标准 C 代码跨平台重新编译即可运行）
6. 既可写应用程序，也可写系统软件（OS、驱动、嵌入式）

## 3. C 程序的基本结构

```c
// 第一个 C 程序
#include <stdio.h>   // 预处理命令：包含标准输入输出头文件

int main(void)       // 主函数：程序入口，有且仅有一个
{                    // 左大括号：函数体开始
    printf("Hello, World!\n");  // 语句：调用库函数输出，以分号结尾
    return 0;        // 返回值：0 表示正常结束
}                    // 右大括号：函数体结束
```

### 3.1 程序构成要素

| 要素 | 说明 | 示例 |
|------|------|------|
| **预处理命令** | 以 `#` 开头，编译前处理，不以分号结尾 | `#include <stdio.h>` |
| **主函数 main** | 程序执行入口，**每个程序必须有且仅有一个** | `int main(void)` |
| **声明部分** | 变量、常量、函数原型声明 | `int a, b;` |
| **执行部分** | 语句（赋值、函数调用、流程控制...） | `a = 10; printf(...);` |
| **返回语句** | 向操作系统返回状态 | `return 0;` |

> ⚠️ **注意**：
> - C 语言**区分大小写**（`main` ≠ `Main`)
> - 语句**必须以分号 `;` 结尾**（复合语句 `{}` 后不加分号）
> - 一个语句可跨多行，多语句可写一行（不推荐）
> - 注释：`// 单行注释`（C99）或 `/* 多行注释 */`（不可嵌套）

## 4. 从源程序到可执行程序

```
hello.c (源程序) 
    │ 预处理 (展开头文件、宏)
    ▼
hello.i (预处理后的源文件)
    │ 编译 (语法分析、生成汇编)
    ▼
hello.s (汇编代码)
    │ 汇编 (汇编→机器码)
    ▼
hello.o (目标文件/二进制目标代码)
    │ 链接 (合并库函数代码、解析符号)
    ▼
hello.exe (可执行文件，Windows) / hello (Linux)
```

> 💡 **教材简化版**：源程序 → **编译** → 目标文件 → **链接** → 可执行文件。  
> 实际 IDE（VS Code、VS、Dev-C++）点"运行"按钮自动完成全过程。

## 5. 在 IDE 中运行第一个程序

### 5.1 VS Code + MinGW（推荐）

1. 新建文件夹 `c-learning`，用 VS Code 打开
2. 新建 `hello.c`，输入上述代码
3. 终端（`Ctrl+~`）运行：
   ```bash
   gcc hello.c -o hello
   ./hello          # Windows 为 hello.exe 或 .\hello.exe
   ```
   输出：`Hello, World!`

### 5.2 Visual Studio 2022

1. 文件 → 新建 → 项目 → "空项目" → 取名 `Hello`
2. 右键"源文件" → 添加 → 新建项 → C++ 文件 → 改名 `hello.c`
3. 粘贴代码 → `Ctrl+F5`（不调试运行）

### 5.3 Dev-C++ / Code::Blocks

1. 文件 → 新建 → 源文件 → 保存为 `hello.c`
2. 粘贴代码 → `F11` (Dev-C++) 或 `F9` (Code::Blocks) 编译运行

### 5.4 Linux / WSL + GCC（推荐用于学习底层）

如果你使用 Linux 或 WSL（Windows Subsystem for Linux），可以直接使用 GCC 编译器：

```bash
# 1. 安装 GCC（Ubuntu/Debian）
sudo apt update
sudo apt install build-essential

# 2. 验证安装
gcc --version

# 3. 编译运行
gcc hello.c -o hello
./hello
```

> 💡 **推荐**：Linux/GCC 环境更接近真实开发，建议学习。详细安装配置见 [附录：Linux GCC 环境搭建与 Makefile 入门](附录-开发环境搭建与GDB调试.md)。

## 6. 编译错误 vs 运行错误

| 类型 | 发现阶段 | 典型例子 | 处理 |
|------|---------|---------|------|
| **语法错误** | 编译期 | 漏分号、拼写错、括号不匹配 | 看报错行号、对照语法改 |
| **链接错误** | 链接期 | `undefined reference to 'printf'`（极少见，库未链接） | 检查库名、路径 |
| **运行错误** | 运行期 | 除零、数组越界、死循环、逻辑错 | 加 `printf` 调试、用调试器断点 |

> 🎯 **新手建议**：**一个错误一个改**，编译器报的第一个错误最准，后面的可能是连锁误报。

## 🎯 课后练习（约 5 分钟）

### 必做（动手敲，不许复制粘贴）

1. **敲出第一个程序**：
   - 在你选择的 IDE 里创建 `hello.c`，**手敲**每个字符
   - 编译运行，确认输出 `Hello, World!`
   - 故意删掉分号、拼错 `printf`、漏 `#include`，观察报错信息

2. **修改输出**：
   ```c
   #include <stdio.h>
   int main(void) {
       printf("I love C language!\n");
       printf("My student ID: 2024xxxx\n");
       return 0;
   }
   ```

3. **观察返回值**（进阶）：
   - Windows PowerShell：运行后输入 `echo $LASTEXITCODE`
   - Linux/macOS/WSL：运行后输入 `echo $?`
   - 正常应显示 `0`。把 `return 0;` 改为 `return 5;` 再试。

### 思考题（写到练习本）

1. C 程序的入口函数叫什么？能有多个吗？
2. `#include <stdio.h>` 中尖括号和双引号有什么区别？（教材 P12）
3. `main` 前面的 `int` 表示什么？`return 0;` 的 0 表示什么？
4. 编译和链接的区别是什么？库函数代码在哪个阶段合并进可执行文件？

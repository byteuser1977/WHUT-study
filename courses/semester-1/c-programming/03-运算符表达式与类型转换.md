## 1. 运算符优先级与结合性（完整表，高→低）

| 优先级 | 运算符 | 结合性 | 说明 |
|--------|--------|--------|------|
| 1 | `()` `[]` `->` `.` | 左→右 | 函数调用、数组下标、成员访问 |
| 2 | `++` `--` `+` `-` `!` `~` `*` `&` `sizeof` `_Alignof` `(type)` | 右→左 | 后置++/--在优先级1，前置在这一级；一元运算符 |
| 3 | `*` `/` `%` | 左→右 | 乘除模 |
| 4 | `+` `-` | 左→右 | 加减 |
| 5 | `<<` `>>` | 左→右 | 移位 |
| 6 | `<` `<=` `>` `>=` | 左→右 | 关系比较 |
| 7 | `==` `!=` | 左→右 | 相等比较 |
| 8 | `&` | 左→右 | 位与 |
| 9 | `^` | 左→右 | 位异或 |
| 10 | `\|` | 左→右 | 位或 |
| 11 | `&&` | 左→右 | 逻辑与（短路） |
| 12 | `\|\|` | 左→右 | 逻辑或（短路） |
| 13 | `?:` | 右→左 | 条件运算符 |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `\|=` | 右→左 | 赋值运算符 |
| 15 | `,` | 左→右 | 逗号运算符 |

> 💡 **记忆口诀**：
> - 单目 > 双目 > 赋值 > 逗号
> - 算术 > 移位 > 关系 > 相等 > 位与 > 位异或 > 位或 > 逻辑与 > 逻辑或 > 条件 > 赋值
> - **括号最强**，不确定就加括号（可读性第一）

## 2. 表达式求值顺序、副作用与序列点

### 2.1 副作用

修改对象存储值的操作：赋值、自增自减、函数调用（可能修改全局/静态变量/参数指向对象）、`volatile` 访问。

### 2.2 序列点

**保证前序副作用完成、后序副作用未开始**的点：
- 完整表达式结束（`;`、`}`、控制表达式、`return` 表达式）
- `&&`、`||`、`?:`、` , `（逗号运算符，非函数参数逗号）
- 函数调用**实参求值完成后、进入函数前**
- 返回语句 `return` 表达式求值后

### 2.3 经典 UB 陷阱

```c
int i = 0;

// 1. 同一序列点内多次修改同一对象
i = i++ + 1;           // UB：i 既被赋值修改，又被 i++ 修改
a[i] = i++;            // UB：i 既做下标修改，又被 i++ 修改
printf("%d %d\n", i++, i++); // UB：实参求值顺序未指定，两个 i++ 无序列点隔开

// 2. 修改与读取无序列点隔开
int x = 10;
int y = x++ + x;       // UB：读取 x (x) 与修改 x (x++) 无序列点

// 3. 函数实参求值顺序未指定（无序列点）
void foo(int a, int b);
int i = 0;
foo(i++, i++);         // UB：两个 i++ 谁先求值不定
```

> ✅ **安全写法**：
> ```c
> int i = 0;
> i = i + 1;           // 明确顺序
> int t = i;           // 先取值
> i = t + 1;           // 再赋值
> 
> // 复杂表达式拆分为多条语句
> int a = 10;
> int t1 = a++;
> int t2 = a;
> int y = t1 + t2;     // 明确顺序
> ```

## 3. 显式类型转换

### 3.1 强制类型转换 `(type)`

```c
double d = 3.14;
int i = (int)d;        // 截断向零取整：3

// 指针转换
void *p = malloc(100);
int *ip = (int *)p;    // C 语言 void* 自动转目标指针，显式转换可省略但建议保留

// 整数与指针互转（需 uintptr_t/intptr_t）
uintptr_t addr = (uintptr_t)ip;
int *ip2 = (int *)addr;
```

### 3.2 安全转换模式

```c
// 1. 有符号→无符号：明确意图
int a = -1;
unsigned int b = (unsigned int)a;  // 明确：按补码重解释为大正数

// 2. 窄化转换：显式 + 断言/检查
long long big = 1234567890123LL;
int small = (int)big;  // 可能截断
// 安全版：
if (big >= INT_MIN && big <= INT_MAX) {
    small = (int)big;
}

// 3. 指针类型双关：用 union 或 memcpy（避免严格别名规则违规）
float f = 3.14f;
uint32_t bits;
static_assert(sizeof(float) == sizeof(uint32_t), "");
memcpy(&bits, &f, sizeof(float));  // 合规取位模式
```

### 3.3 复合字面量（C99）

```c
// 临时创建无名对象，可用于初始化、传参
int *p = (int []){1, 2, 3, 4, 5};  // 临时数组，生命周期到块结束
struct Point { int x, y; };
draw_point((struct Point){10, 20}); // 临时结构体传参
```

## 4. 位运算实战技巧

### 4.1 基础操作宏

```c
// 第 n 位置 1 / 清 0 / 翻转 / 测试
#define BIT_SET(x, n)    ((x) |= (1U << (n)))
#define BIT_CLEAR(x, n)  ((x) &= ~(1U << (n)))
#define BIT_FLIP(x, n)   ((x) ^= (1U << (n)))
#define BIT_TEST(x, n)   (((x) >> (n)) & 1U)

// 低 n 位掩码
#define MASK_LOW(n)      ((n) >= sizeof(unsigned)*8 ? ~0U : ((1U << (n)) - 1))

// 清除最低位的 1：x & (x - 1)
// 取最低位的 1：x & -x (补码特性)
// 判断 2 的幂：x > 0 && (x & (x - 1)) == 0
```

### 4.2 实战场景

```c
#include <stdio.h>
#include <stdint.h>

// 1. 权限掩码
enum Perm { READ = 1<<0, WRITE = 1<<1, EXEC = 1<<2 };
uint8_t perm = READ | WRITE;  // 0b011
if (perm & READ) { /* 可读 */ }
perm |= EXEC;                 // 添加执行权
perm &= ~WRITE;               // 移除写权限

// 2. 标志位压缩存储（节省内存）
struct Config {
    uint32_t enable_log    : 1;
    uint32_t auto_retry    : 1;
    uint32_t use_ssl       : 1;
    uint32_t reserved      : 29;  // 填充到 32 位
};

// 3. 循环缓冲区索引（2 的幂长度）
#define RING_SIZE 16  // 必须是 2 的幂
uint8_t ring[RING_SIZE];
size_t head = 0, tail = 0;
void push(uint8_t v) {
    ring[head] = v;
    head = (head + 1) & (RING_SIZE - 1);  // 快速模运算
}

// 4. 大小端转换
uint32_t hton32(uint32_t x) {  // 主机序→网络序(大端)
    return ((x & 0xFF) << 24) | ((x & 0xFF00) << 8) |
           ((x & 0xFF0000) >> 8) | ((x >> 24) & 0xFF);
}

// 5. 位并行算法：人口计数
int popcount(uint32_t x) {
    x = x - ((x >> 1) & 0x55555555);
    x = (x & 0x33333333) + ((x >> 2) & 0x33333333);
    return ((x + (x >> 4) & 0xF0F0F0F) * 0x1010101) >> 24;
}
// 现代 GCC/Clang 内置：__builtin_popcount(x)
```

> 💡 **位运算黄金法则**：
> - 用 `1U` 避免有符号移位 UB
> - 移位量 ≥ 位宽 = UB
> - 左移有符号负数 = UB
> - 优先用无符号类型做位运算

## 5. 条件运算符 `?:` 与逗号运算符 `,`

### 5.1 条件运算符

```c
// 表达式，非语句，有返回值
int max = (a > b) ? a : b;

// 可嵌套（建议不用，可读性差）
int sign = (x > 0) ? 1 : (x < 0) ? -1 : 0;

// 类型转换：两操作数按常见算术转换统一类型
double d = (cond) ? 1 : 2.0;  // 结果 double
```

### 5.2 逗号运算符

```c
// 顺序求值，值为最后一个表达式的值
int x = (1, 2, 3);  // x = 3

// for 循环多变量更新
for (int i = 0, j = 10; i < j; i++, j--) { ... }

// 宏中多语句合一（配合 do-while(0)）
#define SWAP(a, b) do { int tmp = (a); (a) = (b); (b) = tmp; } while(0)
// 使用：SWAP(x, y); 带分号合法
```

## 6. 编译期常量表达式

### 6.1 整型常量表达式（ICE）

可用于：数组长度（非 VLA）、枚举值、`switch` case、位域宽度、`_Static_assert`。

```c
#define N 10
int arr[N];           // OK
enum { SIZE = N };    // OK
_Static_assert(N > 0, "N must be positive"); // C11 编译期断言
```

### 6.2 C23 `constexpr`（或 C++ 风格）

```c
// C23 支持 constexpr
constexpr int square(int x) { return x * x; }
int arr[square(5)];  // OK，编译期计算 25

// C11/C17 近似：用宏或枚举
#define SQUARE(x) ((x)*(x))
enum { ARR_SIZE = SQUARE(5) };
int arr[ARR_SIZE];
```

## 本讲小结

| 知识点 | 核心规则 |
|--------|---------|
| 优先级 | 单目 > 算术 > 移位 > 关系 > 相等 > 位与 > 位异或 > 位或 > 逻辑与 > 逻辑或 > 条件 > 赋值 > 逗号 |
| 结合性 | 单目/赋值/条件：右→左；其余：左→右 |
| 序列点 | `;` `&&` `||` `?:` `,` 函数调用前/后 |
| UB 红线 | 同序列点多次修改同对象、修改与读取无序列点、实参求值顺序 |
| 显式转换 | `(type)`，指针↔整数用 `uintptr_t`，避免严格别名违规用 `memcpy`/union |
| 位运算 | 用无符号、`1U`、移位量<位宽、内置函数 `__builtin_*` |
| 条件运算符 | 表达式、有返回值、类型按常见算术转换 |
| 编译期常量 | ICE 用于数组长度/enum/case/_Static_assert |

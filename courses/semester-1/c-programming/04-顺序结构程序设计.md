## 1. 什么是顺序结构

程序从上到下**逐行执行**，没有跳转和分支，就像读一本书从第一页看到最后一页。

```c
#include <stdio.h>

int main(void) {
    // 顺序执行：先声明，再赋值，再输出
    int a = 10;      // 第1步：声明变量并赋值
    int b = 20;      // 第2步：声明另一个变量
    int sum = a + b; // 第3步：计算和
    printf("和是：%d\n", sum); // 第4步：输出结果
    return 0;
}
```

## 2. printf 格式化输出

### 2.1 基本格式符

| 格式符 | 说明 | 示例 |
|--------|------|------|
| `%d` | 十进制整数 | `printf("%d", 42);` → `42` |
| `%f` | 浮点数（默认6位小数） | `printf("%f", 3.14);` → `3.140000` |
| `%c` | 单个字符 | `printf("%c", 'A');` → `A` |
| `%s` | 字符串 | `printf("%s", "hello");` → `hello` |
| `%lf` | 双精度浮点数（scanf常用） | |
| `%p` | 指针地址 | |
| `%%` | 输出%本身 | `printf("100%%");` → `100%` |

### 2.2 格式控制

```c
// 宽度控制
printf("%10d", 42);      // 右对齐，宽度10："        42"
printf("%-10d", 42);     // 左对齐：'42        '
printf("%010d", 42);     // 前导零填充：'0000000042'

// 小数位数
printf("%.2f", 3.14159); // 保留2位小数：'3.14'
printf("%10.2f", 3.14);  // 宽度10，2位小数：'      3.14'
```

## 3. scanf 格式化输入

### 3.1 基本用法

```c
int a;
float b;
char c;

scanf("%d", &a);    // 注意：必须用 & 取地址
scanf("%f", &b);
scanf(" %c", &c);   // 前面加空格跳过空白字符
```

### 3.2 常见问题

```c
// 问题1：忘记 &
scanf("%d", a);     // ❌ 错误！应该 &a

// 问题2：缓冲区残留
int a;
char c;
scanf("%d", &a);    // 输入 42 回车
scanf(" %c", &c);   // 前面加空格跳过回车

// 问题3：输入多个值
int x, y;
scanf("%d %d", &x, &y);  // 输入：10 20 或 10回车20
```

## 5. 赋值语句

### 5.1 基本赋值

```c
int a = 10;     // 初始化
a = 20;         // 赋值
a += 5;         // 等价于 a = a + 5
a -= 3;         // 等价于 a = a - 3
a *= 2;         // 等价于 a = a * 2
```

### 5.2 复合赋值运算符

```c
a += b;    // a = a + b
a -= b;    // a = a - b
a *= b;    // a = a * b
a /= b;    // a = a / b
a %= b;    // a = a % b（取模）
a &= b;    // a = a & b（位与）
a |= b;    // a = a | b（位或）
a ^= b;    // a = a ^ b（位异或）
a <<= n;   // a = a << n（左移）
a >>= n;   // a = a >> n（右移）
```

## 🎯 课后练习（约5分钟）

### 必做（动手敲，不许复制粘贴）

1. **温度转换程序**：
   ```c
   #include <stdio.h>
   int main(void) {
       float celsius, fahrenheit;
       printf("请输入摄氏温度：");
       scanf("%f", &celsius);
       fahrenheit = celsius * 9.0 / 5.0 + 32;
       printf("%.1f°C = %.1f°F\n", celsius, fahrenheit);
       return 0;
   }
   ```

2. **输入两个数，输出它们的和、差、积、商**：
   ```c
   #include <stdio.h>
   int main(void) {
       int a, b;
       printf("请输入两个整数：");
       scanf("%d %d", &a, &b);
       printf("和：%d\n", a + b);
       printf("差：%d\n", a - b);
       printf("积：%d\n", a * b);
       if (b != 0) {
           printf("商：%.2f\n", (float)a / b);
       }
       return 0;
   }
   ```

3. **格式化输出个人信息**：
   ```c
   #include <stdio.h>
   int main(void) {
       char name[50];
       int age;
       float height;
       printf("姓名：");
       scanf("%s", name);
       printf("年龄：");
       scanf("%d", &age);
       printf("身高(m)：");
       scanf("%f", &height);
       printf("\n===== 个人信息卡 =====\n");
       printf("姓名：%s\n", name);
       printf("年龄：%d岁\n", age);
       printf("身高：%.2fm\n", height);
       return 0;
   }
   ```

### 思考题（写到练习本）

2. `printf("%.2f", 3.14159)` 输出什么？`printf("%10.2f", 3.14)` 呢？
3. 转义字符 `\n` 和 `\t` 分别有什么作用？
4. `a += 5` 和 `a = a + 5` 有什么区别？（提示：类型转换）

## 本讲小结

| 概念 | 要点 |
|------|------|
| 顺序结构 | 从上到下逐行执行 |
| printf | 格式化输出，`%d/%f/%c/%s` 等格式符 |
| scanf | 格式化输入，必须用 `&` 取地址 |
| 转义字符 | `\n` 换行、`\t` 制表、`\\` 反斜杠 |
| 赋值语句 | `=` 赋值、`+=/-=/*=/` 复合赋值 |
| 表达式语句 | 表达式 + 分号 = 语句 |

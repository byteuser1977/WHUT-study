## 1. 基本类型速查表（x86-64 Linux，LP64 模型）

| 类型关键字 | 别名 | 位宽 | 字节 | 有符号范围 | 无符号范围 | 格式符 | 对齐 |
|-----------|------|------|------|-----------|-----------|--------|------|
| `char` | `signed char` / `unsigned char` | 8 | 1 | -128 ~ 127 | 0 ~ 255 | `%hhd` / `%hhu` | 1 |
| `short` | `signed short` / `unsigned short` | 16 | 2 | -32,768 ~ 32,767 | 0 ~ 65,535 | `%hd` / `%hu` | 2 |
| `int` | `signed int` / `unsigned int` | 32 | 4 | -2,147,483,648 ~ 2,147,483,647 | 0 ~ 4,294,967,295 | `%d` / `%u` | 4 |
| `long` | `signed long` / `unsigned long` | 64 | 8 | -9.22e18 ~ 9.22e18 | 0 ~ 1.84e19 | `%ld` / `%lu` | 8 |
| `long long` | `signed long long` / `unsigned long long` | 64 | 8 | 同 long | 同 unsigned long | `%lld` / `%llu` | 8 |
| `float` | — | 32 | 4 | ≈ ±3.4e38 (7 位有效数字) | — | `%f` / `%e` / `%g` | 4 |
| `double` | — | 64 | 8 | ≈ ±1.7e308 (15-16 位有效数字) | — | `%lf` / `%le` / `%lg` | 8 |
| `long double` | — | 80/128 | 16 | 扩展精度 | — | `%Lf` | 16 |
| `_Bool` | `bool` (stdbool.h) | 8 | 1 | 0 / 1 | — | `%d` | 1 |
| 指针 | `void *` 等 | 64 | 8 | — | 0 ~ 2^64-1 | `%p` | 8 |

> 💡 **标准只保证最小宽度**：`char` ≥ 8 位、`short` ≥ 16 位、`int` ≥ 16 位、`long` ≥ 32 位、`long long` ≥ 64 位。以上表格是 **LP64**（Linux/macOS 64 位）常见实现。Windows 64 位是 **LLP64**（`long` 为 4 字节）。

### 1.1 固定宽度类型 `<stdint.h>`（跨平台首选）

```c
#include <stdint.h>

// 精确宽度
int8_t   u8;   // 正好 8 位有符号
uint32_t u32;  // 正好 32 位无符号

// 最小宽度（至少 N 位，可能更大）
int_least16_t  // 至少 16 位，通常 = int16_t

// 最快宽度（运算最快的至少 N 位类型）
int_fast32_t   // 通常 = int32_t 或 int64_t

// 最大宽度
intmax_t       // 平台最大有符号整型
uintmax_t      // 平台最大无符号整型

// 指针能容纳的整型
intptr_t       // 有符号
uintptr_t      // 无符号，用于指针↔整数转换

// 格式宏（PRIu32 等，配合 printf）
printf("u32 = %" PRIu32 "\n", u32);
```

## 2. `sizeof` 与 `_Alignof`

```c
#include <stdio.h>
#include <stdalign.h>

int main(void) {
    int a = 42;
    double arr[10];
    struct { char c; int i; } s;

    printf("sizeof(int) = %zu\n", sizeof(int));        // 4
    printf("sizeof a = %zu\n", sizeof a);              // 4（不加括号针对表达式）
    printf("sizeof arr = %zu\n", sizeof arr);          // 80（数组名在 sizeof 不退化）
    printf("sizeof s = %zu\n", sizeof s);              // 8（含填充对齐）

    printf("_Alignof(int) = %zu\n", _Alignof(int));    // 4
    printf("alignof(double) = %zu\n", alignof(double)); // 8 (C23 alignof 关键字)

    // 编译期常量，可用于数组长度、结构体填充计算
    int buf[sizeof(double) * 2];  // 合法：sizeof 结果是编译期常量
    return 0;
}
```

> 🎯 **关键点**：
> - `sizeof` 结果类型是 `size_t`（无符号），打印用 `%zu`
> - `sizeof` **不求值**表达式：`sizeof(i++)` 不会让 `i` 自增
> - 数组名在 `sizeof`、`_Alignof`、`&` 三种情况下**不退化**为指针

## 3. 整型的二进制表示：补码

### 3.1 原码、反码、补码（8 位示例）

| 十进制 | 原码 | 反码 | 补码 (现代 CPU 通用) |
|--------|------|------|---------------------|
| +5     | 0 0000101 | 0 0000101 | 0 0000101 |
| -5     | 1 0000101 | 1 1111010 | **1 1111011** |

**补码规则**：正数补码=原码；负数补码=反码+1（或：符号位不变，数值位按位取反+1）

### 3.2 补码的优势

1. **符号位参与运算**：加减法统一用加法器，无需单独处理符号
2. **零的表示唯一**：`00000000`（原码/反码有 `+0` 和 `-0`）
3. **范围对称偏一**：-128 ~ 127（多一个负数 `-128`，补码 `10000000`）

### 3.3 溢出行为

```c
#include <stdio.h>
#include <limits.h>

int main(void) {
    signed char c = 127;   // 01111111
    c = c + 1;             // 有符号溢出：未定义行为 (UB)！
    printf("%d\n", c);     // 可能打印 -128，也可能崩溃，优化器可假设不发生

    unsigned char uc = 255; // 11111111
    uc = uc + 1;            // 无符号溢出：定义为模 2^n 环绕
    printf("%u\n", uc);     // 保证打印 0

    // 安全检测有符号溢出
    int a = INT_MAX, b = 1;
    if (b > 0 && a > INT_MAX - b) { /* 溢出 */ }
    return 0;
}
```

> ⚠️ **铁律**：**有符号整型溢出 = UB（未定义行为）**，编译器可假设不发生并优化掉检查代码。**无符号溢出 = 定义良好的模运算**。

## 4. 整型提升与常见算术转换

### 4.1 整型提升

**规则**：`int` 之窄的整型（`char`、`short`、`_Bool`、位域、枚举）**提升为 `int`**；若 `int` 容不下则提升为 `unsigned int`。

```c
char c1 = 200;  // 假设 char 有符号，200 溢出实现定义
char c2 = 100;
auto result = c1 + c2;  // 两个 char 先提升为 int 再相加
// result 类型是 int，值 = 300（若 char 无符号则不同）

// 位运算也触发提升
unsigned char uc = 0xFF;
auto r = ~uc;  // uc 提升为 int (0x000000FF)，~ 结果 0xFFFFFF00 (int)
// 若赋给 unsigned char：截断为 0x00
```

### 4.2 常见算术转换（两操作数统一类型）

**等级从高到低**：`long double` > `double` > `float` > `unsigned long long` > `long long` > `unsigned long` > `long` > `unsigned int` > `int` > `unsigned short` > `short` > `char`

**算法**：
1. 若有浮点 → 另一方转浮点（按精度升级）
2. 否则整型提升后，按等级转：低等级 → 高等级
3. 同等级：有符号 vs 无符号 → 转无符号（易错！）

```c
int a = -1;
unsigned int b = 1;
printf("%d\n", a > b);  // 输出 0 (假)！-1 转无符号变 4294967295
```

> 🎯 **避坑指南**：
> - **尽量不用无符号类型**表示数量（除非位运算/模运算需要）
> - 混合有符号/无符号比较前，**显式转型**：`(int)b` 或 `(unsigned)a`
> - 循环下标用 `size_t`（无符号），比较时注意 `i >= 0` 永真

## 5. 浮点型细节

```c
#include <stdio.h>
#include <float.h>

int main(void) {
    float f = 3.14f;       // f 后缀指定 float，无后缀默认 double
    double d = 3.14;
    long double ld = 3.14L;

    // 精度对比
    printf("FLT_DIG = %d\n", FLT_DIG);   // 6 位十进制有效数字
    printf("DBL_DIG = %d\n", DBL_DIG);   // 15
    printf("LDBL_DIG = %d\n", LDBL_DIG); // 18+

    // 特殊值
    float inf = 1.0f / 0.0f;   // INF
    float nan = 0.0f / 0.0f;   // NaN
    printf("inf = %f, nan = %f\n", inf, nan);
    // 判断：isinf(), isnan(), isfinite() (math.h)

    // 浮点比较：永远不用 ==
    float x = 0.1f + 0.2f;
    // if (x == 0.3f) ❌
    // 正确：fabs(x - 0.3f) < 1e-6
    return 0;
}
```

> 💡 **浮点陷阱**：
> - `0.1` 无法精确用二进制表示 → 累加误差
> - `float` 只有 23 位尾数（约 7 位十进制），大数吃小数：`1e8f + 1.0f == 1e8f`
> - 金融/精确计算**禁用浮点**，用定点数/整数分存整数/小数部分

## 6. 常量定义三种方式

### 6.1 字面量字面常量

```c
42          // int
42u         // unsigned int
42l / 42L   // long
42ll        // long long
3.14        // double
3.14f       // float
3.14L       // long double
'c'         // int (字符常量，C 语言中字符常量类型是 int)
"hello"     // char[6] (字符串字面量，静态存储，只读)
```

### 6.2 宏常量（预处理文本替换，无类型安全）

```c
#define PI 3.14159265358979323846
#define MAX_SIZE 1024
#define GREETING "Hello"  // 字符串字面量

// 缺点：无作用域、无类型、调试器看不见、宏展开副作用
#define SQUARE(x) ((x)*(x))  // 危险：SQUARE(i++) 展开为 ((i++)*(i++))
```

### 6.3 `const` 修饰的变量（有类型、有作用域、可调试、只读）

```c
const double PI = 3.14159265358979323846;  // 编译期常量（可用于数组长度 C99 VLA 除外）
const int MAX_SIZE = 1024;

const int *p1;       // 指向 const int 的指针：数据只读，指针可改
int *const p2 = &x;  // const 指针：指针只读，数据可改
const int *const p3 = &x; // 双重只读
```

### 6.4 枚举常量（编译期整型常量，有类型、可调试、作用域）

```c
enum Color { RED, GREEN, BLUE };  // 枚举常量类型兼容 int
enum { MAX_ITEMS = 100 };         // 匿名枚举常用于编译期常量

// C23: enum 可指定底层类型
enum Status : uint8_t { OK = 0, ERR = 1 };
```

| 方式 | 类型安全 | 作用域 | 调试可见 | 编译期常量 | 推荐场景 |
|------|---------|--------|---------|-----------|---------|
| `#define` | ❌ | 文件级 | ❌ | ✅ | 条件编译、字符串拼接 |
| `const` | ✅ | 块/文件 | ✅ | ✅ (大多) | 只读变量、参数、数组长度 |
| `enum` | ✅ (整型) | 枚举域 | ✅ | ✅ | 状态码、选项集合、编译期整数 |

> 🎯 **最佳实践**：
> - 编译期整数常量 → `enum` 或 `constexpr` (C23)
> - 只读变量/参数 → `const`
> - 字符串/复杂表达式/条件编译 → `#define`

## 7. 命名规范（Google / Linux Kernel 风格二选一）

| 实体 | 推荐风格 | 示例 |
|------|---------|------|
| 宏常量 / 枚举常量 | `UPPER_SNAKE_CASE` | `MAX_BUFFER_SIZE`, `ERR_TIMEOUT` |
| `const` 全局/静态变量 | `kPascalCase` 或 `UPPER_SNAKE_CASE` | `kDefaultPort`, `DEFAULT_PORT` |
| 局部变量 / 参数 | `snake_case` | `user_count`, `buffer_size` |
| 函数名 | `snake_case` | `calculate_sum`, `init_module` |
| 结构体/联合体/枚举类型名 | `PascalCase` 或 `_t` 后缀 | `UserInfo`, `user_info_t` |
| 结构体成员 | `snake_case` | `user_id`, `name` |
| 类型定义 | `_t` 后缀 | `uint32_t`, `size_t` |

> 💡 **一致性 > 完美**。项目统一风格，配合 `clang-format` 自动格式化。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 基本类型 | 用 `<stdint.h>` 固定宽度类型（`int32_t` 等）跨平台 |
| `sizeof` | 编译期常量、不求值表达式、结果类型 `size_t` |
| 补码 | 有符号溢出 UB，无符号溢出模环绕 |
| 整型提升 | 窄类型→`int` 再运算 |
| 算术转换 | 低等级向高等级，**有符号遇无符号转无符号** |
| 浮点 | 别用 `==` 比较，金融禁用 |
| 常量定义 | 优先 `const`/`enum`，条件编译用 `#define` |
| 命名 | 统一风格，配合 `clang-format` |

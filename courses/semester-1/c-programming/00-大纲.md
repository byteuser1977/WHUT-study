# C 语言程序设计 学习笔记（大一上学期）

> 对标主流教材（谭浩强《C程序设计》、郑人《C语言程序设计》、苏小红《C语言程序设计》）—— 从"Hello World"到"能独立写出带数组、函数、指针、结构体、文件操作的完整程序"。
> 共 **12 讲**，每讲约 10 分钟（正文 5 分钟 + 练习 5 分钟），总计约 2 小时。

---

## 一、这份笔记解决什么问题

C 语言是计算机专业的**基石课**，考试重点、后续课程（数据结构、操作系统、嵌入式）的语言基础。

| 能力维度 | 练的是什么 | 靠什么提升 |
|---------|-----------|-----------|
| **语法与语义** | 数据类型、运算符、流程控制、数组、函数、指针、结构体、文件 | 大量写代码、画内存图、手算表达式 |
| **程序设计思维** | 问题分解、模块化（函数）、数据组织（数组/结构体）、算法实现 | 课后习题、上机实验、期末大作业 |

> ⚠️ **核心原则**：C 语言**不练手学不会**。每讲必须敲代码、跑程序、改参数看现象。光看不敲 = 没学。

---

## 二、学习路线图

按 **入门 → 基础语法 → 核心难点（数组/函数/指针） → 高级类型与文件 → 综合实战** 五步走：

```
第 01 讲：C 语言概述与第一个程序     ← 理解程序结构、main函数、编译运行基本流程
    ↓
第 02~03 讲：数据类型、运算符与表达式  ← 变量/常量、整型实型字符型、各类运算符、类型转换（考试大头）
    ↓
第 04 讲：顺序结构程序设计            ← 格式化输入输出、赋值语句
    ↓
第 05~06 讲：选择与循环结构           ← if/switch、for/while/do-while、break/continue、嵌套循环（考试必考）
    ↓
第 07 讲：数组                        ← 一维/二维数组、字符数组与字符串、字符串处理函数
    ↓
第 08 讲：函数                        ← 定义/声明/调用、参数传递、递归、作用域、存储类别、内部/外部函数
    ↓
第 09 讲：预处理命令                  ← 宏定义（带参/不带参）、文件包含、条件编译
    ↓
第 10 讲：指针                        ← 指针变量、指针与数组/字符串/函数、指针数组、多级指针、main参数（★最难、★最高频）
    ↓
第 11 讲：结构体、共用体、枚举         ← 结构体定义/引用、结构体数组/指针、链表雏形、共用体、枚举
    ↓
第 12 讲：文件操作与综合实战           ← 文件指针、打开关闭、读写函数、定位、文本/二进制、期末项目雏形
```

> 如果只剩三天：**第 01~03（基础）→ 第 05~06（流程控制）→ 第 07/08/10（数组/函数/指针）→ 第 12（文件/实战）**。这覆盖了 90% 考点。

## 五、环境准备（三选一，教材通用）

> 教材通常以 **Visual Studio / Dev-C++ / Code::Blocks** 为例。本笔记推荐现代轻量环境，**不影响考试**，但体验更好。

### 方案 A：Windows + VS Code + MinGW（推荐，轻量、免费、标准）

1. 下载 **MinGW-w64**：https://github.com/niXman/mingw-builds-binaries/releases → 解压到 `C:\mingw64` → 加入 PATH
2. 装 **VS Code** + 插件：C/C++ (Microsoft)、Code Runner
3. 验证：终端 `gcc --version`、`gdb --version`

### 方案 B：Visual Studio 2022 Community（教材常用、调试强、安装大）

- 安装时勾选 **"使用 C++ 的桌面开发"**
- 新建项目 → "空项目" → 添加 `.c` 文件 → `Ctrl+F5` 运行

### 方案 C：Dev-C++ 5.11 / Code::Blocks 20.03（教材配套、轻量、老牌）

- Dev-C++：https://sourceforge.net/projects/orwelldevcpp/
- Code::Blocks：http://www.codeblocks.org/downloads/binaries/ (选 mingw-setup 版)

> ⚠️ **避坑**：**VC++ 6.0 (1998)** 太老不支持 C99（如 `//` 注释、for 循环变量声明、`long long`），**不要用**。

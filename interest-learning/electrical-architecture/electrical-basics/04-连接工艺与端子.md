## 1. 端子是什么

**端子（Terminal）是导线与连接器（或螺栓）之间的过渡件**，负责把电流从线芯稳稳交给另一侧。

| 类型 | 形状特征 | 典型场景 |
|---|---|---|
| 插片端子（Spade） | 一公一母的扁平铜片，宽 2.8 / 4.8 / 6.3 mm | 继电器座、保险丝盒 |
| 环形端子（Ring） | 带圆孔的铜环，孔径与螺栓匹配 | 搭铁点、电池桩头 |
| 子弹头端子（Bullet） | 圆头插柱，用于单线对接 | 灯组、独立负载 |
| 多针护套端子 | 装进塑料护套里的方端子 | ECU、传感器连接器 |

一段合格的端子分三个区：**压接区**（吃住线芯）、**绝缘支撑区**（抱住绝缘皮、抗振）、**接触区**（与对端贴合导电）。

## 2. 压接工艺

**压接（Crimping）**不是「把铜夹住」，而是在极高压强下让铜塑性流动——线芯与端子壁互相嵌入，界面形成**冷焊**式的气密金属连接。

- 剥线长度 ≈ 压接区长度加 1 mm；**线芯一根都不许剪断**，绝缘皮不能伸进压接区。
- 用**与线径同规格的模具**压接，别拿通用钳子凑合；闭口筒端子一般压六角或四点。
- 压完轻拉导线：端子不松、不转、线芯不缩才算过。

| 检查项 | 合格 | 不合格 |
|---|---|---|
| 剖面 | 线芯紧密成团、空隙少 | 松散、有明显空洞 |
| 拉脱力 | 达到该线径要求，拉不断 | 一拉就脱 |
| 绝缘皮 | 剥口整齐、无损伤 | 切伤线芯、断股 |
| 模具匹配 | 与线径同规格 | 用大模压细线 |

| 方式 | 长处 | 短板 |
|---|---|---|
| 压接 | 一致性高、气密、抗振 | 需要对应压接钳与模具 |
| 焊接 | 工具简单、导通好 | 应力集中、易虚焊、助焊剂残留 |
| 螺钉端子 | 可反复拆装 | 容易松动，必须给力矩 |

> 💡 类比：压接像**把两团橡皮泥用力压成一块**，界面已经没有缝；焊接像**用胶水把两块贴住**，胶层本身就是弱点。振动场合，前者的寿命长得多。

> ⚠️ 别「先上锡再压接」：焊锡会蠕变，压接区被填硬后应力集中，抗振反而更差，是虚接的常见来源。

## 3. 连接器装配要点

- **防呆键位（Keying）**：插错就插不进，别硬怼。
- **二次锁（TPA，Terminal Position Assurance，端子定位保持件）**：端子到位后压上它，防止振动中退针。
- 密封连接器要保留**密封圈**，空孔位插**盲堵（Cavity Plug）**；防水等级 IP（Ingress Protection，防护等级）常见 IP67，可短时浸水。
- 插拔时抓**护套本体**，不许拽导线。

5. 导出前逐个孔位核对：都有对端，没有空挂线头。

## 🎯 动手练习（约4分钟）

1. 找一段废线和一个备用端子，剥出正确的长度（压接区加 1 mm）。
2. 用对应模具压接一次，压完对着光看压接筒有没有变形均匀。
3. 轻拉导线，感受它是否稳固；再用小刀剖开压接筒看剖面。
4. 把剖面前的状态填进第 2 节的检查表，逐项打勾。
5. 用一个密封护套，把空孔位插上盲堵，再插拔一次感受防呆键位。

**✅ 你应该看到**：合格压接的剖面里线芯挤成一整块、看不到空隙；空孔位插上盲堵后，护套的密封面是平的，不会留一个能进水的小洞。

## 本讲小结

| 要点 | 说明 |
|---|---|
| 端子分类 | 插片 / 环形 / 子弹头 / 多针护套，按场景与线径挑 |
| 三个功能区 | 压接区吃线芯，绝缘支撑区抗振，接触区导电 |
| 压接原理 | 高压下铜冷焊成一体，气密又抗振，优于焊接 |
| 合格判据 | 剖面紧密、拉脱力够、线芯无损伤、模具与线径匹配 |
| 连接器细节 | 防呆键位、二次锁 TPA、密封圈与空孔盲堵 |
| 常见错误 | 先上锡再压接、拽线插拔、用大模压细线 |

# 第03讲：配电与线束部件（正文约6分钟 + 练习约4分钟）

- 布线时最容易踩的两个坑

## 1. 保护器件：保险丝是第一道防线

**保险丝（Fuse）**里是一条金属熔体，电流过大时发热熔断，把支路彻底切断。看四个参数：**额定电流**、熔断特性（快熔还是慢熔）、**分断能力**、热容量（I²t，电流平方对时间的积分，值越大越能扛短时浪涌）。

选型口诀：**保险丝额定电流按支路总电流选，约取稳态电流的 1.5~2 倍**（给电机启动浪涌留空间），并且**必须小于等于导线的允许载流量**。原因是——**保险丝保护的是导线，不是负载**：只要导线不会先烧，剩下的保护交给负载自己。

> ⚠️ 保险丝必须装在**离电源最近的那一端**。如果反过来装在负载前、而线先绕了大半个车，那段线短路时不受保护，先烧的是线——这就是车队最常见的火灾隐患。

> 💡 类比：保险丝像**总闸下面的分路空开**——它守的是那一段电线，而不是插在末端的电器；线束像**装修时预埋的管线**，规格、走向、标识要在封墙前一次定好，返工的代价极大。

## 2. 线束部件

**线束（Harness）**是把多根导线按路径捆扎固定好的总成，装车时整把插上，比一根根散线快得多也更可靠。

| 部件 | 作用 | 要点 |
|---|---|---|
| 导线 | 导电 | 看**截面积 mm²**（不是口语的「多少平方」），颜色区分回路 |
| 连接器 | 可插拔接口 | 有防呆键位与锁扣，插到位才咔一声 |
| 波纹管 / 编织网 | 防磨防割 | 与热源、旋转件保持距离 |
| 过孔护套 | 穿过金属孔 | 防止钣金口割破绝缘层 |
| 扎带 / 卡扣 | 固定 | 每 150~200 mm 固定一点，留伸缩余量 |
| 分支点 | 一分多 | 压接或焊接后热缩，不许绞接缠胶布 |

导线载流量随敷设方式与环境温度变化，工程估算可参考：

| 截面积 | 约略载流 | 典型用途 |
|---|---|---|
| 0.5 mm² | 5 ~ 8 A | 传感器信号、指示灯 |
| 1.0 mm² | 10 ~ 13 A | 低压负载、继电器线圈 |
| 2.5 mm² | 20 ~ 25 A | 灯组主回路、小功率电机 |
| 6.0 mm² | 40 ~ 50 A | 主电源、启动回路 |

## 3. 接线表与文字电路图

一组「开关控制继电器、继电器点亮灯组」的完整接线表：

| 起点（端子） | 终点（端子） | 线径 | 颜色建议 |
|---|---|---|---|
| 蓄电池 (+) | 主保险丝盒 | 6.0 mm² | 红 |
| 主保险丝盒 | 继电器 30 | 2.5 mm² | 红 |
| 继电器 87 | 灯组 (+) | 1.0 mm² | 黄 |
| 电源开关 | 继电器 85 | 0.5 mm² | 橙 |
| 继电器 86 | 搭铁点 G1 | 0.5 mm² | 黑 |
| 灯组 (－) | 搭铁点 G1 | 1.0 mm² | 黑 |

```
电池(+) → 主保险丝 → 继电器 30 ─ 87 → 灯组 → 搭铁 G1 → 电池(－)
电源开关 → 继电器 85 ─ 86 → 搭铁 G1
```

画进 Visio 的编号步骤（元件库与菜单名称**以你机器上为准**）：

1. 新建电气类模板（如「电气工程」或 Basic Electrical），选空白页。
2. 从左侧元件库拖出所需符号：电源（一长一短线对）、保险丝（矩形中一条折线）、开关（斜线断口）、继电器线圈（矩形标 K）、触点、搭铁（几条长度递减的横线）。
3. 先摆主回路：电源 → 保险丝 → 触点 30，触点 87 → 灯组 → 搭铁，用直角连接线。
4. 再摆控制回路：开关 → 线圈 85/86 → 搭铁，与主回路**分开画**。
5. 双击每条线标注端子号（30/87/85/86）与线径颜色。
6. 自检：每条回路都能一路走到搭铁，没有悬空线头。

## 🎯 动手练习（约4分钟）

1. 挑一条车上支路，量出导线外径并判断截面积。
2. 查它的保险丝安培数，算一算是否落在稳态电流的 1.5~2 倍区间。
3. 用上表核对该截面积的载流量，确认保险丝比导线先熔断。
4. 按第 3 节的表格格式，给这条支路写一份 6 行内的接线表。
5. 把它的电路用箭头链写成一行文字电路图。

**✅ 你应该看到**：你的接线表里每一行都能回答「从哪来、到哪去、多粗、什么颜色」，箭头链从电源出发、最后一定回到搭铁。

## 本讲小结

| 要点 | 说明 |
|---|---|
| 保险丝保护对象 | 保护的是**导线**；额定电流约为稳态电流 1.5~2 倍，且 ≤ 导线载流量 |
| 保险丝位置 | 装在离电源最近的一端，否则线先烧 |
| 线束部件 | 导线、连接器、护套、过孔护套、扎带、分支点，各司其职 |
| 导线规格 | 看截面积 mm²；0.5 / 1.0 / 2.5 / 6.0 是常用档 |
| 接线表 | 起点、终点、线径、颜色四列缺一不可 |
| 文字电路图 | 电池(+) → 保险丝 → 继电器 → 负载 → 搭铁 → 电池(－) |

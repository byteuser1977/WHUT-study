# 第05讲：用 TSMaster 模拟 VCU 发报文（正文约6分钟 + 练习约4分钟）

## 你将学到
- TSMaster 能替车上的哪个角色
- 硬件怎么接上总线，通道与波特率怎么配
- 手动发一帧、周期发一帧的完整操作
- 用 DBC 按物理值发送，比手填十六进制省事在哪

---

## 1. TSMaster 能扮演谁

**TSMaster**（同星智能）是一款 CAN / CAN FD 总线分析、标定与仿真工具，能做三件事：**听**（监控总线上的报文并解析）、**说**（按设定的内容与周期发送报文）、**演**（残余总线仿真——把真车上缺席的节点在软件里补上）。我们要做的是第三件：让 TSMaster **扮演 VCU（Vehicle Control Unit，整车控制器）**，在没有真实 VCU 的台架上把车"喂"起来。

台架接线参考：

| 端子 | 线色建议 | 说明 |
|---|---|---|
| 硬件 CAN_H → 干线 CAN_H | 黄 | 与其余节点并接 |
| 硬件 CAN_L → 干线 CAN_L | 绿 | 与其余节点并接 |
| 硬件 GND → 搭铁 | 黑 | 让参考地一致 |
| 硬件内置终端电阻 | — | **仅在总线缺一端终端电阻时才打开** |

```
[TSMaster 硬件]──CAN_H(黄)──┬──[BMS]
        │                    │
        └──CAN_L(绿)─────────┼──[EPS]
                             └──[EHB]
      （BMS / EPS / EHB = 电池管理 / 电动助力转向 / 电液制动控制器）
      （干线物理两端各接一个 120 Ω 终端电阻）
```

## 2. 接上硬件、配好通道（界面以你机器上为准）

1. 硬件 USB 插入电脑，在 TSMaster 里选择对应硬件型号与通道编号。
2. 设置波特率，必须与总线上其他节点一致（我们整车与动力那一路用 500 kbit/s）。
3. 点"启动 / 连接"，看状态栏是否显示已连接、有无错误帧。
4. 决定内置终端电阻开关：台架线束两端已经有 120 Ω 时必须**关掉**，否则三个 120 Ω 并联变成 40 Ω，压差被拉低、通信反而不稳。

## 3. 手动发一帧

新建一个发送报文：ID 填 0x180（标准帧），DLC 填 8，数据场填 8 个字节的十六进制，点发送。总线上其他节点会正常收到这一帧——因为对它们来说，这帧和真 VCU 发的没有区别。注意**同一个 ID 全网上只能有一个发送者**：如果真 VCU 也在线并且也发 0x180，两者会互相干扰，出现错误帧乃至仲裁冲突。

## 4. 让它像真 VCU 一样周期发

手动点一次只发一帧，而真 VCU 的报文是**周期性**的。把该报文的发送方式设成"周期"、周期填 10 ms，再启动发送，TSMaster 就会每 10 ms 自动补发一帧。做完这一步，台架上的 BMS、EPS 等节点就会认为 VCU 一直在正常工作。

## 5. 用 DBC 按物理值发

手填十六进制容易把因子和偏移算错。把 DBC 加载进 TSMaster 后，发送界面会直接列出这一帧里的**信号**与单位，你填"车速 = 30 km/h"，软件自己折算成原始值写进数据场。这既省事，也顺便验证了你的 DBC 与对方节点是否一致。

> 💡 类比：TSMaster 在这里像剧组的**替身演员**——主角（真 VCU）不在场，替身穿上同样的衣服、按同样的台词和节奏出场，对手戏演员（BMS、EPS）照样能把戏演下去。

> ⚠️ 波特率不一致是最常见的"完全不通"原因（一方 500 k、一方 250 k 时几乎全是错误帧）；CAN_H / CAN_L 接反同样不通，而且不会烧设备，很容易被误判成软件配置问题。

## 🎯 动手练习

1. 新建工程，选择硬件与通道，波特率设为 500 kbit/s，连接。
2. 添加一帧报文：ID 0x180、DLC 8、数据随便填 8 个字节，先手动发一次。
3. 在报文窗口确认能看到自己发出的这帧，发送计数为 1。
4. 把发送方式改成周期 10 ms，启动，观察计数增长速度。
5. 加载 DBC，改用"按信号发送"，把车速改成 30 km/h。
6. 打开数据场的十六进制显示，对照因子与偏移核对写入值。

> ✅ 你应该看到：周期发送后计数约每秒增加 100；报文窗口里这一帧的周期很稳定（抖动通常远小于 1 ms）；改用物理值发送后，数据场里的十六进制**自动变化**，且与你按因子手算的结果一致。

## 本讲小结

| 要点 | 说明 |
|---|---|
| TSMaster 三个角色 | 监控（听）、发送（说）、残余总线仿真（演） |
| 硬件连接 | CAN_H / CAN_L 并接到干线，参考地与车共搭铁 |
| 内置终端电阻 | 总线两端已有 120 Ω 时关掉，避免三并联成 40 Ω |
| 周期发送 | 发送方式设为周期，替 VCU 维持周期性报文 |
| DBC 发送 | 填物理值由软件折算，避免因子偏移算错 |
| 唯一发送者 | 同一 ID 全网只能有一个发送节点，否则互相干扰 |

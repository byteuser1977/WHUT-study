# 第01讲：CAN 总线的基本结构（正文约6分钟 + 练习约4分钟）

## 你将学到
- 车上为什么非要用"总线"，而不是一根根拉线
- CAN 总线的拓扑长什么样：干线、支线、节点怎么接
- CAN_H / CAN_L 两根线为什么必须绞在一起
- 终端电阻装几个、装在哪，万用表怎么验

---

## 1. 从"一功能一线"到"大家共用一对线"

早期车上每个功能都单独拉线：开关到灯、传感器到控制器，两头直连。功能一多线束就爆炸——N 个节点两两直连需要 N(N−1)/2 根线，十几个节点就是上百根，重量、成本、故障率全上去了。

**CAN（Controller Area Network，控制器局域网）** 的做法是：所有节点**共用一对线**，谁想说话谁往这对线上"广播"，其余节点都听。线束从"每对一捆"变成"一条干线"，这就是总线（Bus）这个名字的由来。

## 2. 总线型拓扑：一条干线，节点挂在支线上

| 部件 | 作用 | 规范要求 |
|---|---|---|
| 干线（Bus Line） | 所有节点共用的那对双绞线 | 一根到底，尽量不带分叉 |
| 支线（Stub） | 节点接到干线的那一小段 | 越短越好，量级 0.3 m 以内 |
| 节点（Node） | 控制器加一颗 CAN 收发器 | 收发器差分输入接 CAN_H / CAN_L |
| 终端电阻 | 两端各一个 120 Ω | **只能在两端，合计 60 Ω** |

节点不是串在干线上的"过路客栈"，而是**并联挂接**：任何一个节点故障或被拔掉，其余节点照常通信。这和"串联灯串断一个全灭"完全不同。

接线参考（以我们台架为例）：

| 端子 | 线色建议 | 说明 |
|---|---|---|
| 干线 CAN_H | 黄 | 所有节点 CAN_H 并接 |
| 干线 CAN_L | 绿 | 所有节点 CAN_L 并接 |
| 线束屏蔽层 | — | 单端接地，避免地环流 |
| 节点供电 | 红 / 黑（搭铁） | 就近搭铁，不走线束回电池 |

文字电路图（节点一律并联）：

```text
   CAN_H（黄） ──┬─────────┬─────────┬─────────┬──
   CAN_L（绿） ──┼─────────┼─────────┼─────────┼──  ← 干线两端各 120 Ω
              [VCU]     [BMS]      [EPS]     [EHB]
                └── 各节点经短支线并接，不是串联 ──┘
```

> 💡 类比：点对点布线像**每家都往别家拉一条专线电话**，人一多就织成毛线球；CAN 总线像**教室里的公共广播**——一根线挂在墙上，谁开口全屋都听得见，听的人自己挑要不要理会。

## 3. 为什么是绞在一起的那两根线

CAN 用**差分传输**：CAN_H 与 CAN_L 两根线电压反向变化，接收器只看两者之差（第 02 讲展开）。把两根线**双绞（Twisted Pair，双绞线）** 是为了让外界电磁干扰同时耦合到两根线上，两根线受到的影响一致，相减就抵消掉了。绞距越均匀，抗扰越稳。

> ⚠️ 别把两根线分开走：分开走线长度不同，耦合到的干扰也不同，差分的优势直接损失掉。CAN_H / CAN_L 必须**成对绞合**，也不要和电机动力线长距离并行。

## 4. 我们车上的 CAN 网络

我们车上的节点分几类挂接：**域控制器 / VCU（Vehicle Control Unit，整车控制器）**、**BMS（Battery Management System，电池管理系统）**、**EPS（Electric Power Steering，电动助力转向）**、**EHB（Electro-Hydraulic Brake，电液制动）**、电机控制器、遥控接收机。整车与动力控制这一路通常跑 500 kbit/s，传感器与仪表一类用 250 kbit/s；激光雷达、视觉这类大带宽数据走车载以太网，惯导、遥控、调试走串口——CAN 不是万能的，它擅长的是**小数据量、高可靠、周期性**的报文（EPS / EHB 的严格定义见 [线控转向与线控制动](../../electronic-control/chassis-control/01-线控转向与线控制动.md)）。

> ⚠️ 同一路 CAN 上所有节点**必须统一波特率**（500 k 与 250 k 混接＝整条总线全是错误帧）；终端电阻只装在**物理两端**，不是每个节点都装。

## 🎯 动手练习

1. 车辆断电，断开电池负极。
2. 万用表打到 200 Ω 电阻档，红黑表笔分别接诊断口（OBD-II，On-Board Diagnostics 车载诊断接口）的 CAN_H（6 脚）与 CAN_L（14 脚）；没有诊断口就直接接某一端节点的 CAN_H / CAN_L 引脚。
3. 读数记录。
4. 拔掉中间某个节点的插头，再测一次。
5. 拔掉一端节点的插头，再测一次。

> ✅ 你应该看到：三次读数分别约为 **60 Ω、60 Ω、120 Ω**。60 Ω 说明两端各有一个 120 Ω 在并联；拔掉中间节点不影响读数；拔掉一端只剩一个，读数翻倍。

## 本讲小结

| 要点 | 说明 |
|---|---|
| 总线拓扑 | 所有节点并联挂在一条干线上，共用一对双绞线 |
| 支线 | 节点到干线的那一段，越短越好 |
| 双绞线 | CAN_H / CAN_L 绞合，使共模干扰互相抵消 |
| 终端电阻 | 干线**两端**各 120 Ω，合计 60 Ω |
| 节点独立性 | 单个节点掉线不影响其余节点通信 |
| 波特率 | 同一路 CAN 所有节点必须一致 |

# 电气架构组速查表

> 全组知识骨架，配合 `00-大纲.md` 与各模块讲稿使用。查表用，不是从头读到尾。

## 一、整车电气系统速查

| 项目 | 要点 |
|---|---|
| 电源 | 巴哈赛车 12 V 系统；蓄电池供电，发动机车型另有发电机，电车为动力电池经 DC-DC 降压 |
| 搭铁回路 | 负极就近接车身/车架金属，靠车架当回路导体；**不是每根线都拉回电池负极** |
| 用电器分类 | 常电（如 ECU 记忆）、ACC、大电流执行器（电机/泵）、信号类（传感器） |
| 为什么分回路 | 故障隔离：一路短路只烧自己的保险丝，不拖垮整车 |
| 线径选择依据 | 按**载流量 + 允许压降**双条件算，取二者中较大的线径 |
| 压降经验 | 12 V 系统单线压降一般控制在 **0.5 V 以内**（约 4%），否则灯暗、继电器吸不上 |

## 二、继电器速查

| 项目 | 要点 |
|---|---|
| 本质 | 用小电流线圈控制大电流触点，同时实现控制回路与负载回路的电气隔离 |
| 引脚 | `30` 公共端 ｜ `85`/`86` 线圈两端 ｜ `87` 常开触点 NO ｜ `87a` 常闭触点 NC |
| 常开 NO | 线圈**不通电时断开**，通电时闭合 |
| 常闭 NC | 线圈**不通电时闭合**，通电时断开 |
| 主触点 vs 辅助触点 | 主触点载流量大（走负载电流）；辅助触点载流量小（走信号/小电流），同一继电器可同时有 |
| 续流二极管 | 线圈两端**反向并联**二极管，吸收断电瞬间的反向电动势，保护驱动管 |
| 选型三看 | ①线圈电压（12 V）②触点额定电流 ≥ 负载电流 ×1.5~2 ③触点形式（NO/NC/转换） |
| 典型故障 | 触点氧化导致接触电阻大 → 负载"带不动"；线圈续流二极管漏装 → 驱动管击穿 |

## 三、线束部件速查

| 部件 | 原理与作用 |
|---|---|
| **汇流排** | 一条粗导体（铜排/铜条），把电源正极分给多条支路；承载总电流、替代大量重复接线、降低压降 |
| **分线器** | 把一根主线分成多路同电位支路（一进多出）；用于信号/小电流分配，比汇流排轻便 |
| **继电器** | 见上表；小电流控大电流 + 隔离 |
| **保险丝** | 串联在支路里，过流时熔断切断该支路；按支路额定电流选（约为 1.5~2 倍） |
| **焊锡环** | 热缩管内置锡环，加热后锡熔化的同时热缩管收缩封装；**接线端子处的可加热焊接+绝缘+防水三合一** |
| **铜鼻子** | 又称冷压端子/线鼻；套在导线端头压接后，用螺栓接到端子排/螺栓上，提供可靠大电流接触面 |
| **压接 vs 焊接** | 压接：机械形变接触，抗振、防虚焊，车用首选；焊接：接触电阻低但脆、怕振动疲劳。**车用优先压接** |
| **线号标识** | 每根线两端套号码管，标明回路号；装配与排故靠它 |

## 四、CAN 总线速查

| 项目 | 要点 |
|---|---|
| 拓扑 | 线型（总线型）主干 + 支线；多主结构，无主从 |
| 物理层 | 双绞线 CAN_H / CAN_L，**总线两端各一个 120 Ω 终端电阻**（合计 60 Ω） |
| 通信方式 | 广播式：所有节点都能收到，靠 ID 判断是否与自己相关 |
| 速率 | 经典 CAN 最高 1 Mbps；CAN FD 数据段可到 2~8 Mbps |
| 仲裁 | CSMA/CR 非破坏性仲裁：**ID 数值越小优先级越高**；显性位覆盖隐性位，谁发显性谁赢，输的节点自动退让且不损坏数据 |
| 帧类型 | 数据帧、远程帧、错误帧、过载帧 |
| 错误处理 | 每个节点有发送/接收错误计数器；超限进入"错误被动"，再超限"总线关闭"（Bus-Off） |
| ACK | 任一正确接收的节点在 ACK 位发显性，发送节点据此确认有人收到 |
| 总线负载 | 一般设计控制在 **50% 以下**，过高会导致延迟抖动与丢帧 |

### 差分信号电平（★最容易讲错）

| 位 | CAN_H | CAN_L | 压差 V_diff | 逻辑 |
|---|---|---|---|---|
| 显性 dominant | ≈ 3.5 V | ≈ 1.5 V | ≈ 2 V | 0 |
| 隐性 recessive | ≈ 2.5 V | ≈ 2.5 V | ≈ 0 V | 1 |

- 接收器判定的是 **V_diff = V_CANH − V_CANL**，不是对地绝对电压
- 两根线**反向**变化：一根升、另一根降
- 共模干扰同时抬高/压低两根线 → **压差不变** → 判决不受影响（这就是抗干扰的根源）
- 显性覆盖隐性（0 强于 1）→ 仲裁与错误帧能抢占总线

## 五、报文与信号速查

| 概念 | 说明 |
|---|---|
| **报文 Message** | 总线上独立传输的完整数据单元（一帧），含 ID + 数据场 + CRC + ACK 等 |
| **信号 Signal** | 报文数据场中**一段有物理意义的位字段**，含起始位、长度、字节序、因子、偏移、单位、范围 |
| **包含关系** | 一个报文可承载**多个**信号（打包）；一个信号只属于**一个**报文 |
| **描述文件** | DBC：把信号的位定义与物理含义写下来，工具据此解析与发送 |
| **报文 ID** | 决定优先级（越小越高），并作为"这帧是谁的"依据 |
| **数据场长度** | 经典 CAN 0~8 字节；CAN FD 最多 64 字节 |
| **字节序** | Intel（小端，低字节在前）／Motorola（大端，高字节在前）—— DBC 里必须选对 |
| **物理值换算** | 物理值 = 原始值 × 因子 + 偏移（例：原始 500，因子 0.1，偏移 0 → 50.0 km/h） |

**类比**：报文像快递包裹（有单号 = ID、有大小 = DLC），信号像包裹里的货物（每件都有自己的标签、规格、单位）。一个包裹可装多件货物，一件货物只属于一个包裹。

### TSMaster 模拟 VCU 发报文 —— 操作链路

1. 连接硬件（CAN 分析仪/USB-CAN 盒），确认通道与波特率与整车一致
2. 导入 **DBC**（或手动定义报文与信号）
3. 在发送窗口新建报文：填 ID、DLC、数据、发送方式（周期/单次/事件触发）
4. 或用**信号编辑器**按物理值填参数，工具自动算出数据场各位
5. 开启周期发送 → 总线上其他节点收到并响应
6. 用总线记录/回放验证；确认无误后用于台架联调

> ⚠️ 台架仿真时波特率、终端电阻、ID 定义必须与实车一致，否则节点不响应且难排查。

## 六、整车通信网络速查

| 维度 | CAN | 车载以太网 (100BASE-T1/1000BASE-T1) | 串口 (UART/RS232/RS485) |
|---|---|---|---|
| 速率 | 1 Mbps（FD 更高） | 100 Mbps / 1 Gbps | 几十 kbps ~ 几 Mbps |
| 拓扑 | 总线型，多节点 | 点对点/交换式星型 | 点对点 |
| 距离 | 约 40 m@1Mbps | 约 15 m（T1 单对线） | 十几米（RS485 可达千米） |
| 成本/线束 | 低，两根线挂多个节点 | 高，线束与 PHY 贵 | 极低 |
| 适用 | 整车控制指令、状态量 | 图像、点云等大带宽数据 | 传感器原始输出、调试口 |

### 节点挂载参考（一种可辩护的方案）

| 部件 | 建议网络 | 理由 |
|---|---|---|
| 激光雷达 | 车载以太网 | 点云数据量大，CAN 带宽远不够 |
| 视觉传感器 | 车载以太网 / GMSL 同轴 | 图像帧带宽高 |
| 毫米波雷达 | CAN | 输出的是目标列表（距离/速度/角度），数据量小 |
| 惯性导航 | 串口（TTL/RS232）为主，状态量也可转 CAN | 高频姿态数据走串口；整车只需姿态摘要 |
| 遥控接收机 | 串口（SBUS/PPM）→ VCU，或 CAN 输出型 | 无线链路落地后转串口/CAN |
| 域控制器 | 以太网主干 + 一路 CAN | 决策层，需同时吃大带宽数据与整车状态 |
| VCU | CAN | 整车控制与调度 |
| EPS | CAN | 转向指令与状态 |
| EHB | CAN | 制动请求与状态 |
| BMS | CAN | 电池电压/温度/SOC/允许充放电功率 |
| 电机控制器 | CAN | 扭矩/转速指令与反馈 |

**画拓扑图的判断依据**（比记结论更重要）：数据量 → 带宽需求；控制闭环 → 实时性与确定性；线束长度与重量 → 物理层选择；失效影响 → 是否要冗余。

> ⚠️ 域控制器与 VCU 之间常需**同时**挂以太网与 CAN 两路，别只画一条。

## 七、电气原理图速查

### 7.1 供电回路（蜂鸣器 + 驱动系统指示灯）

```
+12V ──[保险丝 F1]──[开关 S1]──┬──[蜂鸣器 H1]──┐
                               └──[指示灯 L1]──┴── GND(搭铁)
```

- 两负载**并联**：各自独立工作、互不影响；一个坏了另一个照常
- 保险丝按**支路总电流**选；若两负载电流差异大，可各加独立保险丝
- 开关闭合 → 两个负载同时得电 → 均正常工作

| 序号 | 从 | 到 | 建议线径/颜色 |
|---|---|---|---|
| 1 | 电源 +12V | 保险丝 F1 进 | 2.5 mm²，红 |
| 2 | 保险丝 F1 出 | 开关 S1 进 | 1.5 mm²，红 |
| 3 | 开关 S1 出 | 蜂鸣器 H1(+) 与 指示灯 L1(+) 公共节点 | 1.5 mm²，红 |
| 4 | 蜂鸣器 H1(−) | 搭铁 | 1.5 mm²，黑 |
| 5 | 指示灯 L1(−) | 搭铁 | 1.5 mm²，黑 |

### 7.2 继电器逻辑回路（开关闭合→灯亮不响；开关断开→响）

**核心思路**：让开关去控制**继电器线圈**，两个负载分别接在**常闭主触点**与**常开辅助触点**上。

```
                    ┌───────────[ 常闭主触点 30→87a ]──[蜂鸣器 H1]──┐
+12V ─[F1]─┬────────┤                                              ├── GND
           │        └──[开关 S1]──[线圈 85/86]──┐                  │
           │        ┌──[常开辅助触点]──────────[指示灯 L1]──────────┘
           └────────┘
```

| 开关 S1 | 线圈 | 常闭主触点 (30-87a) | 常开辅助触点 | 指示灯 L1 | 蜂鸣器 H1 |
|---|---|---|---|---|---|
| **闭合** | 得电 | **断开** | **闭合** | **亮** ✓ | **不响** ✓ |
| **断开** | 失电 | **闭合** | **断开** | **灭** ✓ | **响** ✓ |

- 推论过程：开关控制线圈 → 线圈状态翻转两个触点 → 两个负载互为反相
- 这是一个典型的"**系统未使能警示**"逻辑：驱动系统没开（开关断开）时蜂鸣器报警；一开就静音并点亮指示灯
- 线圈两端**必须**并续流二极管（阴极接 +12 V 侧）

### 7.3 画图规范

| 项 | 规范 |
|---|---|
| 图纸分区 | 按功能分区（电源/控制/执行/通信），加图框与标题栏 |
| 元件编号 | 字母+序号：K 继电器、S 开关、F 保险丝、H 蜂鸣器、L 指示灯、M 电机 |
| 线号 | 每根线编号（如 X1-12），两端一致，便于排故 |
| 搭铁符号 | 统一用搭铁符号，不要每处都画回电池 |
| 交叉线 | 相连画实心点，不相连画跨线桥 |
| 通信图 | 总线画成主干线，节点用支线挂上去；CAN 两端标 **120 Ω** 终端电阻；区分实线（CAN）、双线（以太网）、虚线（串口） |

## 八、线控底盘电气速查

| 缩写 | 全称 | 电气视角要点 |
|---|---|---|
| **EPS** | Electric Power Steering，电动助力转向 | **仍有机械转向柱**，电机只提供助力；电源需大电流支路 |
| **SBW** | Steer-by-Wire，线控转向 | 真正线控：方向盘与转向机**无机械连接**；必须有冗余电源与冗余通信，失效需安全降级 |
| **EHB** | Electro-Hydraulic Brake，电液制动 | 保留液压执行，踏板与液压解耦，电控建压；本车队方案 |
| **EMB** | Electro-Mechanical Brake，电子机械制动 | 完全无液压，电机直接驱动制动钳 |

> ⚠️ **EPS ≠ SBW**。说"线控转向"时要讲清严格定义（无机械连接）与实车现状（EPS 仍保留机械柱）的差别 —— 这是最容易含糊过去的地方。

- 执行器供电要独立支路 + 独立保险丝，避免与灯光/蜂鸣器共用导致压降
- 关键执行器（转向/制动）考虑**双电源冗余**或至少保证失效时可安全停车
- 通信丢失时的失效策略必须明确：VCU 应能识别超时并进入安全状态

完整展开见 `interest-learning/electronic-control/chassis-control/` 两讲。

## 九、表述结构（通用）

答"简述/说明"类问题时，按这个顺序讲，条理最清楚：

1. **是什么** —— 一句话给定义（英文全称 + 中文）
2. **为什么** —— 解决什么问题、原来有什么弊端
3. **怎么工作** —— 分层或分点拆开（物理层 → 数据层 → 应用层，或 输入 → 处理 → 输出）
4. **关键参数/数据** —— 给具体数字（电压、速率、电阻、字节数）
5. **易错点** —— 主动点出容易混淆的地方（如 EPS 与 SBW）

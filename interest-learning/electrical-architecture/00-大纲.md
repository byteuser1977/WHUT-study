# WUTIB 智能巴哈车队 · 电气架构组 学习笔记

> 从零认识一辆赛车的"血管与神经"：电从哪来、怎么分、怎么接、怎么通信。
> 5 个模块 18 讲，每讲约 10 分钟。零基础可读，不需要先学过电路。

## 一、这份笔记解决什么问题

电气架构组做三件事：

1. **配电** —— 把电池的电安全地分给每一个用电器（汇流排、分线器、保险丝、继电器）
2. **连接** —— 把线可靠地接到器件上，经得住振动、颠簸、泥水（焊锡环、铜鼻子、压接工艺）
3. **通信** —— 让整车各个控制器互相说话（CAN、车载以太网、串口）

读完这份笔记，你应该能：

- 看懂一张电气原理图，并自己画出供电回路与继电器逻辑回路
- 说清 CAN 总线为什么用两根线、为什么抗干扰
- 说清报文和信号的关系，并用 TSMaster 模拟 VCU 发出报文
- 画出一辆巴哈赛车的整车通信网络架构，并说清每个部件为什么挂在那张网上

## 二、学习路线图

```
模块一 电气基础与线束部件   ← 先搞懂"电从哪来、怎么分、怎么接"
        ↓
模块二 CAN 总线与报文        ← 整车的"语言"，最重要的一块
        ↓
模块三 整车通信网络          ← 把各个部件挂到合适的网上
        ↓
模块四 电气原理图设计  ★     ← 把前面学的画出来（动手产出最多）
        ↓
模块五 重点问题自测          ← 合上笔记，自己讲一遍
```

**先学模块一、二，再动模块四。** 模块四全是画图，前面概念不清楚的话会变成"照抄线"。

### CAN 总线

| 知识点 | 对应讲次 | 要点 |
|---|---|---|
| 基本结构与终端电阻 | [can-bus/01](can-bus/01-can总线的基本结构.md) | 线型总线多主广播；**两端各 120 Ω**，只在一边接会导致反射与通信不稳 |
| 差分信号实现 | [can-bus/02](can-bus/02-差分信号实现.md) | 显性 ≈3.5 V/1.5 V（V_diff ≈2 V，逻辑 0），隐性均 ≈2.5 V（V_diff ≈0 V，逻辑 1）；判压差不判对地电压 |
| 报文与信号的关系 | [can-bus/03](can-bus/03-报文与信号关系.md) | 报文=帧（含 ID+数据场），信号=数据场里有物理意义的位字段；**一帧多信号，一信号归一帧** |

## 五、环境与软件准备

| 用途 | 软件/工具 | 说明 |
|---|---|---|
| 画电气原理图 | **Visio** 或 **AutoCAD Electrical** | 二选一即可；Visio 上手快，AutoCAD Electrical 元件库与自动编号更强 |
| CAN 报文收发与分析 | **TSMaster**（同星智能） | 需配 USB-CAN 硬件；支持报文发送、信号编辑、DBC 导入、记录回放 |
| 看 DBC | 各类 DBC 编辑器 / TSMaster 内置 | 报文的 ID、周期、信号位定义都写在里面 |
| 焊接与压接工具 | 压线钳、热风枪/热缩枪、端子、焊锡环 | 实操用，见模块一第 04 讲 |

> ⚠️ Visio / AutoCAD Electrical / TSMaster 都是 Windows 图形软件。笔记里给的是**操作步骤与规范**，菜单项可能随版本变化，**以你机器上为准**。

## 七、学完能做到什么

- 独立完成一条支路的配电设计：选线径、选保险丝、选继电器、定端子
- 看懂并画出供电回路与继电器逻辑回路，能解释每个触点的通断状态
- 讲清 CAN 总线的基本结构、差分信号原理、报文与信号的关系
- 用 TSMaster 搭一个模拟 VCU，周期发出报文并验证被其他节点接收
- 画出一版整车通信网络架构图，并说清每个部件的挂载理由

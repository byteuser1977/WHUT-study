# 第04讲：通信网络架构图绘制（正文约6分钟 + 练习约4分钟）

## 你将学到
- 架构图必须画清三层信息：节点层、链路层、参数层
- 每个部件该挂哪张网，以及背后的四条判断依据
- 三种网络用三种线型区分，终端电阻标在哪

> CAN 差分原理见 [can-bus/02](../can-bus/02-差分信号实现.md)，报文与信号见 [can-bus/03](../can-bus/03-报文与信号关系.md)。本节只讲**怎么画出来**。

---

## 1. 架构图的三层信息

一张能用的架构图必须同时说清三层，缺一层就只是"连线图"：

| 层 | 画什么 | 本车举例 |
|---|---|---|
| 节点层 | 谁挂在这张网上 | 11 个部件，逐个见第 2 节表 |
| 链路层 | 用哪条总线连起来 | CAN（控制类）、车载以太网（大带宽）、串口（惯导/遥控/调试） |
| 参数层 | 每条链路的速率与边界条件 | CAN 500 kbps、两端各一只 120 Ω、报文 ID 段划分 |

> 💡 类比：架构图像**城市交通图**——光有地点（节点层）没用，得标清主干道与小巷（链路层）、写上限速（参数层），别人才走得通。

## 2. 每个部件挂哪张网（★核心）

判断依据只有四条，记它们比背结论有用：

| 判断依据 | 推论 |
|---|---|
| 数据量 | 点云、图像走以太网；少量状态量走 CAN |
| 控制闭环 | 要确定性的走 CAN；不能容忍排队延迟的别挂以太网 |
| 线束与重量 | 串口最省线；CAN 两根线挂多节点 |
| 失效影响 | 转向/制动失效后果重，必须考虑冗余与超时策略 |

按这四条推出来的参考挂载：

| 部件 | 建议网络 | 理由 |
|---|---|---|
| 域控制器 | 车载以太网 + 一路 CAN | 决策层，既吃感知数据也拿整车状态 |
| VCU | CAN | 整车控制调度，收发都是状态量与指令 |
| EPS / EHB | CAN | 转向/制动指令与反馈，要确定性 |
| BMS / 电机控制器 | CAN | 电池状态、扭矩与转速指令反馈 |
| 激光雷达 / 视觉传感器 | 车载以太网 | 点云与图像流，带宽最大 |
| 毫米波雷达 | CAN | 输出目标列表，数据量小 |
| 惯性导航 | 串口 + CAN | 高频姿态走串口，整车只要摘要 |
| 遥控接收机 | 串口 / PWM | 无线链路落地后转串口给 VCU |

> ⚠️ 域控制器与 VCU 之间常需**同时**挂以太网与 CAN 两路，只画一条是最常见的漏项；惯导也常"双挂"。

## 4. 线型与标注规范

| 网络 | 线型 | 颜色 | 必标内容 |
|---|---|---|---|
| CAN | 实线（主干加粗） | 黄/绿双绞 | 速率 + 两端 120 Ω + 报文 ID 段 |
| 车载以太网 | 双线或点划线 | 蓝 | 速率（100/1000BASE-T1） |
| 串口 | 虚线 | 灰 | 电平标准（RS-232/TTL）+ 波特率 |

## 5. 干线接线表与上机步骤

| 序号 | 从 | 到 | 线径 | 颜色 |
|---|---|---|---|---|
| 1 | 节点 CAN_H / CAN_L 引脚 | 干线双绞对 | 0.5 mm² | 黄 / 绿 |
| 2 | 干线两端 | 各一只 120 Ω 终端电阻 | 0.5 mm² | 与干线同色 |
| 3 | 屏蔽层 | 车身搭铁点（单端搭铁） | — | 黑 |

CAN_H 与 CAN_L **必须双绞**，节点引线尽量短。

**上机步骤**（版本相关菜单以你机器上为准）：

1. 新建图纸，选网络拓扑类模板/模具；AutoCAD Electrical 先建项目再建图纸。
2. 画主干：一条水平粗线代表 CAN，两端各插一只电阻符号并注"120 Ω"。
3. 挂节点：每节点一个小方框写位号，短竖线接主干；**先把节点摆完再连线**。
4. 换线型画以太网与串口，旁边注速率与协议名，补图例与标题栏。

## 🎯 动手练习（约4分钟）

1. 在你机器上的 Visio 或 AutoCAD Electrical 里，按第 3 节的文字图画一张架构图。
2. **第 2 节表里的 11 个部件全画上**，一个不许漏（最容易漏掉视觉传感器与惯导）。
3. CAN 主干两端各画一只 120 Ω 并标"合计 60 Ω"；主干上注 `CAN1 500 kbps`。
4. 以太网与串口换用不同线型并各自标注速率，图例里写清三种线型各代表什么。

**✅ 你应该看到**：一条加粗主干带 5 个 CAN 节点、两端各一只 120 Ω；域控制器另接以太网链到激光雷达与视觉传感器；惯导与遥控挂在串口虚线上——11 个部件一个不少。

## 本讲小结

| 项 | 要点 |
|---|---|
| 三层信息 | 节点层（谁挂网）、链路层（哪条总线）、参数层（速率、终端电阻、ID 段） |
| 四条判断依据 | 数据量定带宽、闭环定实时性、线束定物理层、失效影响定冗余 |
| 易漏点 | 域控与 VCU 之间常同时挂以太网 + CAN；惯导常"串口 + CAN"双挂 |
| 线型与终端电阻 | CAN 实线、以太网双线、串口虚线必配图例；120 Ω 只在主干两端 |

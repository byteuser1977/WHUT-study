# 第02讲：供电回路设计（正文约6分钟 + 练习约4分钟）

## 你将学到
- 供电回路的固定骨架：电源 → 保险丝 → 开关 → 负载 → 搭铁
- 两个负载为什么必须并联，串联会出什么洋相
- 保险丝与线径各按什么选
- 车上的"搭铁回路"为什么不把每根线都拉回电池

---

## 1. 供电回路的固定骨架

车上任何一条用电支路，都长这个样子。**文字电路图**：

```text
(+) 蓄电池 ─[ F1 保险丝 ]─[ S1 开关 ]─┬─ ( H1 蜂鸣器 )
                                       └─ ( L1 指示灯 )
(-) 车身搭铁点 ────────────────────────┘
```

拆开只有四件事：**保护（保险丝）、控制（开关）、用电（负载）、回流（搭铁）**。顺序不能乱——保险丝必须装在电源侧最前，它保护的是整条线束；装到开关后面，就只保护了后半段。

两个负载**并联**：蜂鸣器与指示灯各有一根线接在开关之后的公共节点上，另一根各自搭铁。并联意味着两个负载**各自独立**，坏一个，另一个照常工作。

> 💡 类比：并联就像**家里墙上的两个插座**——各插各的，拔掉一个不影响另一个。串联则是把两件电器首尾穿在一根线上：电流必须走完两件才回落，任何一件坏掉，整条回路都断。

> ⚠️ 串联还有一个坑是**分压**：24 V 上串两个一样的负载，每个只分到 12 V，都可能工作不正常。所以车载负载**一律并联**。

## 2. 保险丝与线径怎么选

选型的入口只有一个数：**这条支路的总电流**。

| 项目 | 怎么定 | 本支路举例 |
|---|---|---|
| 支路总电流 I | I = P / U；多负载并联时电流相加 | 蜂鸣器 0.3 A + 指示灯 0.2 A = 0.5 A |
| 保险丝额定 | 略大于总电流，留 1.5~2 倍余量 | 选 1 A（带电机时选慢熔型）|
| 线径 | 按电流查线规表，兼顾压降与机械强度 | 0.75 mm² 够用，取 1.0 mm² 更稳 |
| 支路保护 | 每个负载可再单独串一只小保险丝 | 蜂鸣器支路加 0.5 A，故障只断它 |

**保险丝不是越大越好**：选大了，线束先烧断它才动作；选小了，冷启动或堵转电流一来就误熔断。

## 3. 搭铁回路与接线表

车身是钢制或管架结构，本身就是一根巨大的导体。所以车载电路的做法是：**负极就近固定在车身搭铁点上（螺栓压接）**，而不是每个用电器都单独拉一根线回电池负极。这样省掉一半线束重量与成本，故障点也更少。代价是——**搭铁点的质量直接决定用电器能不能正常工作**：

- 搭铁点必须**打磨到露出金属**再压接，中间隔着一层漆就是几欧姆的接触电阻；
- 搭铁点要**避开高强度受力螺栓**，受力件不承担额外电流，也怕被拧松；
- **不允许搭在塑料件、涂装件**上，那种"搭铁"形同虚设。

**接线表**（线径与颜色为建议值）：

| 序号 | 从 | 到 | 线径 | 颜色建议 |
|---|---|---|---|---|
| 1 | 蓄电池正极 (+) | 保险丝 F1 进线 | 2.5 mm² | 红 |
| 2 | 保险丝 F1 出线 | 开关 S1 端子 IN | 1.5 mm² | 红 |
| 3 | 开关 S1 端子 OUT | 公共节点（两负载并联点）| 1.0 mm² | 黄 |
| 4 | 公共节点 | 蜂鸣器 H1 端子 + | 0.75 mm² | 橙 |
| 5 | 公共节点 | 指示灯 L1 端子 + | 0.5 mm² | 蓝 |
| 6 | 蜂鸣器 H1 端子 − | 车身搭铁点 A | 0.75 mm² | 黑 |
| 7 | 指示灯 L1 端子 − | 车身搭铁点 A | 0.5 mm² | 黑 |

## 4. 上机步骤（版本相关菜单以你机器上为准）

1. 新建图纸；AutoCAD Electrical 先建项目再建图纸，Visio 选电气类模具。
2. 画电源母线：图纸上方一条水平粗线代表 (+)，正极处放电池符号（长短线一对，长线为正）。
3. 插入器件：从符号库取 Fuse、Switch、Buzzer、Lamp，双击改位号 F1 / S1 / H1 / L1。
4. 连主路与支路：母线 → F1 → S1 → 公共节点，再从节点向下引出两条竖线接 H1、L1，末端各引一条线汇到搭铁符号。
5. 标注：每段线写线号，把线径与颜色敲在线的旁边，与第 3 节接线表逐行对齐。

## 🎯 动手练习（约4分钟）

1. 照第 3 节的接线表，在你机器上的 Visio 或 AutoCAD Electrical 里画出这条双负载并联供电回路。
2. 检查三处：保险丝是否在开关**之前**、两个负载是否**并联**、两个负载的负极是否各自回到搭铁点。
3. 用箭头链把回路写成一行文字：`电池(+) → 保险丝 F1 → 开关 S1 → 并联(蜂鸣器 ‖ 指示灯) → 搭铁(−)`。
4. 设蜂鸣器 0.3 A、指示灯 0.2 A，算出支路总电流，标出你选的保险丝额定值。
5. 把两个负载改成串联再画一版，写下它会带来什么问题（提示：分压 + 互相牵连）。

**✅ 你应该看到**：主路上保险丝、开关依次串接；两个负载的进线来自同一个公共节点，出线各自下到搭铁符号——是并联，不是串联。

## 本讲小结

| 项 | 要点 |
|---|---|
| 回路骨架 | 电源(+) → 保险丝 → 开关 → 负载 → 搭铁(−) |
| 保险丝位置与选型 | 装在电源侧最前，保护整条线束；按支路总电流选，留 1.5~2 倍余量 |
| 负载接法 | **并联**，各自独立工作、互不影响；串联会分压并互相牵连 |
| 搭铁回路 | 负极就近压接车架：磨到见金属、避受力螺栓、不搭塑料件 |
| 绘图要素 | 母线 + 器件符号 + 公共节点 + 搭铁符号 + 线径颜色标注 |

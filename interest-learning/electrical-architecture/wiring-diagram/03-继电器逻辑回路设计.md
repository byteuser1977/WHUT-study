# 第03讲：继电器逻辑回路设计（正文约6分钟 + 练习约4分钟）

- 一张"闭合灯亮、蜂鸣器不响"回路的完整推导

## 1. 继电器五个端子（画图要用）

继电器的工作原理与选型见 [electrical-basics/02](../electrical-basics/02-继电器.md)，这里只留画图必须记住的端子分工：

| 端子 | 名称 | 说明 |
|---|---|---|
| 85 / 86 | 线圈两端 | 一端进控制电，一端回搭铁 |
| 30 | 公共端 | 触点侧的电从 30 进来 |
| 87 | 常开触点 NO | **线圈不通电时断开**，通电后闭合 |
| 87a | 常闭触点 NC | **线圈不通电时闭合**，通电后断开 |

> 💡 类比：继电器像**水管的先导阀**——主管道的大阀门你用手拧不动，但能轻松拧开旁边的小阀；小阀一通，水压自己就把大阀门推开了。控制回路走小电流，负载回路走大电流，两边电气隔离。

> ⚠️ 线圈断电瞬间，电感电流被硬切断，会感应出**反向电动势**（可达几十上百伏），足以打穿驱动它的三极管。所以线圈两端要**并一只续流二极管**并**反接**，让电流在两者之间绕圈泄掉。

## 2. 推导"闭合灯亮、蜂鸣器不响"

把开关串在**继电器线圈回路**里：

- **开关闭合** → 线圈得电 → **常闭主触点断开**、**常开辅助触点闭合**；
- 因此**蜂鸣器接常闭主触点支路**——得电时这条支路被切断，蜂鸣器**不响** ✓；
- **指示灯接常开辅助触点支路**——得电时这条支路接通，灯**亮** ✓；
- **开关断开** → 线圈失电 → 触点复位：常闭闭合 → 蜂鸣器**响** ✓；常开断开 → 指示灯**灭** ✓。

触点状态真值表：

| 开关 | 线圈 | 常闭主触点 | 常开辅助触点 | 指示灯 | 蜂鸣器 |
|---|---|---|---|---|---|
| 闭合 | 得电 | 断开 | 闭合 | 亮 | 不响 |
| 断开 | 失电 | 闭合 | 断开 | 灭 | 响 |

| 序号 | 从 | 到 | 线径 | 颜色建议 |

| 1 | 蓄电池正极 (+) | 保险丝 F1 进线 | 1.5 mm² | 红 |

| 3 | S1 | 继电器 K1 的 86 脚 | 0.75 mm² | 橙 |

| 6 | K1 的 87a 脚 | 蜂鸣器 H1 端子 + | 1.0 mm² | 棕 |
| 7 | K1 的 87 脚 | 指示灯 L1 端子 + | 0.5 mm² | 蓝 |

**文字电路图**（`[ ]` 串在线上的器件，`( )` 负载）：

```text
(+) ─[ F1 ]─┬─[ S1 ]─ 86 ┐
            │            [ K1 线圈 ] ⚠ 两端并续流二极管(反接)
            │        85 ─┴── 搭铁(−)
            │
            └─ 30 ┬─[ K1 87a 常闭·主触点 ]── ( H1 蜂鸣器 ) ── 搭铁(−)
                  └─[ K1 87  常开·辅助触点]── ( L1 指示灯 ) ── 搭铁(−)
(-) 车身搭铁点 ──────────────────────
```

## 4. 上机步骤（版本相关菜单以你机器上为准）

1. 新建图纸，进入电气符号模具或 `插入元件 → 符号库`。
2. 取符号：继电器线圈 Coil、常开触点 NO、常闭触点 NC、开关 Switch、保险丝 Fuse、蜂鸣器 Buzzer、指示灯 Lamp、搭铁 Ground。
3. 画线圈支路 F1 → S1 → 86、85 回搭铁，并在 85/86 间并一只二极管（反接）。
4. 画 30 引出的两条支路：87a 串蜂鸣器、87 串指示灯；再填位号、线号与线径颜色。

## 🎯 动手练习（约4分钟）

1. 按第 3 节接线表，在你机器上的 Visio 或 AutoCAD Electrical 里画出这条回路：先摆线圈支路，再摆两条触点支路，最后画搭铁符号。
2. 对照真值表核对：把开关画成闭合，看蜂鸣器支路是否断、指示灯支路是否通。
3. 再画一版错误示范：把蜂鸣器接到 87（常开）上，写下会出现什么现象。

**✅ 你应该看到**：开关闭合时，蜂鸣器支路被 87a 切断（不响），指示灯支路经 87 接通（亮）；开关断开时恰好相反，与真值表两行对上。

## 本讲小结

| 项 | 要点 |
|---|---|
| 端子分工 | 85/86 线圈；30 公共端；87 常开 NO；87a 常闭 NC |
| NO / NC | 以"线圈不通电"为基准：断的是 NO，通的是 NC |
| 主 / 辅助触点 | 主触点载流量大（带大电流负载）；辅助触点小（带信号、指示灯）|
| 回路推导 | 开关串在线圈回路；蜂鸣器走常闭主触点、指示灯走常开辅助触点；线圈并反接续流二极管 |

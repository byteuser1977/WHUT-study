# 第01讲：Visio 与 AutoCAD Electrical 入门（正文约6分钟 + 练习约4分钟）

## 你将学到
- 一张能拿去接线的电气原理图，必须画清哪四样东西
- Visio 与 AutoCAD Electrical 各自适合什么活
- 从零画一张"开关控灯"图的编号操作步骤
- 画图最容易留下的几个隐患，怎么提前避开

---

## 1. 图纸要表达的四样东西

想让别人照着你的图把线接上，图必须回答四个问题，缺一个现场就得靠猜：

| 要表达的东西 | 图上长什么样 | 为什么必须有 |
|---|---|---|
| 器件 | 规范符号（开关、继电器线圈与触点、保险丝、搭铁、负载）| 符号不统一，读图的人认不出这是什么 |
| 连接关系 | 符号之间的连线，相接处画实心点 | 谁和谁通，直接决定能不能通电 |
| 端子编号 | 每个接线点旁的编号（继电器常见 30/87/87a/85/86）| 装车时按号码插线，不靠记忆 |
| 线束信息 | 线径与颜色的文字标注 | 电流多大用多粗的线，颜色区分回路 |

> 💡 类比：电气原理图就像**菜谱**——器件是食材，连线是下锅顺序，端子号是克数。菜谱写"盐适量"，厨房里就出事；图上不写线径和端子号，接线的同学也只能靠猜。

## 2. 两款软件怎么选

| 对比项 | Visio | AutoCAD Electrical |
|---|---|---|
| 定位 | 通用矢量绘图 | 面向电气设计的专用 CAD |
| 符号库 | 模板要自己做 | 自带电气符号库（IEC/GB 风格）|
| 元件编号 | 手工填 | 自动编号，跨页引用联动 |
| 报表 | 无 | 能自动出端子表、BOM（Bill of Materials，物料清单）|
| 上手速度 | 快，界面像 Office | 慢，要先理解"项目—图纸—元件"结构 |
| 适合的活 | 汇报框图、系统架构图、页数少的原理图 | 元件多、页数多、要出端子表与线束表的接线图 |

一句话：**画给人看的图用 Visio，画给产线接线的图用 AutoCAD Electrical。** 车队里两者常常并用——架构图走 Visio，接线图走 AutoCAD Electrical。

> ⚠️ "搭铁"（车身上的负极公共点）的规范符号是**三条递减的横线**，不是三角形。三角形常用来表示天线一类符号，画混了，读图的人会以为这条是信号线。

## 3. 目标图纸：开关直接控制灯泡

这一讲先不碰继电器，把最简回路画规范。**接线表**（线径与颜色为建议值）：

| 序号 | 从 | 到 | 线径 | 颜色建议 |
|---|---|---|---|---|
| 1 | 蓄电池正极 (+) | 保险丝 F1 进线 | 1.5 mm² | 红 |
| 2 | 保险丝 F1 出线 | 开关 S1 端子 IN | 1.5 mm² | 红 |
| 3 | 开关 S1 端子 OUT | 灯泡 X1 端子 + | 1.0 mm² | 黄 |
| 4 | 灯泡 X1 端子 − | 车身搭铁点 | 1.0 mm² | 黑 |

**文字电路图**（箭头链 + 括号表示器件）：

```text
(+) 电池 ─[ F1 保险丝 ]─[ S1 开关 ]─┬─ ( X1 灯泡 )
                                    │
(-) 车身搭铁点 ─────────────────────┘
```

读法：**─[ ]─** 表示串在这条线上的器件；右边的 **┬ ┘** 表示两条支路共享同一个节点；括号里写器件位号（F1、S1、X1）。

## 4. 上机步骤（版本相关菜单以你机器上为准）

1. 新建：Visio 里走 `文件 → 新建 → 基本电气图`；AutoCAD Electrical 里走 `项目 → 新建项目`，再新建一张图纸。
2. 找符号：Visio 在左侧 `模具` 面板选电气类模具，拖出 `保险丝`、`开关`、`灯`；AutoCAD Electrical 用 `插入元件 → 符号库`，选 Fuse（保险丝）、Switch（开关）、Lamp（灯）。
3. 摆件：按"电源在上、负载在下"的老规矩摆，器件都落在栅格上，便于对齐。
4. 连线：用正交线段，别用自由曲线；相接处补一个实心连接点，交叉不相接处不画点。
5. 标号：双击连线写线号（101、102、103），双击器件写位号（F1、S1、X1）。
6. 标线束：在每段线旁注"1.5 红""1.0 黑"，与上面的接线表逐行对应。

## 🎯 动手练习（约4分钟）

1. 照着第 3 节的接线表与电路图，在你机器上的 Visio 或 AutoCAD Electrical 里把这张图重画一遍。
2. 摆件顺序：保险丝 → 开关 → 灯泡，横向串排；再从灯泡右端画一条向下的线引到"搭铁"符号。
3. 收尾用搭铁符号（三条递减横线），**不要**用三角符号。
4. 逐段标注线径与颜色：1.5 红、1.5 红、1.0 黄、1.0 黑。
5. 双击每个器件填位号 F1 / S1 / X1，再双击每段连线填线号 101 / 102 / 103。

**✅ 你应该看到**：一张只有四个器件、四个接线点的图，**器件符号、连接关系、端子与线号、线径颜色四类信息齐全**，打印出来就能照着接。

## 本讲小结

| 项 | 要点 |
|---|---|
| 图纸四要素 | 器件符号、连接关系、端子/线号、线径与颜色 |
| Visio | 通用绘图，上手快，适合架构图与汇报框图 |
| AutoCAD Electrical | 电气专用 CAD，自带符号库 + 自动编号 + 端子表/BOM |
| 规范符号 | 搭铁是三条递减横线；相接处画实心点，交叉不接不画点 |
| 上机六步 | 新建 → 找符号 → 摆件 → 连线 → 标号 → 标线束 |
| 常见隐患 | 符号自造、线号空缺、线径颜色不标、连线交叉不清 |

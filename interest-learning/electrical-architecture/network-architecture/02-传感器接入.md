# 第02讲：传感器接入（正文约6分钟 + 练习约4分钟）

## 你将学到
- 车上五类传感器分别接什么接口、要多大的带宽
- 供电、搭铁、屏蔽这三件事为什么不能省
- 接线表怎么读、文字电路图怎么画

---

## 1. 先盘清有哪些传感器、各走哪条接口

| 传感器 | 接口 | 数据特征 | 供电 |
|---|---|---|---|
| 惯性导航（IMU + GNSS 组合导航） | 串口（UART，常见 115200 bps） | 姿态、角速度、加速度，50~100 Hz | 12 V，独立支路 |
| 激光雷达（LiDAR） | 车载以太网 | 点云，几十 Mbps 级 | 12 V，单独支路 |
| 毫米波雷达 | CAN（部分型号带以太网） | 目标距离与速度，20~50 Hz | 12 V |
| 视觉传感器（摄像头） | 车载以太网 / USB | 图像流，带宽最大 | 12 V，就近搭铁 |
| 遥控接收机 | 串口 / PWM 信号线 | 遥控通道值，50 Hz | 5 V（接收机 BEC 或 DC-DC） |

一句话挑接口：**高带宽的走车载以太网，控制类走 CAN，点对点小数据走串口**。每个传感器一条独立支路，后面单独配保险丝。

## 2. 供电与搭铁：车上的"地"不是零电阻

- 车用**搭铁（ground）**：负极就近接车身/车架，不是每根线都回电池。同一传感器要**就近、单点搭铁**，否则不同支路的电流会在车架上扯出电压差，把信号抬起来。
- 传感器供电从**配电盒保险丝之后**取，保险丝按**支路总电流**选；大功率传感器（激光雷达、补光）单独支路，别和 VCU 挤一根线。
- 信号线用**屏蔽双绞**，屏蔽层**单端搭铁**（一般接采集端）。两端都接会形成地环路，反而更容易引进干扰。

> 💡 类比：一根传感器的线束就像**给客人安排座位**——供电是他的口粮，信号线是他说话的话筒，搭铁是他踩的地板。十个人挤一张桌子吃饭（共用一个搭铁点），谁的话都听不清。

## 3. 文字电路图与接线表

```
蓄电池(+) ─ 主保险丝 ─ 配电盒
                        ├─ F1 ──▶ 激光雷达 V+
                        ├─ F2 ──▶ 惯导 V+
                        └─ F3 ──▶ 域控制器 V+
        （各传感器 V− 就近搭铁到车身/车架，不回电池负极）

信号：惯导 TXD ──屏蔽双绞──▶ 域控 RXD（屏蔽层单端搭铁）
      激光雷达 网口 ──车载以太网线──▶ 域控 网口 1
```

| 端子 A | 端子 B | 线径建议 | 颜色建议 |
|---|---|---|---|
| 配电盒 F1 输出 | 激光雷达 V+ | 0.75 mm² | 红 |
| 车身就近搭铁柱 | 激光雷达 V− | 0.75 mm² | 黑 |
| 激光雷达以太网口 | 域控网口 1 | 车载以太网屏蔽双绞 | 蓝 |
| 惯导 TXD | 域控 RXD | 0.35 mm² 屏蔽双绞 | 黄 |
| 惯导 RXD | 域控 TXD | 0.35 mm² 屏蔽双绞 | 绿 |
| 惯导 V+ / V− | 配电盒 F2 输出 / 搭铁 | 0.5 mm² | 红 / 黑 |

> ⚠️ 串口的 TXD 必须交叉接到对方 RXD，直连（TXD—TXD）一条数据也收不到；CAN 的 CAN_H 与 CAN_L 接反则满总线错误帧。上车前这两处务必用万用表与图纸各核一遍。

## 🎯 动手练习

1. 打开 Visio 或 AutoCAD Electrical，新建"电气工程 / 基本电气"模板（模板名与位置**以你机器上为准**）。
2. 从元件库拖出**保险丝、搭铁符号、连接器**：连接器用矩形框 + 引脚编号表示。
3. 每个传感器画一个方框，按规格书标出引脚名：V+、V−（GND）、信号。
4. 供电线用红色实线，信号线用另一种颜色/线型，搭铁统一收口到搭铁符号。
5. 导出 PDF，上车按接线表逐条核对，优先核对 V+ 与 V− 有没有接反、串口有没有交叉。

> ✅ 你应该看到：图上从任一传感器的 V+ 出发，沿红色线都能追到配电盒上某一个确定的保险丝；V− 都能追到搭铁符号；惯导那两根信号线在图纸上呈交叉（TXD→RXD）。

## 本讲小结

| 要点 | 说明 |
|---|---|
| 接口匹配 | 大带宽（激光雷达/摄像头）走车载以太网，控制类走 CAN，惯导/遥控走串口 |
| 供电原则 | 一条传感器一条支路，从配电盒保险丝后取电，保险丝按支路总电流选 |
| 搭铁 | 负极就近接车身/车架；功率信号分开搭铁，避免共地电压差 |
| 屏蔽 | 信号线屏蔽双绞，屏蔽层单端搭铁，两端接会形成地环路 |
| 必查两处 | 串口 TXD/RXD 要交叉；CAN_H/CAN_L 不能接反 |
| 图纸三件套 | 接线表（端子→端子 + 线径/颜色）、文字电路图、软件编号步骤 |

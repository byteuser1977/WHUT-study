## 1. Linux 基础（只指路）
**要点**：CLI、路径、命令、权限、进程见现有笔记——[linux/01](../../linux/01-linux是什么.md)、[linux/03](../../linux/03-文件系统与导航.md)、[速查表](../../linux/linux-速查表.md)。自测：能否两分钟用 `cd`/`ls`/`grep`/`find` 找到目标文件。

**易错点**：`/` 开头才是绝对路径；`rm` 前先 `ls`。

**怎么讲清楚**：讲"我怎么找文件"的真实过程。

## 2. ROS 构建与 CMakeLists
**要点**：CMakeLists.txt 管"源码怎么变成可执行文件"：找依赖、编译、链接、安装，ROS 2 用 `ament_cmake` 扩展。六个必备件：`cmake_minimum_required`、`project`、`find_package(ament_cmake REQUIRED)`、`add_executable`、`ament_target_dependencies`、`install(DESTINATION lib/${PROJECT_NAME})`，`ament_package()` 必须写在最后一行。C++ 包（`ament_cmake`）要它，Python 包（`ament_python`）只要 setup.py：[ros2/05](../../perception/ros2/05-写第一个节点.md)、[ros-build/02](../ros-build/02-cmakelists逐段解读.md)。

**易错点**：漏 `ament_package()` → `ros2 pkg` 认不出包；漏 `install` → `colcon build` 过、`ros2 run` 找不到。

**怎么讲清楚**：按顺序念六个必备件，各补一句"删掉会怎样"。

## 3. 软件架构与数据流
**要点**：链：传感器 → 感知（检测/分割/跟踪/定位）→ 预测（轨迹）→ 规划（全局路径→局部轨迹）→ 控制（转向+驱动/制动）→ 执行器（EPS/EHB/VCU），每环说清输入输出。

例子：感知把 15 m 外锥桶列入障碍物列表 → 预测判定静止 → 规划抬高该区域代价、降速 → 控制解算出转向角与扭矩指令。线控与 CAN 见 [线控](../../electronic-control/chassis-control/01-线控转向与线控制动.md)、[CAN](../../electrical-architecture/can-bus/03-报文与信号关系.md)。

> 💡 类比：像接力传棒——每棒只看上一棒递来的东西，棒没接稳，后面跑再快也白搭。

**易错点**：说"感知直接控制车"，跳过预测与规划。

**怎么讲清楚**：任取一环，按"输入→处理→输出"讲一遍。

## 4. 感知误检的应对策略
**要点**：误检是假阳性、漏检是假阴性，代价不对称——误检让车变慢，漏检让车撞上。

- **感知端**：多传感器交叉验证（视觉+激光雷达+毫米波互证）；连续 N 帧才确认；输出置信度与不确定性。
- **规划端**：判定不了就按真障碍物保守处理；做代价分级而非 0/1；留紧急重规划通道。
- **控制端**：对规划指令限幅与平滑；留紧急制动兜底。
- **系统级**：失效降级、遥控接管、黑盒日志与回放。

> ⚠️ 常见坑：把"保守"讲成"不动"。一味保守车会动弹不得；正路是多帧确认 + 多源校验压误报。

**易错点**：为压误检削弱检测；只讲感知端，不提另外三层。

**怎么讲清楚**：拿"真锥桶"与"路面叠影"对比处置，再按四层往上叠。

## 5. 排序算法与复杂度
**要点**：详解见 [algorithms/](../algorithms/)，此处只钉要背的：

| 算法 | 平均 / 最坏 | 稳定性 | 空间 |
|---|---|---|---|
| 冒泡 | O(n²) | 稳定 | O(1) |
| 选择 | O(n²) | 不稳定 | O(1) |
| 插入 | O(n²) | 稳定 | O(1) |
| 快速排序 | O(n log n) / **O(n²)** | 不稳定 | O(log n) 递归栈 |
| 归并排序 | O(n log n) | 稳定 | O(n) |

快排最坏 O(n²)（已有序 + 取首元素为基准）；选择与快排不稳（交换会打乱相等元素次序）。实战优先用自带排序：Python `sorted()` 是 **Timsort**（稳定，部分有序近 O(n)），C++ `std::sort` 是**内省排序 introsort**（不稳定），要稳定用 `std::stable_sort`。

**易错点**：说快排总是 O(n log n)；说选择或快排稳定。

**怎么讲清楚**：手推一遍快排分区，稳定性反例当场举。

## 本讲小结

| 要点 | 说明 |
|---|---|
| CMakeLists | 六个必备件；`ament_package()` 收尾；C++/Python 包不同 |

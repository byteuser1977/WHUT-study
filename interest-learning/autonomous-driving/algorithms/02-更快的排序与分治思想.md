## 1. 分治：把一个大问题拆成同款的小问题

第01讲三种写法都在整堆数据上反复扫。分治换个思路：把数据分成两半，各自排好再拼起来。分、治、合三步。当一段只剩一个元素时，它天然有序——这就是递归的终点。

> 💡 类比：两组已按身高排好的队伍合并成一队，不用重新比一遍：两队各看排头，矮的先走——两段有序数据合成一段，只需线性时间。

## 2. 快速排序：围绕基准分成两拨

取一个元素当**基准（pivot）**，其余元素按"不大于基准"和"大于基准"分成两拨，两拨各自递归。基准在一次分区后就落到最终位置。平均 O(n log n)，但**最坏会退化成 O(n²)**：每次分区都歪向一边（输入已有序、基准取首元素）时，递归会变成一条链。

## 3. 归并排序：先拆到单个，再两两合并

递归折半到每段只剩一个元素，再用**合并（merge）**把两个有序段拼成一个：两个指针各扫一段，每次取小的那个。比较次数与初始顺序无关，**稳定 O(n log n)**，代价是要 O(n) 额外空间。

## 4. 代码

```python
import random

def quick_sort(a):
    if len(a) <= 1:
        return a
    pivot = a[0]
    less = [x for x in a[1:] if x <= pivot]
    greater = [x for x in a[1:] if x > pivot]
    return quick_sort(less) + [pivot] + quick_sort(greater)

def merge_sort(a):
    if len(a) <= 1:
        return a
    mid = len(a) // 2
    left, right = merge_sort(a[:mid]), merge_sort(a[mid:])
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            out.append(left[i])
            i += 1
        else:
            out.append(right[j])
            j += 1
    return out + left[i:] + right[j:]

random.seed(1)
data = [random.randint(1, 99) for _ in range(10)]
print("原始:", data)
print("快排:", quick_sort(data))
print("归并:", merge_sort(data))
```

真实输出：

```text
原始: [18, 73, 98, 9, 33, 16, 64, 98, 58, 61]
快排: [9, 16, 18, 33, 58, 61, 64, 73, 98, 98]
归并: [9, 16, 18, 33, 58, 61, 64, 73, 98, 98]
```

## 5. 稳定性：同键元素的先后可能被打乱

**稳定性（Stability）** 指关键字相同的元素排完后相对次序是否与原来一致：按距离排障碍物时，同距离的目标不该被随意调换先后。把两处比较改成只比下标 0 后跑一跑，真实输出：

```text
输入1 [(1,'a'),(1,'b'),(0,'c')]
  选择 -> [(0,'c'),(1,'b'),(1,'a')]        # 'a' 与 'b' 次序反了
输入2 [(2,'a'),(1,'b'),(2,'c'),(1,'d')]
  快排 -> [(1,'d'),(1,'b'),(2,'c'),(2,'a')]
  归并 -> [(1,'b'),(1,'d'),(2,'a'),(2,'c')]
```

选择排序把最小值换到前面时会跨过同键元素；快排把同键元素分到基准两侧时也会乱序；归并的合并写了 `left[i] <= right[j]`，相等时先取左边，次序自然保住。

> ⚠️ 常见坑：元组比较时若连标号一起比，`(1,'a') < (1,'b')` 会按标号分出胜负，稳定性就被掩盖了——必须只比关键字。

## 本讲小结

| 要点 | 说明 |
|---|---|
| 分治三步 | 分、治、合；最小段只剩一个元素即为有序 |
| 快速排序 | 基准分区 + 原地扫描，平均 O(n log n)，最坏 O(n²) |
| 归并排序 | 折半递归 + 线性合并，稳定 O(n log n) |
| 额外空间 | 归并用 O(n)，快排用 O(log n) 递归栈 |
| 稳定性 | 归并稳定；快排与选择都不稳定 |
| 最坏情况 | 有序输入 + 基准取首元素 → 快排退化、递归超深 |

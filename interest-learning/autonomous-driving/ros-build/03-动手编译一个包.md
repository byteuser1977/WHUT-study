# 第03讲：动手编译一个包（正文约6分钟 + 练习约4分钟）

> 这一讲把 [上一讲](02-cmakelists逐段解读.md)的清单跑起来，真建一个 C++ 包（预设 `~/ros2_ws`，见 [05 讲](../../perception/ros2/05-写第一个节点.md)）。

## 你将学到
- 生成 C++ 包骨架并写最小节点
- 把节点登记进两个清单
- 走完 `colcon build` → `source` → `ros2 run`

---

## 1. 建包与写节点

在 `~/ros2_ws/src` 下跑 `ros2 pkg create --build-type ament_cmake cpp_demo`。

> ✅ 你应该看到 `going to create a new package` 日志，以及新目录里的 `CMakeLists.txt`、`src/`。

写进 `cpp_demo/src/talker.cpp`：每 0.5 秒往 `hello` 发一条字符串，和 05 讲的 Python talker 一样，只是把 `rclpy` 换成 `rclcpp`。

```cpp
#include <chrono>
#include <memory>
#include "rclcpp/rclcpp.hpp"
#include "std_msgs/msg/string.hpp"
using namespace std::chrono_literals;

int main(int argc, char ** argv) {
  rclcpp::init(argc, argv);
  auto node = std::make_shared<rclcpp::Node>("talker");
  auto pub = node->create_publisher<std_msgs::msg::String>("hello", 10);
  auto timer = node->create_wall_timer(500ms, [&]{
    auto msg = std_msgs::msg::String();
    msg.data = "hello from cpp";
    pub->publish(msg);
  });
  rclcpp::spin(node);
  rclcpp::shutdown();
}
```

## 2. 登记进两个清单

在 `CMakeLists.txt` 里、`ament_package()` **之前**加上：

```cmake
find_package(rclcpp REQUIRED)
find_package(std_msgs REQUIRED)
add_executable(talker src/talker.cpp)
ament_target_dependencies(talker rclcpp std_msgs)
install(TARGETS talker DESTINATION lib/${PROJECT_NAME})
```

`package.xml` 里补上 `<depend>rclcpp</depend>` 和 `<depend>std_msgs</depend>`。

> ⚠️ 常见坑：只改 `CMakeLists.txt`、忘了 `package.xml`，**本机编译照样能过**，装到别的机器才炸。

## 3. 编译与运行

```bash
cd ~/ros2_ws
colcon build --packages-select cpp_demo    # 只编这个包
source install/setup.bash                  # 新终端都要重新 source
ros2 run cpp_demo talker
```

> ✅ 你应该看到 **`Summary: 1 package finished`**——只有这行出现才算成功，看到 `Failed` 就往上翻报错。`ros2 run` 后安静停住是正常的；另开终端 source 后跑 `ros2 topic hz hello`，应约 `2.000` Hz。跑不起来先看是不是没 source。

> 💡 类比：`colcon build` 是组好零件封罐入库（装进 `install/`），`source install/setup.bash` 是把仓库钥匙挂到腰上，`ros2 run` 才是取货。**换终端等于换人，钥匙要重挂。**

---

## 🎯 课后练习（约4分钟）

1. 照第 1~3 节建好 `cpp_demo`、编译、运行，并用 `ros2 pkg executables cpp_demo` 确认注册成功。
2. 把 `500ms` 改成 `100ms` 重新编译，再看 `ros2 topic hz hello`。

> ✅ 你应该看到：前者输出 `cpp_demo talker`，后者从 2.000 Hz 变成 10.000 Hz。**C++ 包改了源码必须重新编译**（Python 包加 `--symlink-install` 后可免编译）。

## 本讲小结

| 要点 | 说明 |
|---|---|
| 建骨架 | `ros2 pkg create --build-type ament_cmake cpp_demo` |
| 登记目标 | `add_executable` + `ament_target_dependencies` + `install(... DESTINATION lib/${PROJECT_NAME})` |
| 两份清单 | `CMakeLists.txt`（怎么编）与 `package.xml`（依赖谁）必须同时改 |
| 编译运行 | 工作空间根目录 `colcon build --packages-select cpp_demo`，新终端 source 后 `ros2 run <包> <可执行文件>` |

## 1. 从源码到能跑的程序

你写的 `talker.cpp` 就是一份纯文本，CPU 不认识它。它要过三关：**编译（compile）**把源码翻成机器码、**链接（link）**把机器码和依赖库拼到一起、**安装（install）**把生成的东西放到约定的目录。这三关的手工命令很长，敲一次还行，十次就是灾难。

**构建系统（build system）**就是替你干这件事的程序：你把「有哪些源文件、依赖哪些库、产物叫什么名字」写进配置文件，它负责把整套跑完。CMake 是 C/C++ 世界里用得最广的一个，配置文件固定叫 **CMakeLists.txt**。

> 💡 类比：源码像一份菜谱，写着「加盐少许」；构建系统像后厨领班，负责把「少许」翻译成「3 克、第 4 步放」，并盯着每一步做完。

## 2. ROS 2 的两种包

功能包（package）是 ROS 2 里最小的代码组织单位，也是最小的构建单位。按用什么语言写，分成两种：

| 包类型 | 构建类型（build type） | 必需文件 | 源码放哪 |
|---|---|---|---|
| C++ 包 | `ament_cmake` | `CMakeLists.txt` | `src/` |
| Python 包 | `ament_python` | `setup.py` | 包名同名目录 |

`ament_cmake` 是 ROS 2 在标准 CMake 之上加的一层宏（macro），把「找 ROS 依赖」「把自己注册进 ROS 索引」这些 ROS 特有的活儿包了起来。

**本模块最该记住的一条对照**：Python 包用 `setup.py` 登记可执行文件，**不需要 CMakeLists.txt**；C++ 包不需要 `setup.py`，**但一定要 CMakeLists.txt**。05 讲里那个 talker 是 Python 包，配的是 `setup.py`——本模块补的正是 C++ 包这一半。

## 3. 一个功能包里有什么

```text
cpp_demo/
├── package.xml       # 包清单：我叫什么、我依赖谁
├── CMakeLists.txt    # 构建说明：怎么把我编译出来
└── src/talker.cpp    # 源码
```

- **package.xml（包清单，package manifest）**：给工具和别的包看的，`colcon`、`rosdep` 靠它认依赖并自动装。
- **CMakeLists.txt**：给 CMake 看的。声明源文件在哪、链接哪个库、产物装到哪。

两份文件职责不同，却必须对齐：包清单里声明了依赖，构建脚本才能 `find_package` 找到它（下一讲逐行讲）。

> ⚠️ 常见坑：只改一份是新手最常翻的车。改了 `CMakeLists.txt` 忘了 `package.xml`，本机编译照样过，**但别人依赖你的包、或者换台机器安装时才会失败**——报错的时间点和出错的地方完全对不上。

## 🎯 课后练习（约4分钟）

对着系统里现成的包验证上面那张表（包名以你机器上为准）：

```bash
# 1. 看看当前环境里有哪些包
ros2 pkg list | head -n 8

# 2. 一个 C++ 包的构建类型
grep -h build_type /opt/ros/humble/share/turtlesim/package.xml

# 3. 一个 Python 包的构建类型（和第 2 条对比）
grep -h build_type /opt/ros/humble/share/demo_nodes_py/package.xml
```

> ✅ 你应该看到：第 1 条是一串 ROS 包名；第 2 条输出 `<build_type>ament_cmake</build_type>`，第 3 条输出 `<build_type>ament_python</build_type>`。两个包干的事类似，构建类型却完全不同——决定用哪套文件的，是**写包时选了哪种语言**。

## 本讲小结

| 要点 | 说明 |
|---|---|
| 构建系统 | 把编译、链接、安装自动做完的程序；CMake 的配置文件固定叫 `CMakeLists.txt` |
| C++ 包 | 构建类型 `ament_cmake`，必须写 `CMakeLists.txt`，**不需要** setup.py |
| Python 包 | 构建类型 `ament_python`，必须写 `setup.py`，**不需要** CMakeLists.txt |
| ament_cmake | ROS 2 在标准 CMake 上加的宏层，提供 `ament_*` 命令 |
| 两份清单 | `package.xml` 声明「依赖谁」，`CMakeLists.txt` 声明「怎么编」，必须对齐 |
| 怎么看现成包 | `ros2 pkg list`，或翻 `share/<包名>/package.xml` |

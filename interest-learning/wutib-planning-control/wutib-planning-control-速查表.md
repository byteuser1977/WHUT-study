# 规控组知识速查表

## 控制理论

| 概念 | 要点 |
|------|------|
| 开环控制 | 不关心执行结果，结构简单，抗干扰差 |
| 闭环控制 | 引入反馈，自动纠偏，鲁棒性强 |
| PID | 比例 P(偏差) + 积分 I(累积误差) + 微分 D(变化趋势) |
| Stanley | 几何类横向控制：航向误差 + arctan(横向误差) |
| MPC | 模型预测控制，滚动优化，处理约束 |

## Stanley 算法参数

| 参数 | 含义 | 调参方向 |
|------|------|----------|
| k_e | 横向误差增益 | ↑ 纠偏更激进，可能振荡 |
| k_s | 低速软化系数 | ↑ 低速更平滑 |
| k_d | 阻尼增益 | ↑ 抑制振荡更强，响应变慢 |
| δ_max | 最大转角 | 取决于机械结构 |

## Frenet 坐标系

| 轴 | 含义 | 正方向 |
|----|------|--------|
| s | 沿路径弧长 | 前进方向 |
| d | 横向偏移 | 左侧为正 |

## 路径规划代价因素

- 路径长度（越短越好）
- 曲率/平滑度（越小越好）
- 障碍物距离（越远越好）
- 路面平整度（越平越好）
- 车道保持（偏离中心线越少越好）

## ROS 2 核心术语

| 术语 | 一句话 |
|------|--------|
| 节点 Node | 独立运行的程序单元 |
| 话题 Topic | 异步消息通道 |
| 发布/订阅 | 往话题发/从话题收消息 |
| 回调 Callback | 收到消息后触发的函数 |
| 生命周期节点 | 可管理状态（未激活→激活→关闭） |

## 双系统 vs 虚拟机

| | 双系统 | 虚拟机 |
|--|--------|--------|
| 性能 | 原生 | 有损耗 |
| 硬件访问 | 全部 | 部分受限 |
| 切换 | 重启 | 随时 |
| 适用 | 开发/实车 | 学习/轻量开发 |

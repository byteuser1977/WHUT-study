---

## 1. apt 命令（Ubuntu/Debian）

```bash
# 更新软件列表（必须先更新才能装新软件）
sudo apt update

# 升级所有已安装的软件
sudo apt upgrade

# 安装软件
sudo apt install nginx

# 卸载软件
sudo apt remove nginx

# 卸载 + 删除配置文件
sudo apt purge nginx

# 搜索软件
apt search nginx

# 查看已安装的软件
dpkg -l | grep nginx
```

> 💡 `-y` = 自动确认（不再问"是否继续"），适合脚本和练习；手工安装时可以先不加，让它列出将要装什么。

## 2. CentOS/RHEL 对应命令

| Ubuntu (apt) | CentOS (yum/dnf) |
|-------------|-------------------|
| `apt update` | `yum makecache` |
| `apt upgrade` | `yum update` |
| `apt install xxx` | `yum install xxx` |
| `apt remove xxx` | `yum remove xxx` |
| `apt search xxx` | `yum search xxx` |
| `dpkg -l` | `rpm -qa` |
| `dpkg -i x.deb` | `rpm -ivh x.rpm` |
| `apt autoremove` | `yum autoremove` |

> 💡 RHEL 8+ / CentOS 8+ 默认用 `dnf`，`yum` 是它的软链接（旧习惯仍可用），命令写法一样。

## 3. 软件源是什么

软件源（Repository）就是一个**在线软件仓库**，apt 从这里下载软件包。

配置文件位置：
- 老格式：`/etc/apt/sources.list`
- Ubuntu 24.04+ 默认是 deb822 格式：`/etc/apt/sources.list.d/ubuntu.sources`
- 自己加的源通常放在：`/etc/apt/sources.list.d/*.list`

```bash
# 查看当前软件源
cat /etc/apt/sources.list

# Ubuntu 24.04+ 还可以看这个
cat /etc/apt/sources.list.d/ubuntu.sources
```

> 💡 国内用户可以换阿里云/清华源加速下载，搜索"Ubuntu 换源教程"即可。**改完必须执行 `sudo apt update` 才生效。**

## 4. 手动安装 .deb 包

```bash
# 安装下载好的 .deb 文件
sudo dpkg -i package.deb

# 修复依赖问题
sudo apt install -f

# 现代写法：直接让 apt 装本地 deb，依赖会自动处理
sudo apt install ./package.deb
```

### 顺手记的几条

```bash
apt list --upgradable      # 有哪些包可以升级
apt-cache policy nginx     # 这个包会从哪个源装、装哪个版本
```

## 5. 常用软件安装示例

```bash
# 编辑器
sudo apt install vim nano

# 网络工具
sudo apt install curl wget net-tools

# Git
sudo apt install git

# Python
sudo apt install python3 python3-pip

# 压缩解压
sudo apt install zip unzip tar

# 系统监控
sudo apt install htop tree
```

## 🎯 课后练习（约5分钟）

```bash
# 1. 更新软件列表
sudo apt update

# 2. 安装 tree 命令（目录树展示工具）
sudo apt install tree -y

# 3. 用 tree 看看 /etc 的目录结构（只看一层）
tree -L 1 /etc

# 4. 安装 htop（任务管理器）
sudo apt install htop -y

# 5. 运行 htop 看看（按 q 退出）
htop
```

> ✅ 你应该看到（类似）：
> ```
> 命中:1 http://archive.ubuntu.com/ubuntu jammy InRelease
> ...
> /etc
> ├── PackageKit
> ├── X11
> ├── apt
> ...
> （htop 打开一个彩色界面，按 q 退出）
> ```

## 本讲小结

| 命令 | 用途 |
|------|------|
| `apt update` | 更新软件列表 |
| `apt upgrade` | 升级已安装软件 |
| `apt install xxx` | 安装软件（`-y` 自动确认） |
| `apt remove xxx` | 卸载软件 |
| `apt purge xxx` | 卸载 + 删除配置文件 |
| `apt search xxx` | 搜索软件 |
| `dpkg -l` | 查看已安装的软件 |
| `dpkg -i x.deb` | 安装本地 .deb 包（依赖问题用 `apt install -f` 修） |

# 第06讲：用户与权限（正文约5分钟 + 练习约5分钟）

## 你将学到
- root 用户和普通用户的区别
- sudo 和 su 的用法
- 文件权限是什么，怎么改

---

## 1. 两种用户

| 类型 | 提示符 | 能力 |
|------|--------|------|
| **root**（超级用户） | `#` | 什么都能干，删系统也没人拦 |
| **普通用户** | `$` | 只能管自己的文件 |

> ⚠️ 日常用普通用户操作，需要提权时再用 root。永远不要长期用 root。

## 2. sudo：临时提权

```bash
# 用管理员权限执行一条命令
sudo apt update

# 获取 root shell（推荐写法）
sudo -i

# 历史写法，效果和 sudo -i 相同
sudo su
```

> 💡 `sudo` 的准确含义是"以另一个用户（默认 root）的身份执行命令"。输入的是**你自己的密码**，不是 root 密码。

## 3. su：切换用户

```bash
su - root       # 切换到 root（需输入 root 密码；Ubuntu 下通常走不通，见下）
su - "$USER"    # 切换到指定用户（$USER 就是你自己的用户名）
exit            # 退出当前用户，回到上一个用户
```

> ⚠️ Ubuntu 默认不给 root 设密码、也禁用 root 登录，提权请用 `sudo` / `sudo -i`；`su` 主要用于切换到其他普通用户。

## 4. 文件权限详解

用 `ls -la` 看到的权限长这样：

```
-rw-r--r--  1 bit bit  220 Sep 17 10:00 file.txt
drwxr-xr-x  2 bit bit 4096 Sep 17 10:00 mydir
│ │  │  │
│ │  │  └── 其他用户（o）
│ │  └───── 用户组（g）
│ └──────── 文件所有者（u）
└────────── 文件类型（d=目录, -=文件, l=软链接）
```

**权限含义**：

| 权限 | 对文件 | 对目录 |
|------|--------|--------|
| `r`（读） | 可以查看内容 | 可以列出内容 |
| `w`（写） | 可以修改内容 | 可以在目录中增删文件 |
| `x`（执行） | 可以运行 | 可以进入目录 |

示例：`rwxr-xr--`
- 所有者：读+写+执行
- 用户组：读+执行
- 其他人：只读

## 5. chmod：修改权限

### 数字法（推荐记忆）

| 数字 | 权限 |
|------|------|
| 7 | rwx（读+写+执行） |
| 6 | rw-（读+写） |
| 5 | r-x（读+执行） |
| 4 | r--（只读） |
| 3 | -wx（写+执行） |
| 2 | -w-（只写） |
| 1 | --x（只执行） |
| 0 | ---（无权限） |

```bash
chmod 755 script.sh    # 所有者rwx，组r-x，其他人r-x
chmod 644 file.txt     # 所有者rw-，组r--，其他人r--
chmod 700 private/     # 只有所有者能访问
```

> 💡 **速记**：755 给脚本，644 给文件，700 给私有目录，600 给私有文件。

### 符号法

```bash
chmod +x script.sh     # 加执行权限
chmod -w file.txt      # 去掉写权限
chmod u+x script.sh    # 只给所有者加执行
chmod g+w shared.txt   # 给用户组加写权限
chmod o-r file.txt     # 去掉其他人的读权限
```

> ⚠️ 不要对系统文件乱 `chmod` / `chown`：`chmod -R 777 /` 这类事故会直接毁掉系统，`/etc/passwd` 权限错了会让所有人都登录不了。
> 💡 `umask`：新建文件的默认权限由它决定（Ubuntu 默认 022），这就是新文件是 644、新目录是 755 的原因。

## 6. chown：修改所有者

```bash
sudo chown "$USER" file.txt              # 改所有者（改成你自己）
sudo chown "$USER:$USER" file.txt        # 同时改所有者和组
sudo chown -R "$USER:$USER" mydir/       # 递归改整个目录
sudo chown root:root script.sh           # 改为 root 所有
```

> ⚠️ 普通用户**不能**把文件交给别人：改所有者属于管理员操作（不加 `sudo` 会报 `Operation not permitted`）。这也是"不要对系统文件乱 chown"的原因。

## 🎯 课后练习（约5分钟）

```bash
# 1. 创建测试文件
touch ~/testfile.txt
ls -la ~/testfile.txt

# 2. 改为只有自己能读写
chmod 600 ~/testfile.txt
ls -la ~/testfile.txt

# 3. 改为所有人可读
chmod 644 ~/testfile.txt
ls -la ~/testfile.txt

# 4. 创建一个脚本并赋予执行权限
echo 'echo "Hello from script"' > ~/myscript.sh
chmod +x ~/myscript.sh
~/myscript.sh
# 正式的脚本第一行要写 #!/bin/bash（第10讲详解）

# 5. 清理
rm ~/testfile.txt ~/myscript.sh
```

> ✅ 你应该看到（类似）：
> ```
> -rw-r--r-- 1 bit bit 0 Sep 17 10:00 /home/bit/testfile.txt
> -rw------- 1 bit bit 0 Sep 17 10:00 /home/bit/testfile.txt
> -rw-r--r-- 1 bit bit 0 Sep 17 10:00 /home/bit/testfile.txt
> Hello from script
> ```

## 本讲小结

| 概念 | 要点 |
|------|------|
| root | 超级用户，提示符为 `#` |
| sudo | 临时以管理员执行命令 |
| su | 切换用户（Ubuntu 下 root 请用 sudo -i） |
| chmod | 修改权限（755=脚本，644=文件，600=私有文件） |
| chown | 修改所有者（必须加 sudo） |

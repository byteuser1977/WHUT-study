## 1. Linux 目录结构：一棵倒着的树

Windows 有 C盘、D盘、E盘……Linux 没有盘符，**所有东西都在根目录 `/` 下面**。

```
/                    ← 根目录（一切的起点）
├── home/            ← 用户的家（相当于 Windows 的 C:\Users）
│   └── bit/         ← 你的个人目录（用 ~ 表示）
├── etc/             ← 系统配置文件
├── var/             ← 日志、缓存等可变数据
├── usr/             ← 系统程序与资源（/usr/bin 命令、/usr/lib 库、/usr/share 共享数据）
├── tmp/             ← 临时文件（重启可能清空）
├── bin/             ← → /usr/bin（软链接；现代发行版已并入 /usr）
├── root/            ← root 用户的家目录
├── dev/             ← 设备文件
├── proc/            ← 进程信息（虚拟目录）
└── mnt/             ← 挂载点（比如 WSL 里的 /mnt/c 就是 Windows 的 C 盘）
```

> 💡 现在 /bin、/sbin、/lib 都是指向 /usr 下同名目录的软链接，这是 2019 年之后的惯例。

> 💡 记住这 5 个就够日常用了：`/home` `/etc` `/var` `/usr` `/tmp`

## 2. 三个核心导航命令

### pwd — 我在哪？

```bash
pwd
# 输出：/home/bit
# 显示当前所在目录的完整路径
```

### cd — 去哪

```bash
cd /etc          # 去绝对路径（从根目录开始）
cd /home/bit     # 同上

cd Documents     # 去相对路径（从当前目录开始）
# 注意大小写：家目录下实际是 Documents，敲成 documents 会 No such file or directory
cd ..            # 回到上一级目录
cd ../..         # 回到上两级
cd ~             # 回到家目录（等同于 cd /home/bit）
cd               # 不加参数 = 回家目录
cd -             # 回到上一次的目录（超好用！）
```

### ls — 有什么

```bash
ls               # 列出当前目录的内容
ls -l            # 详细列表（权限、大小、日期）
ls -a            # 显示隐藏文件（以 . 开头的文件）
ls -la           # 组合使用：详细 + 隐藏文件
ls /etc          # 列出指定目录
ls -lh           # 文件大小用人类可读格式（KB/MB）
```

输出示例（真实终端的格式长这样）：
```
total 8
drwxr-xr-x  2 bit bit 4096 Sep 17 10:00 Documents
-rw-r--r--  1 bit bit  220 Sep 17 09:00 .bashrc
```

| 列 | 含义 |
|---|------|
| `drwxr-xr-x` | 类型+权限（d=目录，-=文件，l=软链接） |
| `2` | 硬链接数（这一列先不用深究） |
| `bit` | 所有者 |
| `4096` | 大小（字节） |
| `Sep 17 10:00` | 修改日期 |
| `Documents` | 文件名 |

> 💡 你的输出里还会有第一行 `total 8` 和 `.` / `..` 两行，这是正常的（`-a` 会把隐藏项和目录自身也列出来）。

## 3. 绝对路径 vs 相对路径

| 类型 | 含义 | 示例 |
|------|------|------|
| **绝对路径** | 从 `/` 开始的完整路径 | `/home/bit/Documents/report.txt` |
| **相对路径** | 从当前目录开始的路径 | `Documents/report.txt` |

```bash
# 假设当前在 /home/bit
ls Documents/report.txt     # 相对路径 ✓
ls /home/bit/Documents/report.txt  # 绝对路径 ✓
# 两种写法效果一样
```

## 🎯 课后练习（约5分钟）

```bash
# 1. 看看你在哪
pwd

# 2. 去根目录看看有什么
cd /
ls

# 3. 去 /etc 目录，列出所有文件
cd /etc
ls

# 4. 回到家目录
cd ~

# 5. 查看隐藏文件
ls -la

# 6. 用 cd - 回到刚才的 /etc
cd -

# 7. 感受绝对路径与相对路径的区别
cd /var/log           # 绝对路径
pwd                   # → /var/log
cd /                  # 回根目录
cd var/log            # 相对路径（从 / 出发）
pwd                   # 同样 → /var/log

# 8. 读一读 ls -l 的每一列（对照上面的字段表）
cd /etc && ls -l | head -3
```

> ✅ 你应该看到（类似）：
> ```
> /home/bit
> （cd / 后 ls 列出 bin boot dev etc home ...）
> /var/log
> /var/log
> total 876
> drwxr-xr-x 2 root     root       4096 Apr 23 06:03 PackageKit
> drwxr-xr-x 9 root     root       4096 Jan  2  2024 X11
> ```

## 本讲小结

| 概念 | 要点 |
|------|------|
| `/` | 根目录，一切的起点 |
| `~` | 家目录，你的个人空间 |
| `pwd` | 显示当前目录 |
| `cd` | 切换目录（`..` 上一级，`-` 上一次） |
| `ls` | 列出内容（`-la` 最常用） |
| 绝对路径 | 从 `/` 开始 |
| 相对路径 | 从当前目录开始 |

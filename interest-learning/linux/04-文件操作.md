# 第04讲：文件操作（正文约5分钟 + 练习约5分钟）

## 你将学到
- 创建、复制、移动、删除文件和目录
- 通配符（wildcard）的用法
- 查找文件

---

## 1. 创建文件和目录

```bash
# 创建空文件
touch myfile.txt

# 创建目录
mkdir mydir

# 一次性创建多级目录
mkdir -p a/b/c/d
```

> 💡 `-p` = parents：父目录不存在也一路建出来；目录已存在也不报错（可重复执行）。

## 2. 复制文件和目录

```bash
# 复制文件
cp myfile.txt backup.txt

# 复制到指定目录
cp myfile.txt /tmp/

# 复制整个目录（必须加 -r）
cp -r mydir mydir_backup
```

> ⚠️ 复制目录忘了加 `-r` 会报错，这是新手最常见的错误之一。

> 💡 目标是文件还是目录？`cp file1.txt backup/` → 拷进目录；`cp file1.txt copy.txt` → 复制成新名字；目标不存在时会直接创建。`mv` 同理。

## 3. 移动/重命名

```bash
# 移动文件
mv myfile.txt /tmp/

# 重命名文件（移动到同目录 = 重命名）
mv oldname.txt newname.txt

# 移动整个目录
mv mydir /tmp/
```

> 💡 `mv` 是"移动"，但在同一目录下移动 = 重命名。一石二鸟。

## 4. 删除文件和目录

```bash
# 删除文件（注意：rm 默认就不会问你，删了就是删了）
rm myfile.txt

# 删除目录（必须加 -r）
rm -r mydir

# -f = 强制：文件不存在也不报错、写保护文件也不询问
rm -rf mydir
```

> ⚠️⚠️⚠️ **最高级警告**：`rm -rf` 是 Linux 中最危险的命令之一。
> 
> 绝对不要运行：`rm -rf /` — 这会删掉整个系统。
> 
> 绝对不要运行：`rm -rf *` — 这会删掉当前目录下所有文件。
> 
> **安全习惯**：删除前先 `ls` 确认目标，养成 `rm` 前多看一眼的习惯。

```bash
# 给自己上一道保险：每次删除都问一句
alias rm='rm -i'      # 想让它在每次开终端时都生效，就写进 ~/.bashrc
```

## 5. 通配符：批量匹配

```bash
# * 匹配任意字符
ls *.txt          # 列出所有 .txt 文件
ls *.log          # 先看看到底会删哪些
rm *.log          # 确认无误再删
cp *.jpg /tmp/    # 复制所有 .jpg 到 /tmp

# ? 匹配单个字符
ls file?.txt      # 匹配 file1.txt, file2.txt 等（不匹配 file10.txt）
```

## 6. 查找文件

```bash
# 先在家目录里找（快，且不会刷一屏权限错误）
find ~ -name "myfile.txt"

# 要在全盘找，记得把报错丢掉，并做好等待几秒到几十秒的准备
find / -name "myfile.txt" 2>/dev/null

# 在当前目录下找所有 .py 文件
find . -name "*.py"

# 只找目录
find /home -type d -name "Downloads"
```

> 💡 别一上来就 `find /`：普通用户会遇到大量 `Permission denied`，而且全盘搜索很慢。

## 🎯 课后练习（约5分钟）

```bash
# 1. 创建一个练习目录
mkdir -p ~/linux-practice
cd ~/linux-practice

# 2. 创建几个文件
touch file1.txt file2.txt file3.txt

# 3. 创建子目录并复制文件进去
mkdir backup
cp file1.txt backup/

# 3.5 练通配符与查找
touch a.log b.log file10.txt
ls *.log              # → a.log b.log
ls file?.txt          # → file1.txt file2.txt file3.txt（? 只匹配一个字符，不含 file10.txt）
find . -name "*.txt"

# 4. 重命名文件
mv file2.txt renamed.txt

# 5. 列出所有文件确认
ls -la
ls -la backup/

# 6. 安全地删除练习目录：先确认，再删，再验证
cd ~
pwd                     # 确认自己在 /home/你的用户名，不是在 /etc 之类的地方
ls -la linux-practice   # 确认这就是刚才建的练习目录
rm -rf linux-practice   # 确认无误后再删
ls -la                  # 验证它真的没了
```

> ✅ 你应该看到（类似）：
> ```
> a.log b.log
> file1.txt file2.txt file3.txt
> /home/bit
> /home/bit
> ```
> （最后的 `ls -la` 里应该已经找不到 linux-practice 这一项）

## 本讲小结

| 命令 | 用途 | 示例 |
|------|------|------|
| `touch` | 创建空文件 | `touch file.txt` |
| `mkdir -p` | 创建目录（含多级） | `mkdir -p a/b/c` |
| `cp` / `cp -r` | 复制文件/目录 | `cp -r dir1 dir2` |
| `mv` | 移动/重命名 | `mv old.txt new.txt` |
| `rm -r` | 删除目录 | `rm -r mydir` |
| `rm -rf` | ⚠️ 强制删除（不可恢复） | 先 `ls` 确认目标再用 |
| `find` | 查找文件 | `find ~ -name "*.txt"` |

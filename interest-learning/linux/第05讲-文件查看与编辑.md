## 你将学到

---

## 1. 查看文件内容

```bash
cat file.txt          # 一次性显示全部内容（小文件用）
less file.txt         # 分页查看（大文件用，按 q 退出）
head -n 20 file.txt   # 只看前 20 行
tail -n 20 file.txt   # 只看后 20 行
tail -f logfile.log   # 实时跟踪文件变化（看日志神器）
```

> 💡 `less` 比 `cat` 好在：文件很大时不会刷屏，可以一页一页翻。
> 
> 快捷键：`Space` 翻下一页，`b` 翻上一页，`/关键词` 搜索。

## 2. 管道符 `|`：命令串联

管道符（pipe）把上一个命令的输出，变成下一个命令的输入。先记住两个常用搭档：`grep 关键词` = 从输入里筛出含关键词的行；`wc -l` = 数行数。

```bash
# 列出 /etc 下所有文件，只看包含 "pass" 的行
ls /etc | grep pass

# 统计当前目录下的普通文件个数（推荐，结果最准确）
find . -maxdepth 1 -type f | wc -l

# 顺带记住这个坑：ls -la | wc -l 会比真实文件数多 3
# （多算了 total 一行 + . 和 .. 两行）
ls -la | wc -l

# 当前目录里体积最大的几个条目
ls -lhS | head -10

# 想更靠谱地看谁占地方（含子目录），用这个
du -sh * | sort -rh | head
```

> 🎯 类比：管道就像工厂流水线，A 工序做完传给 B，B 做完传给 C。可以一路串下去，比如 `ls /etc | grep pass | wc -l`。

## 3. 重定向：把输出写到文件

```bash
# > 覆盖写入
echo "Hello Linux" > greeting.txt

# >> 追加写入
echo "Line 2" >> greeting.txt

# 把命令输出保存到文件
ls -la > filelist.txt

# 把错误信息也保存（2>&1）
find /etc -name "*.conf" > results.txt 2>&1
```

| 符号 | 含义 |
|------|------|
| `>` | 覆盖写入（原来的内容会消失） |
| `>>` | 追加（在末尾添加） |
| `<` | 输入重定向：把文件当命令的输入（`sort < file.txt`） |
| `2>` | 只把错误输出写到文件（`cmd 2> err.log`） |
| `2>/dev/null` | 丢弃错误输出（不想看那一屏报错） |
| `2>&1` | 把错误输出也一起保存 |

> 💡 三种常见组合对照：`cmd 2> err.log`（只留错误）、`cmd 2>/dev/null`（扔掉错误）、`cmd > out 2>&1`（错误和正常输出都进同一个文件）。

## 4. nano 编辑器（推荐新手）

```bash
nano greeting.txt
```

操作方式：
| 按键 | 功能 |
|------|------|
| 方向键 | 移动光标 |
| 直接打字 | 输入内容 |
| `Ctrl + O` | 保存（Write Out） |
| `Ctrl + X` | 退出 |
| `Ctrl + K` | 剪切一行 |
| `Ctrl + U` | 粘贴 |

> 💡 nano 就是"打开→改→保存→退出"，零学习成本。

## 5. vim 编辑器（进阶必学）

> 💡 第一遍只需记住下面的"三步走"，hjkl / dd / yy 以后回来再查这张表也行。

```bash
vim greeting.txt
```

vim 有三种模式：

| 模式 | 进入方式 | 用途 |
|------|---------|------|
| **普通模式** | 启动默认 | 按键执行命令（移动、删除等） |
| **插入模式** | 按 `i` | 输入文字 |
| **末行模式**（命令行模式 / Command-line mode） | 按 `:` | 保存退出等操作 |

> 💡 按 `:` 进入，回车执行，执行完自动回到普通模式。

**新手三步走**：
1. 按 `i` → 进入插入模式（可以打字了）
2. 编辑完后按 `Esc` → 回到普通模式
3. 输入 `:wq` → 保存并退出（w=write, q=quit）

| 常用命令 | 功能 |
|---------|------|
| `h j k l` | 光标移动：左 下 上 右（方向键同样可用） |
| `i` | 进入插入模式 |
| `Esc` | 回到普通模式 |
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` | 保存并退出 |
| `:q!` | 强制退出（不保存） |
| `dd` | 删除当前行 |
| `yy` | 复制当前行 |
| `p` | 粘贴 |
| `/关键词` | 搜索 |

> 🆘 卡住了怎么办：按几次 `Esc`，再输入 `:q!` 回车（强制退出、不保存）。

> 💡 最小化安装的镜像 / 服务器版常常只有 `vi` 没有 `nano`（`sudo apt install nano` 可装）；`vi` 的用法和 vim 基本一致。

> 🎯 新手建议：先用 nano，等熟悉了再学 vim。vim 学会了效率翻倍，但学习曲线陡。

## 🎯 课后练习（约5分钟）

```bash
# 1. 用 echo 创建文件
echo "Hello, I am learning Linux" > ~/test.txt

# 2. 用 cat 查看
cat ~/test.txt

# 3. 追加内容
echo "Line 2" >> ~/test.txt
echo "Line 3" >> ~/test.txt
cat ~/test.txt

# 4. 用 less 分页查看
less ~/test.txt

# 5. 用 nano 编辑（Ctrl+O 保存，Ctrl+X 退出）
nano ~/test.txt

# 6. 清理
rm ~/test.txt
```

> ✅ 你应该看到（类似）：
> ```
> Hello, I am learning Linux
> Hello, I am learning Linux
> Line 2
> Line 3
> ```

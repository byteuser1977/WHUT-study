## 1. 什么是终端

终端（Terminal）就是一个**黑窗口**，你在里面输入文字命令，Linux 就执行。

打开方式：
- **WSL（Windows，本教程推荐）**：在开始菜单搜索 "Ubuntu" 打开
- **Ubuntu 桌面版**：按 `Ctrl + Alt + T`
- **远程服务器**：用 SSH 工具连接（第09讲会讲）

打开后你会看到类似这样的提示符：

```
bit@my-pc:~$
```

| 部分 | 含义 |
|------|------|
| `bit` | 你的用户名 |
| `@` | 分隔符 |
| `my-pc` | 主机名（电脑名字） |
| `~` | 当前目录（`~` 表示家目录 home） |
| `$` | 普通用户（`#` 表示 root 超级用户） |

> 💡 提示符（prompt）：示例里的 `bit` 是用户名占位符，你自己的会不一样（用 `whoami` 查看）。

## 2. 命令行怎么用

输入命令的格式：

```
命令  [选项]  [参数]
```

示例：
```bash
ls -la /home
│   │   └── 参数：要操作的对象（这里指查看哪个目录）
│   └────── 选项：-l 详细列表，-a 显示隐藏文件
└────────── 命令：列出文件
```

> ⚠️ Linux 命令区分大小写：`ls` 和 `LS` 不是一回事。

### 最常见的两种报错

```bash
ls /tmp
lss /tmp      # 命令敲错 → bash: lss: command not found
LS            # 大小写敲错 → bash: LS: command not found（Linux 区分大小写）
```

看到 `command not found`，先检查拼写和大小写。

## 3. 两个神级快捷键

### Tab 键：自动补全

```bash
# 输入下面内容，然后按 Tab：
ls /et          # 按 Tab → 自动补全为 ls /etc/
cat /usr/b      # 按 Tab → 自动补全为 cat /usr/bin/

# 匹配不唯一时：按一次 Tab 不动，再按一次列出全部候选
ls /usr/s       # 按一次 Tab 无反应 → 再按一次，列出 /usr/sbin /usr/share /usr/src
```

**按一次** Tab：自动补全唯一匹配项。
**按两次** Tab：列出所有可能的匹配项。

> 🎯 这是 Linux 中最重要的快捷键，没有之一。养成习惯，能少打一半字。

### 方向键 ↑↓：历史记录

- `↑` 上翻：回到上一条命令
- `↓` 下翻：回到下一条命令

> 这样就不用反复输入重复命令了。

## 4. 清屏与中断

```bash
clear       # 清屏（快捷键 Ctrl + L 也可以）
```

- `Ctrl + L`：清屏
- `Ctrl + C`：终止当前命令（命令像卡住不动时的第一反应）

## 🎯 课后练习（约5分钟）

1. 打开终端，输入 `whoami`，看看输出什么
2. 输入 `ls /e` 然后按 **Tab**，观察自动补全效果
3. 输入 `pwd`，看看你在哪个目录
4. 按 `↑`，你会发现刚才的 `pwd` 命令又出现了
5. 按 `Ctrl + L` 清屏

> ✅ 你应该看到（类似）：
> ```
> bit
> /home/bit
> ```
> （第 2 步的 `ls /e` 按 Tab 后会补全成 `ls /etc/`）

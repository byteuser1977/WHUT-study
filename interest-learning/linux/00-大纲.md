# Linux 入门快速教程（每讲约 10 分钟）

共 10 讲，每讲约 10 分钟（正文 5 分钟 + 练习 5 分钟），总计约 100 分钟

---

## 第01讲：Linux 是什么 & 为什么学
- Linux 简介（内核 vs 发行版）
- Linux vs Windows/macOS 的核心区别
- 常见发行版（Ubuntu/CentOS/Debian）
- 学习 Linux 的价值（服务器/DevOps/开发）
- 准备工作：Windows 用户安装 WSL

## 第02讲：终端与基本概念
- 什么是终端（Terminal）
- 命令行 vs 图形界面
- 终端窗口结构：提示符、用户名、主机名、路径
- 补全（Tab）与历史（↑↓）

## 第03讲：文件系统与导航
- Linux 目录结构（树形结构，根目录 /）
- 重要目录速记（/home, /etc, /var, /usr, /tmp）
- pwd / ls / cd 三大导航命令
- 绝对路径 vs 相对路径

## 第04讲：文件操作（创建/复制/移动/删除）
- touch / mkdir / cp / mv / rm
- 通配符：* 和 ?
- find 命令快速查找文件
- rm 的危险性与安全习惯

## 第05讲：文件查看与编辑
- cat / less / head / tail
- 管道符 | 与重定向 > >>
- nano 编辑器（新手友好）
- vim 入门（hjkl、插入、保存退出）

## 第06讲：用户与权限
- root 用户 vs 普通用户
- su / sudo 切换用户
- rwx 权限：读/写/执行
- chmod 修改权限（数字法 & 符号法）
- chown 修改所有者

## 第07讲：软件包管理
- apt（Ubuntu/Debian）基础命令
- yum/dnf（CentOS/RHEL）基础命令
- install / update / remove / search
- 软件源（repository）概念

## 第08讲：进程管理
- 什么是进程 vs 程序
- ps aux 查看进程
- top / htop 实时监控
- kill / killall 终止进程
- 后台运行 & nohup

## 第09讲：网络基础
- ip addr 查看 IP
- ping / curl 测试连通性
- ssh 远程连接
- wget / scp 文件传输
- 防火墙基础（ufw / firewalld）

## 第10讲：Shell 脚本入门
- 什么是 Shell 脚本
- 第一个脚本（hello.sh）
- 变量、条件判断、循环
- 权限与执行
- 实用小脚本示例
- 调试与退出码（bash -x / $?）

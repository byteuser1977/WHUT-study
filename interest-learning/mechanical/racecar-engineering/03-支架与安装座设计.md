## 1. 支架是受力构件

**支架/安装座**是把部件固定到车架上的受力构件，四项职能：**定位**（角度、高度、间隙）、**传力**（重力、惯性力、反作用扭矩传回车架）、**隔振限振**、**环境防护**（挡泥水石击、固定线束）。**它是"部件"与"车架"的唯一接口**——支架错了，再好的电机也白搭。

> 💡 类比：支架像**音响的脚架**——音箱再好，脚架一软一歪一晃，低音发浑、定位发飘。

## 2. 智能部件带来的 7 条新要求

**讲出 4~5 条并各有解释就到位了。**

1. **刚度与精度**：传感器测**相对位置与相对运动**，支架一变形读数就漂（助力突变、啮合异响）→ 安装点**局部加强**（加厚、翻边、加强筋）。
2. **位置精度与可调**：气隙、同轴度窗口很小，焊接变形 + 加工公差会累积超标 → **腰形孔**、**调整垫片**、**偏心套/可调拉杆**；可调就必须**防松**（弹垫、自锁螺母、螺纹胶）。
3. **动态与共振**：电机转频、路面冲击、阀块频率可能撞上支架固有频率，**振一下变振十下**→ **模态分析**避频；提刚度也提固有频率；必要时加减振衬套（代价是精度）。
4. **轻量化与拓扑**：限功率 → **车重是直接成本** → **用加强筋代替加厚**（材料离中性面越远刚度越高）、**拓扑优化**挖掉不受力的材料；**刚度优先的件未必适合换铝**（铝模量约为钢的 1/3）。
5. **装配与维修**：赛场边只能蹲着用一把内六角 → 螺栓头留扳手空间；换传感器不该拆半个车头；孔位不冲突，优先**抱箍/夹板**代替钻孔；线束留弯曲半径。
6. **防尘防水防振**：扬尘 → 防尘罩、传感器口朝下；泥水 → 挡泥板、抬高位置、防水接插件（IP）；石击 → 护板；冲击 → 减振衬套。**机械件怕"断"，电子件怕"脏、湿、振"。**
7. **电磁与热**：ECU、驱动器发热、舱内通风差 → 散热路径甚至隔热罩；电机与电磁阀是强干扰源、传感器是弱信号 → **强弱电分开走线**，金属支架搭接影响接地与屏蔽。

## 3. 纯机械 vs 智能部件：支架关注点对比

| 关注点 | 纯机械部件 | 智能部件（EPS/EHB/传感器/ECU） |
|--------|-----------|-------------------------------|
| 核心诉求 | 装得住、不脱落 | **装得准、不漂、不共振、不受污染** |
| 刚度 | "强度不失效" | "**变形不超限**"，刚度不足直接导致功能退化 |
| 动态 | 不抖、螺母不松 | **模态避开激励频段**，必要时隔振并权衡精度 |
| 环境/电气 | 防锈防磕碰 | 防尘防水（IP）、防石击、防高温、防电磁干扰；固定线束 |

> ⚠️ 只写"智能部件要求更高、精度更好"是结论，**没有"为什么"和"高在哪"等于没说**；正确答法：**哪个部件 → 对什么敏感 → 支架要满足什么要求**。

## 4. 六维度表述框架

> **一句话结论** → **六个维度各一句** → **一句结合车队实际落地**。

| 维度 | 一句话要点 | 落到具体部件 |
|------|-----------|--------------|
| **精度** | 保证间隙与同轴度，用腰形孔 + 垫片微调 | 扭矩/角度/轮速传感器 |
| **刚度** | 变形让测量与传动失真，按"变形不超限"设计 | EPS 电机座 |
| **动态** | 避开电机转频、路面冲击、阀块拍频 | 阀块、ECU、线束 |
| **环境** | 泥水扬尘 + 高温 + 电磁干扰 → 防水、防石击、屏蔽 | 接插件、ECU |
| **装配** | 工具可接近、拆装快、孔位不冲突 | 电子件安装点 |
| **轻量化** | 不靠堆厚度求刚度，用加强筋/拓扑优化 | CATIA `Rib` |

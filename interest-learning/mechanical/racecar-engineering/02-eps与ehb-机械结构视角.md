# 第02讲：EPS 与 EHB 的机械结构视角（正文约6分钟 + 练习约4分钟）

## 你将学到
- EPS、EHB 各由哪些部件组成
- 智能部件与纯机械部件的结构差异
- 为什么它们对**空间位置、安装刚度、同轴度**特别敏感（为第 03 讲铺路）

---

## 1. 两个缩写，别搞混

| 缩写 | 全称 | 中文 | 一句话理解 |
|------|------|------|-----------|
| **EPS** | Electric Power Steering | **电动助力转向** | 用**电机**帮你打方向盘 |
| **EHB** | Electro-Hydraulic Brake | **电控液压制动** | 脚踩的力经**电控 + 液压**传到轮缸 |

> ⚠️ EPS 不是电子稳定程序也不是电动驻车；EHB 不是"没有液压的刹车"（那是 EMB），它**仍有完整液压回路**，只是插进一套电控。

车队加装它们，是因为智能巴哈要让电脑能自己打方向、自己刹车——必须有**电信号驱动的执行机构**。

## 2. 部件清单

**EPS（手 → 前轮）**：**扭矩传感器**（测打方向力）+ 车速信号 → **EPS 控制单元（ECU）** → **助力电机** → **减速机构**（减速增扭）→ **转向机**（齿轮齿条）→ 转向拉杆 / 万向节 / 中间轴 → 前轮。按电机位置分**管柱 C-EPS**（好布置但离驾驶员近噪音大）、**小齿轮 P-EPS**、**齿条 R-EPS**（响应好但空间紧）——位置不同，支架受力与精度要求就不同。

**EHB（脚 → 轮缸）**：**踏板行程/力传感器** → **制动控制单元（ECU）** → **液压泵 + 蓄能器**（建压，取代真空助力器）+ **电磁阀块**（进液/出液/隔离阀）+ **压力传感器**（反馈）→ 轮缸 / 制动器。**传统车靠进气真空助力，EHB 靠电机泵建压**；断电靠隔离阀与备份液压通路保底。

## 3. 智能部件 vs 纯机械：差在哪

| 对比维度 | 纯机械部件 | 智能部件（EPS / EHB） |
|----------|-----------|----------------------|
| 动力来源 | 人力 + 机械放大（连杆、拉索、真空助力） | 电机 + 电控，**人力只是输入信号** |
| 信号链 | 脚 → 踏板 → 拉索/连杆 → 执行 | 传感器 → ECU → 电机/电磁阀 → 执行 |
| 失效模式 | 拉索断裂、连杆脱落，**人还留一半控制力** | 断电、传感器故障、ECU 死机，**可能完全失去助力** |
| 位置敏感度 | 低，装歪了人还能踩 | **高**：传感器间隙、同轴度都影响功能 |
| 对支架的要求 | 能固定 | 位置精度、刚度、避振、散热、走线 |

> 💡 类比：纯机械像**自行车刹车**——钢索一拉，力直接到刹车块。EPS/EHB 像**请了个翻译官**：你说中文（脚踩手转），它翻成电信号再传达；翻译官站不稳（支架软）、听不清（有间隙），后果比钢索断更可怕。

## 4. 三个敏感

1. **空间位置与间隙**：很多传感器是**非接触测量**（与齿圈要留几毫米气隙）。**支架变形超过间隙，信号就跳甚至丢失**——这不是精度问题，是功能失效。
2. **安装刚度**：电机有**反作用扭矩**。支架软会：变形→位置漂移、测量失真；**啮合中心距**改变→异响、磨损、助力不均；还会让驾驶员感到虚位、发飘。
3. **同轴度**：电机输出轴与减速机构输入轴不重合会产生**附加径向力**→轴承早期损坏、齿面偏载、噪音振动。靠**加工精度 + 装配定位 + 支架不变形**保证。

另有两点：**液压阀块不能共振**（电磁阀开合与泵脉动是拍频激励，会让阀芯动作不准、接头渗油）；**线束接插件要"活着"**（泥水扬尘冲击会磨破震松，**固定线束是设计要求，不是顺带**）。

## 本讲小结

| 概念 | 要点 |
|------|------|
| EPS | **电动助力转向**：扭矩传感器 + 车速 → ECU → 助力电机 → 减速机构 → 转向机 |
| EHB | **电控液压制动**：踏板传感器 → 制动 ECU → 泵 + 蓄能器 + 电磁阀块 → 轮缸；**仍有液压回路** |
| 本质差异 | 人力从"动力源"变成"输入信号"，中间插入传感器—ECU—执行链 |
| 三个敏感 | **空间位置与间隙**、**安装刚度**（变形→漂移/传动失准）、**同轴度**（附加径向力→轴承损坏） |
| 两个专属问题 | 阀块**共振**、线束接插件受**泥水振动** |
| 失效特征 | 机械件"突然断"，智能件"悄悄漂"，**更隐蔽** |

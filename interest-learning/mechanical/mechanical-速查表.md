# 机械组笔试速查表

> 考前/练习时快速翻。详细解释见对应讲次。软件以 **CATIA 2023 + ANSYS 2024 R2** 为基准，不同版本菜单位置可能有差异，**以你机器上为准**。

## 一、CATIA 常用操作与快捷方式

| 操作 | 怎么做 |
|---|---|
| 旋转视角 | 按住**鼠标中键**拖动 |
| 缩放 | 中键 + 右键拖动，或滚动中键 |
| 平移 | 中键 + 左键拖动 |
| 适应窗口 | `Fit All In`（一般在 `View` 菜单里） |
| 切标准视图（等轴测） | `View > Named Views`（已命名的视图） |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 保存 | `Ctrl+S`（`.CATPart` 单零件 / `.CATProduct` 装配体） |
| 显示/隐藏特征树 | `F3` |
| 多选 | 按住 `Ctrl` 逐个点选 |
| 加几何约束 | `Ctrl` 选中元素 → `Constraints Defined in Dialog Box`（对话框中定义的约束）→ 勾选关系 |
| 临时停用某特征 | 特征上右键 → `Deactivate`（停用）/ `Activate`（启用）——**排错神器** |

> 💡 `Deactivate` 的用法：模型出问题时把最后的圆角停用，一眼就能判断问题是不是圆角引起的。

## 三、草图完全约束自查表（对应 16 分）

```
□ 草图里所有元素都是绿色（完全约束）
□ 用"拖动试探法"逐个拖每个点和每条线 —— 拖不动 = 自由度为零
□ 位置尺寸链完整：第一个点用 Coincidence 钉在草图原点
□ 几何约束优先：平行/垂直/相切/同心/等长/对称，而不是堆尺寸
□ 没有紫色/红色的过约束或冲突约束提示
□ 退出 Sketcher 后，`Sketch` 特征名上没有需要更新的标记
```

| 现象 | 含义 | 怎么修 |
|---|---|---|
| 白色（或高亮色）| 欠约束，还能动 | 补几何约束或尺寸，用拖动试探法定位缺哪个自由度 |
| 绿色 | 完全约束 ✅ | 通过 |
| 紫色 / 红色 | 过约束、冲突 | `Ctrl+Z` 回退，或删掉多余的那一个约束 |
| 尺寸带括号 `( )` | 参考尺寸，不参与约束 | 想真正约束就改成驱动尺寸 |

> 💡 **一个点的自由度 = 2**。四个角点 + 一根线，理论自由度一堆；每加一个有效约束减一个自由度，减到 0 就是完全约束。

## 四、斜面草图定位三种做法（对应题面明确要求）

| 做法 | 怎么操作 | 优点 | 缺点 |
|---|---|---|---|
| ① 建角度/偏移参考平面 | 用 `Plane` 命令建一个相对底面转某个角度的平面 → 在新平面上画草图 | 最直观，斜面的角度关系一眼可见 | 参考平面建错时整个模型会跟着歪 |
| ② **侧面轮廓拉伸法**（推荐） | 在侧面（如 `YZ` 平面）画斜支撑板的**侧视轮廓**（含斜度）→ `Pad` 拉伸成板 | 斜面角度在草图里直接控制，最稳 | 需要在脑子里把侧视图想清楚 |
| ③ 先做竖直面再切 | 先 `Pad` 出竖直板 → 用带角度的 `Pocket` 切出斜面 | 步骤少 | 斜面的"厚度"不好控制，容易切出薄边 |

**三个典型错误**：
1. 角度尺寸标在了错误的参考上 → 改角度时整个模型散架
2. 斜面草图没钉在参考平面上 → 移动父特征时草图跟着跑
3. 先做圆角再做斜面 → 圆角被打断，特征树报错（**圆角永远放最后**）

## 五、孔与圆角（对应 7 分 + 圆角部分）

### Φ12 通孔

```
Hole → 选定位面 → 类型选 Simple（简单孔）+ 直径填 12
     → 底部选 "Up To Last" / "Through All" 做成通孔
     → 定位：在 Positioning 里用位置尺寸 + 同心约束把孔心定死
□ 通孔不能残留一层薄壁 —— 剖切看一眼
```

**`Hole` vs 画圆 + `Pocket`**：位置要精确、类型标准（通孔/盲孔/螺纹）就用 `Hole`；形状不规则、要跟其他轮廓配合才画圆 + `Pocket`。

### R11 圆角

| 圆角失败的常见原因 | 对策 |
|---|---|
| 半径大于相邻边长度 | 减小半径，或先加大那条边 |
| 相交处多个圆角互相干涉 | 分开做，或调顺序 |
| 圆角吃掉了后续特征要用的面 | 把圆角放到特征树**最后** |
| 相邻面本身有瑕疵（碎面/干涉）| 回去修父特征 |

**顺序铁律**：先大后小、先竖向棱边后水平棱边、圆角永远最后。

## 六、肋（Rib）命令要点（对应加分题 6 分）

```
1. 画轮廓草图（加强筋的形状，通常是个三角形或梯形）
2. 画中心线（Rib 的"扫掠路径"）
3. 退出草图 → Rib → 选轮廓 + 中心线
4. 检查肋与立板、底座是否真正相交（不相交会生成失败）
5. 轮廓草图和中心线都要完全约束
```

**为什么肋比"拉伸薄板"强**：加强筋是靠**高度**增加截面惯性矩 —— 截面惯性矩跟高度的三次方成正比，而抗弯强度跟惯性矩成正比。所以让筋"长高"比让板"变厚"划算得多（板厚只能线性提升，还增加重量）。

> ⚠️ 加分题草图也要全约束（5 分），别只顾着把肋做出来。

## 七、ANSYS Workbench 全流程

| 步 | 模块 | 做什么 | 单位 |
|---|---|---|---|
| ① | 拖 `Static Structural` | 建立分析系统 | — |
| ② | `Engineering Data` | 材料：杨氏模量、泊松比、密度 | MPa / 无量纲 / kg·m⁻³ |
| ③ | `Geometry` | 导入 CATIA 模型（或 SpaceClaim 简化） | mm |
| ④ | `Model > Mesh` | 划网格，关键处局部细化 | mm |
| ⑤ | `Model > Static Structural` | 加约束（`Fixed Support`）+ 载荷（`Force` / `Pressure` / `Displacement`） | N / MPa / mm |
| ⑥ | `Solve` | 求解，看是否收敛 | — |
| ⑦ | `Results` | 应力云图、变形图、安全系数 | MPa / mm |

> ⚠️ **单位制是最容易翻车的地方**：mm-N-MPa 是一套自洽单位制，全程不要混进 m 或 Pa。单位不一致的结果看着正常但全是错的。
> ⚠️ 网格必须做**网格无关性验证**：加密网格到结果基本不变，才算网格够细。

## 八、材料属性速查

| 属性 | 含义 | 钢（`Structural Steel`） | 铝（`Aluminum Alloy`） |
|---|---|---|---|
| 杨氏模量 Young's Modulus | "多难被拉长"，决定刚度 | 2.0×10⁵ MPa | 6.9×10⁴ ~ 7.1×10⁴ MPa |
| 泊松比 Poisson's Ratio | 拉长时横向收缩比例 | 0.3 | 0.33 |
| 密度 Density | 单位体积质量，重力/惯性载荷要用 | 7850 kg/m³ | 2700 ~ 2770 kg/m³ |

> 💡 记忆点：**铝的刚度只有钢的 1/3**，密度也差不多是 1/3 —— 这就是为什么"换铝不一定更强，只是更轻"，刚度不足的地方还得靠结构（筋、截面高度）去补。

## 九、车架两种典型工况（对应简答 1，10 分）

| | **弯曲工况 Bending** | **扭转工况 Torsion** |
|---|---|---|
| 载荷特点 | 对称载荷：前后轮同时受载 | 反对称载荷：左右轮一上一下 |
| 约束位置 | 加在**悬架与车架的连接点** | 三点约束 + 一点加载 |
| 典型做法 | 后悬架点 `Fixed Support`；前悬架点用 `Displacement` 只约束纵向横向，允许垂向自由 | 后轴两点 + 前轴左侧点约束垂向；前轴**右侧**点不加约束、只加力 |
| 输出指标 | **弯曲刚度** K_b = 总垂向载荷 / 最大垂向变形（N/mm）；最大应力、最大变形 | **扭转刚度** K_t = 力矩 / 扭转角（N·m/°）；最大应力 |
| 真实场景 | 直线高速通过颠簸路面、跳台落地冲击（车架整体下弯） | 交叉轴、单轮过坎、单侧压石、爬坡一侧翘起、转向侧倾的载荷转移 |
| 考验什么 | 纵梁的抗弯截面 | 车架的**抗扭刚度**（管阵结构的接头与横撑布置） |

> ⚠️ **答题前先去本队设计报告核对工况定义、加载数值、约束位置与验收标准** —— 不同车队、不同年份都不一样。有的车队还会补做制动/转向/侧倾/落地冲击工况，但"弯曲 + 扭转"是车架刚度的基准工况。

## 十、支架与安装座设计六维度（对应简答 2，10 分）

| 维度 | 智能部件带来的新要求 |
|---|---|
| **精度** | 传感器要测准 → 安装刚度、位置精度、同轴度要求提高；目标间隙要保证 |
| **刚度** | 不能靠堆厚度 → 用加强筋 / 拓扑优化提高刚度同时控制重量 |
| **动态** | 支架固有频率要避开电机与车架振动频率，否则共振导致信号漂移、疲劳开裂 |
| **环境** | 越野泥水扬尘冲击 → 密封、防振衬套、防护罩 |
| **装配** | 线束走向与固定、拆装可接近性（比赛现场要修）、孔位不能侵占其他系统 |
| **轻量化** | 上坡功率有限，结构件省下的每公斤都值分 |

**答题框架**：一句话结论（"从'能装住'提高到'装得准、装得稳'"）→ 从上面六维度挑 3~4 个写深入 → 举一个本车队的具体例子收尾。

## 十一、CATIA / ANSYS 定位（对应简答 5，10 分）

```
CATIA  →  回答"长什么样"
          把设计意图变成可制造、可出图、可装配的确定几何
          （顺带给出质量、质心、转动惯量）

ANSYS  →  回答"扛不扛得住"
          在设计阶段用数值方法预演力学行为，替代/减少物理试错

两者是闭环：ANSYS 发现孔边应力集中 → 回 CATIA 加大圆角/加厚垫板 → 再跑一次
```

**开发流程**：`CATIA 建模 → ANSYS 仿真 → 加工装配 → 实车测试`，前两步是设计迭代，后两步是最终验证。

**简答 4 的两个陷阱（都要答"不一定"）**：
- 仿真不合格**不一定**不能加工 —— 仿真假设往往偏保守（载荷取值偏严、约束理想化）；局部超标可通过加强解决；**放行必须有依据、有记录、有责任人**
- 仿真全合格**也可能**出问题 —— 焊接残余应力、装配预紧、材料批次差异、载荷谱未覆盖的真实工况、疲劳与磨损、制造误差、振动共振
- 收尾一句：**仿真是降低风险的工具，不是合格证**

## 十二、答题结构模板（通用）

```
① 一句话结论        ← 先给判断，别铺垫
② 两到三个要点      ← 每个要点 = 判断 + 理由（"因为……"）
③ 一句落地          ← 结合本车队实际（车型/部件/工况）
```

**三条铁律**：先结论后解释 · 每个要点都要有"因为" · 至少一句落到本车队。

**❌ 套话特征**（出现就删）："随着……的发展"、"众所周知"、"具有重要意义"、"提高了效率、保证了安全"、以及任何**换到别道题也成立**的句子。

## 十三、提交规范（对应 4 分，最容易白丢）

| 项 | 要求 |
|---|---|
| 源文件 | `.CATPart`，命名格式 **`必做题1+姓名`** |
| 截图（备选方式） | 每个模型 **2 张**：①等轴测完整模型图 ②草图约束截图 |
| 截图质量 | 必须**完整显示模型、特征树、约束符号**；**只拍局部不予得分** |

| ⚠️ 面试风险 | **会抽查原题** —— 别答自己讲不清的题，答案要能当面展开 |

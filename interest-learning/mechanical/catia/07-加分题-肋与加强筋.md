# 第07讲：加分题——肋与加强筋（正文约20分钟 + 练习约35分钟）

## 你将学到
- `Rib`（肋）命令的原理：轮廓草图 + 中心线，到底谁扫谁
- 为什么肋比"拉伸一块薄板"更省料、更强 —— 用截面惯性矩的直观理解
- 加强筋在赛车结构里的工程意义：受力路径、抗弯、防翘曲
- 开槽（`Slot` / `Pocket`）与孔的完整做法
- 加分题的建议建模顺序，以及"草图全部完全约束"的自查

> 本讲对应笔试**选做加分题（+15 分）**。题目原文的评分细则是：①草图全部完全约束 5 分；②正确使用肋命令生成加强筋、孔与开槽特征完整 6 分；③特征树完整可见、无报错、截图齐全 4 分。也就是说：**必须在特征树里真的出现 `Rib` 特征**（这条是硬指标），且孔和开槽都不能少。

## 1. `Rib`（肋）命令的原理

`Rib` 是"沿一条路径扫掠出一个实体"。它要为对话框提供两个输入：

| 输入 | 英文 | 是什么 | 例子 |
|---|---|---|---|
| 轮廓 | `Profile` | 一个**闭合**的截面形状 | 一个 `6 × 8` 的小矩形、一个 Φ6 的圆 |
| 中心线 / 中心曲线 | `Center curve` | 轮廓要**沿着它走**的那条路径 | 一条斜的直线、一段圆弧 |

结果就是：那个小矩形沿着斜线"扫"过去，扫出一根有厚度的杆子。把这根杆子放在底板和立板的夹角处，它就成了**加强筋**。

`Rib Definition`（肋定义）对话框里还会有 `Profile control`（轮廓控制）之类的选项，用来规定扫掠过程中轮廓的姿态（大致是"保持角度"还是"沿某个方向拉"）。**选项名称和个数在不同版本会有差异，以你机器上为准**；做题时先用默认，方向不对再改。

**两条最容易踩的红线**：

1. **轮廓必须闭合**。小矩形要四条边首尾相接（端点用 `Coincidence` 连上），否则报"轮廓不闭合"。用 `Tools > Sketch Analysis`（草图分析）能查出轮廓是否闭合。
2. **轮廓和中心线必须有交点（相交）**。CATIA 需要知道轮廓从中心线的哪一点开始扫。最常见的新手报错就是这句。对策：把画轮廓的那张草图**建在中心线上**（比如让轮廓平面的某个点与中心线的端点重合），或者让轮廓的一条边穿过中心线。

> 💡 类比：`Rib` 就像**挤牙膏**。牙膏管的出口截面（轮廓）是固定的，你手沿着一条线移动（中心线），挤出来的牙膏条就是那个截面沿着你的路径扫出来的形状。如果出口截面没封严（轮廓不闭合），或者你的手没从出口的正上方开始动（轮廓与中心线不相交），牙膏就挤不出来 —— CATIA 也是这么报错的。

**还有一条捷径值得知道**：CATIA 里有一个专门的 `Stiffener`（加强肋）命令 —— 你只画一条线（作为加强筋的侧截面中线），指定厚度，它会自动延伸到已有材料上并长出三角形筋。做直角支架的加强筋，`Stiffener` 往往比 `Rib` 更快。但**加分题明确要求"正确使用肋命令"，所以请用 `Rib` 交作业**，`Stiffener` 了解即可（**命令位置与名称版本可能有差异，以你机器上为准**）。

## 2. 加强筋的工程意义：为什么肋比"拉伸薄板"强

先看一个容易被忽略的事实：**加强筋的典型截面是个三角形**（根部宽、顶部窄）。为什么不是等厚的矩形？

因为板件受弯时，**弯矩（bending moment）从固定端往自由端递减** —— 根部受力最大，越往边上越没事。加强筋做成三角形，正好是"哪里需要材料就给哪里"，一点不浪费。这就是最朴素的**等强度设计**思想。

再看为什么"加高"比"加厚"管用。矩形截面的抗弯能力用一个叫**截面惯性矩**的量描述（记作 I，大致与 b·h³ 成正比，b 是宽、h 是高）。注意 h 是**三次方**：

| 做法 | 尺寸变化 | 材料用量大约 | 抗弯能力大约 |
|---|---|---|---|
| 加厚 | b 从 6 变 12（厚一倍） | 2 倍 | 2 倍 |
| 加高 | h 从 20 变 40（高一倍） | 2 倍 | **8 倍** |

也就是说，**同样多的材料，往"高度方向"放，收益是往"厚度方向"放的平方量级**。加强筋干的正是这件事：它用很少的材料，把截面高度撑起来。

再加上一条工程上的实打实好处：**焊接薄板时，加强筋能约束变形**。薄板焊接受热会翘曲，加了筋以后刚度上去了，尺寸稳定性好很多 —— 这也是为什么车队的支架、安装座几乎处处都是"薄板 + 加强筋"的组合，而不是一块 20mm 厚的实心铁。

> 💡 类比：一张 A4 纸平放在两个杯子之间，中间放个橡皮就塌了。但你把纸**沿长边折一下**（折出一道棱 = 加了一根"筋"），同样的纸立刻能托住橡皮。纸还是那张纸、重量没变，变的只是"截面高度"。加强筋的全部秘密就在这一折里。

> 💡 再一个类比：加强筋像**老式木椅腿之间那根斜撑**。一根细木条不值钱，但它把两个本来会"各自摇摆"的方向锁在了一起，整把椅子立刻不晃了。它在受力上做的事叫**改变受力路径** —— 把一个方向上的弯矩，转成斜撑的拉压。

**加强筋的三个作用，答题时可以这么写**：

1. **提高刚度 / 抗弯能力**：用最少的材料把截面高度撑起来（I ∝ h³）；
2. **改变受力路径**：把载荷从薄弱区域引到结构的强方向（比如从"板的法向弯曲"变成"沿板面的拉压"）；
3. **控制焊接变形、提供安装面**：给传感器、阀块提供一个刚性、平整的安装位置（这条和简答题 2 的支架设计直接呼应）。

## 3. 开槽与孔的完整做法

加分题要求"孔与开槽特征完整"，所以除了加强筋，还得有孔、有槽。

| 特征 | 命令 | 输入 | 结果 |
|---|---|---|---|
| 孔 | `Hole`（孔） | 一个面 + 定位点 | 加减材料，标准孔（见第05讲） |
| 开槽（负肋） | `Slot`（开槽） | 轮廓 + 中心线 | **从实体中减去**，沿路径挖出一条槽，和 `Rib` 正好相反 |
| 简单槽 / 缺口 | 草图画形状 + `Pocket`（凹槽） | 一张闭合草图 | 挖掉草图轮廓那一块 |
| 长圆孔（腰形孔） | 草图里用 `Elongated Hole`（长圆孔）画 + `Pocket` | 两个圆心 + 半径 | 常见的可调安装孔 |

**`Slot` 和 `Rib` 的关系**：`Rib` 是"沿路径长出一块"，`Slot` 是"沿路径挖掉一块"，输入也是 `Profile`（轮廓）+ `Center curve`（中心曲线），所以两条红线（闭合、相交）完全一样。走线槽、油道槽、减重槽常用它。

**腰形孔（长圆孔）** 特别值得记一下：赛车支架上大量用腰形孔来做安装位置微调（这个在简答题 2 的"可调性"里能用上）。做法：

1. 在安装面上 `Sketch`；
2. 在 `Profile` 工具栏里找 `Elongated Hole`（长圆孔）图标（**版本可能有差异，以你机器上为准**）；
3. 在屏幕上点两下确定两个圆心，再拖一下确定半径；
4. 用 `Constraint` 标尺寸（两个圆心位置、半径），`Coincidence` / 对称约束把它定位到安装面上；
5. 全绿后 `Exit Workbench`，点 `Pocket`，深度选 `Up to last`（到最后一面）打穿。

## 4. 加分题建议建模顺序

| 步 | 做什么 | 为什么 |
|---|---|---|
| 1 | 建**底板**：`xy plane` 草图 + `Pad` | 一切加强筋和孔都长在板上，板先有 |
| 2 | 建**立板**：偏移平面或直接双击底板面 → 草图 + `Pad` | 加强筋要连接"底板"和"立板"两个对象，两个对象都得先在 |
| 3 | 在侧向基准面上画**中心线**（斜线），完全约束 | 这是肋的路径；先定路径，再定截面 |
| 4 | 在与中心线相交的平面上画**轮廓**（小矩形 / 小圆），完全约束 | 这是肋的截面；必须与中心线相交 |
| 5 | `Rib`（肋）：`Profile` 选轮廓，`Center curve` 选中心线 | 生成加强筋 |
| 6 | 打**孔**（`Hole`，含必要的沉头 / 腰形孔用 `Pocket`） | 加分题要求"孔" |
| 7 | **开槽**（`Slot` 或草图 + `Pocket`） | 加分题要求"开槽" |
| 8 | （可选）`Edge Fillet` 倒圆角、`Chamfer` 倒角 | 修饰永远最后 |
| 9 | 自检：所有草图全绿、特征树无报错、特征树展开截图 | 对应加分题评分点①③ |

顺序背后的道理和第06讲一模一样：**从大到小、从平到斜、修饰最后**。加强筋之所以排在第 5 步之后，是因为它要"连在"第 1、2 步做出来的两块板上。

## 5. 加分题的三条评分点怎么自查

| 评分点 | 分值 | 怎么自查 |
|---|---|---|
| ① 草图全部完全约束 | **5** | 双击特征树上**每一张**草图，确认都是深绿；注意**肋的中心线和轮廓是两张独立草图，两张都要全绿**；用 `Tools > Sketch Analysis` 复查 |
| ② 正确使用肋命令生成加强筋、孔与开槽特征完整 | **6** | 特征树里必须能明确找到 `Rib.1`（这是"正确使用肋命令"的可见证据）；同时必须有 `Hole`（或打穿的 `Pocket`）和 `Slot`（或开槽的 `Pocket`） |
| ③ 特征树完整可见、无报错、截图齐全 | **4** | `Tools > Update`（更新）后特征树没有红 / 黄标记；截图时把 `Part1` / `PartBody` **逐级展开**，让所有特征露出来；按题目要求交 2 张（等轴测完整模型图 + 草图约束截图），截图里模型 / 特征树 / 约束符号都要清晰 |

> ⚠️ 常见坑：只做了加强筋，忘了孔或开槽 —— 评分点② 的 6 分是"肋 + 孔 + 开槽"三件事合起来给的，少一件就悬。交之前拿这张表逐条打钩。

> ⚠️ 另一个坑：肋报了错没管，留着红色标记就交了。评分点③ 明确写了"无报错"。修法：双击 `Rib.1` 看提示 → 常见就是"轮廓不闭合"或"轮廓与中心线不相交"两条 → 回草图用 `Coincidence` 把轮廓封死，或调整轮廓平面让它穿过中心线。

## 🎯 动手练习（约35分钟）

目标：从零做一个"底板 + 立板 + 三角加强筋 + 孔 + 腰形孔 + 开槽"的小支架。练习尺寸随便定，流程走通更重要。

### A. 底板与立板（约 8 分钟）

1. `File > New > Part` → `OK`。选 `xy plane` → `Sketch`，`Rectangle` 画矩形，`Coincidence` 把左下角点约束到草图原点，下边 `Horizontality`、左边 `Verticality`，标 `120 × 80`，确认全绿 → `Exit Workbench`。
2. 点 `Pad`，`Length` 填 `10mm` → `OK`。底板完成。
3. 建立板所在的平面：点 `Plane`（平面）图标 → `Plane type` 选 `Offset from plane`（偏移平面）→ 参考选 `xy plane`，偏移量填 `10mm`（正好在底板上表面；不对就点反向）→ `OK`。
4. 选中 `Plane.1` → `Sketch`，画一个 `80 × 60` 的矩形作立板轮廓，`Coincidence` 定位、标尺寸、全绿 → `Exit Workbench` → `Pad`，`Length` 填 `10mm` → `OK`。

### B. 用 `Rib` 做加强筋（约 15 分钟，本讲重点）

5. 在侧向基准面（`zx plane` 或 `yz plane`，看你的朝向）上 `Sketch`，用 `Line` 从底板上表面斜着画一条**直线**，一直连到立板的侧面上 —— 这条线就是加强筋的**中心线**。
6. 用 `Coincidence` + 尺寸把它约束好（例如起点距立板 `60mm`、终点高度 `50mm`），确认全绿（深绿），`Exit Workbench`。建议在特征树里把它改成 `筋中心线` 之类的名字（改名方法见第03讲第 6 节）。
7. 建轮廓草图：选一张**穿过这条中心线**的平面（例如 `yz plane`，或让轮廓平面与中心线相交），→ `Sketch`。
8. 在草图里用 `Rectangle` 画一个小矩形（`6 × 8` 左右，代表筋的横截面）。再用 `Constraints Defined in Dialog Box` 勾 `Coincidence`，让矩形的中心（或某个点）**与中心线的端点重合** —— 这一步是避免 Rib 报错的关键。
9. 给矩形加尺寸和几何约束，确认全绿（注意：**这条轮廓和上一条中心线是两张草图，两张都要全绿**），`Exit Workbench`。
10. 点 `Rib`（肋）图标（在 `Pad` / `Pocket` 那一排工具栏里；也可以走菜单 `Insert > Sketch-Based Features > Rib`，**版本可能有差异，以你机器上为准**）。
11. 在弹出的 `Rib Definition`（肋定义）对话框里：`Profile`（轮廓）选第 8 步那个小矩形草图，`Center curve`（中心曲线）选第 6 步那条斜线草图。
12. 看预览 —— 应该能看到一根矩形截面的杆子沿着斜线扫出来，正好把底板和立板连起来。
13. 如果报错，对照第 1 节的两条红线排查：轮廓不闭合 → 回草图用 `Coincidence` 把四个角封死；轮廓与中心线不相交 → 调整轮廓草图的位置约束，让它穿过中心线。
14. `OK`。点 `Tools > Update`（更新），确认特征树里出现 `Rib.1` 且没有报错标记。

> ✅ 你应该看到：特征树上出现 `Rib.1` 这个特征（**这是加分题拿分的硬证据**）；模型上多出一根斜着的加强筋，一端坐在底板上、一端顶在立板上；`Rib.1` 双击能直接改轮廓或中心线。

### C. 孔、腰形孔、开槽（约 8 分钟）

15. 在底板上打一个孔：选中底板表面 → `Hole` → `Diameter` 填 `8mm` → 深度类型选 `Up to last`（到最后一面）→ 在 `Positioning Sketch` 里用尺寸约束把孔中心定位好（全绿）→ `OK`。
16. 在立板上做一个**腰形孔**（安装微调孔）：双击立板表面 → `Sketch` → 在 `Profile` 工具栏找 `Elongated Hole`（长圆孔）→ 点两下确定两个圆心，再拖出半径 → 用 `Constraint` 标两个圆心位置和半径 → 全绿 → `Exit Workbench` → `Pocket`，深度 `Up to last`（打穿）。
17. 做一个**开槽**：在底板表面 `Sketch`，用 `Rectangle` 画一条窄长矩形当走线槽轮廓（标好尺寸、全绿）→ `Exit Workbench` → `Pocket`，深度填 `5mm`（不打通）。
18. 进阶（可选）：如果你已经熟悉，可以试试用 `Slot`（开槽）命令做同样的槽 —— 输入同样是 `Profile` + `Center curve`，效果是"沿路径挖掉一块"，和 `Rib` 正好相反。

### D. 自检与截图（约 4 分钟）

19. 点 `Tools > Update`（更新）。检查特征树：`Pad.1 > Pad.2 > Rib.1 > Hole.1 > Pocket.1 > Pocket.2`（顺序大致如此），没有红 / 黄标记。
20. 双击特征树上**每一张草图**，确认都是深绿色（全绿）。尤其别漏了 **Rib 用的那两张草图**。
21. 把 `Part1` / `PartBody` 逐级**展开**，点 `Fit All In`（适应全部）让模型占满画面，转到等轴测视角，**截图 1（等轴测完整模型图）**；再进一张草图，确认约束符号清晰，**截图 2（草图约束截图）**。

> ✅ 你应该看到：特征树里同时存在 `Rib.1`、`Hole.1` 和至少一个开槽 / 凹槽特征 —— 这三样齐全，加分题的评分点② 才算完整；所有草图单独打开都是深绿色（评分点① 的 5 分）；特征树展开后一屏能看全，没有报错（评分点③ 的 4 分）。文件按 `加分题+姓名` 的规则命名。

## 本讲小结

| 概念 | 要点 |
|---|---|
| `Rib`（肋） | 轮廓（`Profile`）沿中心线（`Center curve`）扫掠成体 |
| 两条红线 | 轮廓必须**闭合**；轮廓必须与中心线**相交** |
| 轮廓草图与中心线草图 | 是**两张独立草图**，两张都必须完全约束（全绿） |
| `Stiffener`（加强肋） | 更快的加强筋做法（画一条线 + 给厚度），但加分题要求用 `Rib` |
| 加强筋为什么强 | 三角形的形状匹配弯矩递减；截面惯性矩 I ∝ b·h³，"加高"比"加厚"收益是平方量级 |
| 加强筋的三个作用 | 提高抗弯刚度 / 改变受力路径 / 控制焊接变形并提供安装面 |
| 开槽 | `Slot`（开槽）是负的 `Rib`，输入一样；简单槽用草图 + `Pocket` |
| 腰形孔 | `Elongated Hole`（长圆孔）画轮廓 + `Pocket` 打穿，用于安装位置微调 |
| 加分题顺序 | 底板 → 立板 → 中心线 → 轮廓 → `Rib` → 孔 → 开槽 → 圆角 → 自检 |
| 加分题评分点 | ①草图全约束 5 分 ②肋 + 孔 + 开槽齐全 6 分 ③特征树无报错、截图齐全 4 分 |
| 最容易丢分 | 只做加强筋忘了孔 / 开槽；留着报错标记就交；截图没展开特征树 |

# 第02讲：草图与完全约束（正文约6分钟 + 练习约4分钟）

## 1. 自由度与两类约束

草图上的图形本质是一堆**点**（线段端点、圆心），每个点有 **2 个自由度**：x、y 各能挪。

| 几何元素 | 自由度数 |
|---|---|
| 一个孤立点 | 2 |
| 一条独立线段 | 4（两端点各 2） |
| 一个圆 | 3（圆心 2 + 半径 1） |

加约束 = **消自由度**：标一个长度尺寸消 1 个；一个重合约束（点贴原点）一次消 2 个；一个水平约束消 1 个。**自由度归零 = 完全约束**，CATIA 会给它换一种颜色显示。

| | 几何约束 | 尺寸约束 |
|---|---|---|
| 长什么样 | 平行、垂直、相切、同心、重合、等长、对称等符号 | 一条带数字的尺寸线 |
| 表达什么 | 元素之间的**关系** | 元素的大小 / 位置**数值** |

加几何约束：`Ctrl` 选元素 → `Constraints Defined in Dialog Box`（对话框中定义的约束）→ 勾关系 → `OK`；加尺寸：点 `Constraint` 图标 → 点元素 → 放尺寸线 → 双击改数值。

> ⚠️ **约束 ≠ 尺寸，别用尺寸解决关系问题**：矩形四条边都用"到原点距离"钉死是 8 个尺寸；换成"下边水平 + 左边竖直 + 左下角重合到原点 + 长 + 宽"只要 5 个约束。

## 2. 三种颜色与拖动试探法

| 状态 | 颜色 | 含义 | 该做什么 |
|---|---|---|---|
| 欠约束 | 白色 | 自由度没消完，还能动 | 继续加约束 |
| **完全约束** | **深绿色** | 自由度归零，形状唯一确定 | ✅ 笔试要的就是这个状态 |
| 过约束 | 紫红 / 褐红 | 同一自由度被约束了两次 | 删掉多余的那一个 |

**拖动试探法**：按住左键拖草图元素 —— 完全约束的**拖不动**；欠约束的会滑走。

**锚定技巧**：用 `Coincidence`（重合）把草图最有代表性的一点钉到**草图原点**（H 轴与 V 轴交点），一步消掉 2 个自由度，整张草图也不会漂走。收尾用 `Tools > Sketch Analysis` 自检是否完全约束、轮廓是否闭合。

> ⚠️ 最容易吃亏的坑：**完全约束 ≠ 画对了**。本该标 40 的边标成 45，草图一样变绿 —— 变绿只保证模型**可改、可控**，不保证**正确**，尺寸仍要对照图纸核对。

## 3. 过约束的修法与约束策略

> 💡 类比：没完全约束的草图就像**没上螺丝的架子** —— 看着立着，一碰就散（元素还能拖动）。约束就是给每一个自由度上螺丝；上够了才能交付，上重了（过约束）反而会互相顶住。

**现象**：草图变紫红，或刚加完约束图形"跳"一下、别处尺寸变红。**原因**：同一自由度被约束了两次（已用 `Symmetry` 约束到轴，又标到轴的距离）。

**修法**：① `Ctrl+Z` 撤销最后一次加的约束 → ② 想清楚"这件事前面是不是已经表达过" → ③ 多余的那个右键 `Delete` → ④ **能用几何约束表达的，就别再用尺寸**。

**约束策略（顺序不能反）**：先大概画出轮廓 → 用 `Coincidence` 把端点连上（否则轮廓不闭合，`Pad` 直接失败）→ 加水平/垂直/平行/相切/同心/对称等关系约束 → **最后才标数字尺寸，只标图纸上真实标注的那几个** → 所有尺寸**统一基准**。

**省一半尺寸**：对称约束省掉一半位置尺寸；`Equal` 只标一个长度；`Concentricity` 不用标圆心偏移；`Mirror` 画一半再镜像。

## 🎯 动手练习

1. `File > New > Part` → `OK`；选 `xy plane` → `Sketch` → `Rectangle`，画一个矩形（此时是**白色**，欠约束）。
2. 拖一下矩形右下角的点（整条边跟着跑 = 长度和位置都没锁）。
3. 选中矩形**左下角点** + `Ctrl` 选草图原点 → `Constraints Defined in Dialog Box` 勾 `Coincidence` → `OK`。
4. 选**下边**勾 `Horizontality`（水平）、**左边**勾 `Verticality`（垂直）。
5. 用 `Constraint` 给下边、左边标尺寸 `200`、`120`。
6. 再拖右下角的点 —— 已经**拖不动**了；`Tools > Sketch Analysis` 确认已完全约束，图形变**深绿**。

> ✅ 你应该看到：第 5 步后草图整体变**深绿**（完全约束），拖拽几何元素不再有反应；`Sketch Analysis` 提示轮廓闭合、约束齐全。

## 本讲小结

| 概念 | 要点 |
|---|---|
| 自由度 | 点 2 个、线段 4 个、圆 3 个；加约束就是消自由度 |
| 三种颜色 | 白 = 欠约束 / 深绿 = 完全约束 / 紫红 = 过约束 |
| 约束顺序 | 先重合连轮廓 → 再几何关系 → 最后标尺寸；基准尽量统一 |
| 拖动试探法 | 拖不动 = 已约束；能滑走的方向就是缺的约束方向 |
| 过约束 | 同一自由度约束两次；`Ctrl+Z` 或删掉多余的那个 |
| 得分提醒 | 评分点①（16 分）：每张草图退出前必须全绿、关键尺寸与图纸一致 |

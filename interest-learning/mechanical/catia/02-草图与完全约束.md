# 第02讲：草图与完全约束（正文约25分钟 + 练习约35分钟）

## 你将学到
- 为什么"能拖动"就说明草图没画完 —— 自由度（DOF）到底怎么数
- 几何约束（平行/垂直/相切/同心/重合/等长）和尺寸约束的区别，什么时候用哪个
- **草图变绿 = 完全约束**，变白 / 变紫红 / 闪红各自意味着什么
- "拖动试探法"：三秒钟找出欠约束的位置
- 过约束（冲突约束）怎么找、怎么修
- 对称 + 等长 + 镜像：老手省一半尺寸的偷懒技巧

> 这一讲对应笔试评分点 **① 草图完全约束、关键尺寸定位正确（16 分）**，是本教程最该反复读的一讲。16 分是三块结构分里最大的一块。

## 1. 自由度：草图"没画完"的本质

一张草图上的图形，本质是一堆**点**（线段端点、圆心）和由点决定的线、圆弧、圆。每个点有两个自由度：**x 方向能挪、y 方向能挪**。

| 几何元素 | 自由度数 | 说明 |
|---|---|---|
| 一个孤立点 | 2 | x、y 各一个 |
| 一条独立线段 | 4 | 两个端点各 2 个 |
| 一个圆 | 3 | 圆心 2 个 + 半径 1 个 |
| 一个圆弧 | 5 | 圆心 2 + 半径 1 + 起止角 2 |

**自由度（Degree of Freedom, DOF）**就是"这块几何还能往哪几个方向乱动"。加约束的过程就是在**消自由度**：

- 标一个长度尺寸（比如 40mm）→ 消掉 1 个自由度；
- 一个重合约束（点贴在原点上）→ 一次消掉 2 个（x 和 y 都被锁住）；
- 一个水平约束 → 消掉 1 个（转角被锁）。

当自由度归零，草图就**完全约束**了，CATIA 会给它换一种颜色（默认是深绿，俗称"变绿"）。这也是笔试要你截图的东西。

> 💡 类比：草图像**用图钉把一张纸钉在画板上**，每加一个约束 = 按一颗图钉。图钉够多，纸就死死不动；图钉不够，某个角翘着，你手指一拨它就滑走 —— 那就是欠约束。自由度数就是"还剩几个角能翘"。

## 2. 两类约束：几何约束 vs 尺寸约束

| | 几何约束（Geometric Constraint） | 尺寸约束（Dimensional Constraint） |
|---|---|---|
| 长什么样 | 平行 ∥、垂直 ⊥、相切、同心、重合、等长、对称这些符号 | 一条带数字的尺寸线 |
| 表达什么 | 元素之间的**关系** | 元素的**大小 / 位置数值** |
| 改了一处 | 相关元素自动保持这个关系 | 几何跟着数字变 |
| 图纸来源 | 图纸上"看着就该这样"的关系 | 图纸上明确标注的数值 |

**几何约束怎么加**：用 `Ctrl` + 鼠标左键选中一个或一组元素 → 点 `Constraint`（约束）工具栏里的 `Constraints Defined in Dialog Box`（对话框中定义的约束，图标是一个小对话框）→ 在弹出的对话框里勾选你要的关系：`Coincidence`（重合）、`Tangency`（相切）、`Parallelism`（平行）、`Perpendicularity`（垂直）、`Concentricity`（同心）、`Equal`（等长）、`Symmetry`（对称）、`Horizontality`（水平）、`Verticality`（垂直）→ `OK`。**不同版本的按钮位置和文案可能有差异，以你机器上为准。**

**尺寸约束怎么加**：点 `Constraint` 工具栏里的 `Constraint`（尺寸约束）图标 → 点一个元素（得到长度/半径），或先后点两个元素（得到距离/角度），在屏幕上合适的位置点一下放下尺寸线 → 双击尺寸改数值。

**快捷方式**：工具栏上还有 `Quick Constraint`（快速约束），它会根据你选中的元素自己猜一个合理的约束（选中一条线和一个圆，它可能自动给你相切）。猜得对不对要自己看一眼。

> ⚠️ 常见坑：**约束 ≠ 尺寸，别用尺寸解决关系问题**。矩形四条边都用"到原点的距离"钉死，就是 8 个尺寸；而"下边水平 + 左边竖直 + 左下角重合到原点 + 长 + 宽"只要 4 个约束就够，且改起来不散架。约束数量少 = 更容易完全约束 = 更容易改。

## 3. 颜色语言：草图在跟你说什么

| 草图状态 | 典型显示颜色 | 含义 | 你该做什么 |
|---|---|---|---|
| 欠约束（under-constrained） | 白色 | 自由度没消完，还能动 | 继续加约束 |
| **完全约束（iso-constrained）** | **深绿色** | 自由度归零，形状被唯一确定 | ✅ 这就是笔试要的状态 |
| 过约束（over-constrained） | 紫红 / 褐红 | 同一个自由度被约束了两次 | 删掉多余的那一个 |
| 冲突（inconsistent） | 红色（闪烁 / 加粗） | 约束之间自相矛盾 | 找矛盾的尺寸删掉 |

> ⚠️ 颜色是默认配色，**版本 / 主题设置不同可能略有差异，以你机器上为准**。判断的硬标准是：退出草图前看一眼状态栏或 `Tools > Sketch Analysis`（草图分析）的提示。

> ⚠️⚠️ 最容易吃亏的坑：**完全约束 ≠ 画对了**。你本该标 40 的边标成 45，草图一样变绿 —— 因为"信息足够且不矛盾"和"符合图纸"是两件事。变绿只保证你的模型**可改、可控**，不保证**正确**。所以每次标尺寸都要对照图纸核对数值。

## 4. 拖动试探法 + 草图分析：怎么找欠约束

**拖动试探法**（最土但最快）：

1. 把鼠标移到草图上某个元素上，按住左键拖它（有的版本工具栏上有 `Drag` 拖动图标，找不到就直接拖；**版本可能有差异，以你机器上为准**）。
2. 完全约束的元素**拖不动**（CATIA 会给个拒绝的反馈）；欠约束的元素会滑走。
3. 看它往哪个方向滑：整块图形能水平平移 → 缺一个水平位置尺寸；能绕某点旋转 → 缺一个角度约束；某条边的长度能变 → 缺长度尺寸。

**锚定技巧（强烈建议养成）**：先把草图里**最有代表性的一点**用 `Coincidence`（重合）约束钉到**草图原点上**（就是屏幕上 H 轴和 V 轴交点处那个小点，特征树里也能找到 `origin`）。这一步直接消掉 2 个自由度，而且让整个草图"挂"在模型原点上 —— 以后改别的尺寸，这块东西不会漂走。然后再从这一点出发量长宽。

**Sketch Analysis（草图分析）**：在 `Sketcher` 里点 `Tools > Sketch Analysis`，对话框里会给出这张草图的状态信息（是否完全约束、轮廓是否闭合等），是交作业前的自检工具。**菜单文案和标签在不同版本会有差异，以你机器上为准**，但 `Tools` 菜单下找 `Sketch Analysis` 这个词基本没错。

## 5. 过约束 / 冲突约束：现象与修法

**现象**：草图整体变成紫红；或者你刚加完一个约束，图形"跳"了一下，另一处的尺寸变成红色并带个小标记；CATIA 也可能弹出提示说约束已经存在或冲突。

**原因**：同一个自由度被约束了两次。例如：

- 矩形上下两边，你已经用 `Symmetry`（对称）约束到水平轴上了，又给上边标了一个"到水平轴的距离 30" —— 同一件事说两遍；
- 两条边之间已经有了"垂直"几何约束，你又标了一个 90° 角度尺寸 —— 重复；
- 两条边已经有了"等长"，你又各标了一个相同的长度 —— 重复。

**修法（按这个顺序试）**：

1. 先 `Ctrl+Z` 撤销最后一次加的约束，回到变紫红之前的状态；
2. 想清楚"这件事前面的约束是不是已经表达过了"；
3. 如果表达过了，删掉**多余的那一个**：在冲突的约束符号上右键 → `Delete`，或选中后按 `Delete`；
4. 原则记住一句话：**能用几何约束表达的，就别再用尺寸**。

## 6. 约束策略：老手是这么加约束的

1. **先把轮廓大概画出来** —— 形状差不多就行，CATIA 不在意你的手绘精度，后面靠约束纠正。
2. **该连的点先连上**：线段之间必须端点重合，否则轮廓不闭合，后面的 `Pad` 会直接失败（提示轮廓不闭合 / 不封闭）。用 `Coincidence` 把端点一个个连好。
3. **加关系类几何约束**：水平、垂直、平行、相切、同心、对称 —— 这些是"图纸上看一眼就知道"的关系。
4. **最后才标数字尺寸**，而且只标图纸上真实标注的那几个。其余全部交给几何约束。
5. **统一基准**：所有尺寸尽量从同一个基准出发（原点、中心线、或最左边那条边）。基准统一的草图，改起来问题最少；东一个西一个基准的草图，改一处崩一片。

## 7. 省一半尺寸的偷懒技巧

| 技巧 | 怎么做 | 省掉什么 |
|---|---|---|
| 对称 | `Ctrl` 选中要对称的一对元素 + 对称轴 → `Constraints Defined in Dialog Box` → 勾 `Symmetry` | 省掉一半位置尺寸 |
| 等长 | 选中多条线段 → 勾 `Equal` | 只标一个长度，其余自动跟随 |
| 同心 | 两个圆 → 勾 `Concentricity` | 不用再标圆心偏移量 |
| 相切 | 直线 + 圆 → 勾 `Tangency` | 不用算切点坐标 |
| 镜像几何 | 先画一半轮廓，用 `Mirror`（镜像）命令对着轴线镜像出另一半；对**镜像出来的元素** 往往还要补 `Symmetry` 约束才算约束住 | 省掉重复画一半的工作量 |
| 自动约束 | 画图时工具栏的 `Auto Constraint`（自动约束）保持开启，CATIA 会顺手加水平/垂直/相切 | 省事；但**它会加多**，画完记得看一眼 |

> ⚠️ 常见坑：`Auto Constraint` 开太狠，会让草图变成"到处都是死尺寸"，后续极难修改。经验做法：画的时候开着省事，画完用 `Tools > Sketch Analysis` 审一遍，把明显多余的尺寸删掉，再补几何约束。

> 💡 类比：约束策略就像**装修时定家具位置**。你先决定"床靠墙、衣柜贴门"（几何关系），再定"床宽 1.8 米"（尺寸）。如果你一上来就写"床头离左边墙 1.23 米、床尾离右边墙 0.77 米、离上边墙 0.9 米"，房间一量尺寸变了，全家俱都得重排。

## 🎯 动手练习（约35分钟）

目标：把一张"随便画的矩形"做成**完全约束**的草图，并亲眼看一遍欠约束、过约束、冲突三种状态的颜色变化。

### A. 做成完全约束（约 15 分钟）

1. `File > New > Part` → `OK`。
2. 选中特征树上的 `xy plane`，点 `Sketch`（草图）图标进入 `Sketcher`。
3. 点 `Rectangle`（矩形），在屏幕中间画一个矩形。现在它是**白色**的 —— 欠约束。
4. 用鼠标拖着矩形右下角那个点晃一下，观察它怎么动（整条边跟着跑，说明长度和位置都没锁）。
5. 选中矩形的**左下角点**，按住 `Ctrl` 再选中草图原点（H 轴与 V 轴的交点），点 `Constraints Defined in Dialog Box`（对话框中定义的约束），勾 `Coincidence`（重合），`OK`。现在图形被"钉"在原点上了，但还能转、能变大小。
6. 选中矩形的**下边**，用 `Constraints Defined in Dialog Box` 勾 `Horizontality`（水平）；选中**左边**，勾 `Verticality`（垂直）。现在它只能沿长宽方向变。
7. 点 `Constraint`（尺寸约束）图标，点矩形的下边，在下方空白处点一下放下尺寸 → 双击它，改成 `200`。再点左边，标一个尺寸改成 `120`。
8. 再拖一下右下角的点试试 —— 应该**拖不动**了。
9. 点 `Tools > Sketch Analysis`，看状态提示是否告诉你这张草图已经完全约束（**文案版本可能有差异，以你机器上为准**）；确认图形颜色已经变成深绿。
10. 点 `Exit Workbench` 退出，在特征树上点 `Sketch.1`，用 `Pad` 拉一个 `10mm` 的底板出来。这张 `200×120×10` 的草图后面几讲会反复用到。

> ✅ 你应该看到：草图在完成第 7 步后**整体颜色变成深绿**（完全约束），鼠标拖拽几何元素不再有反应；`Sketch Analysis` 里提示轮廓闭合、约束齐全。

### B. 故意制造过约束，再修好（约 10 分钟）

1. 双击特征树上的 `Sketch.1` 回到草图。
2. 这次故意犯错：选中矩形的上边和水平轴，用 `Constraints Defined in Dialog Box` 勾 `Symmetry`（对称）—— 但你已经给下边标过到原点的尺寸了，属于"同一件事说两遍"。
3. 观察图形颜色变成紫红 / 出现冲突标记，CATIA 可能弹出提示。这就是**过约束**的样子。
4. `Ctrl+Z` 撤销，恢复到绿色。
5. 换一种错法：给矩形下边标一个长度 `200`，再给上边也标一个长度 `200`，然后加一个 `Equal`（等长）约束 —— 观察同样的现象。
6. 修好它：删掉你后加的那个多余尺寸或约束（选中 → `Delete`），回到深绿。
7. 退出草图，点 `Tools > Update`（更新），确认模型正常，没有报错标记。

> ✅ 你应该看到：过约束时草图变紫红并有冲突提示；删掉多余约束后重新变深绿；特征树上的 `Pad.1` 不需要重建就自动更新了。

## 本讲小结

| 概念 | 要点 |
|---|---|
| 自由度（DOF） | 几何还能自由移动的方向数；点 2 个、线段 4 个、圆 3 个 |
| 完全约束 | 自由度归零，图形被唯一确定；CATIA 默认显示为**深绿** |
| 几何约束 | 表达元素之间的关系（平行、垂直、相切、同心、重合、等长、对称） |
| 尺寸约束 | 表达大小与位置的数值，来自图纸的明确标注 |
| 约束优先顺序 | 先重合连上轮廓 → 再几何关系 → 最后标尺寸；基准尽量统一 |
| 拖动试探法 | 拖不动 = 已约束；能滑走的那个方向就是缺的约束方向 |
| 过约束 | 同一自由度被约束两次，变紫红；删掉多余的那一个，别硬堆 |
| Sketch Analysis | `Tools > Sketch Analysis`，退出草图前的自检工具 |
| 变绿 ≠ 正确 | 绿只说明"信息齐全且不矛盾"，数值仍要逐条对照图纸 |
| 得分提醒 | 对应评分点①（16 分）：**每张草图退出前都必须是全绿状态**，且关键尺寸与图纸一致；截图要能看清约束符号 |

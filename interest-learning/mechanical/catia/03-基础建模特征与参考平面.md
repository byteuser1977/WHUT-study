# 第03讲：基础建模特征与参考平面（正文约6分钟 + 练习约4分钟）

- 特征树的组织习惯

---

## 1. 主力命令：谁干什么

| 命令 | 输入 | 做什么 | 典型用途 |
|---|---|---|---|
| `Pad`（凸台） | 一张闭合草图 | 沿法向**长出一块实体** | 底座、立板、几乎一切主体 |
| `Pocket`（凹槽） | 一张闭合草图 | 沿法向**挖掉一块实体** | 切槽、切缺口、开窗口 |
| `Shaft`（旋转体） | 闭合草图 + 旋转轴 | 轮廓绕轴旋转成实体 | 轴套、法兰、垫圈、轮毂 |

`Hole` / `Fillet` / `Rib` 见第05、07讲。命令**不在一个地方**：`Pad`/`Pocket`/`Shaft`/`Hole`/`Rib` 在 `Sketch-Based Features` 工具栏，`Fillet`/`Chamfer`/`Shell` 在 `Dress-Up Features` 工具栏。

**`Pad` / `Pocket` 的两条硬性前提**：草图轮廓必须**闭合**（端点要有 `Coincidence`，否则报"轮廓不闭合"）、**不能自交**。对话框里关心 `Type`（`Dimension` / `Up to next` / `Up to last`）、`Length`、`Mirrored extent`（勾上后总厚 = 2 × `Length`）。

**`Shaft`（旋转体）**：轮廓必须在旋转轴**同一侧**（跨过去会变成自交形状），角度默认 `360deg`；回转件用它比 `Pad` + `Pocket` 快十倍。

> 💡 `Pad` 像**拿饼干模子往面团上压出形状、再按厚度切一刀**：模子轮廓必须闭合，断开的模子压不出饼干。`Shaft` 像**陶艺拉坯**：只画侧面那道轮廓线，盘一转整圈就出来了。

## 2. 参考平面：三个默认平面不够用时自建

新建零件只有 `xy` / `yz` / `zx` 三个平面，斜面、台阶面都要自己造一个。点 `Plane` 图标 → `Plane Definition` → 选 `Plane type`：

| `Plane type` | 怎么用 | 典型场景 |
|---|---|---|
| `Offset from plane`（偏移平面） | 选已有平面 + 填偏移距离 | 平行于底面往上 50mm 画草图 |
| `Angle/Normal to plane`（角度/垂直平面） | 选参考面 + 旋转轴 + 填角度 | **斜支撑板这类斜面**（第04讲主角） |

> ⚠️ 建平面时**先看绿色预览确认方向，再点 `OK`** —— 方向反了，在它上面画的草图 `Pad` 出来会往里长。

## 3. 铁律：先定基准，再画草图

错误顺序：在 `xy plane` 上画草图 → `Pad` → 位置不对 → 改草图 → 越改越乱。正确顺序：**先想清楚"这个特征相对于什么定位"，把基准（平面、轴、点）建出来，再在基准上画草图。**

好处有三：**改得动**（基准变了，草图相对基准的关系不变，模型整体跟着走）；**看得懂**（别人一眼看出"这块板相对那个面偏 30mm 建的"，这也是建模思路的一部分）；**好检查**（每个基准都对得上图纸标注）。

## 4. 特征树的组织习惯

特征树是别人翻你模型时第一眼看的东西，三个习惯：

1. **改名**：把 `Sketch.1` / `Pad.1` 改成 `底座草图` 这类能看懂的名字。
2. **有序**：特征树的顺序 = 建模顺序；"回去改前面的特征导致后面更新失败"说明顺序没想清楚。
3. **无报错**：图标带红 / 黄标记就是有错误，`Tools > Update` 试一次，还红就双击进去查，或用右键 `Deactivate`（停用）逐个排除；**收工前特征树必须干净**。

## 🎯 动手练习

1. `File > New > Part` → `xy plane` → `Sketch` 画矩形，`Coincidence` 到原点、下边水平、左边竖直，标 `200 × 120`，全绿退出 → `Pad`，`Length` 填 `12mm`。
2. 点 `Plane` 图标 → `Offset from plane` → 参考 `xy plane`、偏移 `12mm` → 看预览方向（不对就反向）→ `OK`，得到 `Plane.1`。
3. 选 `Plane.1` → `Sketch` 画矩形，`Coincidence` 到原点、水平 + 垂直，标 `40 × 120`，全绿退出 → `Pad`，`Length` 填 `80mm` 做立板。
4. 双击 `Plane.1` 把偏移量从 `12` 改成 `20` → `Tools > Update`。

> ✅ 你应该看到：立板**整体跟着往上挪了 8mm**，而底座厚度没变 —— 这就是"先定基准"的价值；特征树是一条清晰的链 `Part1 > Plane.1 > PartBody > Sketch.1 > Pad.1 > Pad.2`。

## 本讲小结

| 概念 | 要点 |
|---|---|
| `Pad` / `Pocket` | 闭合草图沿法向长出来 / 挖掉；必须闭合、不自交 |
| `Shaft` | 轮廓绕轴旋转成体；轮廓必须在轴的一侧，适合回转件 |
| 参考平面 | 默认平面不够用时自建；`Offset` 与 `Angle/Normal` 最常用 |
| 建平面习惯 | 先看绿色预览确认方向 → 不对就反向 → 再 `OK` |
| 先定基准再画草图 | 基准是"合同"，尺寸有据可依；改基准模型整体跟着走，不散架 |
| 特征树 | 顺序 = 建模顺序；收工前改名、理顺序、清掉所有报错标记 |

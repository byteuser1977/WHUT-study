# 第06讲：综合零件完整拆解（正文约6分钟 + 练习约4分钟）

## 你将学到
- 拿到零件图先"读"什么
- 从空白文件到完整模型的 **8 步建模顺序**
- **要点 → 自查 → 截图要求**对照表（五条全走一遍）

---

## 1. 读图三问

> 💡 类比：建模顺序像**搭积木** —— 先把最稳的底板放平压实，再往上装件。承重面没定就急着做上层，后面每加一个特征都得回头改基准。

- **哪个面是装配基准？** 底座（一整块厚板）几乎总是基准 —— 最平、最大、尺寸最完整，其它特征都相对它定位。
- **能拆成几个体素？** 零件图里就是：**底座 + 斜支撑板 + 立板**，再打孔、倒圆角；每块对应一两个特征。
- **哪个特征最麻烦？** **斜支撑板**（斜面定位最容易出错）—— 要早点想清它的基准。

读图时记下：三个体素主尺寸、斜面角度及参考面、孔的两个定位尺寸、R11 的位置。**具体尺寸以零件图为准**。

## 2. 推荐建模顺序（8 步）

| 步 | 做什么 |
|---|---|
| 1 | 读图：定基准、拆体素、列尺寸清单（图纸没读透就动手 = 返工） |
| 2 | `xy plane` 建**底座草图**，完全约束（基准先立） |
| 3 | `Pad` 出**底座**（后面才有"面"可贴） |
| 4 | 侧向基准面画**斜板侧截面**（或建角度参考平面）→ `Pad`（难点） |
| 5 | 底座上表面（或偏移平面）建**立板**草图 → `Pad` |
| 6 | 打 **Φ12 通孔**（`Hole`、`Up to last`） |
| 7 | 倒 **R11 圆角**（`Edge Fillet`）（依赖最终形状的边） |
| 8 | 自检：无报错、草图全绿、截图、命名 |

**三句通用原则**：**从大到小**（先做基准体）、**从平到斜**（平的先做，需自建基准的后做）、**修饰永远最后**。

## 3. 要点 → 自查 → 截图要求

| 要点 | 怎么自查 |
|---|---|
| ① 草图完全约束、关键尺寸定位正确 | 双击**每一张**草图看是否深绿；每个尺寸与图纸逐条核对（**变绿 ≠ 数值对**） |
| ② 底座 / 斜板 / 立板结构完整、R11 正确 | 三块是否各有一个 `Pad`；圆角半径是否 11mm；有无穿模浮空 |
| ③ Φ12 通孔位置正确、无几何错误 | 双击 `Hole.1` 看 `Diameter`=12、深度是否通孔；从背面看透没透 |
| ④ 建模思路清晰、操作简单 | 特征个数有无废特征；命名是否可读；能否说清顺序和理由 |
| ⑤ 截图 / 文件完整、命名规范 | 见下 |

**截图与产出（最容易忽略、也最容易返工）** —— 每个模型 **2 张截图**：

| 截图 | 内容 | 必须能看到 |
|---|---|---|
| ① 等轴测完整模型图 | 整个模型从等轴测角度拍 | 模型**完整在画面内**、特征树**展开** |
| ② 草图约束截图 | 双击一张草图进入 `Sketcher` 的画面 | 模型轮廓、**特征树**、**约束符号** |

操作要点：中键拖动旋转；`Part1`/`PartBody` **逐级展开**；抓图可用 `Tools > Image > Capture`。文件名写清**零件名 + 你的名字**。

> ⚠️ **只拍局部不合格**：看不到特征树和约束符号，截图等于白拍，其它要点的自查也少了依据。

## 🎯 动手练习

1. **底座**（8 分钟）：`xy plane` → `Rectangle`；`Coincidence` 左下角到原点、下边水平、左边竖直；标图纸尺寸，全绿 → `Pad`。
2. **斜板**（15 分钟）：侧向基准面 → `Sketch` 用 `Line` 画**侧截面**，端点 `Coincidence` 闭合、底边贴底座上表面；标角度和必要尺寸，全绿 → `Pad`。
3. **立板**（8 分钟）：双击底座上表面（或建偏移平面）→ `Sketch` 画轮廓、`Coincidence` 贴底座 → 全绿 → `Pad`。
4. **Φ12 通孔**（5 分钟）：选中打孔面 → `Hole` → 进 `Positioning Sketch` 标两个定位尺寸（从**主基准**量起），全绿退出 → `Diameter` `12mm`、深度 `Up to last`。
5. **R11 圆角**（5 分钟）：`Ctrl` 多选标 R11 的边 → `Edge Fillet`，`Radius` 填 `11mm`。
6. **自检截图**（10 分钟）：`Tools > Update`；逐张草图确认深绿、尺寸核对图纸；展开特征树拍**等轴测完整模型图**，进草图拍**草图约束截图**，保存为「零件名+你的名字」。

> ✅ 你应该看到：特征树是有序长链 `底座草图 > Pad.1 > 斜板草图 > Pad.2 > 立板草图 > Pad.3 > Hole.1 > EdgeFillet.1`；每张草图都是深绿、无报错；两张截图里三样要素齐全。

## 本讲小结

| 概念 | 要点 |
|---|---|
| 8 步顺序 | 读图 → 底座 → 斜板 → 立板（各草图 + `Pad`）→ Φ12 孔 → R11 圆角 → 自检截图 |
| 通用原则 | 从大到小、从平到斜、修饰永远最后 |
| 自检三件事 | 每张草图全绿 + 每个尺寸核对图纸 + 特征树无报错 |
| 截图与产出 | ①等轴测完整模型图 ②草图约束截图，都要完整显示模型 / 特征树 / 约束符号；`.CATPart` 文件名写清零件名与你的名字 |

# 第06讲：必做题完整拆解（正文约25分钟 + 练习约45分钟）

## 你将学到
- 拿到一张零件图，第一步该"读"什么，而不是立刻动手画
- 从空白文件到完整模型的**推荐建模顺序**，以及每一步"为什么是这个顺序"
- 一条**自检清单**：每个评分点怎么自查、截图怎么拍才给分
- 60 分钟怎么分配，以及在考场上最容易被扣分的地方

> 本讲对应笔试**必做题（50 分）的全部 5 条评分细则**，是模块一的收口讲。第02~05讲是零件，本讲是把零件装成一台能跑的机器。

## 1. 第一步：读图，别急着开软件

拿到图纸先做三件事，各花两分钟，能省掉后面半小时的返工。

**第一问：哪个面是装配基准？**
底座（一整块厚板）几乎总是基准 —— 它最平、最大、尺寸最完整。整个零件的其它特征，都应该相对它定位。找到它，你的第一个草图就定了。

**第二问：这个零件可以拆成几个"体素"？**
本题答案写在题目里了：**底座 + 斜支撑板 + 立板**，再打一个孔、倒一圈角。拆成体素的好处是：每一块对应一个（或少数几个）特征，特征树井然有序，评分点④"建模思路清晰"就是靠这个。

**第三问：哪个特征"最麻烦"？**
一定是**斜支撑板**（题目也提醒了"注意斜面草图定位"）。麻烦的东西要**早点想清楚它的基准**，别等做到一半才发现没地方画草图。

**读图时在纸上写下来的东西**（强烈建议，就写在打印出来的图上）：

- 三个体素的**主尺寸**（长宽厚、板厚、高度）；
- 斜面的**角度**，以及它相对哪个面标注；
- 孔的**定位尺寸**（两个方向各一个）和直径；
- 圆角的**半径和位置**（R11 倒在哪几条边）。

> 💡 类比：读图像**搬家前先列家具清单**。你要是直接往楼上搬，搬到一半发现沙发进不了门，就得把所有东西搬下来重来。先列清单、先量门宽，才是省时间的做法。

## 2. 推荐建模顺序（8 步）

这不是唯一正确的顺序，但它是**出错最少、最好改、最好看**的顺序。

| 步 | 做什么 | 为什么是这个顺序 | 对应评分点 |
|---|---|---|---|
| 1 | 读图：定基准、拆体素、列尺寸清单 | 图纸没读透就动手 = 返工 | ④ |
| 2 | 在 `xy plane` 上建**底座草图**，完全约束 | 底座是基准，所有东西相对它定位；基准先立起来 | ① ② |
| 3 | `Pad`（凸台）出**底座** | 有了实体，后面才有"面"可以贴、可以画草图 | ② |
| 4 | 想清斜面基准 → 在侧向基准面画**斜支撑板侧截面**（或建角度参考平面），完全约束 → `Pad` | 斜面是难点，趁思路清楚时做；且它依赖底座顶面 | ① ② |
| 5 | 在底座上表面（或偏移平面）画**立板**草图，完全约束 → `Pad` | 立板要立在底座上、还要和斜板说得上关系，等底座定了再做 | ① ② |
| 6 | 打 **Φ12 通孔**（`Hole`，深度选 `Up to last` 到最后一面） | 孔要穿的是已经存在的实体；孔的位置要靠已定的边来定位 | ① ③ |
| 7 | 倒 **R11 圆角**（`Edge Fillet`） | 圆角依赖最终形状上的边；放在最后，前面结构一改它不用重做 | ② |
| 8 | 自检：特征树无报错、所有草图全绿、截图存档、文件命名 | 交作业前的最后一道关 | ① ③ ④ ⑤ |

**每一"为什么"背后的通用原则，总结成三句话：**

1. **从大到小**：先做最大的、作为基准的那个体，其它都挂在它上面；
2. **从平到斜**：平的、平行于坐标面的先做，斜的、需要自建基准的后做（因为斜的常要参考前面的面）；
3. **修饰永远最后**：圆角、倒角、抽壳这些"修饰特征"放在所有"结构特征"之后。

## 3. 每步的关键提醒

| 步 | 关键提醒 | 详见 |
|---|---|---|
| 2 | 底座草图：左下角 `Coincidence` 到草图原点，加水平 / 垂直约束，只标图纸给的尺寸；退出前必须**全绿** | 第02讲 |
| 3 | `Pad` 的 `Length` 是板厚；注意 `Mirrored extent`（镜像范围）勾没勾，总厚会差一倍 | 第03讲 |
| 4 | 斜支撑板用**侧面轮廓拉伸法**最稳：在侧向基准面一次画出侧截面（角度就是草图里的一个角度尺寸），`Pad` 给厚度。斜面草图里别指望"水平/竖直"约束帮你，要靠尺寸 | 第04讲 |
| 5 | 立板：先建好它所在的基准（底座上表面直接双击，或建偏移平面），再画草图；用 `Coincidence` 让它真真切切贴在底座上 | 第03讲 |
| 6 | `Hole`：`Diameter` = 12；**深度类型选 `Up to last`**；定位尺寸从主基准量起，定位草图也要全绿 | 第05讲 |
| 7 | `Edge Fillet`：`Radius` = 11；先大后小、先竖后横；报错就先临时改小验证是不是几何空间不够 | 第05讲 |
| 8 | `Tools > Update`；看特征树有没有红 / 黄标记；每张草图双击进去确认颜色 | 本讲第 4 节 |

## 4. 自检清单：评分点 → 怎么自查 → 截图要求

**逐条走一遍，每条都在心里回答"是 / 否"。任何一个"否"都不要交。**

| 评分点 | 分值 | 怎么自查（具体动作） | 常见扣分原因 |
|---|---|---|---|
| ① 草图完全约束、关键尺寸定位正确 | **16** | 双击特征树上**每一张**草图进去看颜色是不是深绿；用 `Tools > Sketch Analysis`（草图分析）确认；把每个尺寸的数值和图纸逐条核对（**变绿不等于数值对**）；拖动一下看还有没有能滑走的点 | 有一张草图是白色（欠约束）；尺寸数值抄错；有一张重要的定位草图被忽略了 |
| ② 底座 / 斜支撑板 / 立板结构完整、圆角 R11 正确 | **18** | 数特征树：底座、斜板、立板是不是各有一个 `Pad`；用测量工具或直接看圆角对话框确认半径是 11mm；转一圈模型看有没有穿模、浮空、被吃掉的结构 | 少做一块；斜板角度错 / 位置漂；圆角半径填成别的数；圆角把别的结构啃掉了 |
| ③ Φ12 通孔位置正确、无几何错误 | **7** | 双击 `Hole.1` 看 `Diameter` 是不是 12；看深度类型是不是通孔；从背面看孔透没透；核对两个定位尺寸 | 打成盲孔；直径填错；位置尺寸标在了会漂的参考上；孔和别的结构干涉 |
| ④ 建模思路清晰、操作简单 | **5** | 数一数特征树上的特征个数，看有没有"为了达到目的绕了一大圈"的多余特征；看特征有没有改成有意义的名字；能不能用 3 句话说清"我先建什么、后建什么、为什么" | 特征树一堆没用的特征；顺序乱七八糟；命名全是 `Sketch.7` / `Pad.9` |
| ⑤ 截图 / 文件完整、命名规范 | **4** | 见下面"截图与提交" | 截图只拍了局部；特征树被裁掉了；文件名乱起；只交了一张图 |

### 截图与提交规范（评分点⑤，4 分，最容易白送也最容易白丢）

题目原文要求：**每个模型 2 张截图**：

| 截图 | 内容 | 必须能看到什么 |
|---|---|---|
| ① 等轴测完整模型图 | 从等轴测（斜四十五度）角度看整个模型 | 模型要**完整在画面内**、特征树要**展开可见**、界面不能是空的灰背景 |
| ② 草图约束截图 | 双击一张草图进入 `Sketcher` 的画面 | 模型的轮廓、**特征树**、以及**约束符号**（尺寸线和几何约束图标）都要清晰可辨 |

操作建议：

1. 转视角：按住鼠标中键拖动能旋转模型；先点 `Fit All In`（适应全部，一般在 `View` 菜单里）让模型占满画面；`View > Named Views`（已命名的视图）里通常能找到等轴测视图之类的预设视角（**菜单项名称版本可能有差异，以你机器上为准**）。
2. 特征树要**展开**：把 `Part1` / `PartBody` 逐级展开，让所有特征露出来，别让截图里只有 `Part1` 一行。
3. 抓图：可以用 `Tools > Image > Capture`（工具 > 图像 > 捕获）把 CATIA 窗口存成图片（**版本可能有差异，以你机器上为准**），也可以用系统的截图工具（Windows 上是 `Win + Shift + S`）。
4. **只拍局部不给分**：截图里模型必须完整，特征树必须在，约束符号必须清晰。拍之前先把窗口拉大、把无关面板关掉。
5. 文件命名**照抄题目**：`.CATPart` 文件名用 `必做题1+姓名` 的形式（例如 `必做题1张三`）。

> ⚠️ 常见坑：很多同学觉得自己模型建得不错，随手拍了一张"放大到只剩一个圆角"的图就交了 —— 阅卷老师看不到特征树、看不到约束符号，这 4 分基本没了，甚至会影响 ① 的判定（因为你没证明草图约束住了）。**截图是唯一能让老师看到你"完成度"的东西，认真对待。**

## 5. 时间分配建议（模拟 60 分钟）

| 阶段 | 时间 | 做什么 |
|---|---|---|
| 读图 | 5 分钟 | 定基准、拆体素、在图上标尺寸 |
| 底座 | 8 分钟 | 草图（全绿）+ `Pad` |
| 斜支撑板 | 15 分钟 | 这块最费时间，留足；做完立刻检查角度和位置 |
| 立板 | 8 分钟 | 草图 + `Pad` |
| Φ12 通孔 | 5 分钟 | `Hole` + 定位尺寸 |
| R11 圆角 | 5 分钟 | `Edge Fillet` |
| 自检 + 截图 | 10 分钟 | 逐条走自检清单 + 拍 2 张图 |
| 缓冲 | 4 分钟 | 应对意外 |

**卡住超过 5 分钟就换路**：例如斜板的参考平面方向怎么都不对，立刻换成"侧面轮廓拉伸法"（第04讲第 2 节 B 组）。目标是**把零件做出来**，不是死磕某一种做法。

## 🎯 动手练习（约45分钟）

这一节的"练习"就是**把必做题完整走一遍**。按下面的步骤做，每一步做完都停在原地检查一次。

**准备（2 分钟）**
1. 打开你的零件图，按第 1 节的三问把答案写在纸上：基准是哪个面、三个体素的尺寸、斜面的角度和参考、孔的定位尺寸、R11 倒在哪。
2. `File > New > Part` → `OK`。开始建模前，先在脑子里把第 2 节的 8 步表过一遍。

**第 1 步：底座（8 分钟）**
3. 选中 `xy plane` → `Sketch` → `Rectangle`，画矩形。
4. `Constraints Defined in Dialog Box`：左下角点 `Coincidence` 到草图原点，下边 `Horizontality`，左边 `Verticality`。
5. `Constraint` 标两个尺寸（图纸上的底座长、宽）→ 双击改数值。
6. 检查**全绿**（完全约束）→ `Exit Workbench`。
7. 点 `Pad`，`Length` = 底座厚度（图纸尺寸）→ `OK`。

**第 2 步：斜支撑板（15 分钟）**
8. 选中侧向基准面（按你的零件朝向选 `zx plane` 或 `yz plane`）→ `Sketch`。
9. 用 `Line`（直线）画出斜支撑板的**侧截面轮廓**（通常是一个三边或四边的封闭形状）。
10. 端点两两 `Coincidence` 连上，让轮廓**闭合**（后面 `Pad` 才不会报错）。
11. 用 `Coincidence` 把轮廓的底边与底座上表面对应的高度**贴合**（或标尺寸定位）。
12. 标尺寸：先点斜边和底边，做出**角度**尺寸改成图纸上的角度；再标底边长、竖直边高、板厚等**必要的 3~4 个**尺寸。多一个都可能过约束。
13. 拖动试探：确认没有能滑走的点，草图**全绿**。
14. `Exit Workbench` → `Pad` → `Type` 选 `Dimension`，`Length` = 板厚；需要对称就勾 `Mirrored extent`（镜像范围）；方向不对点 `Reverse Direction` → `OK`。

**第 3 步：立板（8 分钟）**
15. 双击底座上表面（或建一个偏移平面）→ `Sketch`。
16. 画立板的矩形轮廓，`Coincidence` 让它的底边与底座上表面重合，加水平 / 垂直，标图纸上的定位尺寸和尺寸。
17. 检查全绿 → `Exit Workbench` → `Pad`，`Length` = 立板厚度 / 高度（按图纸）→ `OK`。注意 `Mirrored extent` 勾没勾。

**第 4 步：Φ12 通孔（5 分钟）**
18. 选中要打孔的平面（图上有孔的那个面）→ 点 `Hole` 图标。
19. 在 `Hole Definition` 里进入 `Positioning Sketch`（定位草图），用 `Constraint` 标两个定位尺寸（从**主基准**量起），全绿后退出。
20. `Diameter` 填 `12mm`；深度类型选 **`Up to last`（到最后一面）**；`Type` 保持 `Simple`；`Threading` 保持 `None`。
21. `OK`，转到背面确认是通孔。

**第 5 步：R11 圆角（5 分钟）**
22. 选中需要倒圆角的边（图纸上标 R11 的那些），`Ctrl` 多选。
23. 点 `Edge Fillet` → `Radius` 填 `11mm`；按需设置 `Propagation`（相切 / 最小）。
24. `OK`。若是多组圆角，记住**先大后小、先竖后横**。

**第 6 步：自检与截图（10 分钟）**
25. 点 `Tools > Update`（更新）。
26. 双击特征树上**每一张草图**，确认都是深绿；把每个尺寸和图纸核对一遍。
27. 检查特征树：有没有红 / 黄标记，特征是否按合理顺序排列。
28. 把 `Part1` / `PartBody` 逐级**展开**，`Fit All In` 让模型占满画面，转到等轴测视角，**截图 1（等轴测完整模型图）**。
29. 双击关键草图进入 `Sketcher`，确认尺寸线和约束符号清晰可见，**截图 2（草图约束截图）**。如果一张草图装不下所有约束符号，就多拍几张（题目只要求 2 张，但多给不算错）。
30. 保存文件，命名 `必做题1+姓名`。

> ✅ 你应该看到：特征树是一条有秩序的长链 —— `Part1 > xy plane / yz plane / zx plane / (可能的 Plane.1) / PartBody > 底座草图 > Pad.1 > 斜板草图 > Pad.2 > 立板草图 > Pad.3 > Hole.1 > EdgeFillet.1`；**每一张草图单独打开都是深绿色（完全约束）**；模型没有红色报错标记；两张截图里模型、特征树、约束符号三样都齐全。

## 本讲小结

| 概念 | 要点 |
|---|---|
| 读图三问 | 哪个面是基准 / 能拆成几个体素 / 哪个特征最麻烦 |
| 通用顺序原则 | 从大到小、从平到斜、修饰永远最后 |
| 8 步建模顺序 | 读图 → 底座草图 → 底座 Pad → 斜板草图 + Pad → 立板草图 + Pad → Φ12 孔 → R11 圆角 → 自检截图 |
| 斜支撑板 | 难点，用侧面轮廓拉伸法最稳（角度就是草图里一个角度尺寸）→ 第04讲 |
| Φ12 通孔 | 用 `Hole`，`Diameter`=12，深度 `Up to last`（到最后一面）→ 第05讲 |
| R11 圆角 | `Edge Fillet`，`Radius`=11，先大后小、先竖后横，放特征树最后 → 第05讲 |
| 自检三件事 | 每张草图全绿 + 每个尺寸核对图纸 + 特征树无报错 |
| 截图两张 | ①等轴测完整模型图 ②草图约束截图；都要完整显示模型 / 特征树 / 约束符号 |
| 文件命名 | `.CATPart` 命名 `必做题1+姓名`，照抄题目 |
| 卡住怎么办 | 超过 5 分钟换一种做法，目标是做出零件，不是死磕某条路 |

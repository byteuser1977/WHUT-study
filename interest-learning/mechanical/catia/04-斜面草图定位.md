## 1. 斜面难在哪

平面随便挑一个坐标面就能画草图、直接量尺寸；斜面带来三个连锁问题：

1. **没有现成平面可用** —— 得自建参考平面；
2. **尺寸的参考系变了** —— 斜面上草图的 H / V 轴是**相对斜面**的；你以为在标"竖直"，实际标的是"沿斜面方向"；
3. **位置会漂** —— 斜面由前序特征生成，改了前面那个角度，斜面带着上面的草图一起转。

> 💡 在水平桌面上摆积木谁都会；但把桌面**先倾斜 30° 再摆**，"往上叠"和"往桌子里推"就完全是两回事 —— "水平/竖直"的感觉全失效，必须重新想清楚"我说的竖直，是相对桌子还是相对地球"。

## 2. 三种做法对比

| 做法 | 怎么建 | 优点 / 缺点 |
|---|---|---|
| ① 角度参考平面 | 建与基准面成 α 角的平面，再 `Sketch` + `Pad` | 角度是**可改参数**、尺寸标在斜面真实长度上；但平面建错方向就白费功夫 —— 斜面上还要打孔 / 开槽时用它 |
| **★ 侧面轮廓拉伸法** | 在侧向基准面（`zx`/`yz plane`）一次画出侧截面，`Pad` 给厚度 | 角度就是草图里一个**改得动的角度尺寸**、尺寸全在同一张草图基准统一、步骤最少 —— **笔试推荐** |
| ② 直接在实体斜面上画 | 双击实体那个面 → `Sketch` | 最快，三四秒进草图；但面由前序特征生成，改了前面尺寸草图可能漂 / 报错 —— 只适合快速试形状 |
| ③ 先立板再切斜 | `Pad` 竖直板后用 `Pocket` / `Draft` 切出斜面 | 直观、不用角度平面；但**角度不再是一个尺寸，而是一堆尺寸的结果**，图纸改一个数你得反算两个 —— ❌ 不推荐 |

> ⚠️ 斜面草图的定位尺寸一定要挂在**不会跟着斜面转**的基准（底座）上 —— 这是本讲最容易丢分的地方。

选型标准只有一条：**看图纸的角度是相对哪个面标注的，以及斜面之后还要不要在上面画东西。**

## 3. 角度怎么标、关系怎么约束

做法①的 `Angle/Normal to plane` 要填三样：`Reference`（参考面）、`Rotation axis`（旋转轴，一条直线；没有现成的就先在基准面上画一条）、`Angle`（图纸角度值），然后看绿色预览，方向不对就反向。

**标角度**：先后点**两条相交直线**再放尺寸位置；如果出来的是"距离"不是"角度"，双击尺寸（或右键打开定义）改约束类型。更稳的办法是画草图时就把两条线画成明显夹角，`Quick Constraint` 通常会直接给角度。

**贴合关系（得分点）**：斜板底面与底座上表面用 `Coincidence`（重合）真正贴合 —— "看起来贴住了"不算；再补斜板横向位置、倾斜角度、板厚三项尺寸。定位尺寸尽量**从草图自身原点量起**。

## 4. 三大典型错误

1. **尺寸标在错误的参考上**：斜板位置尺寸从斜面自身原点量，角度从 30° 改成 35° 后斜面一转，位置基准跟着转，斜板整体平移 —— 不报错但形状已错。**对策**：位置挂在底座（不动的东西）上，角度挂在斜面本身；侧面轮廓法天然没这个问题。
2. **在斜面草图里用水平 / 垂直约束**：斜面草图的 H 轴与世界的水平面差着那个倾斜角，你以为标的是"竖直"，实际沿斜面偏了 30°。**对策**：斜面草图里明确靠尺寸说话。
3. **同一个三角形被定义两遍**：既标了斜边与底边夹角 30°，又标了斜边长度和竖直边高度 → 过约束变紫红。**对策**：先数"要几个尺寸才能定死" —— 三角形 3 个独立尺寸就够，多一个就冲突。

## 🎯 动手练习

1. 先建底座：`xy plane` 草图矩形，`Coincidence` 到原点 + 水平 + 垂直，标 `200 × 120`，全绿 → `Pad`，`Length` 填 `12mm`。
2. 选 `zx plane` → `Sketch`，用 `Line` 画出斜支撑板的**侧截面**四边形（水平底边贴在底座上表面高度 + 左上斜边 + 竖直边 + 水平上边），端点两两 `Coincidence` 封死。
3. 先后点**斜边和底边**做出角度尺寸改成 `30`，再标底边长 `60`、竖直边高 `70` —— **只留能定死图形的 3~4 个尺寸**；确认整体变**深绿**、无点能滑走。
4. `Exit Workbench` → `Pad`，`Length` 填 `40mm`、勾 `Mirrored extent`；再双击草图把角度 `30` 改成 `45` → `Tools > Update`。

> ✅ 你应该看到：斜支撑板跟着"立起来"，底座尺寸完全没变，特征树无红色标记 —— **角度只在一个地方定义，改它不会让别的东西漂走**。

## 本讲小结

| 概念 | 要点 |
|---|---|
| 斜面为什么难 | 没有现成平面；草图 H/V 轴 ≠ 世界水平/竖直；斜面由前序特征生成会跟着动 |
| 三种做法 | ①角度参考平面（斜面上还要打孔时用）/ ★侧面轮廓拉伸法（笔试推荐）/ ②直接在实体面画 / ③先立板再切（不推荐） |
| 角度怎么标 | 先后点两条相交直线得到角度尺寸；显示为距离就改约束类型；三角形只留 3 个独立尺寸 |
| 贴合关系 | 用 `Coincidence` 让斜板与底座真正贴合，位置尺寸挂在不动的基准上 |
| 三大错误 | 定位尺寸挂在会转的参考上 / 误用水平竖直 / 重复定义导致过约束 |

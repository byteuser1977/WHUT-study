# 第04讲：斜面草图定位（正文约20分钟 + 练习约30分钟）

## 你将学到
- 为什么斜面定位是新手最容易错的地方
- 三种做法对比：①建角度参考平面再画 ②在现有实体面上直接画 ③先做侧面再切
- 斜面角度怎么标、斜面与底面的关系怎么约束
- 三大典型错误：尺寸标错参考、把斜面上的"水平"当成世界的水平、改角度后模型散架

> 笔试必做题的要求里专门写了一句"**注意斜面草图定位**"（对应评分点 ② 结构完整 18 分里的斜支撑板）。这句话不是随便写的 —— 它就是阅卷老师想看你有没有踩过这个坑。

---

## 1. 斜面到底难在哪

平的面，你随便挑一个坐标面（`xy` / `yz` / `zx`）就能画草图，尺寸直接量。斜的面不行，它带来三个连锁问题：

1. **没有现成的平面可用**：`xy` / `yz` / `zx` 都不是你要的斜面，得自己造一个（参考平面，见第03讲）。
2. **尺寸的"参考系"变了**：你在斜面上画草图时，那套 H 轴 / V 轴是**相对于这个斜面**的，不是相对世界的。你以为在标"竖直"，实际标的是"沿斜面方向"。
3. **位置会漂**：斜面本身由前序特征生成，你改了前面那个角度，斜面跟着转，在它上面画的草图也跟着转 —— 如果草图的位置尺寸是相对斜面量的，整个特征会飘走。

> 💡 类比：在水平桌面上摆积木谁都会。但如果你把桌面**先倾斜 30° 再摆**，那"往上叠"和"往桌子里推"就完全是两回事了 —— 你手上那点感觉（水平、竖直）全部失效，必须重新想清楚"我说的竖直，是相对桌子还是相对地球"。斜面草图就是这个道理。

## 2. 三种做法对比

| 做法 | 怎么建 | 优点 | 缺点 | 笔试建议 |
|---|---|---|---|---|
| **① 建角度参考平面，在平面上画草图** | 用 `Plane Definition` 建一个与基准面成 α 角的平面，再 `Sketch` + `Pad` | 角度是**可改的参数**；尺寸就标在斜面的真实长度上，和图纸一致 | 要先想清基准和旋转轴；平面建错方向白费功夫 | ✅ 推荐，笔试首选 |
| **② 直接在实体的斜面 / 侧面上画草图** | 双击实体上那个平面 → `Sketch` | 最快，不用建基准，三四秒进草图 | 这个面由前序特征生成，改了前面的尺寸，草图可能漂 / 报错 | 适合快速试形状，不适合交作业 |
| **③ 先做侧面轮廓再切 / 先立板后切斜** | 先 `Pad` 一个竖直板，再用 `Pocket`（或 `Draft` 拔模）切出斜面 | 直观，不需要角度平面 | 角度是靠"切"出来的，尺寸链变长，一处改动影响一大片；斜面是切出来的面，后面还想在它上面打孔会很别扭 | ❌ 笔试不推荐 |

> ⚠️ 常见坑：做法③最坑的一点是 **"角度不再是一个尺寸，而是一堆尺寸的结果"**。图纸说斜面与底面成 30°，你在做法③里靠"先切 30mm 深、再切 20mm 进"凑出这个角度 —— 图纸改一个数，你得反算出两个数。做法①里那个角度就是一个 `30deg` 的尺寸，改一次就行。

**还有一个经常更好用的变体（做法①的兄弟）**：如果斜支撑板在**侧视图**上就是一个清晰的三角形 / 梯形轮廓，那就干脆**在侧向基准面（`zx plane` 或 `yz plane`，看你的零件朝向）上，把整个侧面轮廓一次画出来**，然后用 `Pad` 给厚度（勾 `Mirrored extent` 镜像范围做对称）。这样：

- 那个 30° 角**直接就是草图里的一个角度尺寸**，看得见、改得动；
- 所有尺寸都在**同一张草图**里，基准统一，不存在"改了角度位置漂走"的问题；
- 不需要建角度参考平面，步骤更少（对应评分点④"操作简单"）。

选做法的判断标准只有一条：**看图纸上这个角度是相对哪个面标注的，以及斜面后面还要不要在上面画东西**。

| 如果你的情况是…… | 就用 |
|---|---|
| 图纸直接标了斜面与某个面的夹角，且斜面之后还要在上面打孔 / 开槽 | 做法①（角度参考平面） |
| 侧视图上轮廓很清晰，斜面只是"板的侧截面形状" | 侧面轮廓拉伸法 |
| 只是想快点看个形状、不打算改 | 做法② |

## 3. 建角度参考平面的具体要点

点 `Plane`（平面）图标 → `Plane Definition`（平面定义）→ `Plane type` 选 `Angle/Normal to plane`（角度 / 垂直平面）。这个类型通常要填三样：

1. `Reference`（参考面）：和它成角度的那个面，一般是 `xy plane` 或 `zx plane`；
2. `Rotation axis`（旋转轴）：一条**直线**，平面绕着它转。屏幕上没有现成的线时，先在合适的基准面上用草图 `Line` 画一条，退出草图后它就能被选；
3. `Angle`（角度）：图纸上的角度值。

然后**看绿色预览**：方向不对就点反向，或者改用另一个参考面。**各个版本这个对话框里字段名称和额外选项会有差异，以你机器上为准。**

建完记得：**这个角度平面本身最好也是"有据可依"的** —— 比如绕的那条轴是底座的某条边，角度就是图纸标的那个角。这样以后改它，模型仍然可控。

## 4. 斜面角度怎么标、关系怎么约束

**标角度**：在 `Sketcher` 里，先后点**两条相交的直线**，再点一下放尺寸的位置。如果出来的尺寸是"距离"而不是"角度"，就在尺寸上双击（或在尺寸上右键打开它的定义），把约束类型改成角度；**具体怎么切换类型版本可能有差异，以你机器上为准**。更稳的办法是画草图时就把两条线画成明显的夹角，CATIA 的 `Quick Constraint` 通常会直接给角度。

**约束斜面与底面的关系**（这是得分点，别偷懒）：

| 关系 | 用什么约束 | 为什么 |
|---|---|---|
| 斜支撑板底面贴在底座上表面 | `Coincidence`（重合）—— 让两块板的接触面互相贴合，或者让两者的边共线 | "看起来贴住了"不算，模型重算后可能穿模 |
| 斜板在底座上的位置（横向） | 尺寸约束：距底座左边 `XX`mm，或 `Coincidence` 到底座的中心线 | 图纸上标的那个定位尺寸 |
| 斜面的倾斜角度 | 角度尺寸（做法①里标在草图内 / 做法①里作为平面参数） | 图纸标注 |
| 斜板的厚度 | 尺寸约束（或在侧面轮廓法里由 `Pad` 的 `Length` 给） | 图纸标注 |

**一个实用习惯**：斜面草图里的定位尺寸，尽量**从斜面草图的自身原点（`origin`）量起**，并用 `Coincidence` 把斜板的一个角点钉在这个原点上。原因：斜面草图的坐标系是跟着参考平面走的，把它钉死在平面原点上，平面一动整块跟着动，不会出现"斜板飞出去"的惨剧。

## 5. 三大典型错误

**错误一：尺寸标在错误的参考上，改了角度模型散架。**

典型表现：斜板在底座上的位置尺寸，是"从斜面自身原点量"的。你把斜面角度从 30° 改成 35°，斜面转了，位置尺寸的基准也跟着转，斜板整体平移到了别处 —— 模型没报错，但形状已经不对了。

对策：让"角度"和"位置"**归到各自该管的基准上**。位置尺寸挂在底座（不动的东西）上，角度挂在斜面本身上。做法①里可以用底座上的一条边做定位参考；侧面轮廓法里所有尺寸都在同一张草图上，天然没这个问题。

**错误二：在斜面草图里用水平 / 垂直约束，误以为是"世界的水平"。**

在斜面草图里，`Horizontality`（水平）指的是**沿这个草图 H 轴方向**，而这个 H 轴是斜面自己的坐标系 —— 它和世界的水平面差着那个倾斜角。

后果：你以为给一条线加了"竖直"，实际它沿斜面偏了 30°，尺寸怎么都对不上图纸。

对策：在斜面草图里**明确靠尺寸说话**。要么直接用角度尺寸把方向和图纸对上，要么把这个斜面上的草图改成"用尺寸标注真实长度 + 用几何约束表达元素之间的关系"，别指望"水平/竖直"帮你。

**错误三：过约束 —— 同一个三角形被定义了两遍。**

典型表现：斜板侧面是个三角形，你既标了斜边与底边的夹角 30°，又标了斜边的长度和竖直边的高度 —— 三角形本来就"两边一角"就够了，多标一个必然冲突，草图变紫红。

对策：动手前先数一下"这张图要几个尺寸才能定死"。三角形：3 个独立尺寸就够。多一个就过约束（回看第02讲第 5 节）。

## 🎯 动手练习（约30分钟）

### A. 建底座（约 5 分钟）

1. `File > New > Part` → `OK`。选 `xy plane` → `Sketch`。
2. 画矩形，左下角 `Coincidence` 到原点，下边 `Horizontality`，左边 `Verticality`，标尺寸 `200 × 120`。
3. 确认变深绿 → `Exit Workbench` → `Pad`，`Length` 填 `12mm` → `OK`。

### B. 推荐做法：侧面轮廓拉伸法做斜支撑板（约 12 分钟）

1. 选中特征树上的 `zx plane`（侧面平面；如果你的零件朝向不一样就选 `yz plane`）→ `Sketch`。
2. 用 `Profile` 里的 `Line`（直线）画一个能代表斜支撑板侧截面的四边形：一条水平底边（贴在底座上表面高度上）、一条从底边右端往左上方走的斜边、一条竖直边、一条水平上边。
3. 加几何约束把轮廓封死：端点用 `Coincidence` 两两连上。
4. 加定位约束：用 `Coincidence` 把底边那一段与底座上表面（在草图里对应到 `zx` 坐标系的那个高度）贴合，或者直接标尺寸把底边定位在底座顶面上。
5. 标尺寸（这是关键一步）：先后点**斜边**和**底边**，出来角度尺寸就双击改成 `30`；如果出来的是距离，就换约束类型（**版本可能有差异，以你机器上为准**）。再标斜板厚度方向所需的尺寸，比如底边长 `60`、竖直边高 `70`。**总共只留能定死图形的 3~4 个尺寸。**
6. 检查草图是否**整体变深绿**；拖动一下看看有没有哪个点还能滑走，能滑就补约束。
7. `Exit Workbench` → 点 `Pad`（凸台）→ `Type` 选 `Dimension`，`Length` 填 `40mm`，勾 `Mirrored extent`（镜像范围，向两侧对称拉伸，总厚 80mm；只想单侧拉就别勾，长度填 80）。
8. 观察：预览是一块斜着的板。方向不对就点 `Reverse Direction`（反向）。
9. `OK`。点 `Tools > Update`（更新）确认无报错。
10. **改角度测试**：双击特征树上的这张侧面轮廓草图，把角度 30 改成 45，回车 → `Exit Workbench` → 点 `Tools > Update`。

> ✅ 你应该看到：斜支撑板跟着"立起来"了，而底座尺寸完全没变；特征树上是 `... Sketch.1 > Pad.1 > Sketch.2 > Pad.2`，没有红色报错标记。**这就是基准统一的好处 —— 角度只在一个地方定义，改它不会让别的东西漂走。**

### C. 对照做法①：建角度参考平面（约 13 分钟）

1. 先在 `zx plane` 上 `Sketch`，用 `Line` 画一条**水平的直线**当作旋转轴，用 `Coincidence` + `Horizontality` + 尺寸把它定位好，变绿后 `Exit Workbench`，得到 `Sketch.3`。
2. 点 `Plane`（平面）图标 → `Plane type` 选 `Angle/Normal to plane`（角度 / 垂直平面）→ `Reference` 选 `xy plane` → `Rotation axis` 选刚才那条线的草图 → `Angle` 填 `30deg`。
3. 看绿色预览：它在水平面基础上转了 30°。方向不对就反向。`OK`，特征树多出 `Plane.1`。
4. 选中 `Plane.1` → `Sketch`。用 `Rectangle` 画一个 `120 × 40` 的矩形（用 `Coincidence` 把它的角点约束到本草图原点），标尺寸、全绿、退出。
5. 点 `Pad`，`Type` 选 `Up to next`（到下一个面）或 `Up to last`（到最后一面），让这块板**长到底座里穿过去** → `OK`。
6. 双击 `Plane.1`，把角度从 `30deg` 改成 `45deg` → `OK` → `Tools > Update`。
7. 对比 B 组和 C 组的结果：两种方法最终都能做出斜板，但**改角度时，C 组多了一层"参考平面"要维护**，而且斜板上要打孔时，C 组能在斜面本身上画草图（更自然）。

> ✅ 你应该看到：斜支撑板是一块**厚度均匀**的斜板，它和底座有明确的贴合关系；把 `Plane.1` 的角度改动后，斜板跟着转，而你在斜板草图里标的尺寸（比如板宽 120）保持有效。**若斜板浮空、穿模或位置乱跳，就回到第 5 节对照错误一，检查你的定位尺寸是挂在哪个参考上的。**

## 本讲小结

| 概念 | 要点 |
|---|---|
| 斜面为什么难 | 没有现成平面可用；草图自己的 H/V 轴不等于世界的水平/竖直；斜面由前序特征生成，会跟着动 |
| 做法① | 建 `Angle/Normal to plane` 角度参考平面再画；角度是可改参数，斜面上后续打孔最自然 |
| 做法② | 直接在实体面上画；快，但不适合交作业（参数化弱） |
| 做法③ | 先立板再切斜面；角度变成尺寸链的结果，不推荐 |
| 侧面轮廓拉伸法 | 在侧向基准面上一次画出侧截面（角度就是草图里一个角度尺寸），`Pad` 给厚度；基准统一、最不容易散架 |
| 选型标准 | 看图纸的角度是相对哪个面标的、斜面之后还要不要在上面画东西 |
| 角度怎么标 | 先后点两条相交直线 → 得到角度尺寸（若显示为距离，改约束类型）；斜率三角形只留 3 个独立尺寸 |
| 贴合关系 | 用 `Coincidence` 让斜板与底座真正贴合，别靠"看起来贴住" |
| 错误一 | 定位尺寸挂在了会跟着斜面转的参考上 → 改角度模型漂走 |
| 错误二 | 在斜面草图里用水平/竖直约束，误当成世界的水平/竖直 |
| 错误三 | 斜率三角形被定义两遍 → 过约束变紫红，删掉多余尺寸 |

# 第05讲：孔与圆角（正文约20分钟 + 练习约30分钟）

## 你将学到
- `Hole`（孔）命令和"草图画圆 + `Pocket`"的区别，什么时候用哪个
- 通孔 / 盲孔 / 螺纹孔的设置，孔怎么定位
- `Fillet`（倒圆角）的参数：等半径、变半径、`Propagation`（传播）是怎么回事
- 圆角失败的常见原因，以及"先大后小、先竖后横"这个顺序为什么管用
- 圆角为什么应该放在特征树的最后

> 本讲直接对应笔试两个评分点：**③ Φ12 通孔位置正确、无几何错误（7 分）**，以及 **② 里的 R11 圆角（属于 18 分那一块）**。26 分都压在打孔和倒角上，值得花时间。

## 1. `Hole` 还是"画圆 + `Pocket`"？

同一个孔，CATIA 里至少有两条路：

| | `Hole`（孔）命令 | 草图画圆 + `Pocket`（凹槽） |
|---|---|---|
| 操作 | 选一个平面 / 定位点 → 设直径、深度、类型 | 在面上画圆 → 标尺寸定位 → `Pocket` 挖穿 |
| 是不是标准孔 | 是，参数就是"直径 / 深度 / 沉头 / 螺纹" | 不是，只是一个圆孔形状 |
| 改直径 | 双击 `Hole.1` 改一个数字 | 要进去改草图里的圆直径 |
| 能不能带沉头 / 螺纹 | 能（`Type` / `Threading` 选项卡） | 要自己画剖面轮廓 |
| 特征树可读性 | 树上直接写 `Hole`，一眼看懂 | 树上只有 `Sketch` + `Pocket`，看不出是孔 |
| 适合 | **标准孔、螺栓过孔、通孔（本题的 Φ12）** | 异形孔、非圆孔、复杂剖面 |

结论给得很直接：**笔试里的 Φ12 通孔用 `Hole` 命令**。理由有三个 —— 参数清晰（`Diameter` 填 12，一眼可见）、深度类型能直接选"到最后一面"保证是通孔、特征树可读性好（评分点④"建模思路清晰"吃这个）。

> 💡 类比：`Hole` 就像体检时的**采血针**：型号标准、按规格选就行。草图画圆 + `Pocket` 像自己做陶艺挖洞：想挖成什么形状都行，但每次都要重新画一遍。量产的、标准的孔，当然用标准件。

## 2. `Hole Definition` 对话框里有什么

`Hole Definition`（孔定义）对话框一般分几页（**页签名称和数量在不同版本会有差异，以你机器上为准**）：

| 页 / 项目 | 中文 | 你要关心什么 |
|---|---|---|
| `Diameter` | 直径 | 本题填 `12mm`（图纸标 Φ12，Φ 就是直径的意思） |
| `Depth`（`Extension` 页） | 深度 | 见下面的深度类型表 |
| `Type` | 类型 | `Simple`（简单孔）/ `Tapered`（锥孔）/ `Counterbored`（沉孔）/ `Countersunk`（锥沉孔）/ `Counterdrilled`（沉孔带锥） |
| `Threading` | 螺纹 | `None`（无）/ 公制细牙 / 公制粗牙。**填 Φ12 不会自动加螺纹**，要螺纹得自己选 |
| `Positioning Sketch`（定位草图） | 定位草图 | 点进去进 `Sketcher`，用点和尺寸决定孔中心在哪 |
| `Reverse Direction` | 反向 | 孔打的方向反了就用它 |

**深度类型（这一步决定通孔还是盲孔）**：

| 深度类型 | 中文 | 含义 | 用途 |
|---|---|---|---|
| `Blind` / `Dimension` | 盲孔 / 按尺寸 | 打到指定深度就停 | 螺纹底孔、销孔 |
| `Up to next` | 到下一个面 | 打穿遇到的第一个面就停 | 单层板 |
| `Up to last` | 到最后一面 | 一直打到最后一张面为止 | **多层结构里最稳的"通孔"** |
| `Up to plane` / `Up to surface` | 到指定平面 / 曲面 | 打到你指定的参考为止 | 有明确终止面的场合 |

> ⚠️ 常见坑：**只填了 `Diameter` 就 `OK`，结果打出一个盲孔**（默认深度往往是个具体数值，不是"打穿"）。题目要的是**通孔**，所以深度一定要选 `Up to last`（到最后一面）—— 如果你的模型这里只有一块板，选 `Up to last` 和 `Up to next` 结果一样。交作业前从背面看一眼孔到底透了没有。

> 💡 类比：通孔与盲孔，就像**打通整堵墙的洞**和**只在墙上钻进去一半的洞**。一个是管子能穿过去，一个是塞栓塞。

## 3. 孔怎么定位（位置分就在这儿）

孔的位置是评分点③的核心。CATIA 里孔的中心其实就是一个**草图点**，所以定位方法和定位一个点完全一样，都是第02讲那套：

| 定位方式 | 怎么做 | 什么时候用 |
|---|---|---|
| 两条边做基准，标两个尺寸 | 在定位草图里，用 `Constraint`（尺寸约束）标"孔中心到左边 XX、到下边 YY" | **最稳，笔试首选**（对应图纸上两个定位尺寸） |
| 与已有特征同心 | `Concentricity`（同心）约束到已有的圆 / 圆弧 | 要跟别的孔的轴线对齐时 |
| 在圆周上均布 | 先做孔，再用 `Circular Pattern`（圆形阵列）或直接阵列出多个 | 法兰螺栓孔 |
| 与中心线对称 | `Symmetry`（对称）约束到中心线 | 对称件上的孔 |

**强烈建议**：定位尺寸**从零件的主基准（角点、中心线、底面）量起**，不要从一条"你画草图时顺手用的"边量起。理由和第04讲一样 —— 基准换了，孔的位置跟着漂。定位草图画完**必须也是完全约束（全绿）**，这是评分点①的一部分。

## 4. `Fillet`（倒圆角）

点 `Edge Fillet`（边线倒圆角，`Dress-Up Features` 工具栏里，或 `Insert > Dress-Up Features > Edge Fillet`）。对话框主要项目：

| 项目 | 中文 | 说明 |
|---|---|---|
| `Radius` | 半径 | 本题填 `11mm`（图纸标 R11，R 就是半径的意思） |
| `Object(s) to fillet` | 要倒圆角的边 | 在模型上点边；多选时新边会加进列表 |
| `Propagation` | 传播方式 | `Tangency`（相切）：自动延伸到相切连续的一整条边链；`Minimal`（最小）：只倒你点的那一段 |
| `Edge(s) to keep` | 保留的边 | 复杂交汇处用来阻止圆角吃掉某些边，防止失败 |
| `Tangency` | 相切模式 | 圆角与相邻面保持相切（默认），一般不用动 |

另外还有 `Variable Radius Fillet`（变半径圆角）、`Chordal Fillet`（弦长圆角）、`Face-Face Fillet`（面-面圆角）、`Tritangent Fillet`（三面相切圆角）。**做题用 `Edge Fillet` 就够了**，等半径、统一 R11。

**圆角失败的常见原因**：

| 失败现象 | 原因 | 对策 |
|---|---|---|
| 提示半径过大 / 无法计算 | 半径比相邻的边或面还大 | 减小半径看看能不能成功，再回图纸核对尺寸 |
| 圆角"吃掉"了旁边的特征 | 圆角半径大于被夹在两条边之间的面的宽度 | 用 `Edge(s) to keep` 保留关键边，或改顺序 |
| 相邻圆角干涉 | 两个圆角在交角处互相抢地方 | **先大后小**；或一次把相交的边放在同一个 `Edge Fillet` 里做 |
| 圆角跨过孔 / 缺口 | 圆角的相切传播顺着边链爬过去了 | 把 `Propagation` 从 `Tangency` 改成 `Minimal`，只倒这一段 |
| 前面的特征一改，圆角报错 | 边的编号随几何变化（拓扑命名问题） | 圆角放最后做；把它 `Deactivate` 停用，改完再启用 |

> 💡 类比：圆角就像**给棱角打磨抛光的砂纸**。R11 是大倒角，砂纸一顿磨；如果两个地方同时磨，磨到交界处就会"互相啃"—— 所以先磨大门（大半径）、再磨小角（小半径），或者一次把那几条边一起磨，让软件自己协调。

## 5. 为什么圆角要放在特征树的最后

三个理由，每一个都真实影响你的得分：

1. **圆角依赖"边"，而边是前面的特征生出来的**。你在前面动一处尺寸，边的编号 / 位置变了，圆角就得重算，很容易报错。放最后，前面的结构稳定了，圆角一次成功。
2. **圆角是"修饰"，不是"功能"**。底座该多厚、孔该在哪，这些才是结构问题。把圆角全堆在最后，等于把结构改动和外观改动分开，改起来顺手得多。
3. **调试方便**：CATIA 里可以右键特征选 `Deactivate`（停用）/ `Activate`（启用）。模型出问题时，把最后的圆角停用，一眼就能看出问题是不是圆角引起的。

**顺序经验：先大后小、先竖后横。**

- **先大后小**：半径大的圆角先做。大半径占用空间多，早点做，后面小的去适配它，冲突少。
- **先竖后横**：竖直方向的棱边先倒，水平方向的边后倒。这样水平边倒圆角时的相邻面已经确定，不会和竖直圆角的端部打架。

## 6. 特征树最后要检查什么

- 树上能看到独立的 `Hole.1`（不是藏在某个 `Pocket` 里）；
- 孔的定位草图和其它草图都是**深绿（完全约束）**；
- 没有带红色 / 黄色标记的特征；`Tools > Update` 之后依然没有；
- 圆角特征排在最后，双击能随时改半径。

## 🎯 动手练习（约30分钟）

练习尺寸是随便定的，只为了把流程走通。

### A. 做底板并在上面打 Φ12 通孔（约 15 分钟）

1. `File > New > Part` → `OK`。选 `xy plane` → `Sketch`，画矩形，`Coincidence` 到原点，加水平 / 垂直，标 `200 × 120`，全绿后 `Exit Workbench`。
2. 点 `Pad`，`Length` 填 `12mm` → `OK`。底板完成。
3. 选中底板**上表面**（在模型上点一下那个面），点 `Hole`（孔）图标 —— 它在 `Pad` / `Pocket` 那一排工具栏里，也可以走菜单 `Insert > Sketch-Based Features > Hole`（**版本可能有差异，以你机器上为准**）。弹出 `Hole Definition` 对话框。
4. 在对话框里的 `Positioning Sketch`（定位草图）那一栏，点草图图标进入 `Sketcher`。屏幕上应该能看到一个代表孔中心的点。
5. 在草图里用 `Constraint`（尺寸约束）给这个点标两个尺寸：到左边 `60mm`、到下边 `80mm`（图纸给的定位尺寸是多少就填多少）。也可以用 `Constraints Defined in Dialog Box` 勾 `Coincidence` 把点约束到底板的某条边上 —— 怎么符合图纸怎么来。
6. 确认草图**变深绿（完全约束）**，点 `Exit Workbench` 回到 `Hole Definition`。
7. `Diameter`（直径）填 `12mm`。
8. 找到深度设置（一般在 `Extension` / `Definition` 页），把类型改成 **`Up to last`（到最后一面）**，这样才是通孔。方向不对就点 `Reverse Direction`（反向）。
9. `Type` 保持 `Simple`（简单孔），`Threading`（螺纹）保持 `None`（无）—— 图纸没要求螺纹就别加。
10. `OK`。从**背面**转一下视图，确认孔是通的。

> ✅ 你应该看到：特征树出现 `Hole.1`，排在 `Pad.1` 后面；孔在底板上是一个直径 12mm 的圆孔，深度类型是到最后一个面（通孔）。双击 `Hole.1` 能直接改直径 —— 这就是用 `Hole` 命令而不是 `Pocket` 的好处。

### B. 做 R11 圆角（约 10 分钟）

1. 按 `Ctrl` 依次点选底板**四条竖直的棱边**（如果只是练习，选一条也行）。
2. 点 `Edge Fillet`（边线倒圆角）图标 → `Radius`（半径）填 `11mm`。
3. 看预览：如果这四条边是"相切连续"的一条链，`Propagation` 设成 `Tangency`（相切）会顺着把一整条边倒掉；只想倒被点中的那一段就改成 `Minimal`（最小）。
4. 如果 CATIA 报错说无法计算 / 半径过大，先把半径临时改小到 `5mm` 看能不能过，能过说明是半径比几何尺寸还大 —— 回图纸核对 R11 标在哪条边上。
5. `OK`。点 `Tools > Update`（更新）。
6. **对比实验**：双击 `Hole.1` 把直径改成 `30mm`，`OK` → 观察 R11 圆角是否正常（它排在孔后面，孔变了圆角会重算，这也是"圆角放最后"的原因之一）。再把直径改回 `12mm`。

> ✅ 你应该看到：棱边被 R11 的圆角代替，面与面之间是光滑过渡；特征树上是 `Pad.1 > Hole.1 > EdgeFillet.1` 的顺序，圆角在最后一位，且没有红色报错标记。

### C. 故意制造一次圆角失败（约 5 分钟）

1. 在底板上再打一个 `Hole`，直径 `20mm`，**定位到离某条棱边只有 8mm 的位置**（故意让离边距离小于 R11）。
2. 退出草图后 `OK`。
3. 现在双击 `EdgeFillet.1` 看它能否重算 —— 圆角半径 11 大于孔边到棱边的距离 8，这个圆角很可能会报错或形状异常。
4. 观察报错信息的位置，然后把这个孔的位置改到离边 20mm 以外，或把圆角半径改小，看模型恢复。
5. 记录你观察到的现象 —— 这就是第4节"圆角失败原因"那张表在真实模型上的样子。

> ✅ 你应该看到：几何被改动后 `EdgeFillet.1` 前面出现报错 / 更新标记，双击它能看到具体提示。**修好它的过程，就是你以后排查圆角问题的标准流程。**

## 本讲小结

| 概念 | 要点 |
|---|---|
| `Hole` vs 画圆 + `Pocket` | 标准孔（本题 Φ12 通孔）用 `Hole`：参数清晰、特征树可读；异形孔才用画圆 + `Pocket` |
| `Diameter` / `Depth` | Φ12 → `Diameter` 填 `12mm`；**通孔必须选 `Up to last`（到最后一面）**，别默认成盲孔 |
| `Type` / `Threading` | `Simple`（简单孔）够用；不选螺纹就没有螺纹 |
| 孔定位 | 就是个草图点：用尺寸（或重合/同心/对称约束）定住，**尺寸从主基准量起**，定位草图必须全绿 |
| `Edge Fillet` | `Radius` 填 `11mm`；`Propagation` 用 `Tangency`（相切）或 `Minimal`（最小） |
| 圆角失败原因 | 半径大于相邻边 / 面宽、圆角互相干涉、相切链传播过头、前序特征改动导致边变化 |
| 顺序经验 | **先大后小、先竖后横**；相交的边尽量放在同一个 `Edge Fillet` 里做 |
| 圆角为什么放最后 | 圆角依赖前面生出的边；放最后好改好查，出问题可 `Deactivate`（停用） |
| 得分提醒 | 评分点③（7 分）：孔直径 12、是通孔、中心位置与图纸一致、无几何错误；评分点② 中的 R11 圆角：半径数值正确、位置正确、无报错 |

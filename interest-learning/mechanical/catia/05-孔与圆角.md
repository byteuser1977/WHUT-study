# 第05讲：孔与圆角（正文约6分钟 + 练习约4分钟）

## 你将学到
- `Hole` vs 画圆 + `Pocket` 的选型
- 通孔设置与孔定位方法
- `Fillet` 失败的原因与对策
- 顺序经验"先大后小、先竖后横、圆角永远最后"

> **本讲重点：通孔定位与圆角顺序** —— Φ12 通孔位置要准，R11 圆角要放在特征树最后。

---

## 1. `Hole` 还是"画圆 + `Pocket`"

> 💡 类比：`Hole` 像用**台钻**打孔 —— 孔径、深度、沉头、螺纹都是标准选项，填完就标准；画圆 + `Pocket` 像用**铣刀**自己铣个洞 —— 形状自由，但参数全得自己管。

| | `Hole` 命令 | 草图画圆 + `Pocket` |
|---|---|---|
| 参数 | 直径 / 深度 / 沉头 / 螺纹，是标准孔 | 只是一个圆孔形状 |
| 改直径 | 双击 `Hole.1` 改一个数字 | 要进去改草图里的圆 |
| 特征树 | 直接写 `Hole`，一眼看懂 | 只有 `Sketch` + `Pocket`，看不出是孔 |
| 适合 | **标准孔、螺栓过孔、通孔（综合零件里的 Φ12）** | 异形孔、非圆孔、复杂剖面 |

**结论：Φ12 通孔用 `Hole` 命令** —— 参数清晰、深度能直接选通孔、特征树一眼可读。

**深度类型（决定通孔还是盲孔）**：`Blind`/`Dimension` 到指定深度就停（盲孔）；`Up to next` 打穿第一个面；**`Up to last`（到最后一面，等效 `Through All`）—— 最稳的通孔**。

> ⚠️ **只填了 `Diameter` 就 `OK`，打出来的是盲孔**（默认深度是个具体数值，不是"打穿"）。要做通孔，深度必须选 `Up to last`；收工前从背面看一眼透了没有。

## 2. 孔怎么定位

孔中心就是一个**草图点**，定位方法和定位一个点一样：在定位草图里用 `Constraint` 标"到左边 XX、到下边 YY"两个尺寸（**最稳，首选做法**），也可以用 `Concentricity`（同心）对齐已有圆、`Symmetry`（对称）约束到中心线。

定位尺寸**必须从零件主基准（角点、中心线、底面）量起** —— 基准换了孔会漂。定位草图也**必须全绿**。

## 3. `Fillet`：参数、失败原因与顺序

`Edge Fillet`（边线倒圆角）在 `Dress-Up Features` 工具栏。参数：`Radius`（这里填 `11mm`）、`Object(s) to fillet`（点边，`Ctrl` 多选）、`Propagation`（`Tangency` = 延伸到相切连续的一整条边链；`Minimal` = 只倒点中的那一段）、`Edge(s) to keep`（阻止圆角吃掉某些边）。

**圆角失败四原因**：

| 现象 | 原因 | 对策 |
|---|---|---|
| 提示半径过大 / 无法计算 | 半径比相邻的边 / 面宽还大 | 临时改小验证，再回图纸核对 |
| 相邻圆角干涉 | 两个圆角在交角处互相抢地方 | **先大后小**；或把相交的边放进同一个 `Edge Fillet` |
| 圆角跨过孔 / 缺口 | 相切传播顺着边链爬过去了 | `Propagation` 从 `Tangency` 改成 `Minimal` |
| 前面特征一改就报错 | 边的编号随几何变化 | 圆角放最后做；必要时 `Deactivate`（停用） |

> ⚠️ **顺序经验：先大后小、先竖后横、圆角永远最后。** 大半径占用空间多，早点做让小的去适配它；竖直棱边先倒、水平边后倒，才不会和竖直圆角端部打架；圆角依赖前面生出的"边"，放最后才好改好查。

## 🎯 动手练习

1. `xy plane` → `Sketch` 画矩形，`Coincidence` 到原点 + 水平 + 垂直，标 `200 × 120`，全绿 → `Pad`，`Length` 填 `12mm`。
2. 选中底板上表面 → 点 `Hole` 图标 → 进 `Positioning Sketch`，给孔中心点标两个尺寸（到左边 `60`、到下边 `80`），确认**深绿**后退出。
3. `Diameter` 填 `12mm`；深度类型改成 **`Up to last`（到最后一面）**；`Type` 保持 `Simple`、`Threading` 保持 `None` → `OK`，从**背面**确认孔是通的。
4. `Ctrl` 选中四条竖直棱边 → `Edge Fillet`，`Radius` 填 `11mm`、`Propagation` 按需选 → `OK` → `Tools > Update`。

> ✅ 你应该看到：特征树是 `Pad.1 > Hole.1 > EdgeFillet.1` 的顺序（圆角最后、无红色报错）；孔从背面看是透的；双击 `Hole.1` 能直接改直径。

## 本讲小结

| 概念 | 要点 |
|---|---|
| `Hole` vs 画圆 + `Pocket` | 标准孔（如 Φ12）用 `Hole`；异形孔才用画圆 + `Pocket` |
| 通孔 | `Diameter` 填 `12mm`，深度**必须选 `Up to last`**，别默认成盲孔 |
| 孔定位 | 就是草图点：尺寸从主基准量起，定位草图必须全绿 |
| 圆角参数 | `Edge Fillet`，`Radius` = `11mm`，`Propagation` 用 `Tangency` 或 `Minimal` |
| 失败四原因 | 半径大于相邻边 / 面宽、圆角干涉、相切链传播过头、前序特征改动导致边变化 |
| 顺序经验 | 先大后小、先竖后横、圆角永远最后；出错可 `Deactivate` 停用排查 |

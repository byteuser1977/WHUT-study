# 第01讲：五道简答题答题框架（正文约20分钟 + 练习约25分钟）

## 你将学到
- 简答题为什么"背定义"拿不到分，什么写法才能拿到分
- 一套通用的答题结构（结论 → 要点 → 落地），五道题都能套
- 每道题考什么、必须提到的关键词、以及最容易丢分的地方

---

## 0. 先看清规则：这部分的判分逻辑和你想的不一样

试题原文里有一句话，是整张卷子最重要的提示：

> **答案不唯一，鼓励写出自己独立的思考与见解，请勿直接使用 AI 生成的套话答案，能够体现自己思考过程即可得分。**

这句话拆开看是三层意思：

| 原文 | 翻成人话 |
|---|---|
| 答案不唯一 | 没有标准答案，判分看的是**推理链条**，不是结论对不对 |
| 请勿使用 AI 套话 | "有限元仿真是一种高效的数值计算方法，在工程领域应用广泛"这种话 = 0 分 |
| 体现思考过程即可得分 | 你**怎么想到的**、**为什么这么判断**，比答案本身更值分 |

> 💡 类比：这就像老师问你"为什么这道题要这么做"。答"因为公式是这样"是背的；答"因为这里要求的是变化率，而条件给的是总量，所以要先把总量转成变化率"才是懂了。**阅卷人想看的是后一种。**

所以本讲不给你现成答案，给你**答题结构 + 得分要点 + 丢分点**。填进去的内容必须是你自己的判断。

---

## 1. 通用答题结构（五道题都能套）

每道题 10 分，写 150~300 字就够了。按这个三步走：

```
① 一句话结论         ← 先给判断，别铺垫。阅卷人一眼看到观点
② 两到三个要点       ← 每个要点 = 判断 + 理由，不要只扔名词
③ 一句落地           ← 结合本车队实际（车型/部件/工况），证明你是想过而不是抄的
```

**得分与丢分的分界线**：

| ✅ 得分写法 | ❌ 丢分写法 |
|---|---|
| "弯曲工况对应直线高速通过颠簸路面，因为前后轮同时受载，车架整体产生下弯变形" | "弯曲工况是常见工况之一，对车架影响很大" |
| "仿真不合格不等于不能加工，因为仿真的载荷取值往往偏保守" | "仿真很重要，我们要重视仿真" |
| 出现至少一个**具体**的部件/参数/场景 | 通篇是"稳定性、安全性、可靠性"这类形容词 |

**三条铁律**：

1. **先结论后解释**。不要"随着汽车工业的发展……"这种铺垫开场，那是套话的典型特征。
2. **每个要点都要有"因为"**。判断 + 理由是完整的得分单元，只有判断会被当成猜测。
3. **至少有一句落到本车队**。提到 EPS/EHB、车架、支架这些本题特有的东西，就自动脱离了套话。

## 2. 五道题的答题框架

### 简答 1：车架仿真主要分析哪两种典型工况？对应什么实际行驶场景？（10 分）

**这题考什么**：你有没有真的翻过设计报告、知不知道车架是干什么用的。

**答题结构**：

```
① 结论：主要是"弯曲工况"和"扭转工况"两种（这是车架刚度的两个基准工况）
② 弯曲工况：怎么加载（前后轮同时受载）→ 车架整体下弯 → 出变形/应力
   对应场景：直线高速通过颠簸路面、跳台落地冲击
③ 扭转工况：怎么加载（单侧车轮受载/一侧悬空）→ 车架被拧 → 出扭转变形
   对应场景：交叉轴、单侧过坎、单轮压石、爬陡坡时一侧翘起
④ 落地：本队报告里还会补充制动/转向等工况，但弯曲+扭转是基准
```

**必须提到的关键词**：弯曲工况、扭转工况、前后轮同时受载、单侧车轮受载、变形量、扭转刚度 / 弯曲刚度。

**常见丢分点**：
- 只写"弯曲和扭转"，不写对应场景 → 后半问没答，直接丢一半分
- 场景写反了（把"单轮过坎"说成弯曲）
- 不写"以本队报告为准"就去猜具体数值 → 报告里写什么就是什么，**答题前先翻报告**

**自查**：能不能一句话说清"为什么单侧受载会产生扭转"？（提示：力的作用点偏离车架中心线，左右两侧变形不一致）

---

### 简答 2：智能化部件相比纯机械部件，对支架、安装座的设计提出了哪些新要求？（10 分）

**这题考什么**：你有没有从机械结构的角度想过"电子件装上车会带来什么麻烦"。

**答题结构**：按六个维度展开，挑 3~4 个维度写深入，比六个都写一句强。

```
① 结论：智能化部件把"能装住"的要求提高到了"装得准、装得稳"
② 精度维度：传感器要测准 → 支架的刚度、位置精度、同轴度要求提高
③ 动态维度：电机/阀块有振动激励 → 支架固有频率要避开，否则共振
④ 环境维度：越野赛道泥水扬尘冲击 → 密封、防振衬套、防护
⑤ 轻量化维度：不能靠堆厚度求刚度 → 加强筋、拓扑优化
⑥ 装配维修维度：线束走向、拆装可接近性
```

**必须提到的关键词**：安装刚度、位置精度 / 同轴度、固有频率 / 共振、防振衬套、加强筋、线束走向。

**常见丢分点**：
- 写成"电子部件更精密所以要更小心"这种空话 → 0 分
- 只答"需要更结实的支架" → 只覆盖了刚度一个维度
- 不区分"智能化带来的**新增**要求"和"本来就有的要求" → 题目问的是**新要求**

**自查**：能不能举一个具体例子？（如：转向角传感器的支架如果太软，车架扭转变形会让传感器基准漂移，读数就不准了 —— 这就是"刚度影响功能"）

### 简答 3：什么是有限元仿真？仿真在赛车设计中有什么价值？（10 分）

**这题考什么**：上课视频有没有看进去，能不能用自己的话讲清楚。

**答题结构**：

```
① 定义：把连续的实体切成有限个单元，每个单元用简单力学关系求解，再拼回整体近似结果
② 关键判断：它是数值近似解，不是精确解 —— 这句话体现理解深度
③ 价值（挑 3 条，每条一句理由）：
   - 省试制成本：改设计只需重跑一次，不用反复加工实件
   - 看见看不见的东西：应力分布、变形趋势，实物上测不到
   - 快速比方案：几种结构形式可以横向比较谁更优
   - 提前暴露薄弱点：在加工前就知道哪里会先坏
   - 能做极端工况：实车不敢跑的工况可以仿真
④ 落地：结合本队说一句（如车架改管径/换接头形式时先仿真对比）
```

**必须提到的关键词**：单元、网格、节点、近似解、应力分布、变形、试制成本。

**常见丢分点**：
- 只写"有限元是一种数值计算方法"就停住 → 定义占 3~4 分，价值占 6~7 分
- 把价值写成"提高效率、保证安全"这种口号 → 必须说**通过什么机制**提高效率
- 不写"近似" → 少了最能体现理解的判断

**自查**：能不能用一句生活化的比喻讲清有限元？（如：估算不规则操场面积，切成很多小方格分别数再求和）

---

### 简答 4：仿真不合格一定不能加工吗？仿真全合格实车就不会出问题吗？（10 分）

**这题考什么**：**工程判断力**。这是五道题里最能拉开差距的一题，因为它故意设了两个"绝对化"的陷阱。

**答题结构**：

```
① 结论：两个答案都是"不一定"，两问都要明确表态
② 第一问为什么不一定：
   - 仿真假设往往偏保守（载荷取值偏严、约束理想化、忽略了实际变形协调）
   - 局部应力超标但整体安全，可通过局部加强解决，不必推翻整个设计
   - 关键判断：放行必须有依据、有记录、有责任人 —— 这才叫工程决策
③ 第二问为什么也可能出问题：
   - 模型简化与真实的差距：焊接残余应力、装配预紧、焊缝质量
   - 输入不确定性：材料批次差异、实际载荷谱覆盖不到
   - 仿真覆盖不到的失效模式：疲劳、磨损、振动与共振、腐蚀
   - 制造与装配误差
④ 落地综合一句：仿真是降低风险的工具，不是合格证
```

**必须提到的关键词**：保守假设、局部应力集中、工程决策要有依据、焊接残余应力、装配预紧、疲劳、载荷谱、模型简化。

**常见丢分点**：
- 只答一问 → 两问各 5 分，只答一问直接丢一半
- 答"仿真合格就肯定没问题" → 完全踩中陷阱
- 只罗列"会有误差"不说误差**从哪来** → 理由不具体不算分
- 忘掉最后那句总结 → 这句是把两个答案串起来的点睛之笔，最容易拿分

**自查**：能不能说出至少三个"仿真覆盖不到的失效模式"？

### 简答 5：CATIA 和 ANSYS 在开发流程中各自的定位是什么？（10 分）

**这题考什么**：你有没有把两个软件放进同一条流程里去理解，而不是当两门课。

**答题结构**：

```
① 结论：一句话把两者分开
   CATIA 回答"长什么样"—— 把设计意图变成可制造、可出图、可装配的确定几何
   ANSYS 回答"扛不扛得住"—— 在设计阶段用数值方法预演力学行为
② 两个软件的定位分别展开（各 2~3 句）
③ 流程定位：CATIA 在前（定义设计空间与结构形式）
   ANSYS 在中（校验与迭代，不合格就回 CATIA 改）
   加工装配与实车测试在后（最终验证）
④ 关键判断：ANSYS 的结论要"回到"CATIA 去落实成尺寸/圆角/加强筋
   —— 两个软件是闭环，不是串行各干一段
```

**必须提到的关键词**：设计意图、确定几何、可制造 / 可出图、预演力学行为、迭代、闭环。

**常见丢分点**：
- 写成"CATIA 是建模软件，ANSYS 是仿真软件" → 这是名词解释，不是定位
- 忘了"迭代/闭环"这层关系 → 这恰恰是流程思维的核心分
- 不结合流程顺序泛泛而谈

**自查**：能不能举一个"ANSYS 的结果反过来改变 CATIA 模型"的具体例子？（如：孔边应力集中 → 回 CATIA 加大圆角半径或加厚垫板）

## 3. 提交规范（容易被忽略但真的扣分）

试题在提交须知里写得很细，这几条一定要照做：

| 项 | 要求 |
|---|---|
| 源文件方式 | 提交 `.CATPart`，命名格式 `必做题1+姓名` |
| 截图方式 | 每个模型 **2 张**：①等轴测完整模型图 ②草图约束截图 |
| 截图质量 | 必须**完整显示**模型、特征树、约束符号；**只拍局部图片不予得分** |
| 简答题 | 直接答在报名表答题区，标清题号，不用抄题 |
| 选做策略 | 至少答 3 题（技术类≥2、思维类≥1），鼓励多答，但**前提是你真掌握** |

> ⚠️ **面试会抽查原题**。原文："面试时可能会抽取你们回答的原题考查，如果出现问题会扣大分。"所以**别答你自己讲不清的题的** —— 挑了题就要能当面展开讲。

## 🎯 动手练习（约25分钟）

### 练习 1：先读报告，再答题（15 分钟）

简答 1、2、5 都要求"根据车队设计报告"。**答题前必须先把报告里相关的部分找出来**：

1. 翻到报告的结构分析章节 → 找出实际分析了哪几个工况、边界条件怎么设的 → 这就是简答 1 的答案来源
2. 翻到转向/制动系统章节 → 找出 EPS/EHB 的具体部件与安装方式 → 这是简答 2 的素材
3. 翻到开发流程或技术路线章节 → 看报告自己怎么描述 CATIA 与 ANSYS 的分工 → 这是简答 5 的答案来源

把找到的三处原文摘录下来（不用抄全，记页码和关键句）。

### 练习 2：用三步结构写一题（10 分钟）

挑简答 4（最能拉开差距的那题）自己写一遍，然后拿下面的自检表对照：

| 自检项 | 是 / 否 |
|---|---|
| 开头第一句就是结论（两个"不一定"都表态了） | |
| 至少写了 3 个"因为……"（不是只列名词） | |
| 提到了至少两个具体的失效模式（焊接残余应力 / 疲劳 / 共振…） | |
| 结尾有一句总结（仿真是降低风险的工具，不是合格证） | |
| 全文没有出现"随着……的发展""众所周知"这类开场套话 | |
| 字数 150~300 字 | |

> 对照答案要点见 [racecar-engineering/01-巴哈赛车与开发流程.md](../racecar-engineering/01-巴哈赛车与开发流程.md)。

### 练习 3：把 AI 的话改成人话（进阶）

让 AI 写一遍某道题，然后做两件事：
1. 圈出所有"换到任何一道题都成立"的句子 —— 那些就是套话，删掉
2. 每删一句，就补一句你自己的判断或一个具体例子

改完对比一下：字数可能差不多，但**信息量完全不同** —— 这就是阅卷人想看的东西。

## 本讲小结

| 概念 | 要点 |
|---|---|
| 判分逻辑 | 看推理链条不看结论；套话零分；体现思考过程即可得分 |
| 通用结构 | ①一句话结论 → ②两三个"判断+理由" → ③一句结合本车队的落地 |
| 三条铁律 | 先结论后解释；每个要点都要有"因为"；至少一句落到本车队 |
| 简答 1 | 弯曲工况（前后轮同时受载 / 颠簸路面、落地）＋扭转工况（单侧受载 / 交叉轴、单轮过坎）；以本队报告为准 |
| 简答 2 | 从精度—刚度—动态—环境—装配—轻量化六个维度展开，举具体例子 |
| 简答 3 | 切成有限个单元分别求解再拼回；关键判断"是近似解"；价值要讲机制不讲口号 |
| 简答 4 | 两问都答"不一定"；放行要有依据；仿真覆盖不到焊接残余应力/疲劳/共振等；**仿真是工具不是合格证** |
| 简答 5 | CATIA 答"长什么样"，ANSYS 答"扛不扛得住"；两者是闭环迭代不是串行 |
| 提交规范 | `.CATPart` 命名 `必做题1+姓名`；截图 2 张且必须完整显示模型/特征树/约束符号 |
| 面试风险 | 会抽查原题，**别答自己讲不清的题** |

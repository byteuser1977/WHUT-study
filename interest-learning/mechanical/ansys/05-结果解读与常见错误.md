# 第05讲：结果解读与常见错误（正文约6分钟 + 练习约4分钟）

## 你将学到
- 应力云图与变形图怎么读（两个坑）
- 安全系数怎么算、多少算合格
- 应力集中与**四条工程对策**
- 结果不可信的信号

---

## 1. 读云图与变形图

`Solution` 下插入 **Equivalent (von-Mises) Stress**，先看**颜色标尺**：上端红=最大、下端蓝=最小，**先读上下限数值和单位**，再看**红色区在哪**——**位置比数值更重要**。

1. **图例自动缩放**：图例上限被拉到当次最大值，120 MPa 和 30 MPa 两次都看着"红一片"，**每次都要读数值**。
2. **变形放大系数**：`Total Deformation` 的 `Scale Factor` 默认可能是 `Auto Scale`，把零点几毫米画成夸张大变形，**看真实量级前先设 `1.0 (True Scale)`**。

变形图：`Total Deformation` 找最大变形位置，**算刚度必须用 `Directional Deformation`**（弯曲看 Y 位移，扭转看加载点 Y 位移）；形态不对说明约束加错。

> 💡 类比：云图像**热成像仪**——一眼看出哪儿"烫"，但它是近似值不是实测；姿势是**先找"哪儿最热"，再问"为什么"**。

## 2. 安全系数

**安全系数 n = 屈服强度 σs ÷ 最大等效应力 σmax**

σs 取实际用材质保书/设计报告（Q235 约 235 MPa、Q345 约 345 MPa）；σmax 用云图**有工程意义**的最大值；也可插入 `Safety Factor` 结果项，`Stress Limit Type` 选 `Tensile Yield`。

**多少算合格**：静载、载荷明确时 **n ≥ 1.5~2**；冲击/疲劳/焊接接头要 **n ≥ 2~3**（焊缝质量、残余应力、疲劳吃掉余量）；**车队目标值以本队设计报告为准**。

> ⚠️ **别在奇异点上算安全系数**：尖角处应力随网格加密无限增大，能算出 n = 0.8 的"车架要断了"，加个圆角就变 3.0（问题在几何不在强度）。

## 3. 应力集中与四条工程对策

**应力集中**：力流遇截面突变被挤在一起，局部应力放大若干倍，裂纹常从这里起源。高发位置：**尖角/直角过渡**（可放大 3~10 倍，网格越细越大）、**孔边**（约 3 倍）、**焊接接头**（几何突变 + 热影响区组织改变 + 残余拉应力叠加，最常见的失效起点）。

| 对策 | 怎么做 |
|------|--------|
| **① 加圆角/倒角** | 直角改 R 圆角，半径越大集中越低 |
| **② 加垫片/加大承压面积** | 加厚垫片、做大法兰面、点接触改面接触 |
| **③ 改受力路径** | 加筋、加斜撑、开口框改闭合框，把力"引流"走，**最有效** |
| **④ 优化接头设计** | 焊缝避开高应力区，合适坡口，接头加套管，避免焊缝交叉 |

验证对策：改完几何**在同样网格尺寸下**重算对比应力降幅。

## 4. 结果不可信的信号

| 信号 | 现象 / 怎么查 |
|------|--------------|
| **网格太粗** | 云图像马赛克、加密后变化 > 10% → 做网格无关性 |
| **假约束** | 应力偏低、变形偏小、四角全固定 → 数约束了几个自由度，对得上受力路径吗 |
| **载荷没依据** | 拍脑袋填数、没乘动载系数 → 必须有出处（质量表×g×系数） |
| **单位/密度错** | 变形差 1000 或 10⁶ 倍、密度填 7850 → 手算校核数量级 |
| 材料模型用错 | 只给线弹性却想预测塑性/吸能/疲劳 |
| 未收敛 | 力收敛曲线震荡、求解报错 → 看 `Solution Information` |
| 奇异点当结论 | 尖角应力越加密越大却当真实应力 → 加圆角后是否消失 |

> ⚠️ 一句话：**结果不可信的最大原因通常不是软件算错，而是人填错**。

## 🎯 动手练习（约4分钟）

1. `Element Size` 设 **20 mm** 求解，读 `Equivalent Stress` 最大值和位置；改 **10 mm**、**5 mm** 各重算，看应力是否稳定。
2. 把 `Total Deformation` 的 `Scale Factor` 从 `Auto Scale` 改成 **1.0**，看变形被夸大了几倍。
3. `Solution` → `Insert` → **Safety Factor**，`Stress Limit Type` 选 `Tensile Yield`（缺屈服强度就回 `Engineering Data` 补——**这个坑你一定会踩**）。
4. 在最小安全系数位置**加圆角**，**保持网格尺寸不变**重新求解，对比该位置应力。

> ✅ 你应该看到：最大应力随加密上升但**位置基本不变**（一直涨不停＝奇异点）；**加圆角后该位置应力明显下降（常降 30%~50%）**；`Scale Factor` 改 1.0 后变形图变平淡才是真实量级。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 云图 | 先读图例上下限与单位，再看红色区在哪；**位置比数值重要**；算刚度用 `Directional Deformation` |
| 两个陷阱 | 图例自动缩放不能比颜色；变形图 `Scale Factor` 先设 1.0 |
| 安全系数 | **n = 屈服强度 ÷ 最大等效应力**；静载 1.5~2，冲击/疲劳 2~3 |
| 应力集中四对策 | 加圆角 / 加垫片扩大承压面 / 改受力路径加筋加斜撑 / 优化接头与焊缝 |
| 不可信信号 | 网格太粗、假约束、载荷无依据、单位密度错、材料模型错、未收敛、奇异点当结论 |

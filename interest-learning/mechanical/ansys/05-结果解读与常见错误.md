# 第05讲：结果解读与常见错误（正文约25分钟 + 练习约30分钟）

## 你将学到
- 怎么看应力云图：颜色标尺、图例上限被"拉伸"的陷阱、最大值的位置比数值更重要
- 安全系数怎么算，多少算合格
- **应力集中**是怎么来的（尖角、孔边、焊接接头），以及四条工程对策
- **仿真结果不可信的七个信号**——学会自己给自己的结果挑毛病
- 怎么把一堆云图讲成一句领导/评委听得懂的"人话"

---

## 1. 看懂应力云图（Equivalent Stress Contour）

在 `Solution` 下插入 **Equivalent (von-Mises) Stress**（等效应力，也叫 von Mises 应力），回车后出现彩色云图。

> ⚠️ 本讲操作针对 **ANSYS Workbench 2024 R2**；结果项 `Details` 面板字段名在不同小版本可能略有差异，**以你机器上为准**。

三个必看的东西：

| 看什么 | 在哪儿 | 说明 |
|--------|-------|------|
| **颜色标尺（Legend）** | 图左上/左下角那根彩条 | 上端红 = 最大值，下端蓝 = 最小值。**先看上下限的数值和单位** |
| **单位** | 标尺上的单位、或 Details 里的 `Results` | Workbench 默认单位制下应力常显示为 **MPa**；如果显示的是 Pa，数值会大 10⁶ 倍 |
| **红色区在哪** | 模型上 | **位置比数值更重要**：红色集中在哪个接头、哪根管、哪个孔边 |

两个新手必踩的坑：

1. **图例自动缩放造成的错觉**：软件默认把图例上限拉到"当次分析的最大值"，所以两次分析看起来都是"红一片"，但一次最大 120 MPa、一次最大 30 MPa。**每次都要读数值，不能只看颜色。**
2. **变形图的放大系数**：`Total Deformation` 的 Details 里有个 `Scale Factor`（放大系数），默认可能是 **Auto Scale**，会把零点几毫米的变形画成夸张的大变形。**看变形图前先把 `Scale Factor` 设成 `1.0 (True Scale)`**，否则你会以为车架在打摆子。

> 💡 类比：云图像**热成像仪**——一眼看出哪儿"烫"。但热成像给的是**表面温度**，云图上的应力同样是软件算出来的近似值，不是仪器实测。看云图的姿势是：**先找"哪儿最热"，再问"为什么是这儿"。**

### 变形图（Total Deformation / Directional Deformation）

- **Total Deformation（总变形）**：每点位移的大小（不分方向），用来找最大变形位置。
- **Directional Deformation（方向变形）**：指定 X/Y/Z 分量，**算刚度必须用这个**：垂向弯曲刚度看 Y 向位移，扭转工况看加载点的 Y 向位移。
- 看变形图看三件事：**最大值多大、在哪儿、形态对不对**（弯曲是 U 形下塌、扭转是螺旋形；形态不对说明约束加错）。

## 2. 安全系数（Safety Factor）

$$\text{安全系数 } n = \frac{\text{屈服强度 } \sigma_s}{\text{最大等效应力 } \sigma_{max}}$$

| 项 | 从哪来 |
|----|-------|
| 屈服强度 σs | Q235 约 235 MPa，Q345 约 345 MPa，6061-T6 约 240~275 MPa。**以实际用材的质保书/设计报告为准** |
| 最大等效应力 σmax | 云图读数，**但要取"有工程意义"的那个最大值**（见第 4 节） |
| 安全系数 n | 也可在 `Solution` 下插入 **Safety Factor**，设 `Stress Limit Type` 为 `Tensile Yield` |

**多少算合格？** 没有万能数字，取决于工况与行业惯例：
- 静载、载荷明确：**n ≥ 1.5 ~ 2** 是常见工程做法；
- 冲击/疲劳/焊接接头：要更高，**n ≥ 2 ~ 3**，因为焊缝质量、残余应力、疲劳效应都会吃掉余量；
- **车队的目标值以本队设计报告为准**，报告里一般会写"各工况最小安全系数不低于 X"。

> ⚠️ 常见坑：**别在奇异点上算安全系数**。尖角处最大应力随网格加密无限增大，用它能算出 n = 0.8 的"车架要断了"，但换个圆角就变 3.0——这说明问题在几何形状，不在结构强度。正确做法是：先做应力集中对策（第 3 节），再对"平滑位置"读应力。

## 3. 应力集中（Stress Concentration）与四条工程对策

**应力集中**：当力流（载荷传递路径）遇到截面突变，流线被迫挤在一起，局部应力被"放大"若干倍；而裂纹，往往就从那里起源。

三个高发位置：

| 位置 | 为什么 | 放大倍数直观感 |
|------|-------|--------------|
| **尖角 / 直角过渡** | 力流被迫绕着急弯走，截面突变 | 尖锐内角可放大 3~10 倍以上；网格越细越大（会发散） |
| **孔边** | 孔把材料挖空了，力流被迫从孔两侧"绕行" | 圆孔边约 3 倍；椭圆孔更长方向更严重 |
| **焊接接头（焊趾、焊缝端部）** | 几何突变 + 材料组织改变（热影响区）+ 残余拉应力三重叠加 | 巴哈车架最常见、也最危险的失效起点 |

### 四条工程对策

| 对策 | 怎么做 | 为什么有效 |
|------|-------|-----------|
| **① 加圆角 / 倒角** | 把直角改成 R 圆角（管接头布置圆角、支座边缘倒圆）；半径越大，应力集中越低（受空间与焊接可达性限制） | 让力流"平缓过渡"，截面变化不再突兀 |
| **② 加垫片 / 加大承压面积** | 螺栓连接处加厚垫片、把安装座的法兰面做大、把点接触改成面接触 | 把集中载荷摊到更大的面上，单位面积受力下降 |
| **③ 改受力路径（加筋、加斜撑、加闭合框）** | 在应力大的位置加三角斜撑把力"引流"到另一根管上；把开口框架改成闭合框架提抗扭 | 从根上减少该区域的载荷通量，最有效的办法 |
| **④ 优化接头设计** | 避免焊缝设在应力集中区与高应力区；用合适的坡口与焊脚尺寸；管接头加套管/鞍座；避免超长焊缝与焊缝交叉 | 焊趾是天然的应力集中源，把焊口从高应力区搬走比把管子加粗更划算 |

> 💡 类比：应力集中就像**堵车**。一条宽阔的高速（粗管子）突然收窄成一个路口（尖角/孔/焊缝），车流不会凭空消失，只能挤在一起慢慢挪——堵点就是最容易"出事"的地方。加圆角 = 把路口改成渐变车道；加垫片 = 加宽收费站；改受力路径 = 修一条新路把车引走。

**验证对策是否有效**：改完几何重划网格重算，比较该位置应力降了多少。**必须在同样网格尺寸下对比**，否则比的是网格密度而不是设计。

## 4. 仿真结果不可信的七个信号

答简答题、做设计报告、和学长对方案时，这七条最有用——**学会自己给自己的结果挑毛病**。

| # | 信号 | 现象 | 怎么查 |
|---|------|------|--------|
| 1 | **网格太粗** | 云图像马赛克；加密后结果变化超过 10% | 做网格无关性（第 03 讲） |
| 2 | **假约束** | 应力偏低、变形偏小、云图"太平"；四角全固定 | 数一数约束了几个自由度，和真实受力路径对得上吗 |
| 3 | **载荷取值没依据** | 载荷是"拍脑袋"填的 1000 N；没乘动载系数 | 载荷必须有出处（质量表 × g × 系数），写进报告 |
| 4 | **单位搞错** | 变形大了 1000 倍或 10⁶ 倍；密度填成 7850 而不是 7.85e-9（t/mm³ 制） | 做一次手算数量级校核 |
| 5 | **材料模型用错** | 只给线弹性，却想预测撞坏/塑性变形/吸能；想算疲劳却没有 S-N 曲线 | 明确你分析的是**强度**还是**塑性/吸能/疲劳**，前者线弹性够用，后者不够 |
| 6 | **结果发散 / 没收敛** | 力收敛曲线震荡不下降；求解报错 | 看 `Solution Information` |
| 7 | **奇异点当结论** | 尖角处应力越加密越大，被当成真实应力 | 看它是不是奇异点（加圆角后是否消失） |

**还有两条容易忽略的"隐性不可信"**：
- **模型简化太多**：删圆角没事，删掉关键斜撑、焊接当完全刚接、忽略装配预紧 → 结果与实车不符；
- **只算了强度，没算别的失效模式**：振动共振、疲劳、磨损、装配误差、螺栓松动——**仿真只管结构强度，管不了这些**（模块三"仿真全合格也会出问题"的答案来源）。

> ⚠️ 一句话总结：**结果不可信的最大原因通常不是软件算错，而是人填错**——材料、约束、载荷、单位、简化，每一项都可能是误差源。

## 5. 把仿真结论讲成一句"人话"

云图、表格、刚度数字都不是结论——**结论是一句话**。模板：

> 在 **【工况】** 下，**【结构部位】** 的最大等效应力为 **【XX MPa】**，最大变形为 **【X.XX mm】**，**【弯曲/扭转】刚度**为 **【XXX N/mm 或 XXX N·m/deg】**，相对 **【许用值/上一版/目标值】** 有 **【余量/超限】**；最危险的部位是 **【具体位置】**，建议 **【加圆角 / 加斜撑 / 加厚垫片】**；本次分析未考虑 **【焊接残余应力 / 疲劳 / 装配预紧】**，需在 **【试验 / 后续分析】** 中验证。

举例（示意，不是标准答案）：

> 扭转工况下，车架最大等效应力 287 MPa，出现在**前环与左侧纵梁的接头焊趾处**；扭转刚度约 1.2×10³ N·m/deg。该处应力集中明显，Q235 下安全系数不足 1.0，建议**加大接头圆角并加一根斜撑分流**，改善后复算降到 190 MPa 以下。本次为线弹性静力分析，未计入残余应力与疲劳，需试验验证。

四个层次：**数值 → 位置 → 判断（够不够） → 建议（怎么办）**。少任何一层都不算结论。

## 🎯 动手练习（约30分钟）

在你的车架/梁模型上，练"挑毛病"和"提改进"。

1. 把 `Mesh` 的 `Element Size` 设成 **20 mm**，`Solve`，读 `Equivalent Stress` 最大值和位置，记进下表第 1 行。
2. 改成 **10 mm**，`Solve`，记第 2 行；改成 **5 mm**，记第 3 行。
3. 把 `Total Deformation` 的 `Scale Factor` 从 `Auto Scale` 改成 **1.0 (True Scale)**，截图对比，体会变形被夸大了多少倍。
4. `Solution` → `Insert` → **Safety Factor**，在 Details → `Stress Limit Type` 里选 **Tensile Yield**，看最小安全系数出现在哪。（如果材料库里没有屈服强度，说明这条结果算不出来，先回 `Engineering Data` 补 `Tensile Yield Strength`——**这个坑你一定会踩一次**。）
5. 找到最小安全系数所在的位置，回到 `SpaceClaim`/几何里，**在那个位置加一个圆角**（或把圆角半径加大）。
6. 重划网格（**单元尺寸与上次相同**）、重新 `Solve`，把该位置应力抄进表里对比。
7. 把七条"不可信信号"逐条对照你的模型检查，写成 7 行小列表。
8. 用第 5 节的模板，把你的结果写成一句 3~4 行的话。

| 网格尺寸 | 单元数 | 最大应力 (MPa) | 出现位置 | 最大变形 (mm) | 最小安全系数 |
|---------|-------|---------------|---------|--------------|------------|
| 20 mm | | | | | |
| 10 mm | | | | | |
| 5 mm | | | | | |
| 5 mm + 加圆角 | | | | | |

> ✅ 你应该看到：
> - **最大应力随加密上升、位置基本不变**；如果它稳定在某个值附近，说明这个位置是真实的应力集中；如果一直涨不停，那就是奇异点（尖角/点约束处）；
> - **加圆角后该位置的应力明显下降**（常常下降 30%~50% 甚至更多）——这就是应力集中对策的量化效果；
> - `Scale Factor` 改成 1.0 后，变形图变得"平淡"，这才是真实变形量级；
> - 插入 `Safety Factor` 时如果弹出提示说缺少 `Tensile Yield Strength`，去 `Engineering Data` 里给材料补上这一项再回来看；
> - 你会发现自己模型上至少"中"了七条信号里的一两条——**这才是这次练习真正的收获**。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 应力云图 | 先读图例上下限与单位，再看红色区在哪；位置比数值重要 |
| 图例陷阱 | 图例每次自动缩放，两次分析的颜色不可直接比 |
| 变形图陷阱 | `Scale Factor` 默认可能是 Auto，看真实量级要先设 1.0 |
| 方向变形 | 算刚度必须用 Directional Deformation，不能用 Total Deformation |
| 安全系数 | n = 屈服强度 / 最大等效应力；静载常见 1.5~2，冲击/疲劳要更高 |
| 应力集中 | 尖角、孔边、焊接接头的力流拥挤，局部应力被放大数倍 |
| 四条对策 | 加圆角 / 加垫片扩大承压面 / 改受力路径加筋加斜撑 / 优化接头与焊缝位置 |
| 不可信信号 | 网格太粗、假约束、载荷无依据、单位错、材料模型错、未收敛、奇异点当结论 |
| 隐性风险 | 过度简化、焊接残余应力、装配预紧、疲劳与振动——仿真管不到 |
| 讲成人话 | 数值 → 位置 → 判断（够不够）→ 建议（怎么办），最后补一句局限 |
| 心态 | 结果不可信通常不是软件错，是人填错；要会给自己挑毛病 |

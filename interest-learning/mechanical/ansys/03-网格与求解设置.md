# 第03讲：网格与求解设置（正文约25分钟 + 练习约30分钟）

## 你将学到
- 网格划分的三个关键参数：单元尺寸、单元类型、局部细化
- 四面体和六面体到底怎么选，为什么车架常用壳单元 + 梁单元
- **网格无关性验证**：怎么证明"我的结果不是网格的锅"
- 约束（Fixed Support / Displacement）和载荷（Force / Pressure / Remote Force / Moment）分别怎么加、加在哪
- 求解不收敛怎么办，"假约束"是怎么产生的

## 1. 网格划分：给模型穿衣服

在 `Model` 里，`Mesh` 这一节决定"切成多少块"。三个核心参数：

| 参数 | 在哪儿设 | 作用 | 怎么定 |
|------|---------|------|--------|
| **Element Size（单元尺寸）** | Mesh → Details → `Sizing` → `Element Size` | 全局单元边长，越小越准越慢 | 从"结构特征尺寸的 1/10 左右"起试，比如 50 mm 管的车架先用 10~15 mm |
| **单元类型** | Mesh → Details → `Method` → `Method` | 四面体（Tetrahedrons，默认）/ Hex Dominant（六面体为主）/ Sweep（扫掠）/ Multizone | 复杂几何用四面体省事；规则长条管件用 Sweep 出六面体 |
| **局部细化** | 右键 Mesh → `Insert` → `Sizing` / `Refinement` | 只把关心的部位（焊趾、孔边、安装座）切细 | 选中面/体 → `Element Size` 填更小的值 |

> ⚠️ 本讲操作针对 **ANSYS Workbench 2024 R2**；`Sizing`、`Method`、`Quality` 下的具体字段名在不同小版本可能略有差异，**以你机器上为准**。

同时看两个质量指标（在 `Mesh` → Details → 展开 `Quality` 与 `Statistics`）：
- **`Mesh Metric`（网格度量）**：选 `Element Quality`（单元质量，0~1，越接近 1 越好）或 `Skewness`（畸变度，越接近 0 越好）。
- **`Aspect Ratio`（长宽比）**：单元最长边与最短边的比值，太瘦长的单元精度差。

> 💡 类比：网格就像**给衣服打版**。同样的布（几何），格子划得太粗，做出来的衣服只能看出个大概轮廓（应力云图像马赛克）；划得太细，裁片多到缝不完（求解要几小时）。**关键是"该细的地方细"**——也就是应力变化剧烈的地方（尖角、孔边、受力点）必须密集，应力平滑的地方可以粗。

### 四面体 vs 六面体

| 对比项 | 四面体（Tetrahedrons） | 六面体（Hexahedral） |
|--------|----------------------|---------------------|
| 自动划分 | 几乎任何几何都能划 | 需要规则几何，或先切块 |
| 同样精度所需单元数 | 多 | 少（大约少 3~5 倍） |
| 计算时间 | 慢 | 快 |
| 弯曲变形表现 | 偏"硬"，容易低估变形（可用二阶单元缓解） | 好 |
| 适合 | 复杂铸件、支架、有圆角的实体 | 长条管件、规则板件 |

**车架这类空间管阵结构**，工程上更常见的做法是**壳单元（Shell）+ 梁/管单元（Beam）**：把钢管当梁单元，把座舱板当壳单元。这样单元数量从几十万降到几千，还能直接得到"扭转刚度、弯曲刚度"这种整体指标。**具体用哪种建模策略以本队设计报告和历史模型为准**——不同车队、不同年份的做法可能不一样。

## 2. 网格无关性验证（这一节是"专业"和"业余"的分界线）

**网格无关性**：不断加密网格，直到结果基本不再变化。只有做到这一步，你才能说"这个结果是结构的性质，不是网格的产物"。

操作套路：

1. 先用粗网格（比如 Element Size = 20 mm）跑一遍，记下最大应力 σ₁ 和最大变形 δ₁。
2. 加密一倍（10 mm），记下 σ₂、δ₂。
3. 再加密（5 mm），记下 σ₃、δ₃。
4. 画一张小表：

| 单元尺寸 | 单元数 | 最大应力 (MPa) | 最大变形 (mm) |
|---------|-------|---------------|--------------|
| 20 mm | … | σ₁ | δ₁ |
| 10 mm | … | σ₂ | δ₂ |
| 5 mm | … | σ₃ | δ₃ |

**判据**：相邻两次加密，**变形变化 < 2%~5%、应力变化 < 5%**，就可以认为网格无关了，之后报告里用中间那档网格。

> ⚠️ 反例（很常见）：如果你的最大应力**越加密越大、停不下来**，那不是网格问题，是**奇异点（Singularity）**——尖角、点约束、点载荷处理论应力趋于无穷大。这种位置的应力值**没有工程意义**，别拿它算安全系数。处理办法：加圆角、把点载荷改成面载荷或 `Remote Force`，或者只关心离该点一定距离外的应力值（圣维南原理）。

## 3. 约束和载荷怎么加

### 3.1 约束（Boundary Conditions）

| 约束类型 | 含义 | 典型用途 |
|---------|------|---------|
| **Fixed Support（固定支撑）** | 把选中的面/边/点完全锁死（平动 + 转动都为 0） | 模拟焊接在底盘上的安装点、后轴支座 |
| **Displacement（给定位移）** | 只锁住你指定的方向（比如只允许 `Y = 0`） | 对称面的法向约束、扭转工况中"只允许上下动"的一侧车轮 |
| **Remote Displacement（远端位移）** | 通过一个远端点（Remote Point）作用的位移约束 | 想约束某个位置"平均"行为时用 |
| **Frictionless Support（无摩擦支撑）** | 只约束法向，不约束切向 | 对称面常用 |

加约束的三条铁律：
1. **施加在真实的存在处**：车架通过悬架与车轮相连，悬架的力通过**安装孔/支座面**传给车架，所以约束就加在那些孔面或支座面上，不要随便挑一根管子的中间锁死。
2. **不多不少**：约束太多 = 假约束（结构被人为地加固了，应力偏低、变形偏小，得出"很安全"的假结论）；约束太少 = 刚体位移，应力爆表。
3. **加在面上而不是点上（能加面就加面）**：点约束、点载荷会人为制造无穷大的应力集中。

> 💡 类比：约束就像**用夹子固定一块木板**。你夹得太死（六个方向全锁），木板当然不会动——但那是因为夹子，不是因为木板结实；你一个夹子都不用，木板往哪跑都不知道。真实结构是被"几个具体的点"托住的，仿真要复现的正是这几处。

### 3.2 载荷（Loads）

| 载荷类型 | 单位 | 适用场景 |
|---------|-----|---------|
| **Force（力）** | N | 集中力；可 `Vector`（给方向）或 `Components`（给 XYZ 分量） |
| **Pressure（压强）** | MPa（按单位制） | 分布载荷，如气动压力、制动踏板的踏板面压力 |
| **Remote Force（远端力）** | N | 力作用在几何之外的某个位置（如通过悬架传到车架），软件自动折算成力 + 力矩 |
| **Moment（力矩）** | N·mm | 直接施加力矩 |
| **Standard Earth Gravity（标准重力）** | m/s²（默认 9806.6 mm/s²） | 自重；`Direction` 选 -Y |
| **Acceleration（加速度）** | mm/s² | 冲击/制动工况的惯性载荷，比"加重力"更灵活 |
| **Bearing Load（轴承载荷）** | N | 沿圆柱面按余弦分布，模拟轴对孔的压 |
| **Hydrostatic Pressure（静水压力）** | MPa | 液体压力（如油箱、水箱壁） |

> ⚠️ 常见坑：**载荷要写在工况里说明来源**。车架弯曲工况的载荷从哪来？——乘员与座椅质量、发动机质量、油箱、备胎，加上路面通过轮心传给车架的反力。这些数字全部来自**本队设计报告里的质量表和载荷分配**，不能自己拍脑袋。

### 3.3 求解设置与"看收敛"

- **线性静力分析（Static Structural 默认）是直接解一次方程**，不存在"迭代收敛"问题。你只要确认没报错、结果算完了。
- **什么时候才看收敛**：有**非线性**（大变形 `Large Deflection`、材料塑性 `Plasticity`、接触 `Contacts`）或**迭代求解**时，才需要看 **`Solution Information`**（求解信息）里的**力收敛曲线**和残差输出。曲线应该单调下降并低于判据线；来回震荡说明发散，结果不能用。
- **警告（Warning）要逐条读**，不要点"关闭"就出结果。常见的有：网格质量偏低、有未约束的自由度、接触未设置、结果可能不准确等。**具体提示文字以你机器上的版本为准。**
- 求解不收敛的常见对策：① 加约束消除刚体位移；② 打开 `Large Deflection`；③ 检查接触类型（`Bonded` 绑定 / `No Separation` 不分离 / `Frictional` 摩擦 / `Frictionless` 无摩擦）；④ 载荷步分几步慢慢加载（`Analysis Settings` → `Auto Time Stepping`）。

## 🎯 动手练习（约30分钟）

在上一讲的 1000 × 50 × 50 mm 方钢模型上做**网格无关性实验**。

1. 打开上一讲的工程，双击 `Model` 进入 Mechanical。
2. 左侧树点 `Mesh`，右下 `Details of "Mesh"` → 展开 `Sizing` → `Element Size` 填 **20 mm**。
3. 右键 `Mesh` → `Generate Mesh`。
4. 展开 `Statistics`，记下 **`Nodes`（节点数）** 和 **`Elements`（单元数）**；展开 `Quality`，看 `Mesh Metric` 选 `Element Quality` 后的 `Min` 值。
5. 点 `Solution` 工具条的 **Solve**，分别点开 `Total Deformation` 和 `Equivalent Stress`，把**最大值**记到表里（第 1 行）。
6. 回到 `Mesh`，把 `Element Size` 改成 **10 mm**，重新 `Generate Mesh` 并 `Solve`，记第 2 行。
7. 改成 **5 mm**，重复，记第 3 行。
8. 再加一档局部细化：右键 `Mesh` → `Insert` → **Refinement（细化）**，选中**左端固定面的根部附近面**，`Refinement` 级别填 **2**，重新生成并求解，观察最大应力怎么变。
9. 打开 `Solution Information`，翻一下求解日志，看看有没有警告信息。

> ✅ 你应该看到：
> - 单元数从 20 mm 到 5 mm 大约增长十几到几十倍；
> - **最大变形随网格加密只变化百分之几然后稳定**——这就是网格无关了；
> - **最大应力如果一直随加密往上走**（比如从 60 MPa 涨到 120 MPa 还不停），说明它出现在固定端的**尖角/点约束奇异处**，这个数值不能用来算安全系数；
> - 求解日志里如果没有红字（Error），只有黄色 Warning，通常是可以出结果的，但要读懂警告说了什么。

## 本讲小结

| 概念 | 要点 |
|------|------|
| Element Size | 全局单元尺寸，先由结构特征尺寸估，再靠无关性验证定档 |
| Method | 四面体通用、六面体省算力；长条管件优先扫掠/梁单元 |
| 局部细化 | 应力变化剧烈处（尖角、孔边、焊趾）加密，其余可粗 |
| 网格质量 | 看 Element Quality（越接近 1 好）与 Skewness（越接近 0 好）、长宽比别太瘦 |
| 网格无关性 | 加密到变形变化 <2%~5%、应力变化 <5%，即可定档 |
| 奇异点 | 尖角/点约束/点载荷处应力发散，数值无工程意义，别算安全系数 |
| Fixed Support | 完全锁死，用在真实安装面 |
| Displacement | 只锁指定方向，常用在对称面与扭转工况的单侧约束 |
| Force / Pressure / Remote Force | 集中力 / 分布压强 / 几何外的力；能加面就别加点 |
| 收敛 | 线性静力解一次即完；非线性/接触才看 Solution Information 收敛曲线 |
| 检查清单 | 无 Error、警告读懂、约束合理无助刚、载荷有来源 |

# 第03讲：网格与求解设置（正文约6分钟 + 练习约4分钟）

## 你将学到
- 单元尺寸、单元类型、局部细化三个参数
- 四面体 vs 六面体怎么选
- **网格无关性验证**怎么做
- 约束与载荷怎么加，"假约束"怎么产生

---

## 1. 网格：三个参数 + 两种单元

| 参数 | 在哪儿设 | 怎么定 |
|------|---------|--------|
| **Element Size** | Mesh → `Sizing` | 从特征尺寸的 1/10 起试（50 mm 管的车架先用 10~15 mm） |
| **单元类型** | Mesh → `Method` | 复杂几何用四面体（默认）；规则长条管件用 `Sweep` 出六面体 |
| **局部细化** | 右键 Mesh → `Insert` → `Sizing`/`Refinement` | 只加密关心的部位：焊趾、孔边、安装座 |

质量指标看 `Element Quality`（越大越好）、`Skewness`（越接近 0 越好）、`Aspect Ratio` 别太瘦长。四面体几乎任何几何都能划，但同精度下单元数比六面体多 3~5 倍、算得慢、弯曲时偏"硬"容易低估变形；六面体省算力但需规则几何。**车架这类空间管阵**更常用**壳单元 Shell + 梁单元 Beam**，单元数从几十万降到几千，还能直接得到弯曲/扭转刚度——**用哪种策略以本队设计报告和历史模型为准**。

> 💡 类比：网格像**给衣服打版**——划太粗只看出马赛克轮廓，划太细裁片多到缝不完。**关键在"该细的地方细"**：尖角、孔边、受力点这些应力变化剧烈处必须密，平滑处可粗。

## 2. 网格无关性验证

不断加密网格直到结果基本不变，才能说结果是结构的性质、不是网格的产物。

1. 粗网格（Element Size = 20 mm）跑一遍，记最大应力 σ₁、最大变形 δ₁；
2. 加密到 10 mm 记 σ₂、δ₂，再到 5 mm 记 σ₃、δ₃，列成小表对比。

**判据：相邻两次加密，变形变化 < 2%~5%、应力变化 < 5%**，即认为网格无关，报告取中间那档。

> ⚠️ 若最大应力**越加密越大、停不下来**，那是**奇异点（Singularity）**——尖角、点约束、点载荷处理论应力趋于无穷，**该数值没有工程意义，别拿它算安全系数**。对策：加圆角、把点载荷改成面载荷或 `Remote Force`、或只看离该点一定距离外的应力（圣维南原理）。

## 3. 约束、载荷与求解

| 约束 | 含义 | 典型用途 |
|------|------|---------|
| `Fixed Support` | 平动+转动全部锁死 | 焊在底盘上的安装点、后轴支座 |
| `Displacement` | 只锁指定方向（如仅 Y = 0） | 对称面法向约束、扭转工况中单侧车轮 |
| `Frictionless Support` | 只约束法向 | 对称面 |

**加约束三条铁律**：① 加在**真实存在处**——悬架通过安装孔/支座面把力传给车架，就加在那些面上，别锁管子中间；② **不多不少**——太多＝假约束（结构被人为加固，应力偏低、变形偏小，得出"很安全"的假结论），太少＝刚体位移、应力爆表；③ **能加面就别加点**（点约束/点载荷会制造无穷大应力集中）。

**载荷**：`Force`（N）／`Pressure`（MPa 分布压力）／`Remote Force`（N，作用在几何外，软件自动折算成力＋力矩）／`Moment`／`Standard Earth Gravity`（-Y）／`Acceleration`（冲击惯性载荷）。

> ⚠️ **载荷必须有来源**：弯曲工况载荷来自乘员座椅、发动机、油箱、备胎质量和路面经轮心传来的反力，全部出自**本队设计报告的质量表与载荷分配**，不能拍脑袋。

求解：线性静力**直接解一次方程，不存在迭代收敛**，确认没报错即可；只有非线性（大变形/塑性/接触）才在 `Solution Information` 看力收敛曲线（应单调下降，震荡＝发散）。**警告逐条读**；不收敛对策：补约束消刚体位移、开 `Large Deflection`、查接触类型、分载荷步加载。

## 🎯 动手练习（约4分钟）

在上一讲的 1000 × 50 × 50 mm 方钢上做**网格无关性实验**。

1. 双击 `Model`，`Mesh` → `Sizing` → `Element Size` 填 **20 mm**，`Generate Mesh`，记下 `Statistics` 里的节点数与单元数。
2. `Solve`，读 `Total Deformation` 与 `Equivalent Stress` 最大值，记第 1 行。
3. 依次改成 **10 mm**、**5 mm**，各重新生成并求解，记第 2、3 行。
4. 右键 `Mesh` → `Insert` → `Refinement`，选固定端根部附近面，级别填 **2**，重算观察最大应力怎么变。

> ✅ 你应该看到：单元数从 20 mm 到 5 mm 涨十几到几十倍；**最大变形只变化百分之几然后稳定**（网格无关）；**最大应力若一直随加密上涨**（如 60 涨到 120 MPa 还不停），说明它在固定端尖角/点约束的奇异处，**不能用来算安全系数**。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 单元尺寸 | 先按特征尺寸估，再靠无关性验证定档 |
| 单元类型 | 四面体通用、六面体省算力；管阵优先扫掠或梁/壳单元 |
| 网格无关性 | 加密到变形变化 <2%~5%、应力 <5% 即可定档 |
| 奇异点 | 尖角/点约束/点载荷处应力发散，无工程意义，别算安全系数 |
| 约束铁律 | 加在真实安装面、不多不少、能加面就不加点 |
| 载荷 | 必须有来源（设计报告质量表）；线性静力解一次即完，非线性才看收敛曲线 |

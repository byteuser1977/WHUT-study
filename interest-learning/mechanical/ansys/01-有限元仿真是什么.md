## 1. 核心思想与五个必须认识的词

给形状不规则的操场估面积：没有公式可用，就画满 1 m × 1 m 的方格数格子，格子越小估得越准。有限元（FEM）就是这个思路：**把连续结构切成有限个单元 → 每个单元列一个简单方程 → 拼回整体求解**。

| 术语 | 一句话 |
|------|--------|
| **节点 Node** | 网格上的取样点，求解对象是每个节点的位移 |
| **单元 Element** | 相邻节点围成的一小块（四面体/六面体/壳/梁），"小方程"的载体 |
| **网格 Mesh** | 全部单元的总和 |
| **自由度 DOF** | 一个节点能独立运动的方向数；三维实体节点有 3 个平动（UX/UY/UZ） |
| **刚度矩阵 K** | "多大力产生多大变形"的系数总表，核心方程 **K·u = F** |

K 由软件拼，F（载荷）由你填，u（节点位移）是结果。求解顺序是**先位移 → 再应变 → 最后应力**，所以约束加错后面全是错的（第 03 讲的"假约束"）。

> 💡 类比：一根弯曲的扁担手算不出来，但切成 100 段短杆，每段都是初中就学过的简单梁，首尾接起来整根扁担的变形就出来了——**有限元就是"把难问题切成很多简单题，再拼回去"**。

## 2. 是数值近似解，不是精确解

三层原因：① **离散化误差**——用折线代替光滑曲线，单元越粗越失真；② 单元内部按**形状函数**插值，真实位移未必如此；③ 解几十万阶方程的**数值/浮点误差**。

所以工程上不说"仿真是对的"，而说"仿真收敛了、结果对得上手算和实验"。判断准不准的三把尺：**网格无关性**（加密一倍变化只有百分之几）、**手算校核**（当简支梁算一遍对数量级）、**试验/实车验证**。

## 3. 仿真在赛车设计里的 5 条价值

| 价值 | 一句话 |
|------|--------|
| 省试制成本 | 改的是文件，不是钢管、焊接和装车工时 |
| 看得见应力分布 | 云图指出哪根管最吃力、哪根在"划水"，经验看不出来 |
| 快速比方案 | 改斜撑位置、换管径壁厚，一晚能比 5 个方案 |
| 提前暴露薄弱点 | 焊趾、孔边、悬架安装座等裂纹高发区提前标出来 |
| 能做极端工况 | 3 米落地冲击、极限交叉轴，实车不敢试也试不出来 |

> ⚠️ 仿真是**降低风险的工具，不是合格证**；表述时补一句"结果需配合试验与设计报告复核"。

## 4. "有限元仿真及其价值"的表述骨架

**定义**：把连续弹性体离散成有限个单元、在每个节点解平衡方程 K·u=F、再复原整体应力与变形的**数值近似**方法 → **关键认识**：精度取决于网格质量、约束载荷是否真实、材料参数是否准确，必须做网格无关性检查并与手算/试验对照 → **价值**：挑 2~3 条并结合本车队（省物理试错、应力可视化找薄弱点、快速比方案支撑轻量化、算极端工况）→ **落点**：让车队在加工之前就判断车架扛不扛得住。

## 🎯 动手练习（约4分钟）

1. 打开 **Workbench 2024 R2**（不是 Mechanical APDL 那套老界面）。
2. 左侧 `Toolbox` → `Analysis Systems`，把 **Static Structural** 拖到工程图区。
3. 双击方块里的 `Engineering Data`，点上方 `Engineering Data Sources`，选 `General Materials`，把 `Structural Steel` 点 **+** 加入本工程。
4. 在 `Properties` 表里找到 `Young's Modulus`、`Poisson's Ratio`、`Density` 三行，把数值抄下来。

> ✅ 你应该看到：工程图区出现带 `Engineering Data / Geometry / Model / Setup / Solution / Results` 格子的方块；材料属性出现钢的典型值（杨氏模量十万 MPa 量级、泊松比 0.3 上下、密度 7800 kg/m³ 量级）。**以你机器上实际显示的为准**，不要求背精确数字，第 02 讲专讲怎么填。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 有限元（FEM） | 把连续体切成有限个单元，逐单元建方程再拼成整体结果 |
| 基本词 | 节点=取样点、单元=小块、网格=全体单元、3 个平动自由度、K·u=F |
| 近似性 | 离散化 + 形状函数 + 数值误差 → 只是**数值近似解** |
| 可信度三把尺 | 网格无关性、手算校核、试验验证 |
| 仿真价值 | 省试制、看应力分布、快速比方案、提前暴露薄弱点、能做极端工况 |
| 定位 | 降低风险的工具，不是合格证 |

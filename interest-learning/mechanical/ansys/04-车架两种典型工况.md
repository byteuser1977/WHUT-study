## 1. 为什么"弯曲 + 扭转"是车架刚度的基准工况

车架是整车的**骨架**：悬架、动力总成、座椅、油箱、防滚架都挂在它上面。受力分两类：

- **对称载荷**：前后轴同时被顶起来 → 车架整体被压弯；
- **反对称载荷**：左右轮一个上一个下 → 车架被拧成一个"麻花"。

工程上把这两类分解成两个"基准工况"（baseline load cases）：

| 工况 | 载荷对称性 | 主要考验 | 典型问题 |
|------|-----------|---------|---------|
| **弯曲工况（Bending）** | 左右对称 | 车架的**垂向刚度与纵梁/横梁的抗弯能力** | 下弯变形过大、底部管子压屈、焊缝开裂 |
| **扭转工况（Torsion）** | 左右反对称 | 车架的**抗扭刚度与抗扭框架的闭合性** | 扭转角过大、前悬架几何被改变、操控变差 |

> 💡 类比：车架像**一张体操垫**。弯曲工况 = 两人抬垫子两头、中间站一个人，垫子中间下塌；扭转工况 = 两人各抬垫子一个角、另两个角按在地上，垫子被拧成螺旋面。前者考验"抗不抗塌"，后者考验"抗不抗拧"。

**为什么扭转比弯曲更受重视？** 因为扭转刚度直接决定"车架会不会吃掉悬架的设定"：车架太软，转向时车身一拧，两边车轮的camber/toe就跟着变，操控立刻变糊。

> ⚠️ 本讲操作针对 **ANSYS Workbench 2024 R2**（车队统一版本），面板字段名在不同小版本可能略有差异，**以你机器上为准**。
>
> ⚠️ **重要提醒**：不同车队、不同年份的设计报告，工况定义、加载数值、约束位置可能都不一样（有的车队还会补做制动工况、转向工况、侧倾工况、落地冲击工况）。**本讲给的是通用做法与思考框架，具体数值、约束点、验收标准一律以本队设计报告为准**——答题和做仿真之前，先去报告里核对。

## 2. 弯曲工况（Bending）

### 2.1 对应的真实行驶场景

- **直线高速通过颠簸路面**：前后轮同时被路面"顶"起来，车架整体下弯；
- **落地/跳跃落地冲击**：四个轮子同时受到向上的大反力；
- **制动时的纵向载荷转移**（近似对称加载）；
- **满载静置**：乘员 + 发动机 + 油液的自重压弯车架。

### 2.2 边界条件怎么加

| 项目 | 做法 |
|------|------|
| 约束位置 | 加在**悬架与车架的连接点**（前摆臂安装点/减振器上支点、后轴支座）——悬架才是车架与地面的传力路径 |
| 约束方式 | 常用 `Fixed Support`（固定支撑）加在后悬架安装点；前悬架安装点用 `Displacement`（给定位移）只约束**纵向与横向**，允许垂向自由——这样载荷才能传下去 |
| 也可行 | 前后都 `Fixed Support`（常这么做以拿到弯曲刚度指标，但要在报告里说明） |

### 2.3 加载方式

- **加载位置**：质心/质量集中处——座椅、发动机、油箱、备胎对应的**横梁或纵梁节点**；
- **加载形式**：优先用 **Remote Force（远端力）** 或 **Force** 加在**节点/面**上，或按设计报告把重量按前后轴分配成两个集中力加在对应横梁上；
- **载荷大小**：各部件质量 × 重力加速度；若考虑**动载系数**（颠簸工况常乘 2~3 倍），要在报告里写明依据；
- 别忘了加 **Standard Earth Gravity（标准重力）** 给车架自重。

### 2.4 输出什么指标

| 输出量 | 在 Workbench 里的结果项 | 意义 | 注意 |
|--------|----------------------|------|------|
| 最大等效应力 | **Equivalent (von-Mises) Stress** | 判断管子会不会屈服、焊缝附近是否超限 | 看位置，躲开奇异点 |
| 最大垂向变形 | **Total Deformation** / **Directional Deformation**（方向选 Y） | 车架"塌"了多少 | 用相对量 |
| **弯曲刚度** | 算出来的 | K_b = 总垂向载荷 / 最大垂向变形（单位 N/mm） | 要在报告里写清载荷加在哪、变形取哪一点 |
| 安全系数 | **Safety Factor** | 屈服强度 / 最大等效应力 | 尖角处不算 |

## 3. 扭转工况（Torsion）

### 3.1 对应的真实行驶场景

- **单侧车轮过坎 / 交叉轴**：一侧前轮压在石头上、另一侧悬空，车架被拧；
- **爬坡时的对角线受力**：巴哈赛道坡道、坑洼路常见；
- **一侧车轮悬空**（最典型的扭转工况）；
- **转向侧倾时的载荷转移**：转弯外侧轮受载增加、内侧减少，形成绕纵轴的力偶（也可以单独做侧倾工况）。

### 3.2 边界条件怎么加

扭转工况的核心是：**"三点约束 + 一点加载"**。

1. 把**后轴两个悬架安装点全部 `Fixed Support`**（完全锁死）——相当于把车尾按在地上；
2. 前轴**左侧**悬架安装点加 `Displacement`，约束垂向（Y = 0）；
3. 前轴**右侧**悬架安装点作为加载点——**不加约束，只加力**；
4. 检查：共约束 6 个刚体自由度，结构不会被"锁死"到无法变形。

> ⚠️ 常见坑：四个悬架点全都 `Fixed Support`，车架被夹死，会得到"极其刚硬"的假结果——这就是**假约束**：约束比真实多 = 刚度虚高 = 结论偏乐观。

### 3.3 加载方式

- 在前轴右侧（或左侧，即需要抬升的那一侧）加载点施加**垂向力** F，方向为 Y（向上或向下，看你要模拟哪侧悬空）；
- 施加位置用悬架安装点，通过 **Remote Force** 作用，避免单节点假应力集中；
- **扭矩怎么算**：T = F × d，其中 d 通常取**轮距（track width）**或前后悬架安装点横向距离的等效值。**用哪个 d，以本队设计报告的定义为准，并在报告里写明。**

### 3.4 输出什么指标

| 输出量 | 怎么得到 | 意义 |
|--------|---------|------|
| 最大等效应力 | **Equivalent (von-Mises) Stress** | 扭转下最危险的管子/焊口在哪 |
| 加载点垂向位移 Δy | **Directional Deformation**（方向 Y） | 拧了多少 |
| 相对扭转角 θ | θ = arctan(Δy / L)，L 为前后轴距（或前后加载点纵向距离） | 单位：度 |
| **扭转刚度** | **K_t = T / θ**，单位 N·m/deg | 车架抗拧能力的核心指标 |
| 安全系数 | **Safety Factor** | 同弯曲工况 |

**扭转刚度的量级感**：空间管阵车架的扭转刚度一般在 **10³ N·m/deg 量级**。**具体目标值以本队设计报告为准**。

> 💡 类比：扭转刚度就像**拧毛巾的难度**。一条平摊的毛巾（没有闭合框）很容易拧；把毛巾卷成筒、两头扎紧，就难拧多了。所以车架抗扭的关键不是"管子多粗"，而是**"力能不能走一条闭合的回路"**——这就是为什么前环、后环、防火墙斜撑对扭转刚度贡献那么大。

## 4. 【简答第 1 题，10 分】答题结构

题目：*根据车队设计报告，车架仿真主要分析哪两种典型工况，说明这两种工况对应的赛车实际行驶场景。*

**推荐结构（一句话结论 → 两种工况各一段 → 一句落点）：**

1. **一句话结论**：车队车架的结构仿真主要围绕**弯曲工况**和**扭转工况**两种基准工况展开，分别考核车架的垂向抗弯刚度和抗扭刚度。
2. **弯曲工况**：左右对称加载，模拟前后轮同时受载——对应**直线高速通过颠簸路面、跳跃落地冲击、满载静置**等场景；输出最大等效应力、最大垂向变形和弯曲刚度（载荷/最大变形）。
3. **扭转工况**：左右反对称加载，后轴约束、前轴单侧加载，模拟一侧车轮被顶起——对应**单侧车轮过坎、交叉轴、一侧悬空、转向侧倾时的载荷转移**等场景；输出最大等效应力、加载点垂向位移，并用"扭矩 / 相对扭转角"算出扭转刚度（N·m/deg）。
4. **落点**：这两种工况是车架刚度的基准，另外可能还会补做制动、转向、侧倾等工况；**具体工况定义、加载数值和验收指标以本队设计报告为准**。（写上这一句，评卷人一眼就知道你真读过报告。）

> ⚠️ 答题时不要只写"弯曲和扭转"四个字。**得分点在"对应的行驶场景"** ——这是题目点名要的。每个工况写 2~3 个场景，并用一句机械原理把它们串起来（对称受力 → 弯；反对称受力 → 扭）。

## 🎯 动手练习（约40分钟）

用你的车架模型（或第 02 讲的方钢梁当练习件）分别做两种工况。

### 练习 A：扭转工况

1. 打开工程，双击 `Model` 进 Mechanical。
2. 左侧树右键 `Static Structural` → `Insert` → **Fixed Support**，选**后端两个悬架安装面**，`Apply`。
3. 再 `Insert` → **Displacement**，选**前端左侧安装面**，在 `Details` 里把 `Y Component` 设为 **0**（Free 状态的其他方向不管），`Apply`。
4. 右键模型树 → `Insert` → **Remote Point**（远端点），选前端右侧安装面，建一个远端点；再 `Insert` → **Remote Force**，`Scoping Method` 选 `Remote Point`，指向刚建的点，`Define By` 用 `Components`，给 **Y 方向 1000 N**。。
5. 右键 `Solution` → `Insert` → **Equivalent (von-Mises) Stress**；再插入 **Directional Deformation**，`Orientation` 选 **Y Axis**。
6. 点 **Solve**。
7. 点开 `Directional Deformation`，读加载点 Y 位移 Δy。
8. 手算：T = F × d（d 用加载点横向距离，换成 m），θ = arctan(Δy / L) 换算成度（Δy 与 L 同单位），K_t = T / θ。
9. 把 F 改成 2000 N 再解一次：线弹性下位移与刚度应基本按比例变化。

### 练习 B：弯曲工况

1. 把 `Displacement` 与 `Remote Force` 删除（右键 → `Delete`），只留必要的约束。
2. 前后悬架安装点改成对称的约束方案（后轴 `Fixed Support`，前轴 `Displacement` 只约束纵向与横向两向）。
3. `Insert` → **Force**，加在座椅横梁与发动机横梁位置，方向 **-Y**，数值按重量分配填（如 300 N）。
4. 再 `Insert` → **Standard Earth Gravity**，方向 **-Y**。
5. `Insert` 结果项：**Equivalent Stress**、**Total Deformation**。
6. `Solve`，读最大变形 δ，算弯曲刚度 K_b = 总载荷 / δ。

> ✅ 你应该看到：
> - 两种工况的最大应力位置**不在同一个地方**：弯曲工况的红色区常出现在**横梁与纵梁交界、座椅横梁附近**；扭转工况的红色区常出现在**前环/后环与纵梁的接头、悬架安装座附近**；
> - 两种工况的变形图形态完全不一样：弯曲是**整体均匀下塌（U 形）**，扭转是**一头几乎不动、另一头被拧起（螺旋形）**；
> - 载荷加倍，位移基本加倍（线性）——如果不是线性关系，检查有没有接触或大变形没开；
> - 你算出的扭转刚度在 **10³ N·m/deg 量级**；如果算出来是 10 或者 10⁵，多半是单位搞错了（N·mm/deg 和 N·m/deg 差 1000 倍）。
>
> ⚠️ 这两组数值只是量级感，不是标准答案。**把自己的结果与设计报告的目标值对比**，差得远就回头查约束、载荷、单位。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 空间管阵车架 | space frame，钢管焊接桁架，靠三角形闭合回路传力 |
| 基准工况 | 弯曲（对称）+ 扭转（反对称），是车架刚度的两根标尺 |
| 弯曲工况 · 场景 | 颠簸路面、落地冲击、满载静置、制动载荷转移 |
| 弯曲工况 · 约束 | 加在悬架安装点；后轴常 Fixed Support，前轴给定位移 |
| 弯曲工况 · 载荷 | 座椅/发动机/油箱/备胎重量（×动载系数）+ 重力，加在对应横梁 |
| 弯曲工况 · 指标 | 最大等效应力、最大垂向变形、弯曲刚度 N/mm |
| 扭转工况 · 场景 | 单侧过坎、交叉轴、单轮悬空、转向侧倾载荷转移 |
| 扭转工况 · 约束 | 后轴两点固定 + 前轴一侧约束垂向 = "三点约束、一点加载" |
| 扭转工况 · 载荷 | 前轴另一侧垂向力 F（Remote Force），T = F × d |
| 扭转工况 · 指标 | 最大等效应力、加载点垂向位移、相对扭转角 θ、扭转刚度 N·m/deg |
| 最大陷阱 | 四角全固定 = 假约束 → 刚度虚高、结论乐观 |
| 单位陷阱 | N·m/deg 与 N·mm/deg 差 1000 倍 |
| 唯一依据 | **以本队设计报告为准**：工况定义、加载数值、d 的取法、验收目标值 |
| 答题得分点 | 两种工况 + 各自的受力对称性 + 各自对应的真实行驶场景 |

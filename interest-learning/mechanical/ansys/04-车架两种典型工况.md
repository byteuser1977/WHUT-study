## 1. 为什么是这两种工况

车架受力分**对称**（前后轴同时被顶起 → 压弯）与**反对称**（左右轮一上一下 → 拧成麻花）两类，于是定出两个基准工况：**弯曲**考验垂向刚度与纵梁/横梁抗弯，**扭转**考验抗扭刚度与框架闭合性。

> 💡 类比：车架像**一张体操垫**——弯曲＝两人抬两头、中间站人，垫子下塌；扭转＝各抬一个对角、另两角按住，垫子被拧成螺旋面。

> ⚠️ 不同车队、不同年份的工况定义、加载数值、约束位置都可能不同。**本讲是通用框架，具体数值、约束点、验收标准一律以本队设计报告为准**。

## 2. 弯曲工况（Bending）

**场景**：颠簸路面（前后轮同时被顶起）、落地冲击、满载静置、制动纵向载荷转移。

**边界条件**：加在**悬架与车架的连接点**（摆臂安装点、减振器上支点、后轴支座）——悬架才是车架与地面的传力路径。常见做法：后悬架安装点 `Fixed Support`，前悬架安装点用 `Displacement` 只约束纵向与横向、允许垂向自由；前后都固定也行，但需在报告里说明。

**加载**：座椅/发动机/油箱/备胎对应的**横梁或纵梁节点**，用 `Remote Force`/`Force`；大小为质量 × g，乘**动载系数**（颠簸常 2~3 倍）要写明依据；别忘 `Standard Earth Gravity`。

**输出**：最大等效应力（`Equivalent (von-Mises) Stress`，躲开奇异点）、最大垂向变形（`Directional Deformation` 取 Y）、**弯曲刚度 K_b = 总垂向载荷 ÷ 最大垂向变形（N/mm）**；报告要写清载荷加在哪、变形取哪点。

## 3. 扭转工况（Torsion）

**场景**：单侧车轮过坎／交叉轴、一侧车轮悬空、转向侧倾载荷转移。

**边界条件 = "三点约束 + 一点加载"**：① 后轴两个悬架安装点全部 `Fixed Support`（把车尾按在地上）；② 前轴**左侧**安装点加 `Displacement`，约束垂向 Y = 0；③ 前轴**右侧**安装点**只加力、不加约束**；④ 共约束 6 个刚体自由度，不会锁死到无法变形。

**加载**：需抬升一侧加垂向力 F（用 `Remote Force` 避免单节点假应力集中）；**扭矩 T = F × d**，d 通常取轮距或前后安装点横向距离，**取哪个 d 以设计报告为准并写明**。

**输出**：最大等效应力、加载点垂向位移 Δy（`Directional Deformation` 取 Y）、**相对扭转角 θ = arctan(Δy / L)**（L 为轴距）、**扭转刚度 K_t = T ÷ θ（N·m/deg）**。空间管阵车架 K_t 一般在 **10³ N·m/deg 量级**；**目标值以本队设计报告为准**。

> ⚠️ 最大陷阱：四个悬架点全 `Fixed Support` → **假约束**，车架被夹死、结果"极其刚硬"（约束比真实多 ＝ 刚度虚高 ＝ 结论乐观）。

## 4. 【简答第 1 题，10 分】答题结构

一句话结论（围绕**弯曲**、**扭转**两种基准工况，分别考核垂向抗弯刚度与抗扭刚度）→ **弯曲**：左右对称、前后轮同时受载，对应颠簸路面、落地冲击、满载静置，输出最大应力、最大垂向变形与弯曲刚度 → **扭转**：左右反对称、后轴约束前轴单侧加载，模拟一侧车轮被顶起，对应单侧过坎、交叉轴、单轮悬空、侧倾载荷转移，输出最大应力、加载点垂向位移与扭转刚度（T/θ）→ 落点：还可能补做制动/转向/侧倾工况，**具体定义与验收指标以本队设计报告为准**。

**得分点在"对应的行驶场景"**：别只写"弯曲和扭转"四个字，每工况写 2~3 个场景，并用一句机械原理串起来（对称→弯，反对称→扭）。

## 🎯 动手练习（约4分钟）

用车架模型（或第 02 讲方钢梁）做扭转工况。

1. `Insert` → `Fixed Support` 选**后端两个悬架安装面**；前端**左侧**安装面加 `Displacement`，`Y Component` = **0**。
2. 前端**右侧**安装面建 `Remote Point`，加 `Remote Force` 指向它，给 **Y 方向 1000 N**。
3. `Solution` 插入 `Equivalent (von-Mises) Stress` 与 `Directional Deformation`（`Orientation` = **Y Axis**），`Solve`，读加载点位移 Δy。
4. 手算：T = F × d（d 换成 m），θ = arctan(Δy / L) 换算成度，K_t = T / θ。

> ✅ 你应该看到：变形图**一头几乎不动、另一头被拧起（螺旋形）**；K_t 在 **10³ N·m/deg 量级**（算出 10 或 10⁵，多半是 N·mm/deg 混了 N·m/deg）。这只是量级感，要拿结果与设计报告目标值对比。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 基准工况 | 弯曲（对称）+ 扭转（反对称），车架刚度两根标尺 |
| 弯曲工况 | 颠簸/落地/满载；约束加在悬架安装点；出最大应力、垂向变形、**K_b = 载荷/变形（N/mm）** |
| 扭转工况 | 交叉轴/单轮悬空/侧倾；**三点约束 + 一点加载**；**K_t = T/θ（N·m/deg）** |
| 最大陷阱 | 四角全固定 = 假约束 → 刚度虚高、结论乐观 |
| 得分点与依据 | 两工况 + 受力对称性 + 真实场景；**一律以本队设计报告为准** |

## 1. 颜色特征为什么脆

先把"颜色特征"说清楚：它指的是**用像素的 RGB/HSV 数值落在哪个区间，来判断这个像素属于什么目标**。比如"偏灰白 = 路面、偏橙红 = 锥桶"。它便宜、直观、跑得飞快，所以是所有人的第一选择。

但它有一个致命前提：**颜色值必须稳定地反映物体的"真实颜色"**。赛道上这个前提被四件事同时打破：

| # | 原因 | 机理 | 赛道上的表现 |
|---|------|------|--------------|
| 1 | 光照强度与色温变化 | 相机传感器输出的是"颜色 × 光照"，光照变了，输出值整体偏移 | 同一段土路，正午 V≈160，逆光 V≈60 |
| 2 | 自动白平衡（AWB）漂移 | 相机会根据画面内容猜"什么算白"，画面一变猜法就变 | 画面里进了大片绿草，整幅图偏品红，阈值全偏 |
| 3 | 泥水/积水改变反射率 | 泥浆覆盖后，物体的**表面材质**变了，反射光谱也变了 | 灰白土路被泥盖住 → 变成深褐，与阴影、草地颜色接近 |
| 4 | 通道饱和（截断） | 强光下像素值达到 255 上限，RGB 三通道全饱和 | 白色变纯白、彩色变纯白，颜色信息**永久丢失**，任何后处理都救不回来 |

> 💡 类比：颜色特征就像"靠衣服颜色认人"。白天在教室里，看一眼就知道谁是红衣服；但换成夜里的霓虹灯下、或者对方套了一件雨衣，你认不出来了。**问题不在你的眼睛，在于"衣服颜色"这个线索本身就不稳定。**
> 工程上的对策不是"把眼睛练得更尖"，而是**多找几条不依赖颜色的线索**：形状、纹理、运动、几何、先验。

> ⚠️⚠️ **第 4 条是重点，也是最容易被忽略的**：通道饱和是不可逆的信息丢失。图像一旦被截断成 255，后续 CLAHE、白平衡、任何算法都无法还原细节。所以现场调参第一件事是**降曝光/加偏振片/加遮光罩**，从采集端保住动态范围，而不是等图像废了再去算法端补救。

## 2. 九条替代/增强方案

下面 (a)~(i) 每条都按"**原理 → 优点 → 代价**"三段讲。答题时不必全写，**挑 4~6 条展开 + 说清为什么这么组合**就是一份满分答案。

### (a) 换颜色空间 + 自适应阈值

**原理**：把 RGB 换成 HSV 或 Lab。HSV 把"亮不亮（V）"和"什么色（H、S）"分离开，Lab 的 L 通道近似人眼亮度感知且更接近"光照无关"。再把固定的 `cv2.inRange` 换成自适应阈值或 **Otsu 大津法**（一种自动寻找最佳分割阈值的方法：让分出来的两类像素内部差异最小、类间差异最大）。

**优点**：改动最小、几乎零算力代价；Otsu 能跟着画面自动挪阈值。
**代价**：只能对抗**全局**光照变化，对抗不了局部强光/阴影；HSV 的 H 通道在低饱和区域噪声极大（灰白色路面 H 值本来就是随机的）。

### (b) 光照归一化

**原理**：在分割之前先把光照"拉平"。三件常用工具：
- **CLAHE（限制对比度的自适应直方图均衡化）**：把图分块，每块单独做直方图均衡，再限制对比度放大幅度避免噪声爆炸 → 局部阴影/高光区域也能拉出细节。
- **白平衡校正**：用灰度世界法/白色 patch 把偏色拉回中性。
- **Gamma 校正**：压缩高光、提亮暗部（`V' = V^(1/γ)`）。

**优点**：通用前置步骤，对扬尘（对比度低）、逆光（动态范围大）都有效；算力开销小。
**代价**：CLAHE 会**放大噪声**、破坏原本的颜色一致性；Gamma 没法恢复已经饱和的像素。

### (c) 纹理与边缘特征

**原理**：不看"什么颜色"，看"表面长什么样"。
- **LBP（局部二值模式）**：比较中心像素与周围 8 个邻居，编码成一个 8 位二进制数 → 描述局部粗糙度。土路粗糙、泥浆平滑，纹理能量差异明显。
- **Sobel / Canny 边缘**：求梯度幅值，抓几何轮廓。
- **HOG（梯度方向直方图）**：统计局部梯度方向的分布 → 对光照变化非常不敏感，是经典的"抗光照特征"。

**优点**：**天然抗光照变化**（梯度是相对量，光照整体增减时梯度方向基本不变）；能抓到颜色抓不到的泥水边界。
**代价**：泥水+扬尘会把纹理抹平（低对比度区无梯度）；纹理特征维数高、计算量大；草丛纹理对 LBP 是巨大干扰源。

### (d) 颜色 + 纹理多特征融合投票

**原理**：每个像素/每个候选区域由 N 个弱判据各投一票（颜色、纹理、梯度、亮度），总分超过阈值才算"可行驶区域"。这叫**多特征融合 / 投票机制**，本质是用"多个弱证据"顶替"一个强证据"。

**优点**：单条线索失效时其它线索兜底，鲁棒性提升最明显；实现简单、可解释性强。
**代价**：权重要调（可用网格搜索）；误检会被"多头投票"放大，需要后处理（形态学、连通域面积筛选）压制。

### (e) 超像素聚类与区域生长

**原理**：**超像素（superpixel）**是把颜色/纹理相近的相邻像素先聚成一个个"小块"（如 **SLIC** 算法），后续所有判断都以"块"为单位，不再逐像素。区域生长则是从种子点出发，把"与种子足够像"的邻居不断并入同一区域。

**优点**：块内部特征稳定，抗单点噪声能力远强于逐像素；计算量比全图逐像素分类更低；能得到**自然的分割边界**而不是锯齿。
**代价**：SLIC 在泥水/边界模糊区域容易"跨区粘连"（把路和草聚成一块）；需要预分割耗时；聚类参数（块大小、紧凑度）对结果敏感。

### (f) 时域滤波：帧间一致性

**原理**：赛道是连续视频，**上一帧的结果是最好的先验**。
- **帧间一致性检查**：本帧判定结果与上一帧差异过大的区域，标记为可疑，暂不采信。
- **历史帧投票**：用最近 N 帧（如 5 帧）的判定做多数表决，单帧噪声被压制。
- **卡尔曼滤波**：用"运动模型预测 + 观测修正"的方式平滑目标位置与速度（对障碍物跟踪尤其有用）。

**优点**：几乎不增加单帧算力；对随机噪声、瞬时遮挡（扬尘飘过、行人走过）效果极好。
**代价**：颠簸会造成帧间大位移，纯投票会拖出"拖影"；引入**延迟**（N 帧投票 = 延迟 N 帧），与实时性冲突，一般 N 取 3~5；目标快速突变时响应变慢。

### (g) 多传感器融合

**原理**：视觉的短板是"光照 + 测距不准"，那就用别的传感器补。
- **深度相机（RGB-D）**：直接给每个像素的距离，用**几何信息**（离地高度、地面平面拟合）区分"地面"和"障碍物"，绕开颜色。
- **激光雷达（LiDAR）**：主动发射激光，**不受光照影响**，能给出精确点云与地面分割。
- **毫米波雷达**：穿透扬尘、雨雾能力强，测速测距准，但角分辨率低、无纹理。

融合层次：**数据级**（原始数据先对齐再算）→ **特征级**（各自提特征后拼）→ **决策级**（各自出结论再投票，最常用、最稳）。

**优点**：从根本上解决视觉失效问题；几何信息天然给出障碍物的三维尺寸和距离。
**代价**：成本与功耗上升（巴哈赛车载重与供电都紧张）；**外参标定**复杂（要把各传感器的坐标系统一对齐，颠簸后标定还会漂）；数据量增大，算力压力上升。

### (h) 基于学习的语义分割

**原理**：**语义分割（semantic segmentation）**是给每个像素分类（路面 / 草 / 泥 / 天空 / 障碍物）。用 U-Net / SegFormer / DeepLab 等网络，在**自己采集的巴哈赛道数据集**上微调（fine-tune，在预训练权重基础上用少量自己的数据继续训练）。

**关键在数据**：用**数据增强**模拟恶劣工况——随机调亮度/对比度/色温（模拟逆光、夜间）、加雾化（模拟扬尘）、加运动模糊（模拟振动）、随机加泥点遮罩、随机透视变换（模拟颠簸视角变化）。

**优点**：上限最高，能学到人写不出来的判别规则；一次训练覆盖多种工况；端到端输出可行驶区域。
**代价**：需要**标注数据**（像素级标注极其耗时，一张图要标十几分钟）；赛道上算力吃紧，通常得配量化/剪枝才能实时；网络是黑盒，出错时难定位原因；对没见过的极端工况仍可能崩。

### (i) 先验知识与几何约束

**原理**：这条赛道有大量**免费的先验**，不用白不用：
- **赛道宽度约束**：可行驶区域的水平宽度应该在 2~4 m 对应的一定的像素范围内，过宽/过窄的候选区域直接否决。
- **消失点检测（vanishing point）**：平直道路上，左右边界线延长会交于图像中的一个点（消失点）。赛道边界模糊时，即使单帧边缘断断续续，**用消失点约束"边界只能往那个点收敛"**能补出断掉的线。
- **左右边界连续性约束**：相邻行之间边界横坐标的变化率有限，突跳就是错检。
- **时间连续性 + 上一帧 ROI**：只在上一帧结果附近搜索，缩小搜索范围。

**优点**：**零算力、零标注、可直接否决错检**，性价比最高；和任何其它方法都能叠加。
**代价**：先验一旦不成立就反噬（急弯、分叉口、赛道被堵改道时，"宽度约束"会误杀正确结果）；需要为特例写降级分支。

> 💡 类比：这九条就像"在雾天找路"的九种办法——修眼镜（换颜色空间+光照归一化）、摸地面粗细（纹理）、问同伴刚才走的哪（时域滤波）、开手电筒量距离（多传感器）、请个实地走过的人（学习法）、抬头找远处的灯（先验消失点）。**聪明的做法不是挑一种，而是同时用几种、互相验证。**

## 4. 推荐组合方案（可直接写进答题纸）

思路是**分层串联，每层解决一类失效，后面兜前面的底**：

```text
① 采集端：降曝光 + 偏振片/遮光罩，保住动态范围，避免通道饱和
        ↓
② 预处理：去畸变 → CLAHE 光照归一化 → 高斯/中值滤波去噪
        ↓
③ 特征提取：HSV 阈值（颜色）+ Sobel/Canny 梯度（几何）+ LBP（纹理）
        ↓
④ 融合判决：三路特征加权投票 → 得初步可行驶区域掩码
        ↓
⑤ 时域滤波：最近 5 帧多数表决 + 卡尔曼平滑边界
        ↓
⑥ 先验后处理：形态学闭运算补洞 → 最大连通域筛选
              → 赛道宽度约束 + 消失点约束 + 左右边界连续性检查
        ↓
⑦ 输出：可行驶区域多边形 + 置信度，通过 ROS 2 Topic 发给控制组
```

为什么是这个组合？
- **②CLAHE 和 ⑥先验 是"零成本高收益"**，一定是第一优先级；
- **③④ 用三种不同物理机理的特征互相兜底**：光照变了颜色失效但梯度还在，纹理被泥水抹平但颜色还部分可用；单一特征全崩的场景极少同时出现；
- **⑤ 几乎不花算力就压掉大量瞬时噪声**（扬尘飘过、单帧模糊）；
- **(g)(h) 留作迭代方向**：等有预算、有数据集再上，先说清"为什么现在不上"（成本/算力/标注人力），这也是加分的工程判断。

> ⚠️ 常见坑：把 (h) 学习型分割当成"一劳永逸的答案"写在第一位。阅卷老师最想看到的恰恰是**你懂 DL 但没盲目迷信 DL**——赛道算力受限、标注数据稀缺、失效时不可解释，这三条足以让它排在"过渡/长期方案"里。答题时把"方案 + 为什么 + 代价"写全，比堆名词得分高得多。

## 🎯 课后练习（约15分钟）

### 练习 1：三路特征融合，看它比单一颜色强多少

```python
# demo02_fusion.py
import cv2
import numpy as np

img = cv2.imread("road_backlight.jpg")   # 换成你自己的逆光照片
if img is None:                          # ⚠️ 少了这句，路径写错时会抛出难懂的断言错误
    raise SystemExit("读不到 road_backlight.jpg，检查路径与文件名")
img = cv2.resize(img, (640, 480))
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# --- ① 光照归一化：CLAHE 拉平局部明暗 ---
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
gray_eq = clahe.apply(gray)
hsv[:, :, 2] = clahe.apply(hsv[:, :, 2])          # 只对 V（亮度）做均衡，H/S 不动

# --- ② 三路特征，各自出一个掩码 ---
# 路1：颜色（HSV + Otsu 自适应阈值，比写死阈值强）
_, m_color = cv2.threshold(hsv[:, :, 2], 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# 路2：几何（Canny 边缘 → 闭运算把断线连起来）
edges = cv2.Canny(gray_eq, 50, 150)
m_edge = cv2.morphologyEx(edges, cv2.MORPH_CLOSE, np.ones((7, 7), np.uint8))

# 路3：纹理（LBP 的极简版：局部标准差，粗糙=高，平滑=低）
blur = cv2.GaussianBlur(gray_eq, (5, 5), 0)
tex = cv2.Laplacian(blur, cv2.CV_32F)
m_tex = (np.abs(tex) < 12).astype(np.uint8) * 255  # 平滑区域 → 判为路面候选

# --- ③ 加权投票融合 ---
vote = (0.5 * (m_color / 255) + 0.2 * (m_edge / 255) + 0.3 * (m_tex / 255))
fused = (vote > 0.5).astype(np.uint8) * 255

# --- ④ 形态学 + 最大连通域筛选 ---
fused = cv2.morphologyEx(fused, cv2.MORPH_CLOSE, np.ones((15, 15), np.uint8))
cnts, _ = cv2.findContours(fused, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
out = img.copy()
if cnts:
    big = max(cnts, key=cv2.contourArea)      # 只保留最大的一块，滤掉零碎误检
    cv2.drawContours(out, [big], -1, (0, 255, 0), 3)
    print(f"最大可行驶区域面积 = {cv2.contourArea(big):.0f} 像素")

cv2.imwrite("out_color_only.png", m_color)   # 只有颜色
cv2.imwrite("out_fused.png", out)            # 三路融合
print("已输出 out_color_only.png / out_fused.png，用看图工具对比两者")
```

> ✅ 你应该看到：`out_color_only.png` 里逆光路面几乎全黑（真实逆光照片下掩码基本是空的），`out_fused.png` 里即使逆光也能圈出一块可达路面多边形；终端打印出最大连通域面积。
> （若你的照片不够逆光，两张图差别会不明显——那就换成树影下或背光处拍的那张再跑。）
> **把这两张对比图写进你的答题里**——"单颜色失效、融合后恢复"的视觉证据，是 20 分题最有杀伤力的部分。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 颜色特征脆的根因 | 光照/色温变化、AWB 漂移、泥水改变反射率、通道饱和（不可逆） |
| 必做基础三件套 | CLAHE 光照归一化 + HSV/Lab 自适应阈值 + 时域帧间滤波 |
| 抗光照的主力 | 梯度/纹理类特征（Sobel、Canny、LBP、HOG）天然对光照不敏感 |
| 性价比最高的后处理 | 先验约束：赛道宽度、消失点、左右边界连续性（零算力） |
| 上限最高但有门槛 | 学习型语义分割（缺标注数据 + 算力紧张 + 黑盒不可解释） |
| 推荐组合 | 采集保动态范围 → CLAHE → 颜色/梯度/纹理三路投票 → 5 帧投票滤波 → 形态学+先验后处理 → ROS 2 发布 |
| 答题四段式 | 承认本质（域偏移）→ 融合方案 → 工程流水线 → 可量化的验收标准 |

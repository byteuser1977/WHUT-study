# 智能巴哈·感知组 入门到进阶学习教程

> 面向零基础大一新生的课外学习路线 —— 从"这是什么"到"我能在车上把它跑起来"。
> 全部内容围绕武汉理工大学智能巴哈车队**感知组初次招新试题**的知识点展开，共 **6 大类、27 讲**。

---

## 一、这份教程解决什么问题

招新试题里的每一道题，背后都对应一块真实工程知识：

| 试题在问什么 | 其实在考什么 |
|---|---|
| ROS 2 的发布者订阅者是什么 | 机器人各模块之间怎么说话 |
| `(480, 640, 3)` 是什么意思 | 图像在计算机里到底是什么 |
| 写个程序拍张照 | 能不能把算法跑起来、能不能处理工程细节 |
| 识别可行驶区域 | 感知组的核心工作 |
| git add/commit/push 各干了啥 | 会不会管自己的代码 |
| 报错怎么读、怎么求助 | 能不能自己解决问题 |
| 算法太卡怎么办 | 边缘设备上的工程权衡 |
| 泥水赛道颜色失效怎么办 | 鲁棒性思维 —— 感知组真正的门槛 |
| 怎么跟 AI 提效对话 | 现代工程的基本功 |

**换句话说**：这份教程不是"题库答案合集"，而是把题目背后的知识体系铺成一条路。看完走完，你不只是会答题，而是具备进感知组干活的基础。

## 二、学习路线图（科普 → 进阶）

```
                    【第一阶段：环境与工具】
   大类二 Python+OpenCV 图像基础  ──→  大类四 Git 版本控制
   （图像是什么、怎么处理）             （代码怎么管）
                        │
                        ▼
                    【第二阶段：机器人框架】
   大类一 ROS 2 通信与诊断
   （模块之间怎么传数据 —— 这是感知组的地基）

                        │
                        ▼
                    【第三阶段：核心能力】
   大类三 AI 识别与视觉感知
   （可行驶区域识别 —— 感知组的主战场）

                        │
                        ▼
                    【第四阶段：工程与实战】
   大类五 工程思维  ──→  大类六 巴哈赛道感知实战
   （报错、协作、算力、AI 提效）    （真实赛道为什么难、方案怎么设计）
```

**为什么这么排**：
- 先学 Python/OpenCV，是因为后面所有代码都用它；先学 Git，是因为你从第一天就该有"存快照"的习惯
- ROS 2 放在第二，因为它本身不产生算法，只负责传数据；不懂它，你写的感知代码上不了车
- 巴哈赛道实战放最后，因为它需要前面所有知识做支撑，也是招新试题里分值最高、最能体现差距的部分

## 五、环境准备清单（可复制执行）

### 方案 A：Windows + WSL（推荐新手）

```bash
# 1. 管理员 PowerShell 里装 WSL（装完重启）
wsl --install

# 2. 进入 Ubuntu，更新系统
sudo apt update && sudo apt upgrade -y

# 3. 装 Python 与基础库
sudo apt install -y python3 python3-pip git

# 4. 装 OpenCV 与 NumPy
pip3 install opencv-python numpy matplotlib

# 5. 验证
python3 -c "import cv2, numpy; print('OpenCV', cv2.__version__, '| NumPy', numpy.__version__)"
git --version
```

### 方案 B：原生 Ubuntu 22.04

同方案 A 的第 2~5 步。ROS 2 建议使用官方 apt 源：

```bash
# ROS 2 Humble（Ubuntu 22.04 对应版本）
sudo apt install -y software-properties-common curl
sudo add-apt-repository universe -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
sudo apt update
sudo apt install -y ros-humble-desktop python3-colcon-common-extensions
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
ros2 --version   # 能打印版本就成功了
```

> ⚠️ WSL 里跑 ROS 2 需要 WSL2 + Ubuntu 22.04；WSL1 不支持。
> ⚠️ 如果 `ros2 --version` 报 command not found，多半是忘了 `source /opt/ros/humble/setup.bash`。

## 七、学完能做到什么

- ✅ 能独立用 Python + OpenCV 打开摄像头、处理图像、做阈值分割与形态学处理
- ✅ 能看懂并跑通 ROS 2 的节点/话题/发布订阅，会用命令行诊断话题频率
- ✅ 能自己写一份"可行驶区域识别"程序并解释每一步为什么这么做
- ✅ 能用 Git 管住自己的代码，改乱了能救回来
- ✅ 面对报错能自己定位，能把问题描述清楚去求助
- ✅ 知道车载算力不够时该往哪些方向优化
- ✅ 能针对巴哈赛道这种恶劣环境说出颜色特征失效后的替代方案
- ✅ 能写出高信息量的提示词，让 AI 真正帮到你的工程工作

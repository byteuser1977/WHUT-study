## 1. 工作空间与功能包

ROS 2 的代码组织只有两级：**工作空间 → 功能包**。

- **工作空间（workspace）**：一个总目录，通常叫 `ros2_ws`，里面所有代码由你统一编译。
- **功能包（package）**：ROS 2 里最小的代码组织单位，一个包 = 一个功能模块。**节点写在功能包里。**

```bash
# 标准结构（背下来）
ros2_ws/
├── src/                     # 只放源码，你在这里写代码
│   └── perception_demo/     # 一个功能包
├── build/                   # colcon 编译过程的中间文件（不手动改）
├── install/                 # 编译产物（不手动改）
└── log/                     # 编译日志（不手动改）
```

> 💡 类比：工作空间像**一个车间**，功能包像车间里的**一台机床**。`src/` 是你动手改装机床的地方，`build/`、`install/`、`log/` 是车间自己吐出来的边角料——**永远不要去手改这三个目录**，出问题就整个删掉重新编译。

> ⚠️ 常见坑：**不要在 `src/` 之外建包**。经常有人把功能包建在 `~/` 下，然后困惑"为什么 `colcon build` 说找不到包"——因为 colcon 只认当前目录树里的 `src/`。

## 3. 最小发布者（talker.py）

在 `~/ros2_ws/src/perception_demo/perception_demo/` 下新建 `talker.py`：

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String


class MinimalPublisher(Node):
    """最小发布者：每 0.5 秒往话题 /perception_hello 发一条字符串。"""

    def __init__(self):
        super().__init__('minimal_publisher')          # ① 节点名，全局唯一
        self.publisher_ = self.create_publisher(
            String,            # ② 消息类型
            'perception_hello',  # ③ 话题名（不带 / 会自动补成 /perception_hello）
            10)                # ④ 发送队列长度
        self.timer = self.create_timer(0.5, self.timer_callback)  # 每 0.5s 触发一次 ≈ 2 Hz
        self.count = 0

    def timer_callback(self):
        msg = String()
        msg.data = f'第 {self.count} 帧 / hello from perception'
        self.publisher_.publish(msg)                     # 发出去
        self.get_logger().info(f'发布: "{msg.data}"')     # 打印，方便肉眼确认
        self.count += 1


def main(args=None):
    rclpy.init(args=args)          # 初始化（搭好 DDS 环境）
    node = MinimalPublisher()      # 创建节点
    try:
        rclpy.spin(node)           # 一直"转"，处理回调，直到 Ctrl+C
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()        # 销毁节点
        rclpy.shutdown()           # 清理


if __name__ == '__main__':
    main()
```

**代码要点**：`create_publisher` 的三要素是"类型、话题名、队列长度"；`create_timer` 是"隔多久触发一次回调"；`rclpy.spin()` 是"让节点活着并不断响应事件"——**没有 spin，节点会瞬间退出**。

## 4. 最小订阅者（listener.py）

同目录下新建 `listener.py`：

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String


class MinimalSubscriber(Node):
    """最小订阅者：每收到一条 /perception_hello 就打印一次。"""

    def __init__(self):
        super().__init__('minimal_subscriber')
        self.subscription = self.create_subscription(
            String,                 # 类型必须和发布者一致
            'perception_hello',     # 话题名必须完全一致
            self.listener_callback,  # 收到消息时调用的函数
            10)
        self.count = 0

    def listener_callback(self, msg):
        self.count += 1
        self.get_logger().info(f'收到第 {self.count} 条: "{msg.data}"')


def main(args=None):
    rclpy.init(args=args)
    node = MinimalSubscriber()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

> ⚠️ 常见坑：**发布者和订阅者的"话题名 + 消息类型"必须完全一致**（`perception_hello` + `std_msgs/msg/String`），差一个字符或换个类型就永远收不到，而且**不报错**。这是新手 90% 的"收不到数据"的原因，排查方法就是上一讲的 `ros2 topic info -v`。

## 5. 注册可执行文件并编译

改两处配置文件，让 ROS 2 知道有这么两个可执行程序：

`setup.py` 里加上 `entry_points` 和 launch 目录：

```python
from glob import glob
import os
from setuptools import find_packages, setup

package_name = 'perception_demo'

setup(
    name=package_name,
    version='0.1.0',
    packages=find_packages(exclude=['test']),
    data_files=[
        ('share/ament_index/resource_index/packages', ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
        (os.path.join('share', package_name, 'launch'), glob('launch/*.launch.py')),
    ],
    install_requires=['setuptools'],
    zip_safe=True,
    maintainer='you',
    maintainer_email='you@example.com',
    description='感知组入门示例：最小发布者与订阅者',
    license='Apache-2.0',
    entry_points={
        'console_scripts': [
            'talker = perception_demo.talker:main',
            'listener = perception_demo.listener:main',
        ],
    },
)
```

`package.xml` 里补上依赖（`<depend>rclpy</depend>` 和 `<depend>std_msgs</depend>`），并把 `<build_type>` 保持为 `ament_python`。然后在工作空间根目录编译：

```bash
cd ~/ros2_ws
colcon build --symlink-install
source install/setup.bash
```

> ✅ 你应该看到：
> ```
> Starting >>> perception_demo
> Finished <<< perception_demo [1.2s]
>
> Summary: 1 package finished [1.5s]
> ```
> **只有出现 `Summary: 1 package finished` 才算真的成功**；如果看到 `Failed`，把报错往上翻，通常是 Python 缩进或 `setup.py` 语法错误。

> 💡 类比：`colcon build` 像**把散装零件装进工具箱**；`source install/setup.bash` 是**把工具箱挂到身上**（和第01讲的 source 一个道理）；`ros2 run` 则是**从工具箱里取出一个工具开动**。三个动作缺一不可。

> ⚠️ 常见坑：**`--symlink-install` 很值得加**，它让 Python 源码以软链接方式安装——以后改了 `.py` 直接重启节点即可生效，**不用重编译**；但改了 `setup.py`（新增可执行文件）或 launch 文件，还是必须重新 `colcon build`。另外，每开一个新终端都要重新 `source install/setup.bash`，否则 `ros2 run perception_demo talker` 会报 `Package not found`。

## 6. launch 文件入门

每次开四个终端、手动敲四条 `ros2 run`，很烦。**launch 文件**就是"一键启动脚本"。

在包里新建 `launch/demo.launch.py`：

```python
from launch import LaunchDescription
from launch_ros.actions import Node


def generate_launch_description():
    return LaunchDescription([
        Node(
            package='perception_demo',
            executable='talker',      # 对应 setup.py 里 entry_points 的名字
            name='talker_node',       # 重命名节点（可选）
            output='screen',          # 日志打在屏幕上
        ),
        Node(
            package='perception_demo',
            executable='listener',
            name='listener_node',
            output='screen',
        ),
    ])
```

```bash
cd ~/ros2_ws && colcon build --symlink-install && source install/setup.bash
ros2 launch perception_demo demo.launch.py
```

> ✅ 你应该看到（两个节点的日志交替出现）：
> ```
> [talker_node-1] 发布: "第 0 帧 / hello from perception"
> [listener_node-2] 收到第 1 条: "第 0 帧 / hello from perception"
> [talker_node-1] 发布: "第 1 帧 / hello from perception"
> [listener_node-2] 收到第 2 条: "第 1 帧 / hello from perception"
> ```
> 按 `Ctrl+C` 会**同时**关掉两个节点，省掉了逐个关窗口的麻烦。

> 💡 类比：`ros2 run` 像**自己开火做饭**（材料在哪、火候多大都要自己盯），launch 文件像**写好的一桌套餐**：一条命令，几个节点按顺序上齐，参数也一起带上，换车、换场景时改一个文件就行。真车上通常就是"一条 launch 拉起相机 + 感知 + 控制"。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 工作空间 | `ros2_ws/`，代码只写在 `src/`；`build/install/log` 不要手改 |
| 功能包 | 代码组织的最小单位，用 `ros2 pkg create --build-type ament_python` 生成 |
| 发布者 | `create_publisher(类型, 话题名, 队列)`；用 `create_timer` 定时发布 |
| 订阅者 | `create_subscription(类型, 话题名, 回调, 队列)`；回调里处理消息 |
| 节点活起来的关键 | `rclpy.init()` → `rclpy.spin(node)` → `destroy_node()` + `shutdown()` |
| 注册可执行 | `setup.py` 的 `entry_points` 里登记 `名字 = 包.文件:main` |
| 编译 | `colcon build --symlink-install`，然后在**每个终端** `source install/setup.bash` |
| launch | 用 `LaunchDescription + Node(...)` 一条命令启动多个节点，`Ctrl+C` 一起关 |
| 排错口诀 | 收不到数据 → 先比对话题名与消息类型是否完全一致 |

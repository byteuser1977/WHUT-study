## 1. 先说结论：切片语法长什么样

**自测题**：如果想截取图片的上半部分（前 240 行像素），NumPy 切片（Slicing）语法应该怎么写？

答案（任写一种都对）：

```python
top = img[0:240, :]     # 显式写法
top = img[:240]         # 简写，效果完全相同
```

完整可运行的例子：

```python
import cv2

img = cv2.imread("test.jpg")        # shape (480, 640, 3)
top = img[0:240, :]                 # 取第 0~239 行，全部 640 列
print(img.shape, "->", top.shape)   # (480, 640, 3) -> (240, 640, 3)
cv2.imwrite("top.jpg", top)
```

> ✅ 你应该看到：
> ```
> (480, 640, 3) -> (240, 640, 3)
> ```

注意三点：
1. `0:240` 是**左闭右开**：包含第 0 行，**不包含**第 240 行。所以拿到的是第 0~239 行，正好 240 行。
2. 第二个位置的 `:` 表示"这一维全都要"，即 640 列一列不漏。
3. 第三维（通道）不写就默认全保留，所以结果仍是 3 通道的彩色图。**如果想连通道也一起写全，就是 `img[0:240, :, :]`，结果一模一样。**

> 💡 类比：切片就像在 Excel 里**框选一片单元格**然后复制。`img[0:240, :]` = "从第 0 行框到第 240 行之前，列不限，全选"，复制出来的就是新的一张表，原表一点都没变。

## 2. 把切片语法彻底搞懂：`img[行, 列]`

记住一个总原则：**第一个下标管"竖直方向"，第二个下标管"水平方向"**——和上一讲 `shape=(高, 宽, 3)` 是同一套顺序。

```python
img[r, c]              # 单个像素（返回 BGR 三个数）
img[r1:r2, c1:c2]      # 一片矩形区域
img[:240, :]           # 上半个（前 240 行）
img[240:, :]           # 下半个（第 240 行到最后一行）
img[:, :320]           # 左半边（前 320 列）
img[:, 320:]           # 右半边
img[100:200, 200:400]  # 中间任意一块矩形
img[::2, ::2]          # 每隔一行、每隔一列取一个 → 缩小一半
img[::-1, :]           # 上下翻转
```

常用的省略写法：

| 写法 | 等价于 | 含义 |
|------|--------|------|
| `img[:240]` | `img[0:240, :]` | 开头省略 = 从 0 开始 |
| `img[240:]` | `img[240:, :]` | 末尾省略 = 一直到最后 |
| `img[:]` | `img[0:H, :]` | 整张图（复制一份） |
| `img[::2]` | 每隔一行取一行 | 下采样 |

> ⚠️ 常见坑一：**搞混行列，切出一张"躺着"的图**。想要"上半部分"却写成 `img[:, 0:240]`，拿到的是**左半部分**。写之前先默念"先行后列"。

> ⚠️ 常见坑二：**切片拿到的是"视图（view）"不是"副本"**。对普通 NumPy 数组来说，`top = img[0:240, :]` 之后再 `top[:] = 0` 会把**原图的上半部分也涂黑**。这是 NumPy 为了省内存的默认行为（共享底层数据）。
>
> - 想安全地独立操作，显式复制一份：`top = img[0:240, :].copy()`
> - 想"直接改原图某一块"（很常用！比如给 ROI 涂色、叠加结果显示），反而可以利用这一点：
>   ```python
>   img[0:240, :] = (0, 0, 255)     # 直接把上半部分涂红（BGR）
>   ```

> ⚠️ 常见坑三：**索引越界不报错，只是默默切小了**。`img[0:600, :]` 在 480 行的图上不会崩溃，它会给你 480 行。想及时发现，可以自己 `assert top.shape[0] == 240`。

## 3. 什么是 ROI？为什么每套感知算法第一步都是它

**ROI = Region of Interest，感兴趣区域**，就是"我只关心图里的这一块，其他部分不要"。

在感知组的小车上，摄像头装在前方、拍到的画面通常长这样：

```
┌─────────────────────────────┐
│      天空 / 树 / 远处建筑      │  ← 没有信息，白算
├─────────────────────────────┤
│      可行驶路面 + 赛道        │  ← 真正有用的区域 = ROI
│         (车道线)             │
└─────────────────────────────┘
```

于是标准操作：**先切一刀，只把下半部分交给后面的算法。**

```python
h, w = img.shape[:2]          # 480, 640
roi = img[int(h * 0.5):, :]   # 取下面 50% → 240 行
```

> 💡 类比：ROI 就像**读课本时用荧光笔划重点**。整本书 300 页，但考试只考第 10 章——你不会每页都背一遍。划出重点区域，后面的复习（算法）速度快、还更准确。

ROI 的三个现实好处：

| 好处 | 说明 | 粗略收益 |
|------|------|----------|
| 省算力 | 像素少了，后续每个算子都少算 | 切一半面积 → 计算量约减半 |
| 提准确率 | 排除天空、树木、行人无关区域造成的误检 | 误检显著下降 |
| 降延迟 | 车载设备上直接换 FPS | 20 FPS → 30+ FPS 很常见 |

（第 05 大类"算力优化"会把这一条展开讲，这里先记住：**ROI 是性价比最高的优化手段，没有之一**。）

## 4. 另外三个必备小操作：缩放、翻转、画矩形

### 4.1 缩放 `cv2.resize`

```python
small = cv2.resize(img, (320, 240))          # 参数是 (宽, 高) ⚠️ 又是反的！
half  = cv2.resize(img, None, fx=0.5, fy=0.5)  # 按比例缩：宽高都乘 0.5
```

> ⚠️ 注意 `cv2.resize` 的第二个参数是 **`(宽, 高)`**，跟 `shape` 的 `(高, 宽, 3)` **顺序相反**。这是新手翻车重灾区：`cv2.resize(img, (240, 320))` 出来的是 240 宽、320 高的**竖图**。
>
> ```python
> h, w = img.shape[:2]
> small = cv2.resize(img, (w // 2, h // 2))   # ✅ 用 h/w 变量写，不会记错
> ```

插值方式（第三个参数 `interpolation`）：
- 缩小：`cv2.INTER_AREA`（质量最好，别用默认）
- 放大：`cv2.INTER_LINEAR` 或 `cv2.INTER_CUBIC`

### 4.2 翻转 `cv2.flip`

```python
flip_h = cv2.flip(img, 1)    # 水平翻转（左右镜像），像照镜子
flip_v = cv2.flip(img, 0)    # 垂直翻转（上下倒过来）
flip_b = cv2.flip(img, -1)   # 两个方向都翻
```

什么时候用？
- 摄像头装反了 / 镜像输出（自拍习惯）→ `flip(img, 1)`
- **数据增强**：深度学习训练时把图翻一翻，等于白捡一倍数据

### 4.3 画矩形 `cv2.rectangle` —— 做标注

```python
out = img.copy()                                   # 别在原图上画
cv2.rectangle(out, (x1, y1), (x2, y2), (0, 255, 0), 2)
#                左上角    右下角   颜色(BGR)   线宽
cv2.putText(out, "ROI", (x1, y1 - 8),
            cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 2)
cv2.imwrite("roi_marked.jpg", out)
```

- 坐标是 `(x, y)` = `(列, 行)`，**和切片顺序又反了**：切片的 `img[y, x]` 变成画图的 `(x, y)`。
- 颜色仍是 BGR：`(0, 255, 0)` = 纯绿色，`(0, 0, 255)` = 纯红色。
- 线宽 `2` 表示画 2 像素粗的框；写 `-1` 表示**填充**整个矩形。

> ⚠️ 三个函数的坐标顺序总结（背下来能省很多调试时间）：
>
> | 函数 | 坐标顺序 |
> |------|----------|
> | `img[y, x]` 切片 | 先行后列 = **(y, x)** |
> | `cv2.resize(img, (w, h))` | **(宽, 高)** |
> | `cv2.rectangle(img, (x, y), ...)` | **(x, y)** |

## 本讲小结

| 概念 | 要点 |
|------|------|
| 切片 `img[行范围, 列范围]` | **先行后列**；`0:240` 左闭右开（含 0 行、不含 240 行） |
| 取上半部分 | **`img[0:240, :]`，简写 `img[:240]`（本讲核心）** |
| 省略号 | 开头省略=从 0 开始，末尾省略=到最后，`:` 表示"全都要" |
| 视图 vs 副本 | 切片默认共享数据，改它会影响原图；要独立用 `.copy()` |
| ROI | 感兴趣区域；先裁掉天空等无效区，省算力 + 提准确率 |
| `cv2.resize` | 第二个参数是 **`(宽, 高)`**，与 `shape` 相反；缩小用 `INTER_AREA` |
| `cv2.flip` | `1` 左右镜像 / `0` 上下翻转 / `-1` 都翻 |
| `cv2.rectangle` | 坐标为 `(x, y)`；颜色 BGR；线宽 `-1` 表示填充 |

## 1. 摄像头和"拍照"其实是两回事

你手机上按一下快门，得到一张照片。但程序里的摄像头是**另一种东西**：

程序打开摄像头后，摄像头会**每秒往你手里塞 30 张左右的画面**（30 FPS），一张接一张，永不停止。程序的活是"不停地接住这些画面，挑一张存下来"。

所以"拍照"这个动作，在代码里拆成三步：

| 步骤 | 代码 | 类比 |
|------|------|------|
| 1. 打开水龙头 | `cap = cv2.VideoCapture(0)` | 打开摄像头（建立连接） |
| 2. 接一杯水 | `ok, frame = cap.read()` | 读**一帧**画面（就是一张图） |
| 3. 拿杯子存起来 | `cv2.imwrite("a.jpg", frame)` | 把这一帧写成文件 = 拍照完成 |

> 💡 类比：摄像头像**一直开着的水龙头**，`read()` 是拿杯子去接一杯水，`imwrite()` 是把这杯水倒进瓶子保存。所谓"拍照"，本质是**"从视频流里截取某一帧并写进硬盘"**——这也是为什么视频文件能被逐帧拆成图片。

`read()` 返回的是**两个东西**：`ok`（成功没成功，True/False）和 `frame`（那一帧的图像，就是上一讲学的 `shape=(480,640,3)` 的 NumPy 数组）。**一定要检查 `ok`**，否则摄像头没插好时，后面所有代码都在操作一个 `None`，报一堆看不懂的错。

## 2. 完整可运行脚本：`take_photo.py`

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
调用电脑自带摄像头拍照。
用法：python3 take_photo.py
操作：窗口弹出后，按 空格 拍照并保存当前帧，按 q 或 ESC 退出。
"""
import os
import time
import cv2

CAMERA_INDEX = 0        # 0 = 默认摄像头；打不开就试 1
SAVE_DIR = "photos"     # 照片保存目录

os.makedirs(SAVE_DIR, exist_ok=True)          # 目录不存在就创建，已存在也不报错

# Windows 下用 DirectShow 后端打开摄像头，速度快、更稳定
backend = cv2.CAP_DSHOW if os.name == "nt" else cv2.CAP_ANY
cap = cv2.VideoCapture(CAMERA_INDEX, backend)

if not cap.isOpened():                        # 打开失败要立刻报错退出，别硬撑
    print(f"❌ 无法打开摄像头 (index={CAMERA_INDEX})，请检查：")
    print("   1) 摄像头是否被其他程序占用（微信/腾讯会议/浏览器）")
    print("   2) 试试把 CAMERA_INDEX 改成 1 或 2")
    print("   3) WSL 里默认访问不到摄像头，请在 Windows 的 Python 里运行本脚本")
    raise SystemExit(1)

cap.set(cv2.CAP_PROP_FRAME_WIDTH, 640)        # 设置采集分辨率（可选）
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 480)
print(f"✅ 摄像头已打开 (index={CAMERA_INDEX})，按【空格】拍照，按【q】退出")

shot_count = 0

try:
    while True:
        ok, frame = cap.read()                # 读一帧
        if not ok:
            print("⚠️ 读取帧失败（摄像头可能被拔掉或占用），退出")
            break

        frame = cv2.flip(frame, 1)            # 水平镜像，自拍更像"照镜子"

        # 左上角显示提示文字（画在画面上，不会影响保存？会——但这里就是要它进照片）
        cv2.putText(frame, "SPACE = shoot, q = quit",
                    (10, 30), cv2.FONT_HERSHEY_SIMPLEX,
                    0.7, (0, 255, 0), 2)

        cv2.imshow("Camera - press SPACE", frame)   # 显示这一帧

        key = cv2.waitKey(1) & 0xFF           # 等 1 毫秒，看有没有按键
        if key == ord(" ") or key == ord("s"):      # 空格 或 s → 拍照
            shot_count += 1
            filename = os.path.join(
                SAVE_DIR,
                time.strftime("photo_%Y%m%d_%H%M%S") + f"_{shot_count}.jpg",
            )
            cv2.imwrite(filename, frame)
            print(f"📷 已保存：{filename}  ({frame.shape[1]}x{frame.shape[0]})")
            time.sleep(0.3)                   # 防手抖连拍重复存
        elif key == ord("q") or key == 27:    # q 或 ESC → 退出
            break
finally:
    cap.release()                             # 释放摄像头，别占着不放
    cv2.destroyAllWindows()                   # 关掉所有 OpenCV 窗口
    print(f"👋 已退出，本次共拍 {shot_count} 张，文件在 ./{SAVE_DIR}/")
```

## 3. 逐行解释（重点看这些）

| 代码 | 作用 | 为什么必须写 |
|------|------|--------------|
| `cv2.VideoCapture(0, backend)` | 打开第 0 号摄像头 | `0` 是摄像头编号（一般笔记本内置的是 0）；外接 USB 摄像头常是 1 |
| `cv2.CAP_DSHOW` | Windows 专用后端（DirectShow） | Windows 上不指定这个，打开摄像头可能要等 **5~10 秒**，甚至整个程序卡住 |
| `os.name == "nt"` | 判断是不是 Windows | 让同一份代码在 Windows 和 Linux 都能跑 |
| `cap.isOpened()` | 检查是否打开成功 | 失败时给**人话提示**，比后面报 `'NoneType' object has no attribute 'shape'` 强一百倍 |
| `cap.set(..., WIDTH/HEIGHT)` | 请求 640×480 | 不设的话可能是 1280×720，图片更大、处理更慢；注意这是"请求"，摄像头可以不听 |
| `cap.read()` | 读一帧 | 返回 `(ok, frame)` 两个值，**必须接住两个** |
| `cv2.flip(frame, 1)` | 水平镜像 | 不加的话拍出来左右是反的，自拍看着别扭 |
| `cv2.putText(...)` | 在画面上写字 | 坐标 `(x,y)` 是文字**左下角**的起点；颜色 BGR |
| `cv2.imshow(name, frame)` | 弹窗显示 | 窗口名相同的会复用同一个窗口 |
| `cv2.waitKey(1)` | **关键**：等 1ms 并处理 GUI 事件 | ① 不给它时间，窗口就会"假死"白屏；② 它的返回值就是**你按下的键** |
| `& 0xFF` | 只保留低 8 位 | 有些平台返回值带高位（如 0xFF...），不 mask 会导致按键判断永远失败 |
| `ord(" ")` | 把字符转成键码 | 空格的键码是 32 |
| `time.strftime(...)` | 生成时间戳文件名 | 避免覆盖上一张；`photo_20260918_201530_1.jpg` 这种名字自带信息 |
| `cap.release()` | 释放摄像头 | 不调用的话摄像头灯一直亮着，别的程序打不开 |
| `cv2.destroyAllWindows()` | 关闭所有窗口 | 不然关不掉，只能强杀进程 |
| `try / finally` | 保证异常时也释放 | 按 `Ctrl+C` 中断时也能干净退出 |

> 💡 类比：`waitKey(1)` 是**这个循环的心跳**。OpenCV 的窗口不会自己刷新——你得每转一圈喊它一声"喂，刷新一下，顺便看看用户按了什么键"。所以**循环里必须有 `waitKey`**，否则窗口就是一块白板。

## 4. 运行说明（Windows / Ubuntu / WSL 三种情况）

### 4.1 安装依赖（三个平台通用）

```bash
pip install opencv-python numpy
```

> ⚠️ 装 `opencv-python`，**不要**装 `opencv-python-headless`：headless 版本没有 GUI 模块，`cv2.imshow` 会直接报错 `AttributeError: module 'cv2' has no attribute 'imshow'`。

验证：

```bash
python3 -c "import cv2; print(cv2.__version__)"
```

> ✅ 你应该看到类似：`4.10.0`

### 4.2 Windows（**强烈推荐在 Windows 上做**）

1. 把上面的代码存成 `take_photo.py`（UTF-8 编码）
2. 在该文件所在目录打开 CMD 或 PowerShell：
   ```bash
   python take_photo.py
   ```
3. 弹出窗口后，**人坐进画面里**，按空格拍照
4. 到 `photos\` 目录里找照片，挑一张清晰的保存下来

> ✅ 你应该看到（终端）：
> ```
> ✅ 摄像头已打开 (index=0)，按【空格】拍照，按【q】退出
> 📷 已保存：photos/photo_20260918_201530_1.jpg  (640x480)
> ```
> 同时屏幕上出现一个实时画面窗口，画面里有绿色的 "SPACE = shoot, q = quit"。

### 4.3 Ubuntu 桌面

同上。若提示打不开摄像头，先确认当前用户在 `video` 组：`sudo usermod -aG video $USER`（改完要重新登录）。

### 4.4 ⚠️ WSL 用户注意：默认**访问不到摄像头**

WSL 是虚拟环境，Windows 的摄像头设备默认不会透传给 WSL，`cv2.VideoCapture(0)` 通常返回"打不开"。三种解决办法，按推荐度排序：

| 方案 | 做法 | 评价 |
|------|------|------|
| **① 在 Windows 侧跑脚本** | 用 Windows 的 Python 执行 `take_photo.py` | ✅ 最简单，照片直接存在 Windows 里，后面好整理 |
| ② usbipd 透传 USB 摄像头 | Windows 装 `usbipd-win`，`usbipd attach --wsl` 把 USB 摄像头转发进 WSL | 内置摄像头（非 USB）转发不了；较折腾 |
| ③ 手写一个"兜底"版本 | 没有摄像头时读本地视频/图片，先把逻辑跑通 | 调代码时很好用（见下面练习） |

> 💡 结论：**这个练习就在 Windows 的 Python 里跑，别跟 WSL 较劲。** 本教程其他讲次的学习依然在 WSL 里进行，只有"真用摄像头"这一件事回 Windows。

## 5. 常见坑速查

| 现象 | 原因 | 解决 |
|------|------|------|
| 程序卡住 5~10 秒才出图 | Windows 默认后端慢 | 加 `cv2.CAP_DSHOW` |
| `❌ 无法打开摄像头` | 被占用 | 关掉微信、腾讯会议、浏览器、OBS、相机 App |
| 打开成功但画面全灰/全黑 | 笔记本**物理摄像头挡板**/隐私开关没开 | 检查 F10 之类的摄像头热键、Windows 隐私设置 |
| 图像颠倒 | 摄像头装反 | `cv2.flip(frame, 0)` 或 `-1` |
| 窗口白屏 / "无响应" | 循环里没有 `cv2.waitKey` | 补上 `cv2.waitKey(1)` |
| 按 q 退不出 | 少了 `& 0xFF` | `key = cv2.waitKey(1) & 0xFF` |
| `module 'cv2' has no attribute 'imshow'` | 装成了 headless | `pip uninstall opencv-python-headless -y && pip install opencv-python` |
| 报错 `'NoneType' object has no attribute ...` | 没检查 `ok`，或图片路径错 | 检查 `ok`；`cv2.imread` 失败返回 `None` 也是同一个坑 |
| 外接摄像头打不开，内置能开 | 编号不是 0 | 依次试 `1`、`2` |
| 照片 Saved 了但打不开 | 扩展名与实际格式不符 | 就用 `.jpg` / `.png`，别乱写 |
| 程序结束后摄像头灯还亮 | 没 `cap.release()` | 放在 `finally` 里 |

ok, frame = cap.read()

## 本讲小结

| 概念/函数 | 要点 |
|-----------|------|
| `cv2.VideoCapture(index)` | 打开摄像头；`0` 是默认，外接常是 `1`；Windows 建议加 `cv2.CAP_DSHOW` |
| `cap.isOpened()` | 判断是否打开成功，失败给提示而不是让它崩 |
| `cap.read()` | 读一帧，返回 `(ok, frame)`；**必须检查 `ok`** |
| 拍照的本质 | 从连续视频流里取一帧 + `cv2.imwrite` 写盘（**本讲核心**） |
| `cv2.imshow` + `cv2.waitKey(1)` | 显示与按键；`waitKey` 是窗口的"心跳"，缺了会白屏 |
| `ord(" ")` / `ord("q")` / `27` | 空格 / q / ESC 的键码；配合 `& 0xFF` 使用 |
| `cap.release()` + `destroyAllWindows()` | 释放资源，放在 `finally` 里 |
| `cv2.imwrite(path, img)` | 保存；文件名加时间戳避免覆盖 |
| WSL 提醒 | WSL 默认访问不到摄像头，这个练习在 Windows 的 Python 里做 |

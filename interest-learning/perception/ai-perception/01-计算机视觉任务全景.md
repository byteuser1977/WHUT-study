## 1. 计算机视觉 = 让电脑「看图说话」

计算机视觉（Computer Vision，简称 CV）的目标只有一句话：把图像变成**结论**。

对人来说，看一眼就知道「这是马路、前面有个锥桶、右边是草地」；对电脑来说，一张 480×640 的彩色图就是 480×640×3 = 921600 个 0~255 的整数（这就是大类二讲的 NumPy 数组）。CV 做的事，就是把这一堆数字压成一句电脑能用的结论。

> 💡 类比：把 CV 任务想象成看一张班级合影。
> - **分类（Classification）**：只回答「这是几班」——整张图给一个标签。
> - **检测（Detection）**：回答「照片里有 3 个人，分别在左边、中间、右边」——给每个目标画一个框。
> - **分割（Segmentation）**：回答「每一个像素属于人脸、衣服还是背景」——逐像素上色。
> - **跟踪（Tracking）**：回答「刚才穿红衣服那个人，现在走到哪了」——同一个人跨帧对号入座。

注意这四件事的**输出粒度**是逐级变细的：一个标签 → 几个框 → 一张和原图一样大的标注图 → 一串带编号的轨迹。粒度越细，信息越多，算力也越贵。

## 2. 四大任务对照表

| 任务 | 输入 | 输出 | 输出粒度 | 代表算法 | 车上典型用途 |
|------|------|------|----------|----------|--------------|
| 分类 | 一张图 | 1 个类别标签 | 整图 | ResNet、MobileNet | 场景判断（白天/夜间、公路/越野） |
| 检测 | 一张图 | N 个 `(类别, 框, 置信度)` | 目标级 | YOLO、Faster R-CNN | 障碍物、锥桶、行人 |
| 语义分割 | 一张图 | 每个像素的类别 | 像素级 | FCN、U-Net、SegFormer | **可行驶区域**、路面/非路面 |
| 实例分割 | 一张图 | 像素级 + 每个实例编号 | 像素级+实例 | Mask R-CNN、YOLO-Seg | 分别标出每一个锥桶的轮廓 |
| 跟踪 | 视频帧序列 | 目标 ID + 轨迹 | 时序目标级 | 卡尔曼滤波、ByteTrack | 给障碍物编号、估速度 |

区别一句话记法：**分类给「是什么」，检测给「有什么、在哪」，分割给「每个像素是什么」，跟踪给「还是不是刚才那个」。**

### 分割的三个层次（别搞混）

- **语义分割（Semantic）**：只分类别，不区分个体。画面里 3 个锥桶都会被涂成同一片「锥桶色」，连成一块。
- **实例分割（Instance）**：既分类别也分个体，3 个锥桶是 3 个不同编号的区域。
- **全景分割（Panoptic）**：语义 + 实例的合并版（背景用语义、物体用实例）。

## 3. 感知组在车上到底干什么

巴哈赛车（Baja）是越野小车，没有激光雷达、没有高精地图，主要靠**一个前置摄像头**看路。感知组的活儿就是把摄像头画面翻译成「车能不能往这边开」，具体拆成三件：

| 车上要做的事 | 对应 CV 任务 | 输出给谁 | 备注 |
|--------------|--------------|----------|------|
| **可行驶区域识别** | 语义分割（2 类：可开/不可开） | 规划控制 | 第03讲实战，**对应试题 3(1)** |
| **车道/边界线识别** | 分割或边缘检测+拟合 | 规划控制 | 赛道边界模糊时最难 |
| **障碍物识别** | 目标检测（YOLO 一类） | 规划、急停 | 行人、锥桶、物块 |
| **多帧跟踪** | 跟踪 | 决策 | 避免同一障碍物每帧都当新目标 |
| 相机自检 | 去畸变、曝光检查 | 系统状态 | 第05讲 |

> 💡 类比：可行驶区域识别就像在陌生的泥土场地上**用眼睛扫出一片「能站人的空地」**——你不用知道这块地叫什么名字、属于谁，只要知道「这块能走、那块是沟」。而障碍物检测相当于「这块空地里站着几个人」，需要精确知道每个人的位置和大小。前者是「铺路」，后者是「点名」。

> ⚠️ 常见坑：不要拿检测框当掩膜用。检测框是一个矩形，框里大部分像素是背景（比如一个人站在路中间，检测框里 70% 是路面）。如果把检测框当成「这里有障碍」的区域，车会误判一大片路面不能走，运动规划会直接瘫痪。**框是「大概是这个目标」，掩膜才是「像素级的精确范围」。**

## 4. 怎么选：分割 vs 检测

| 你的需求 | 选哪个 | 理由 |
|----------|--------|------|
| 形状不规则、面积大的区域（路面、天空、水面） | 语义分割 | 目标没有规则边界，框不住 |
| 一个个独立小目标（锥桶、人、袋子） | 目标检测 | 每个目标都要独立计数与定位 |
| 既要区域又要个体 | 实例/全景分割 | 算力最高，边缘端慎用 |
| 只要「有没有」 | 分类 | 最省算力 |
| 视频里同一个目标的连续位置 | 跟踪 | 单帧检测无法给出 ID |

从零基础到上车，推荐的**降级顺序**是：能分割就分割（拿到像素级路面）→ 分割太慢就退化成检测框 + 车道拟合 → 再慢就退化成分类（只看画面中间区域是不是路面）。这套「降级思路」在第05讲和思维类第 3 题（算力优化）里还会反复用到。

## 🎯 课后练习（约8分钟）

不用装深度学习框架，用已经装好的 OpenCV 就能亲手体会「像素级分割」和「目标级检测」的区别。

先准备一张图（可以用大类二第03讲拍的桌面照片）：

```bash
# 确认环境（Ubuntu 22.04 / WSL）
python3 -c "import cv2, numpy; print(cv2.__version__, numpy.__version__)"
```

新建 `task_demo.py`：

```python
import cv2
import numpy as np

img = cv2.imread("myphoto.jpg")
if img is None:
    raise SystemExit("读不到图片，检查文件名和路径")
h, w = img.shape[:2]
print("图像尺寸:", w, "x", h)

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (5, 5), 0)

# ---- 这是最原始的「语义分割」：把图分成 亮/暗 两类 ----
thr, binary = cv2.threshold(blur, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print("自动阈值 =", round(thr, 1))
print("亮区像素占比 = %.1f%%" % ((binary > 0).mean() * 100))

# ---- 这是「检测」：给一个矩形框 ----
x, y, bw, bh = int(w * 0.3), int(h * 0.3), int(w * 0.4), int(h * 0.4)
boxed = img.copy()
cv2.rectangle(boxed, (x, y), (x + bw, y + bh), (0, 0, 255), 2)

cv2.imwrite("out_binary.png", binary)      # 逐像素的结论（分割）
cv2.imwrite("out_box.png", boxed)          # 一个框的结论（检测）
print("已保存 out_binary.png / out_box.png")
```

运行：

```bash
python3 task_demo.py
```

> ✅ 你应该看到（类似）：
> ```
> 图像尺寸: 640 x 480
> 自动阈值 = 121.0
> 亮区像素占比 = 43.7%
> 已保存 out_binary.png / out_box.png
> ```

打开两张输出图对比：`out_binary.png` 是**黑底白块**的像素级结论，`out_box.png` 是原图上多了一个红框。再回答一个问题写到作业本上：**如果任务是「找出可行驶区域」，这两个结果哪个更有用？为什么？**（提示：看框里有多少是路面）

## 本讲小结

| 概念 | 要点 |
|------|------|
| 分类 | 整图一个标签，最省算力 |
| 目标检测 | 输出若干「类别 + 矩形框」，适合独立小目标 |
| 语义分割 | 逐像素分类，适合形状不规则的大区域（路面） |
| 实例分割 | 逐像素 + 区分个体，算力最高 |
| 跟踪 | 跨帧给同一目标分配固定 ID，能估速度 |
| 感知组三大任务 | 可行驶区域（分割）、车道边界（分割/拟合）、障碍物（检测+跟踪） |
| 选择原则 | 目标规则小 → 检测；目标不规则大 → 分割；只要有没有 → 分类 |
| 别踩的坑 | 检测框 ≠ 掩膜，框里大部分是背景 |

## 1. 传统方案的天花板

第03讲的方案只用了「亮度 + 形态学」这些**手工设计的规则**（也叫传统视觉 / 规则法）。它的优点是快（毫秒级）、不要 GPU、逻辑可解释；缺点是：

| 短板 | 具体表现 |
|------|----------|
| 规则靠人写 | 换个赛道、换个光照，阈值就要重调 |
| 特征太浅 | 只会看「亮不亮、大不大」，看不懂「泥土路上的车辙」「阴影里的坑」 |
| 难表达多类别 | 想同时分出「路面 / 草地 / 积水 / 天空」几乎写不出规则 |
| 抗干扰弱 | 逆光、泥水、反光直接失效（思维类第 4 题就是在问这个） |

**深度学习的思路完全不同**：不再由人告诉程序「看亮度」，而是给模型看几万张标好的图，让它**自己从数据里学出该看什么特征**。代价是需要训练数据、需要算力、可解释性差。

> 💡 类比：传统视觉像**照着菜谱做菜**——步骤清晰、谁都能复现，但换个食材（换场景）就得改菜谱；深度学习像**跟老师傅学徒**——看了几万遍怎么做，自己悟出了手法，遇到新食材也能应付，但你问他「为什么这么切」，他可能说不清。

## 2. 语义分割：给每个像素发一个类别证

语义分割（Semantic Segmentation）的任务是：输入一张 `(H, W, 3)` 的图，输出一张 `(H, W)` 的**类别图**——每个位置存一个整数，表示这个像素属于第几类。

```
输入 image: (480, 640, 3)   uint8   0~255
       ↓ 神经网络
输出 logits: (N_class, 480, 640)    每个像素在每一类上的"得分"
       ↓ argmax（按类别维度取最大）
类别图: (480, 640)          每个像素一个类别号
```

有了类别图，把「路面」那一类的像素挑出来变成 255，其余置 0，**就得到了第03讲里那张掩膜**——所以深度学习方案可以直接替换掉第03讲流水线的第 4~6 步，抗干扰能力强得多。

**两个必须记住的函数**：

| 操作 | 代码 | 说明 |
|------|------|------|
| 取每个像素得分最高的类别 | `torch.argmax(logits, dim=1)` | 得到 `(H, W)` 类别图 |
| 提取某一类做掩膜 | `mask = (pred == ROAD_ID)` | 得到布尔图 |

> ⚠️ 常见坑：不同模型/数据集里「路面」的类别编号完全不同。ADE20K 里 `road` 是第 **6** 类，Cityscapes 里 `road` 是第 **0** 类，VOC 压根没有 road 类。**用之前必须先查这个模型训练用的数据集有哪些类、编号是多少**，否则你会把「天空」当路面。

### U-Net 一句话原理

U-Net = **编码器（下采样提取语义）+ 解码器（上采样恢复分辨率）+ 跳连（skip connection）**。左边一路不断缩小尺寸、变厚通道（看全局、知道「这是什么」），右边一路把尺寸放大回来（还原「在哪里」），中间用跳连把左边的细节直接搬给右边，所以分割边界特别准。因为结构图是 U 形而得名，最早用于医学影像。

### SegFormer 一句话原理

SegFormer = **Transformer 编码器（分层多尺度注意力）+ 极简 MLP 解码器**。它把图切成小块（patch）后像读句子一样用注意力机制建模全局关系，并且一次性输出 1/4、1/8、1/16、1/32 四个尺度的特征，最后用一个轻量的 MLP 把它们融合成预测。特点：**又快又准、模型小（B0 只有 3.7M 参数）**，非常适合边缘设备，是目前车载语义分割的主流选择之一。

### YOLO 一句话原理

YOLO（You Only Look Once，「只看一眼」）= **把目标检测变成一次回归**：把图划分成网格，网络一次前向就同时预测出「每个格子附近有没有目标、是什么类、框的四个坐标是多少」。早期两阶段方法（如 Faster R-CNN）要先提候选框再分类，慢；YOLO 一步到位，所以极快——这正是车载实时检测需要它。现在主流是 **YOLOv8 / v11** 系列，最小的 `yolov8n` 只有 3.2M 参数，CPU 上也能跑到十几 FPS。

## 3. 分割 vs 检测：什么场景用哪个

| 你要解决的问题 | 推荐任务 | 推荐模型 | 输出 | 典型耗时（640×480, CPU） |
|----------------|----------|----------|------|---------------------------|
| 可行驶区域（形状不规则的大片区域） | 语义分割 | SegFormer-B0 / U-Net | 掩膜 | 100~400 ms |
| 障碍物（一个个独立目标，要计数/定位） | 目标检测 | YOLOv8n | 类别 + 矩形框 | 30~80 ms |
| 既要路面形状又要每个锥桶的轮廓 | 实例分割 | YOLOv8n-seg | 掩膜 + 实例 ID | 60~150 ms |
| 只要「画面中间是不是路面」 | 分类 | MobileNetV3 | 1 个标签 | 5~15 ms |

**工程结论**：车载实时场景通常组合使用——**分割负责「哪里有路」，检测负责「路上有谁」**，两路结果一起送给规划模块。第05讲会讲这两路怎么用 ROS 2 话题接起来。

## 4. 标注数据从哪来

模型再好，没数据也白搭。三条路：

| 来源 | 怎么做 | 产出格式 | 适合谁 |
|------|--------|----------|--------|
| **labelme**（本地开源工具） | `pip install labelme` → `labelme` 打开图片 → 用多边形描出路面 → 保存 | 每张图一个 `.json`（含多边形坐标） | 自己拍几十张图做小实验 |
| **Roboflow**（在线平台） | 网页上传图片 → 在线框选/涂色 → 一键导出 | YOLO txt / COCO json / PNG 掩膜 | 团队协作标注，免费额度够学生用 |
| **公开数据集** | 直接下载别人标好的 | Cityscapes（道路 5k 精标）、BDD100K（10 万张）、ADE20K（150 类） | 想直接训练，不想标注 |

labelme 的 `.json` 转成掩膜图（自己写训练数据时必须做）：

```python
import json
import numpy as np
import cv2

with open("road_001.json", "r", encoding="utf-8") as f:
    data = json.load(f)

h, w = data["imageHeight"], data["imageWidth"]
mask = np.zeros((h, w), np.uint8)            # 0 = 背景
for shape in data["shapes"]:
    if shape["label"] == "road":             # 只看标记为 road 的多边形
        pts = np.array(shape["points"], dtype=np.int32)
        cv2.fillPoly(mask, [pts], 255)       # 多边形填充成白

cv2.imwrite("road_001_mask.png", mask)
print("掩膜已生成，白色像素占比 %.1f%%" % ((mask > 0).mean() * 100))
```

> ✅ 你应该看到（类似）：
> ```
> 掩膜已生成，白色像素占比 34.2%
> ```
> 打开 `road_001_mask.png`，应看到黑色背景上有一块白色多边形，形状与你描的路面一致。

> 💡 类比：labelme 标注就是**给模型准备「标准答案」的作业本**。你想让模型学会认路面，就得先亲手把「什么是路面」画给它看几百次；标注质量差（描得潦草、漏标阴影里的路），模型学出来就是错的——这叫「垃圾进垃圾出」（Garbage In, Garbage Out）。

## 5. 用预训练模型跑通一张图

「预训练权重」= 别人已经在几十万张图上训练好的模型参数。我们直接下载来用（这一步叫**推理 / inference**），不用自己训练。

### 安装

```bash
# 检测（含 CPU 版 PyTorch，约 800 MB，第一次装会慢）
pip install ultralytics

# 分割（HuggingFace transformers + PyTorch）
pip install transformers torch
# 国内网络建议加镜像，否则 HuggingFace 下载会超时
export HF_ENDPOINT=https://hf-mirror.com
```

> ⚠️ 常见坑：装完 `ultralytics` 后报 `ModuleNotFoundError: No module named 'torch'`，说明 PyTorch 没装上（多半是网络断了）。重跑 `pip install torch --index-url https://download.pytorch.org/whl/cpu`。

### 权重从哪下载

| 模型 | 权重文件 | 下载方式 | 大小 |
|------|----------|----------|------|
| YOLOv8n 检测 | `yolov8n.pt` | **首次运行自动下载**到当前目录；手动下载地址见 GitHub `ultralytics/assets` 的 Releases | ≈6 MB |
| YOLOv8n 分割 | `yolov8n-seg.pt` | 同上 | ≈7 MB |
| SegFormer-B0 (ADE20K) | `nvidia/segformer-b0-finetuned-ade-512-512` | `from_pretrained()` 自动下载到 `~/.cache/huggingface/hub/` | ≈15 MB |
| torchvision 分割 | `deeplabv3_resnet50` | `weights=DeepLabV3_ResNet50_Weights.DEFAULT`，从 `download.pytorch.org/models/` 下载 | ≈160 MB |

### 代码 A：语义分割跑一张图（先找出路面）

```python
# seg_demo.py —— 用 SegFormer 做语义分割，提取"路面"做掩膜
import numpy as np
import torch
import cv2
from PIL import Image
from transformers import AutoImageProcessor, SegformerForSemanticSegmentation

MODEL_NAME = "nvidia/segformer-b0-finetuned-ade-512-512"
IMG_PATH = "road.jpg"

processor = AutoImageProcessor.from_pretrained(MODEL_NAME)
model = SegformerForSemanticSegmentation.from_pretrained(MODEL_NAME)
model.eval()                                  # 切到推理模式（关掉 dropout 等训练专用层）

img_bgr = cv2.imread(IMG_PATH)
if img_bgr is None:
    raise SystemExit(f"读不到图片：{IMG_PATH}")
img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)
h, w = img_bgr.shape[:2]

inputs = processor(images=Image.fromarray(img_rgb), return_tensors="pt")
with torch.no_grad():                         # 不需要梯度，省内存
    outputs = model(**inputs)                 # logits: (1, 150, h/4, w/4)

logits = torch.nn.functional.interpolate(     # 上采样回原图尺寸
    outputs.logits, size=(h, w), mode="bilinear", align_corners=False)
pred = logits.argmax(dim=1)[0].numpy()        # (h, w) 每个像素的类别号

ROAD_ID = 6                                   # ADE20K 中 road 的类别编号
mask = np.where(pred == ROAD_ID, 255, 0).astype(np.uint8)
print(f"模型输出类别图 shape = {pred.shape}")
print(f"路面像素占比 {((mask > 0).mean() * 100):.1f}%")

overlay = img_bgr.copy()
overlay[mask > 0] = (0, 255, 0)
result = cv2.addWeighted(img_bgr, 0.6, overlay, 0.4, 0)
cv2.imwrite("seg_result.png", result)
print("分割效果图已保存: seg_result.png")
```

运行：

```bash
python3 seg_demo.py
```

> ✅ 你应该看到（类似）：
> ```
> 模型输出类别图 shape = (480, 640)
> 路面像素占比 31.8%
> 分割效果图已保存: seg_result.png
> ```
> 第一次运行会先下载约 15 MB 权重，屏幕上会有一行下载进度条，第二次运行就是秒开。

### 代码 B：目标检测跑一张图（再找出障碍物）

```python
# det_demo.py —— 用 YOLOv8n 做目标检测
from ultralytics import YOLO
import cv2

model = YOLO("yolov8n.pt")        # 首次运行自动下载约 6 MB
results = model("road.jpg", conf=0.35, verbose=False)

for r in results:
    for box in r.boxes:
        cls_id = int(box.cls[0])
        conf = float(box.conf[0])
        x1, y1, x2, y2 = [int(v) for v in box.xyxy[0]]
        print(f"{model.names[cls_id]:<12} 置信度 {conf:.2f}  框 ({x1},{y1})-({x2},{y2})")

annotated = results[0].plot()     # ultralytics 自带画框
cv2.imwrite("det_result.jpg", annotated)
print("检测结果已保存: det_result.jpg")
```

运行：

```bash
python3 det_demo.py
```

> ✅ 你应该看到（类似）：
> ```
> person       置信度 0.89  框 (212,140)-(298,431)
> car          置信度 0.76  框 (401,203)-(590,318)
> 检测结果已保存: det_result.jpg
> ```

> ⚠️ 常见坑：YOLO 的 COCO 80 类里**没有「锥桶（traffic cone）」**这个类，也没有「路面」。想检测巴哈赛道的锥桶，必须自己标注几十张图再用 `model.train(data="mydata.yaml", epochs=50)` 微调（fine-tune）。**预训练模型只能认出它见过的东西**，这一点答题时一定要写清楚。

> 💡 类比：预训练模型像**一个刚毕业的优等生**——通用常识都会（人、车、狗、杯子都认得），但你们车队的专用术语（锥桶、赛道边界）他没学过，需要你拿几十张样图给他「补课」（微调）。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 传统视觉 vs 深度学习 | 前者靠人写规则（快、可解释、脆），后者靠数据学特征（准、抗干扰、要算力与数据） |
| 语义分割 | 输出 `(H, W)` 类别图，argmax 得到每像素类别，提某一类即得掩膜 |
| U-Net | 编码器 + 解码器 + 跳连，边界准，医学影像起家 |
| SegFormer | Transformer 分层编码 + MLP 解码，小而准，适合边缘端 |
| YOLO | 一次前向直接回归出「类别 + 框」，一步到位所以快 |
| 类别编号 | ADE20K 的 road = 6，Cityscapes 的 road = 0，VOC 无 road，用前必查 |
| 标注工具 | labelme（本地，出 json）、Roboflow（在线，一键导出）、公开数据集 |
| 预训练权重 | 无需自己训练，`from_pretrained` / `YOLO("yolov8n.pt")` 自动下载 |
| 常用组合 | 分割找路 + 检测找人/障碍物，两路结果一起给规划 |
| 主要局限 | 预训练模型只认见过的类别，锥桶等专用目标需自己标注 + 微调 |

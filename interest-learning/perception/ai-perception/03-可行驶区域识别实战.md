## 1. 整体思路：一句话 + 一张图

**一句话**：可行驶区域 = 照片里「亮度适中、纹理平坦、位于画面下方、面积最大」的那块连通区域。

**流水线（这是答题时要画出来的图）**：

```
原图 (BGR)
   │ ① 灰度化                     3 通道 → 1 通道，降 2/3 运算量
   ▼
灰度图 gray
   │ ② 高斯模糊                   抹掉纹理噪声，让同质区域更"整块"
   ▼
平滑图 blur
   │ ③ 切 ROI（只保留画面下半部分）  缩小搜索范围，提速 + 防天空干扰
   ▼
ROI 灰度图
   │ ④ 阈值分割（Otsu 自动阈值）     按亮度分成 路面 / 非路面 两类
   ▼
二值图 binary（白=可行驶）
   │ ⑤ 形态学闭运算                填孔洞、连断缝
   ▼
干净二值图
   │ ⑥ 找最大连通域                只留面积最大的那一块（= 主路面）
   ▼
掩膜 mask
   │ ⑦ 与原图叠加 + 描边            生成给人看的识别效果图
   ▼
效果图 result.png
```

> 💡 类比：这条流水线就像**在沙地上用筛子找一块最大的平地**。
> - 灰度化 + 模糊 = 闭上一只眼、眯起眼睛看，忽略细节（沙粒、小石子）；
> - 阈值分割 = 按「颜色深浅」把地和草分开，深色的算草地、浅色的算平地；
> - 闭运算 = 把地上零散的小坑、小水洼填平（不然一会儿又算成草地了）；
> - 最大连通域 = 最后只认那块**连成一片**的最大平地，脚边的小碎石缝里那点平地直接不要。

## 2. 用到的基础操作（一句话复习）

| 操作 | 函数 | 一句话作用 |
|------|------|-----------|
| 灰度化 | `cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)` | 三通道压成一通道，0=黑 255=白 |
| 高斯模糊 | `cv2.GaussianBlur(img, (k, k), 0)` | 用高斯权重给邻域像素加权平均，抹掉高频噪声 |
| 阈值分割 | `cv2.threshold(..., THRESH_BINARY + THRESH_OTSU)` | 大于阈值→255，否则→0；Otsu 自动算阈值 |
| 形态学闭运算 | `cv2.morphologyEx(img, cv2.MORPH_CLOSE, k)` | 先膨胀后腐蚀，填小孔洞、连接近邻区域 |
| 连通域分析 | `cv2.connectedComponentsWithStats` | 数出图里有几块独立白区，并给出各自的面积/外框 |
| 叠加显示 | `cv2.addWeighted` | 按权重混合两张图，做半透明涂色 |

> ⚠️ 常见坑：`cv2.GaussianBlur` 的核大小必须是**奇数**（3、5、7、9…），填 `(6,6)` 会直接报错。
> ⚠️ 另一个坑：OpenCV 里阈值操作的判断是「严格大于」还是「大于等于」不影响结果，但**输入必须是单通道**（灰度图），彩色图传进去会报 `error: (-215) ...`。

## 3. 完整可运行代码

新建 `drivable.py`，把 `IMG_PATH` 改成你自己的照片路径。

```python
# drivable.py —— 可行驶区域识别（传统视觉方案，不依赖深度学习）
import cv2
import numpy as np

IMG_PATH = "road.jpg"            # ← 换成你自己的照片
OUT_PATH = "drivable_result.png"

# ---------- 1. 读图 ----------
img = cv2.imread(IMG_PATH)
if img is None:
    raise SystemExit(f"读不到图片：{IMG_PATH}（检查路径和文件名）")
h, w = img.shape[:2]
print(f"图像尺寸: {w} x {h}")

# ---------- 2. 灰度化 ----------
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# ---------- 3. 高斯模糊（核必须是奇数） ----------
blur = cv2.GaussianBlur(gray, (7, 7), 0)

# ---------- 4. ROI：只保留画面下半部分 ----------
roi_top = int(h * 0.5)                 # 从 50% 高度开始
roi = blur[roi_top:, :]                # 形状 (h-roi_top, w)

# ---------- 5. 阈值分割：Otsu 自动找阈值 ----------
thr_val, binary = cv2.threshold(roi, 0, 255,
                                cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print(f"Otsu 自动阈值 = {thr_val:.1f}")

# 判断"白"还是"黑"代表路面：
# 用图像最底边中央 60x60 的像素当"路面采样点"（车轮正前方一定是路面）
seed = binary[-60:, w // 2 - 30: w // 2 + 30]
if (seed > 0).mean() < 0.5:
    binary = cv2.bitwise_not(binary)   # 反相，保证"白 = 可行驶"
    print("检测到路面为暗区，已反相")

# ---------- 6. 形态学闭运算：修补孔洞、连接断缝 ----------
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (25, 25))
closed = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)

# ---------- 7. 提取最大连通域 ----------
num, labels, stats, _ = cv2.connectedComponentsWithStats(closed, connectivity=8)
mask_roi = np.zeros_like(closed)
if num > 1:
    areas = stats[1:, cv2.CC_STAT_AREA]     # 跳过 label=0（背景）
    biggest = 1 + int(np.argmax(areas))     # 最大区域的 label
    mask_roi[labels == biggest] = 255
    print(f"共 {num - 1} 个连通域，最大面积 {int(areas.max())} 像素")
else:
    print("未找到任何连通域，检查阈值/ROI 设置")

# ---------- 8. 还原成整图尺寸的掩膜 ----------
mask = np.zeros((h, w), np.uint8)
mask[roi_top:, :] = mask_roi

# ---------- 9. 叠加可视化 ----------
overlay = img.copy()
overlay[mask > 0] = (0, 255, 0)                    # 可行驶区域涂绿
result = cv2.addWeighted(img, 0.6, overlay, 0.4, 0) # 半透明混合

cnts, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
cv2.drawContours(result, cnts, -1, (0, 0, 255), 2)  # 红色描边界

print(f"可行驶区域占全图 {((mask > 0).mean() * 100):.1f}%")
cv2.imwrite(OUT_PATH, result)
print("识别效果图已保存:", OUT_PATH)
```

```bash
python3 drivable.py
```

## 4. 代码里的关键点解释

| 代码行 | 为什么这么写 |
|--------|--------------|
| `cv2.GaussianBlur(gray, (7,7), 0)` | 7×7 是经验值：核太小（3×3）噪声去不掉，太大（15×15）会把窄路面糊没 |
| `roi_top = int(h * 0.5)` | 摄像头装在车头约 0.5 m 高、向下倾斜，**画面下半部分才是路面**，上半部分是天空/远处 |
| `THRESH_OTSU` | 不用手填阈值，Otsu 会自动找「让两类像素类内方差最小」的那个值 |
| 采样底边中央判断极性 | 车轮正前方必然是路面，用它当锚点判断「白=路面」还是「黑=路面」，避免硬编码 |
| `kernel = 25×25 椭圆` | 椭圆核比矩形核更接近自然孔洞形状，边缘更圆润；25 与画面成比例 |

## 5. 【答题主体】识别思路与逻辑，分点阐述

这一节就是答题纸上要写的内容。**建议直接按这 6 点写，每点 3~5 行。**

### 5.1 预处理为什么这么做（灰度化 + 高斯模糊）

- **灰度化**：可行驶区域这一任务的本质是「路面 vs 非路面」的**二分类**，与颜色关系不大（泥土路、水泥路、柏油路颜色各异，但都是「平坦、亮度均匀」的）。把 3 通道变 1 通道，运算量降到原来的 1/3，同时避免三通道分别处理带来的不一致。
- **高斯模糊**：原始图像的像素级噪声（CCD 噪点、沙粒、小石子、画在地上的细小纹理）会让阈值分割产生大量「椒盐点」。高斯模糊相当于给每个像素和邻居做加权平均，把高频细节抹掉，让**同一类区域内部更均匀**，分割结果更「整块」。
- 注意**模糊要在分割之前**做，顺序不能反：先分割再模糊会把好不容易分出来的边界又糊掉。

### 5.2 分割依据是什么（阈值分割 + Otsu）

- **核心假设**：在灰度直方图上，可行驶路面（路面亮度集中、方差小）和非路面（草地/树木/碎石，亮度分散）会形成**两个峰**。阈值就是把这两个峰分开的那条线。
- 本方案用的是**全局阈值 + Otsu 自动选取**：Otsu 会遍历所有可能阈值，选出让「类内方差之和最小（等价于类间方差最大）」的那个，也就是直方图两个峰之间的谷底。它比手动填 `cv2.threshold(gray, 127, 255, ...)` 更稳健，因为不同照片的曝光完全不同。
- 为什么不直接用颜色（HSV）？在巴哈赛道场景里颜色会因泥水、扬尘失效（这是思维类第 4 题的答案），而**亮度/纹理的区分度比颜色更稳定**。但如果照片里路面与草地亮度接近，就需要切换到 HSV/Lab 方案（见第02讲和第 7 节）。

### 5.3 为什么要形态学修补（闭运算）

- 阈值分割出来的二值图里，路面上常有大大小小的**黑孔洞**：井盖、阴影斑、水坑、白色标线的反光差、几粒深色石头。这些孔洞在后续「取最大连通域」时没问题，但如果孔洞太多太大，路面会被**切断成好几块**，最大那块就只剩一半。
- **闭运算 = 先膨胀后腐蚀**：膨胀把白区的孔洞和缝隙填掉、把邻近的白块连起来；随后的腐蚀再把整体尺寸收回去，**不改变区域的大致大小，只补内部缺陷**。这正好符合我们的需求。
- 核（kernel）大小就是「能补多大的洞」：25×25 的椭圆核能补掉直径约 25 像素以内的孔洞。核越大补得越狠，但也会把「路面与草地之间真实的窄缝」一起填掉，所以要权衡。

### 5.4 为什么要选最大连通域

- 连通域 = 二值图里**连成一片**的白色像素集合。阈值分割后通常会出现很多块：路、远处天空的亮斑、白车、浅色岩石、路面反光带。
- 从**先验知识**看：这台车正前方的可行驶区域一定是画面里**面积最大的那一块**，且它与画面底边相接。其他亮块面积小、位置散，属于噪声。
- 因此用 `connectedComponentsWithStats` 拿到每块的面积，取最大的一块作为最终的可行驶区域，就能把绝大部分误检一次清掉。这是**用场景先验（prior）换鲁棒性**的典型做法，代价是「如果真实路面被切成两块，只会保留大的那块」。

### 5.5 如何生成掩膜与可视化

- **掩膜（mask）**：一张与原图同尺寸、只有 0/255 两种值的单通道图，255 表示「可行驶」。它是这台车后续环节真正需要的数据结构（规划模块按掩膜做碰撞检测）。注意 ROI 裁剪后要**把掩膜贴回原图的对应位置**（`mask[roi_top:, :] = mask_roi`），否则可视化会错位。
- **叠加可视化**：把掩膜当调色板，用 `overlay[mask > 0] = (0, 255, 0)` 把对应像素染绿，再用 `cv2.addWeighted(原图, 0.6, overlay, 0.4, 0)` 做半透明混合——**保留原图纹理同时看清识别范围**，比直接输出纯黑白二值图更便于人工检查。最后描一圈红色轮廓，让人一眼看到边界在哪。
- 颜色选绿 + 红：绿色表示「安全可走」，红色边界表示「临界线」，符合工程直觉。

### 5.6 如何评估效果

| 维度 | 方法 | 期望 |
|------|------|------|
| 主观正确性 | 把效果图和原图并排看 | 绿色区域应覆盖真实路面，不溢出到草地/天空 |
| 量化指标 | 手工标一张真值掩膜，算 **IoU = 交集/并集** | 简单场景 IoU > 0.7 算合格 |
| 成本指标 | 统计单帧耗时 | 640×480 上应 < 40 ms（即 > 25 FPS） |
| 稳定性 | 换 5 张不同光照/不同场景的照片各跑一次 | 成功率（IoU>0.5）应 ≥ 4/5 |
| 边界质量 | 看红色轮廓是否贴合真实边界 | 不应出现锯齿、断裂、飞点 |

量 IoU 的小代码：

```python
import cv2, numpy as np
pred = cv2.imread("mask_pred.png", 0) > 0     # 你的结果
gt   = cv2.imread("mask_gt.png", 0) > 0       # 手工标注的真值
iou = (pred & gt).sum() / (pred | gt).sum()
print(f"IoU = {iou:.3f}")
```

### 5.7 失败场景与改进方向（答题时写上这段会加分）

| 失败场景 | 现象 | 改进思路 |
|----------|------|----------|
| 逆光/阴影 | 大片路面变暗，被判成非路面 | 用**自适应阈值**（`cv2.adaptiveThreshold`）局部处理，或先做直方图均衡化（CLAHE） |
| 泥水覆盖路面 | 路面亮度接近草地 | 改用 **HSV/Lab 多通道联合阈值**，或加入纹理特征（边缘密度） |
| 强反光/水面 | 亮斑断裂成多块 | 闭运算核加大；或用「与底边相连的最大块」代替「面积最大块」 |
| 路面被切成 2 块 | 只保留了一半 | 合并「面积 > 阈值」的多个连通域，而不是只取最大 |
| 上坡/俯仰变化 | ROI 固定 50% 切错 | ROI 按地平线估计动态调整（第05讲） |
| 夜晚/低照度 | 全图接近全黑 | 补光/HDR 相机；或退化为「热区+边缘」方案 |

## 6. 生成提交用的效果图脚本

作业要求「提交识别效果图」，一张对比图最直观。新建 `make_report_figure.py`：

```python
# make_report_figure.py —— 生成 2x2 对比图，用于作业提交
import cv2
import numpy as np

IMG_PATH = "road.jpg"
OUT_PATH = "report_figure.png"

img = cv2.imread(IMG_PATH)
if img is None:
    raise SystemExit(f"读不到图片：{IMG_PATH}")
h, w = img.shape[:2]

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (7, 7), 0)
roi_top = int(h * 0.5)
roi = blur[roi_top:, :]

thr_val, binary_roi = cv2.threshold(roi, 0, 255,
                                    cv2.THRESH_BINARY + cv2.THRESH_OTSU)
seed = binary_roi[-60:, w // 2 - 30: w // 2 + 30]
if (seed > 0).mean() < 0.5:
    binary_roi = cv2.bitwise_not(binary_roi)

kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (25, 25))
closed = cv2.morphologyEx(binary_roi, cv2.MORPH_CLOSE, kernel)

num, labels, stats, _ = cv2.connectedComponentsWithStats(closed, connectivity=8)
mask = np.zeros((h, w), np.uint8)
if num > 1:
    areas = stats[1:, cv2.CC_STAT_AREA]
    biggest = 1 + int(np.argmax(areas))
    mask[roi_top:, :] = np.where(labels == biggest, 255, 0).astype(np.uint8)

overlay = img.copy()
overlay[mask > 0] = (0, 255, 0)
result = cv2.addWeighted(img, 0.6, overlay, 0.4, 0)
cnts, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
cv2.drawContours(result, cnts, -1, (0, 0, 255), 2)

def to3ch(m):
    """单通道图转三通道 + 加标题（cv2.putText 不支持中文，用英文）"""
    t = cv2.cvtColor(m, cv2.COLOR_GRAY2BGR)
    cv2.putText(t, "1", (10, 30), cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 0, 255), 2)
    return t

panels = [
    ("original",   img),
    ("threshold",  cv2.cvtColor(binary_roi, cv2.COLOR_GRAY2BGR)),  # 仅 ROI 部分
    ("mask",       to3ch(mask)),
    ("overlay",    result),
]
# 阈值图补足到整图高度（上半部分填黑），方便拼图
panels[1] = ("threshold", cv2.copyMakeBorder(
    panels[1][1], roi_top, 0, 0, 0, cv2.BORDER_CONSTANT, value=(0, 0, 0)))

top = np.hstack([panels[0][1], panels[1][1]])
bottom = np.hstack([panels[2][1], panels[3][1]])
grid = np.vstack([top, bottom])

for i, (name, _) in enumerate(panels, start=1):   # 左上、右上、左下、右下加编号
    pos = {1: (10, 30), 2: (w + 10, 30), 3: (10, h + 30), 4: (w + 10, h + 30)}[i]
    cv2.putText(grid, str(i), pos, cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 0, 255), 2)

cv2.imwrite(OUT_PATH, grid)
print("对比图已保存:", OUT_PATH, "尺寸:", grid.shape[1], "x", grid.shape[0])
```

## 本讲小结

| 概念 | 要点 |
|------|------|
| 可行驶区域 | 图像中车辆可以安全通行的像素集合，本质是「路面/非路面」二分类 |
| 灰度化 | 3 通道 → 1 通道，降运算量；本任务不依赖颜色 |
| 高斯模糊 | 抹掉高频噪声，让同质区域成块；核必须奇数，放在分割之前 |
| ROI 裁剪 | 只处理画面下半部分，提速 + 排除天空干扰 |
| Otsu 阈值 | 自动找直方图双峰之间的谷底，比手填阈值稳健 |
| 形态学闭运算 | 先膨胀后腐蚀，填内部孔洞、连断缝，不改变整体尺寸 |
| 最大连通域 | 用「画面里最大的一块白区 = 主路面」这条先验清掉误检 |
| 掩膜（mask） | 与原图同尺寸的 0/255 单通道图，是交给规划模块的正式数据 |
| 可视化 | 掩膜当调色板染绿 + `addWeighted` 半透明混合 + 描红边 |
| 评估 | 主观看边界 + IoU 量化 + 单帧耗时 + 多场景稳定性 |
| 主要局限 | 逆光/泥水/反光会失效，需上 HSV、自适应阈值或深度学习方案 |

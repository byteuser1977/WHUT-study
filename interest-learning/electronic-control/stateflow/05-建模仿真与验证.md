# 第05讲：建模仿真与验证（正文约6分钟 + 练习约4分钟）

## 你将学到
- 用激励时序把状态机跑起来
- 五条必验工况与逐段核对方法
- 两个调试技巧（动画高亮 / 断点单步）

---

## 1. 验证用的激励时序

```text
t=0.0s 上电                              → Standby（VCU_Mode = 0）
t=1.0s Manual_Enable=1, RC_Online=1      → Manual（VCU_Mode = 1）
t=2.0s RC_Online=0                       → 回 Standby（VCU_Mode = 0）
t=3.0s Auto_Enable=1, Auto_System_OK=1   → Auto（VCU_Mode = 2）
t=4.0s Emergency_Stop=1                  → Emergency（Target_Torque=0, Brake_Request=1）★
t=5.0s Emergency_Stop=0, Emergency_Reset=1 → 回 Standby，且 Brake_Request 必须已清零
```

## 2. 怎么造激励

- **`Signal Editor`**：定义几路信号、各自的分段时刻与取值，最贴合上面这张时序表。
- **拼模块**：每路输入用 `Step`（阶跃）+ `Constant`（常量）组合，先接 `Chart` 的输入口。

仿真时长设 `6s`，**固定步长 `Fixed-step` 取 `0.001s`**（取太大可能漏掉瞬间的急停信号），求解器可选 `ode4` 或离散求解器，**以你机器上为准**。

## 3. 看波形

把 `Chart` 的 `VCU_Mode` / `Target_Torque` / `Brake_Request` 三个输出接 `Scope`。`VCU_Mode` 是模式编号，**用阶梯显示（`Stair`）比连线更清楚**；也可以接 `To Workspace` 存下来在 MATLAB 里画。核对时**逐段对比时间点**，别只看"大概对"。

## 4. 五条必验工况

| # | 工况 | 期望 |
|---|---|---|
| 1 | 待机 → 遥控 → 回待机 | `VCU_Mode` 0 → 1 → 0 |
| 2 | 待机 → 自主 → 回待机 | `VCU_Mode` 0 → 2 → 0 |
| 3 | 遥控中按急停 | 立刻 `VCU_Mode = 3`、`Brake_Request = 1` |
| 4 | 自主中按急停 | 同上（证明最高优先级与当前模式无关）|
| 5 | 急停复位回待机 | `VCU_Mode = 0` 且 `Brake_Request` **已归零** |

> ⚠️ 第 3、4 条是重点：波形上应看到 `VCU_Mode` 从 1 或 2 **直接跳到 3**，中间不经过别的模式 —— 若出现"先回 Standby 再进 Emergency"，说明急停转移挂错了层级。

## 5. 两个调试技巧

- **动画高亮（`Animation`）**：运行时激活状态会高亮，一眼看出"现在在哪个状态、走了哪条边"。非常快的转移可能一闪而过，**最终还是看波形**。
- **断点单步**：`Stateflow` 编辑器的 **`Debug` 选项卡**可设断点、单步执行，让仿真在某个状态或转移上停住，用来查"为什么这一条没进去"。

> 💡 类比：仿真像**体检**不是**治病** —— 波形不对只是症状，回到转移条件表逐条比对才找得到病根。

## 🎯 动手练习

1. 给 `Chart` 补 6 个 `Input` 源（`Signal Editor` 或 `Step` 组合），按第 1 节时序表设好时间点。
2. 三个输出接 `Scope`，仿真时长 `6s`、固定步长 `0.001s`，运行。
3. 逐段核对 0→1→0→2→3→0 的跳变时刻是否与激励一致。
4. 复现"在 Manual 里按急停"：把 `Emergency_Stop` 的阶跃时间改到 `t=1.5s`，再跑一遍。
5. 复现"在 Auto 里按急停"：改到 `t=3.5s`，再跑一遍。
6. 检查 `t=5s` 后 `Brake_Request` 是否回到 0；没回就回第 04 讲补 `Emergency` 的 `exit:` 动作。

> ✅ 你应该看到：`VCU_Mode` 是一条阶梯曲线，依次出现 0 → 1 → 0 → 2 → 3 → 0；`Brake_Request` 在 `t=4s` 跳成 1、`t=5s` 回 0；`Target_Torque` 在 Standby 与 Emergency 期间恒为 0。

## 本讲小结

| 概念 | 要点 |
|---|---|
| 激励来源 | `Signal Editor` 或 `Step` + `Constant` 拼 |
| 仿真配置 | 时长 6s、固定步长 0.001s |
| 观测 | `VCU_Mode` / `Target_Torque` / `Brake_Request` 接 `Scope` |
| 五条工况 | 遥控往返 / 自主往返 / 遥控中急停 / 自主中急停 / 复位归零 |
| 调试 | `Animation` 看状态高亮，`Debug` 设断点单步 |

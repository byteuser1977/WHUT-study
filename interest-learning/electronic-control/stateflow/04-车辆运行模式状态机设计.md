## 1. 层次结构与四个状态

```text
  默认转移 ──→ ┌ Operational ───────┐
              │ Standby·Manual·Auto│
              └────────────────────┘
              │ [Emergency_Stop || Vehicle_Fault]
              ▼
          Emergency ──[Emergency_Reset && !Emergency_Stop]──→ Standby
```

`Emergency` 与 `Operational` 平级；三个模式是后者的**排他（OR）子状态**。急停挂在**父状态出边**上 → 超状态出边优先，急停无条件赢。

> 💡 类比：像**总闸与分闸** —— 总闸一拉，分闸全得让路。

| 状态 | `VCU_Mode` | 主要输出 |
|---|---|---|
| `Standby` 待机 | **0** | `Target_Torque = 0` |
| `Manual` 遥控驾驶 | **1** | 遥控命令转执行机构信号 |
| `Auto` 自主驾驶 | **2** | 目标速度/转角/扭矩控制 |
| `Emergency` 紧急 | **3**（建议） | `Brake_Request = 1` |

## 2. 转移条件表

| # | 源 → 目标 | 条件 |
|---|---|---|
| 0 | 默认转移 → `Standby` | 无（Default transition）|
| 1 | `Standby` → `Manual` | `[Manual_Enable && RC_Online]` |
| 2 | `Standby` → `Auto` | `[Auto_Enable && Auto_System_OK]` |
| 3 | `Manual` → `Standby` | `[!Manual_Enable \|\| !RC_Online]` |
| 4 | `Auto` → `Standby` | `[!Auto_Enable \|\| !Auto_System_OK]` |
| 5 | `Operational` → `Emergency` | `[Emergency_Stop \|\| Vehicle_Fault]` ★最高优先级 |
| 6 | `Emergency` → `Standby` | `[Emergency_Reset && !Emergency_Stop]` |

## 3. 各状态动作

```text
Standby  entry: VCU_Mode = 0; Target_Torque = 0; during: Target_Torque = 0;
Manual   entry: VCU_Mode = 1;
Auto     entry: VCU_Mode = 2;
Emergency entry: VCU_Mode = 3; Target_Torque = 0; Brake_Request = 1;
         during: Target_Torque = 0; Brake_Request = 1;
         exit: Brake_Request = 0;  ← 必须清零
```

> ⚠️ **`Brake_Request` 必须在 `Emergency` 的 `exit:` 里清零**，否则退出紧急后制动请求挂着，车动不了。

## 4. 遥控与自主互斥的两层保障

1. **结构层**：Manual 与 Auto 是**排他（OR）兄弟状态**，同时只激活一个。
2. **仲裁层**：两条件同时为真靠**执行顺序**裁决 —— 右键 `Standby` 打开执行顺序设置，把 **`→ Manual` 排在 `→ Auto` 前**。
3. **加固写法**：条件互锁 `[Manual_Enable && RC_Online && !Auto_Enable]`、`[Auto_Enable && Auto_System_OK && !Manual_Enable]`。

## 🎯 动手练习

1. 建 `vcu_mode.slx`，拖 `Chart` 进编辑器，画 `Operational` 大框。
2. 三个模式状态拖入框内，`Emergency` 留在框外。
3. 默认转移指向 `Standby`，按第 2、3 节填条件与动作。
4. 右键 `Standby` 设执行顺序，`→ Manual` 排在 `→ Auto` 前。
5. 截图：状态名 + 全部条件 + 动作都要可见（局部截图不合格）。

> ✅ 你应该看到：框内三子状态、框外 `Emergency`；7 条转移（默认1+条件6）都画好，`Emergency` 内可见 `exit: Brake_Request = 0;`。

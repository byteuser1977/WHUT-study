# 第02讲：状态转移条件与动作语法（正文约6分钟 + 练习约4分钟）

## 你将学到
- `entry:` / `during:` / `exit:` 各自什么时候执行
- 转移标签 `[条件]{动作}` 的完整写法
- `&&` `||` `!` 逻辑运算与默认转移
- 变量作用域在哪定义（`Model Explorer`）

---

## 1. 状态动作三兄弟

```text
state Standby
  entry: VCU_Mode = 0; Target_Torque = 0;   % 进入时执行一次
  during: Target_Torque = 0;                % 停留期间每个步长都执行
  exit: ...                                 % 离开时执行一次
```

| 关键字 | 何时执行 | 次数 | 本设计用法 |
|---|---|---|---|
| `entry:` | 刚进入该状态 | 1 次 | 置 `VCU_Mode`、`Brake_Request = 1` |
| `during:` | 停留期间 | 每个步长 | 持续保持 `Target_Torque = 0` |
| `exit:` | 离开该状态前 | 1 次 | 把 `Brake_Request` 清零 |

> 💡 类比：`entry:` 是进门换拖鞋，`during:` 是坐在屋里别乱跑，`exit:` 是出门关灯锁门 —— 忘了关灯（清标志），下次进来就乱套。

## 2. 转移标签语法

```text
[Manual_Enable && RC_Online]              % 只有条件
[Emergency_Stop]{Brake_Request = 1;}      % 条件 + 动作
```

- **方括号 `[...]` 是条件，必填**；不写条件就是"无条件转移"，一进源状态立刻跳走，这是新手最常踩的坑。
- **花括号 `{...}` 是转移动作，可选**，写在条件后面，**转移发生的那一刻**执行。
- 逻辑运算：`&&`（与）、`||`（或）、`!`（非）；输出取值 `true` / `false`；比较用 `==` `!=` `>` `<`。
- ⚠️ 别把 `&&` 写成 `&`：那是按位与，条件评估结果可能出乎你意料。

## 3. 默认转移

图上从**空白处出发**、没有源状态的箭头就是默认转移（Default transition）—— 模块启动 / 复位时走它，决定**上电第一个状态**。本设计上电默认进 `Standby`。

## 4. 变量在哪定义

`Chart` 里打开 **`Model Explorer`**（或 `Tools > Explore`）加数据，每条定 **名称 / 作用域 / 数据类型**：

| 作用域 | 含义 | 本设计用 |
|---|---|---|
| `Input` | 外部给 `Chart` 的信号，出现在输入口 | `Manual_Enable`、`RC_Online`、`Emergency_Stop` 等 6 个 |
| `Output` | `Chart` 输出给模型的信号 | `VCU_Mode`、`Target_Torque`、`Brake_Request` |
| `Local` | 只在图内用的中间变量 | 本设计可不用 |
| `Parameter` | 常量参数 | 阈值、限值 |

布尔量用 `boolean`，扭矩用 `single`（车上通常不用 `double`；**具体以你机器上工程设置为准**）。

> ⚠️ 变量没在 `Model Explorer` 里定义就直接引用，会报 undefined symbol；先定义，再连信号。

## 本讲小结

| 概念 | 要点 |
|---|---|
| `entry:` | 进入状态时执行一次，用于置模式与输出 |
| `during:` | 停留期间每个步长执行，用于持续保持 |
| `exit:` | 离开前执行一次，**清标志必须写在这里** |
| 转移标签 | `[条件]` 必填、`{动作}` 可选，顺序不能颠倒 |
| 默认转移 | 空白处出发的箭头，决定上电首个状态 |
| 变量作用域 | `Input` / `Output` / `Local` / `Parameter`，在 `Model Explorer` 定义 |

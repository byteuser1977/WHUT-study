---

## 1. 建模型的六个标准动作

1. **新建**：`simulink` → `Blank Model`，**立刻 `Ctrl+S` 起名**（别留在 `Untitled`）。
2. **拖模块**：从 Library Browser 按名字搜（如 `Gain`），拖进画布。
3. **连线**：按住模块边上的小箭头拖到目标模块端口，箭头方向即数据流向。
4. **设参数**：双击模块填参数。**参数不要写死数字**，写成变量（如 `Kp`、`Ki`）由 `.m` 脚本赋值，方便批量试不同参数。
5. **运行**：点工具栏 `Run`。
6. **看波形**：双击 `Scope`，或用 `To Workspace` 把数据存到工作区再画。

## 2. 求解器与步长：仿真精度的命门

配置入口：`Model Configuration Parameters`（快捷键 **`Ctrl+E`**，或菜单 `Modeling` → `Model Settings`），在里面找 `Solver`。

| 配置项 | 说明 |
|---|---|
| `Type` | `Fixed-step`（定步长）/ `Variable-step`（变步长）|
| 变步长典型 | `ode45`：自适应步长，通用、算得快，适合前期试逻辑 |
| 定步长典型 | `ode4`（四阶 Runge-Kutta）；**车控仿真几乎都用定步长** |
| `Fixed-step size` | 控制器常用 **`0.001` s（1 ms）**，与 VCU 任务周期对齐 |
| `Stop time` | 仿真时长，如 `10` 表示跑 10 秒模型时间 |

**为什么控制偏好定步长**：真实 VCU 是每 1 ms 执行一次控制代码，只有用同样的节拍仿真，才能验证"代码在这个周期里跑得完吗、延迟有多大"。变步长省时间，但步长一直在变，跟真实执行节奏对不上。

> 💡 类比：步长就是**行车记录仪的采样间隔**——1 秒拍一张，急刹车的瞬间根本拍不到；1 毫秒拍一张，路面抖动都拍得清。步长太小算得慢，太大丢细节，1 ms 是车控的甜点。

## 3. 波形不对的三个常见原因

| 现象 | 原因 | 怎么查 |
|---|---|---|
| 曲线毛刺多、锯齿状 | **采样步长太大** | 把 `Fixed-step size` 从 `0.01` 改到 `0.001` 再看 |
| 数值差 1000 倍、量级离谱 | **参数单位错**（rad/s 与 rpm、N·m 与 N·mm 混用） | 逐个模块核对参数单位，统一 SI |
| 输出飞走或一直顶在限幅值 | **反馈没接成闭环**（接成正反馈，或反馈支路断了） | 顺着信号线走一圈：输出能不能回到比较点 |

> ⚠️ 第三个坑最常见：`Sum` 上反馈支路该接**减号**端口却接成正号，误差越滚越大，几分钟波形就发散。看 `Sum` 图标上的小符号，`|+-` 才是做负反馈。

## 🎯 动手练习（约4分钟）

1. 新建模型存为 `practice03.slx`，拖入 `Step`、`Sum`、`Gain`、`Integrator`、`Scope`。
2. 连线：`Step` → `Sum` 的 `+` 端；`Integrator` 输出 → `Sum` 的 `-` 端（形成负反馈）；`Sum` → `Gain` → `Integrator` → `Scope`。
3. 双击 `Gain` 设 `2`；`Ctrl+E` 里把 `Type` 设为 `Fixed-step`、`Solver` 选 `ode4`、`Fixed-step size` 填 `0.001`、`Stop time` 填 `10`。
4. 点 `Run`，双击 `Scope` 看阶跃响应。
5. 把 `Fixed-step size` 改成 `0.1` 再 `Run`，对比曲线是否变粗糙。
6. 把 `Sum` 的负号端口改成加号，观察波形发散，再改回来。

> ✅ 你应该看到：正常时曲线**先冲上去、再平缓收敛到设定值**（一阶惯性）；步长 0.1 时曲线出现明显折线感；接成正反馈后曲线指数上升发散。

## 本讲小结

| 项 | 要点 |
|---|---|
| 建模型六步 | 新建 → 拖模块 → 连线 → 设参数 → 运行 → `Scope` 看波形 |
| 参数 | 写成变量不放死数，便于批量试参数 |
| 定步长 | 车控首选，`ode4` + `0.001` s，与 VCU 任务周期对齐 |
| 变步长 | `ode45` 自适应步长，适合前期快速验逻辑 |
| 配置位置 | `Ctrl+E`（Model Configuration Parameters）→ `Solver` |
| 三大病因 | 步长太大、单位错、反馈没接成闭环 |

## 1. 整理思路：分组记，别背流水账

Simulink 的库很多，关键不是背得多，而是**有分类、有中文对照、能说用途**——按九个库分组整理，末尾补一句"最常用的五件套"。

## 2. 九个库分组与代表模块

| 库（Library） | 代表模块（中英对照） | 典型用途 |
|---|---|---|
| `Sources` 信号源 | `Constant` 常量、`Step` 阶跃、`Sine Wave` 正弦、`Clock` 时钟、`Signal Generator` 信号发生器 | 设定值、测试激励、时间信号 |
| `Sinks` 信号汇 | `Scope` 示波器、`Display` 数值显示、`To Workspace` 存到工作区 | 看结果、存数据 |
| `Continuous` 连续系统 | `Integrator` 积分、`Derivative` 微分、`Transfer Fcn` 传递函数 | 速度＝加速度的积分；表示电机/悬架动态 |
| `Math Operations` 数学运算 | `Gain` 增益、`Sum` 求和、`Product` 乘积、`Abs` 绝对值 | 放大、相加、取模值 |
| `Logic and Bit Operations` 逻辑与位运算 | `Logical Operator` 逻辑运算（AND/OR/NOT）、`Relational Operator` 比较（`>`、`<`、`==`） | 条件判断：车速>5 且急停未按下 |
| `Signal Routing` 信号路由 | `Mux` 多路合成、`Demux` 分解、`Bus Creator` 总线创建 | 打包多路进一个 `Scope`，或拆开总线 |
| `Discontinuities` 非线性 | `Saturation` 饱和限幅、`Dead Zone` 死区、`Rate Limiter` 变化率限幅 | **车上必备**：扭矩上下限、摇杆死区、扭矩变化率限制 |
| `Discrete` 离散 | `Unit Delay` 单位延时、`Zero-Order Hold` 零阶保持 | 取上一拍的值、按固定周期采样 |
| `Stateflow` 状态流 | `Chart` 状态机模块 | 模式管理：待机/遥控/自主/紧急 |

> 💡 类比：这些库像**五金店货架**——`Sources` 是电源、`Sinks` 是万用表、`Math Operations` 是扳手、`Discontinuities` 是保险丝。

> ⚠️ 模块的**分类路径在版本之间会变**，用库里搜名字最稳，**具体路径以你机器上为准**；整理时写模块名与用途即可。

## 3. 最常用五件套（收尾一句）

**五件套 = `Constant` / `Gain` / `Sum` / `Integrator` / `Scope`**，正好是一条最小控制回路：**设定值（`Constant`）→ 与反馈相减（`Sum`）→ 误差放大（`Gain`）→ 积分成控制量（`Integrator`）→ 看波形（`Scope`）**。

再补一句：上车时 `Saturation`（限幅）和 `Rate Limiter`（变化率限幅）几乎**必备**——执行机构有物理极限，指令不能无限大、不能跳变。这句话最能体现你动过手。

---

## 🎯 动手练习（约4分钟）

1. 打开 Library Browser，点开 `Sources`、`Math Operations`、`Sinks`、`Discontinuities`，悬停对照上表认一遍。
2. 新建 `practice02.slx`，拖入 `Step`、`Gain`、`Saturation`、`Scope`，连成 `Step → Gain → Saturation → Scope`，`Gain` 填 `10`。
3. 双击 `Saturation` 设 `Upper limit` = `5`、`Lower limit` = `-5`，`Run` 看波形；再把上限改成 `100` 运行一次，对比两条曲线。
4. 用 `Mux` 把"限幅前"和"限幅后"两路并成一个 `Scope` 输入，一次看两条线。

> ✅ 你应该看到：`Upper limit` = 5 时波形在 **5 处被削平**（阶跃幅度 10 被砍到 5）；改成 100 后不再削顶。这就是限幅在车上保护执行机构的作用。

## 本讲小结

| 要点 | 内容 |
|---|---|
| `Sources` / `Sinks` | `Constant`、`Step`、`Sine Wave`、`Clock`、`Signal Generator` / `Scope`、`Display`、`To Workspace` |
| 运算与逻辑 | `Integrator`、`Derivative`、`Transfer Fcn` / `Gain`、`Sum`、`Product`、`Abs` / `Logical Operator`、`Relational Operator` |
| 路由 / 离散 / 非线性 | `Mux`、`Demux`、`Bus Creator` / `Unit Delay`、`Zero-Order Hold` / `Saturation`、`Dead Zone`、`Rate Limiter`、`Chart` |
| 结论 | 五件套 `Constant`-`Gain`-`Sum`-`Integrator`-`Scope`；车上必加 `Saturation` 与 `Rate Limiter` |
| 整理提醒 | 按九个库分组 + 中文对照 + 用途；分类路径随版本变，以你机器上为准 |

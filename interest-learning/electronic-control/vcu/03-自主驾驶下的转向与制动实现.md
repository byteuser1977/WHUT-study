# 第03讲：自主驾驶下的转向与制动实现（正文约6分钟 + 练习约4分钟）

## 你将学到
- 自主模式下"感知 → 规划 → 控制 → VCU → 执行机构"的完整链路
- VCU 在自主链路里做哪三件事：指令转换、仲裁、闭环修正
- 两道安全闸门：急停最高优先级、信号丢失必降级

---

## 1. 完整链路：从看到路到车停下

```text
感知（摄像头/雷达/IMU） → 规划（路径与速度规划）
   → 控制（算出目标速度 / 目标转向角 / 目标扭矩）
   → VCU（模式判定 → 指令转换 → 仲裁 → 限幅）
   → 执行机构（电机控制器 / 线控转向 / EHB）
   → 车辆运动 → 反馈回感知与控制
```

**规划控制模块输出的就是三个目标值：目标速度、目标转向角、目标扭矩。** VCU 拿到它们之后不重算路径，只负责把它们变成执行机构听得懂的指令，并守住安全边界。

## 2. VCU 的三件事：转换、仲裁、闭环修正

**① 指令转换（单位与接口对齐）**
目标转向角 → 线控转向执行器的角度指令；目标扭矩 → 电机控制器的扭矩指令；速度需要减速时 → EHB 的制动请求。VCU 还要统一量纲和正负号约定，避免"上层给度、下层收弧度"这类低级错误。

**② 仲裁（谁说了算）**
多路指令同时存在时按固定优先级裁决，并做**平滑**（避免阶跃指令造成冲击）。自主模式下最常见的一条仲裁规则就是：**制动请求与驱动请求同时有效时，制动赢**。

**③ 闭环修正（PID 是典型手段）**
控制模块用 **PID** 比较"目标值 − 反馈值"算修正量：转向环的反馈是**实际前轮转角**，速度环的反馈是**车速**，姿态与加速度的反馈是 **IMU**。误差大就加大修正，误差归零就稳住——这就是"闭环"比"开环发令"可靠的原因。

> ⚠️ 闭环要能跑起来，还有一个容易被忽略的前提：**指令周期和反馈周期要匹配**。VCU 按定步长周期（典型 10 ms）发指令、读反馈，如果上位系统几十毫秒才给一次目标值，就必须做保持与插值，否则两拍之间的指令会抖。自测时点一句"周期一致性"，很显功底。

> 💡 类比：空调设 26℃（目标值）不算完，还得看室温（反馈）才决定压机开多大（修正量）。设定值只是愿望，反馈才让它落地。

## 3. 安全限幅：让指令撞上硬墙

| 限幅项 | 为什么需要 |
|--------|-----------|
| 角度限幅 | 保护转向机械与线束，防执行器超程 |
| 扭矩斜率限制 | 防指令阶跃导致轮胎打滑、传动系冲击 |
| 制动优先于驱动 | 两个请求冲突时制动赢，绝不允许"边刹边驱" |
| 速度上限 | 赛道路面与规则约束，超限即限扭或制动 |

限幅放在 VCU 里做，执行机构才不会收到超出机械能力的指令；这也正是上一讲说的"把安全逻辑集中在一处"。

## 4. 两道不能忘的安全闸门

**① 急停最高优先级。** 自主模式再"自动"，也只是**运行模式之一**：一旦急停开关被按下或检测到严重故障，VCU 立即切紧急模式——禁驱动力、出制动请求，并忽略遥控与自主的全部指令。换句话说，自主链路的所有输出都要先过这道闸门，而不是绕过它。

**② 任一路信号丢失必须降级。** 感知丢、自主系统心跳丢、CAN 报文超时、转角或 IMU 反馈失效——任何一路都不是"继续跑"的理由，而是触发降级：按策略**回待机**（最保守）或**切遥控**（有人接管）或**直接进紧急**（车已失稳风险）。原则只有一句：**不确定时选更安全的那一档。**

> ⚠️ 别把降级写成"报警提示、继续行驶"。没有可用的反馈量还继续闭环，PID 只会对着错数据越修越偏，这是实车最危险的一类 bug。

## 🎯 动手练习（约4分钟）

1. 默画第 1 节的链路图，标出三个目标值分别从哪来、送到哪个执行机构。
2. 给转向环、速度环各写出：目标值、反馈量、执行机构、可能的干扰。
3. 列出至少 4 处该做限幅的位置，并说明不加会出什么问题。
4. 假设"自主模式行驶中 IMU 反馈丢失"，用 3 句话写出你设计的降级策略（从触发条件到最终状态）。

> ✅ 你应该看到：链路五段完整且方向正确；三个目标值一一对上执行机构；限幅清单里包含角度限幅、扭矩斜率限制、制动优先于驱动；降级策略明确落到回待机/切遥控/进紧急之一，并点出急停在自主模式下仍是最高优先级。

## 本讲小结

| 项 | 要点 |
|----|------|
| 链路 | 感知 → 规划 → 控制 → VCU → 执行机构 → 反馈 |
| 三个目标值 | 目标速度、目标转向角、目标扭矩（规划控制模块输出） |
| VCU 三件事 | 指令转换（单位/接口对齐）、仲裁（优先级 + 平滑）、闭环修正（PID） |
| 反馈量 | 实际转角、车速、IMU（加速度/角速度） |
| 安全限幅 | 角度限幅、扭矩斜率限制、**制动优先于驱动**、速度上限 |
| 两道闸门 | 自主模式下急停仍是最高优先级；任一路信号丢失必须降级 |

# 第02讲：VCU 的输入输出与执行机构（正文约6分钟 + 练习约4分钟）

## 你将学到
- VCU 一共有哪几路输入、哪几路输出
- 一张"来源 → VCU → 执行机构 → 反馈"的信号流表
- CAN 一句话原理，以及 VCU 为什么必须靠它

---

## 1. 输入盘点：VCU 听到什么

| 来源 | 信号 | 进来长什么样 |
|------|------|-------------|
| 遥控接收机 | 转向、油门、制动、模式开关 | PWM（脉宽）或 SBUS 串口帧，也可能直接是 CAN 报文 |
| 自主驾驶系统 | 目标速度、目标转向角、目标扭矩 | CAN 报文（数值）+ 系统状态位 |
| 急停开关 | 急停按下 / 解除 | 硬线数字量（开关量） |
| 车辆状态传感器 | 车速、转向角、IMU（加速度/角速度）、电机转速 | CAN 报文或模拟量 |
| 执行机构与电池 | 故障码、温度、电压、SOC | CAN 报文（多为诊断/状态帧） |

> ⚠️ 急停**优先走硬线**而不是 CAN：总线可能丢帧、被占用甚至断线，而急停是最高优先级信号，绝不能依赖"报文能不能及时到"。

## 2. 输出盘点：VCU 说出去什么

- **驱动扭矩指令** → 电机控制器（正值驱动、负值可做能量回馈或电制动）
- **转向指令** → 线控转向执行器（目标转角，执行器内部再闭环）
- **制动请求** → EHB 电控液压制动（请求建压或目标压力，由制动 ECU 建轮缸压力）
- **状态与心跳** → 通过 CAN 广播给各节点（当前模式、是否就绪、故障等级）

注意"**请求**"二字：VCU 输出的是期望值，不是最终物理量。真出力多少由执行器自己闭环决定——这也是为什么要靠反馈来确认。

## 3. 信号流表：一张表看懂整车控制

| 环节 | 来源 | 经 VCU 做什么 | 执行机构 | 反馈回 VCU 的量 |
|------|------|--------------|----------|----------------|
| 驱动 | 遥控油门 / 自主目标扭矩 | 仲裁、限幅、斜率限制 | 电机控制器 → 驱动电机 | 电机转速、实际扭矩、母线电流 |
| 转向 | 遥控转向 / 自主目标转角 | 模式判定、角度限幅 | 线控转向执行器（转向电机） | 实际前轮转角、转角传感器信号 |
| 制动 | 遥控制动 / 自主制动请求 | 制动优先判定 | EHB（泵 + 电磁阀块） | 轮缸压力、减速度（IMU） |
| 安全 | 急停开关 / 故障码 | 最高优先级仲裁 | 禁驱动力 + 出制动请求 | 急停状态回读、故障确认 |

最后两列是全表的灵魂：**没有反馈，VCU 只是"发令"，无法知道指令有没有落地**。

## 4. CAN 一句话原理与作用

**CAN（Controller Area Network）是车用总线：所有节点挂在同一对差分线上，报文带着标识符（ID）广播，谁需要谁收。** 好处正好对上车用需求：

- **多节点**：一对线挂十几二十个节点，省掉点对点布线（整车减重）
- **抗干扰**：差分信号 + 报文校验，比单端模拟线扛电磁噪声
- **带诊断**：有超时、错误计数、故障帧，通信本身可被监视，掉线能被发现

> 💡 类比：CAN 像对讲机频道，不是打电话。你按下说话，全频道都听得到，谁的活谁接；没人应答或串音了，你也能立刻察觉。

VCU 是靠节拍工作的：底层**定步长周期任务**（典型 10 ms 一档）读报文 → 算 → 发指令，所以报文超时判定、周期一致性是它的基本功课。

## 🎯 动手练习（约4分钟）

1. 不看书，把第 1、2 节的输入、输出各默写出 4 条，标出哪些走硬线、哪些走 CAN。
2. 照第 3 节画一张信号流表，行改成"驱动 / 转向 / 制动"，每列填上你自己能想到的内容。
3. 挑一条链路（例如制动），写出"反馈量是什么、如果反馈丢失 VCU 会怎样"。
4. 用两句话回答：为什么急停不只用 CAN、CAN 相比点对点线束赢在哪。

> ✅ 你应该看到：输入输出各 4 条以上且区分硬线/CAN；信号流表四列完整；能说出"急停走硬线 + 反馈缺失即降级"；CAN 三优点（多节点、抗干扰、带诊断）齐全。

## 本讲小结

| 项 | 要点 |
|----|------|
| 输入 | 遥控接收机、自主系统目标值（速度/转角/扭矩）、急停开关、车辆状态（车速/转角/IMU）、故障码 |
| 输出 | 驱动扭矩 → 电机控制器；转角 → 线控转向；制动请求 → EHB |
| 信号流 | 来源 → VCU 仲裁限幅 → 执行机构 → 反馈回 VCU（闭环） |
| 输出性质 | VCU 发的是**期望值/请求**，实际物理量由执行器闭环 |
| CAN | 广播式车用总线：多节点、抗干扰、带诊断；急停另走硬线 |
| 一句话 | 没有反馈，VCU 只是发令员；有了反馈才谈得上整车控制 |

## 1. 自测标准与通用结构

这五个重点问题都归到**讲清道理**这一类：自测时看的是**有没有讲清因果与取舍**，不是背名词。每个问题 150~300 字。

```
① 一句话结论   ← 先给判断（"VCU 是整车控制器"优于"随着汽车电子发展……"）
② 两三个要点   ← 每个要点 = 判断 + 理由，不能只扔名词
③ 一句落地     ← 提到巴哈/我们的 VCU/遥控与自主，立刻脱离套话
```

> 💡 类比：这些自测像**跟队友讲方案** —— 只说"VCU 很重要"没人听懂；说清"它是唯一同时看到遥控与自主指令的地方，所以急停判断只能放它这儿"，才叫讲清了。

> ❌ 出现就删："随着……的发展"、"众所周知"，以及任何**换到别的问题也成立**的句子。

## 2. 五个重点问题的表述骨架（一张表看完）

| 重点问题 | 表述骨架 | 关键点 | 易错点 |
|---|---|---|---|
| **Simulink 常用模块** | 按库分类列 **8~10 个**并说用途：`Constant`/`Step`（信号源）、`Scope`/`Display`（看结果）、`Gain`/`Sum`（运算）、`Integrator`（积分）、`Saturation`/`Rate Limiter`（**必备限幅**）、`Mux`/`Demux`（打包）、`Unit Delay`（离散）、`Chart`（状态机）。收尾给"常用五件套 = Constant·Gain·Sum·Integrator·Scope" | 来源/显示/数学/逻辑/限幅 | 只列名字不说用途 |
| **VCU 是什么、主要功能** | ①定义：**VCU = Vehicle Control Unit 整车控制器**，车辆的中央控制与协调单元②功能至少 6 条：信号采集解析 / 驾驶模式管理 / 指令仲裁与限幅 / 指令输出到执行机构 / 故障诊断与安全保护 / 通信（CAN）与上下电管理 ③落点：核心价值是**把安全逻辑集中在一处** | 整车控制器、模式管理、仲裁、限幅、CAN、安全状态 | 与电机控制器 MCU 搞混 |
| **MBD 流程 + 怎么烧录到 VCU** | 见第 3 节 — **两块都要答** | MBD、MIL/SIL/PIL/HIL、Embedded Coder、.hex、刷写 | 漏 V 模型链条或把烧录说成"下载模型" |
| **线控转向/制动定义与理解** | 见第 4 节 — **必须写"自己的理解"** | X-by-Wire、SBW 解耦、EHB、冗余降级、ISO 26262 | 没写自己的理解；EPS 与 SBW 混淆 |
| **自主模式下如何实现转向与制动** | ①链路：感知→规划→控制→**VCU**→执行机构 ②输入：规划输出**目标速度/目标转向角/目标扭矩** ③VCU 做转换与仲裁（转角→线控转向、扭矩→电机控制器、制动→**EHB 建缸压**）④闭环：转角/车速/IMU 反馈修正（PID）⑤安全：角度限幅、扭矩斜率限制、**制动优先于驱动** ⑥自主模式仍受**急停优先级**约束；信号丢失要能降级 | 目标转向角、目标扭矩、EHB 建压、限幅、降级 | 不讲 VCU 在中间做什么；忘记安全降级 |

## 3. MBD 与烧录展开

```
① MBD 是什么：把模型当"唯一设计源"，需求→模型→仿真→代码→测试都围绕它展开
② V 模型五阶段（必须写全）：需求与系统设计 → 模型开发与 MIL → SIL → 代码生成 → PIL/HIL → 实车标定
③ 一条铁律：先仿真后上车 —— 先在 MIL 里跑通逻辑，再生成代码上台架
④ 烧录四步：固定接口与数据类型 → 配置 Model Configuration Parameters（定步长 + ert.tlc）
   → Embedded Coder 生成 C 代码，用目标板工具链编译成 .hex/.bin
   → JTAG/SWD 或 CAN bootloader 刷写 → 台架验证后上车标定
⑤ 落点：烧录前后记录模型版本与固件版本
```

**易错点**：只答"MBD 就是用模型开发"；把烧录说成"把模型下载进去"（实际是生成 C 代码再编译刷写）。

## 4. 线控与"自己的理解"展开

```
① 定义：线控 = X-by-Wire，用电信号 + 电控执行器替代机械/液压/气动的力传递路径
② 分述：线控转向 SBW —— 方向盘与转向轮"解耦"（转角传感器 → ECU → 转向电机）；
        与 EPS 的区别：EPS 只"助力"，机械连接仍保留
        线控制动 —— EHB 电控液压（踏板传感器 → ECU → 电磁阀块/泵建压）
        vs EMB 电控机械（电机直驱卡钳）
③ 自己的理解（两面都写，这是关键部分）：
   好处：布置自由、响应快、手感可软件标定、天生适配自动驾驶
   代价：失去机械备份→须冗余与失效降级；强依赖供电与通信→EMC/看门狗；成本与复杂度上升；涉 ISO 26262 / ASIL
```

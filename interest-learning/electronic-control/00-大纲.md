# WUTIB 智能巴哈车队 · 电控组 Simulink 与 Stateflow 学习笔记

> 面向想进车队电控组的大一新生 —— 从"没碰过 Simulink"到"能独立在 Stateflow 里把车辆状态机画出来并跑通"。
> 这是一条面向零基础、从科普到进阶的学习路线，围绕 **Simulink 与 MBD、VCU 与整车控制、Stateflow 状态机、线控底盘** 四块知识展开，共 **5 个模块、16 讲**，每讲约 10 分钟。

---

## 一、这份教程解决什么问题

要掌握的是两块能力，一块偏理解、一块偏动手：

| 能力 | 学的是什么 | 学到什么程度 |
|---|---|---|
| 工程理解 | 对 Simulink / VCU / 线控的**工程认知** | 讲清因果与取舍，不是背名词 |
| 动手建模 | **Stateflow 状态机设计 + 安全控制思想** | 状态、转移、优先级、输出一个不漏 |

> ⚠️ 状态机这块的产出是**框图**，所以重点不是"看懂"，而是**能在 Simulink 里画出来并仿真验证**——第 04 讲给了完整设计，第 05 讲给了验证方法。

---

## 二、学习路线图

按 **会说 → 会画 → 会验证 → 能讲清** 四步走：

1. **模块一 Simulink 与 MBD（5 讲）** — 界面与建模思想 → 常用模块库 → 第一个模型 → MBD 开发流程 → 代码生成与烧录
2. **模块二 VCU 与整车控制（3 讲）** — VCU 是什么与主要功能 → 输入输出与执行机构 → 自主驾驶下的转向制动实现
3. **模块三 Stateflow 状态机设计（5 讲）** — 本教程的重点：状态机思想与界面 → 语法 → 优先级与层次结构 → **车辆运行模式状态机设计** → 建模仿真与验证
4. **模块四 线控底盘认知（2 讲）** — 线控转向/制动的定义与理解 → 执行器与安全冗余
5. **模块五 重点问题自测（1 讲）** — 五个重点问题的表述骨架与易错点，把前面知识组装成自己的话

> 如果只剩三天：**模块三（重点 03/04 讲）→ 模块五 → 模块一第 02/04/05 讲 → 模块二第 01 讲**。这几块直接覆盖了最常用的核心知识。

## 五、环境与软件准备

| 项 | 要求 |
|---|---|
| 主软件 | **MATLAB + Simulink**（R2021b 及以上；含目标硬件支持包）|
| 必备工具箱 | **Stateflow**（画状态机）、**Embedded Coder / Simulink Coder**（生成 C 代码）、Control System Toolbox（可选） |
| 磁盘与内存 | MATLAB 全家桶很大，建议预留 30 GB 以上；8 GB 内存能跑，16 GB 更稳 |
| 获取途径 | **学校正版授权**或 MATLAB 校园版；也可用学校机房（**以车队通知为准**）。不要用来源不明的破解版软件 |
| 没有 MATLAB 怎么办 | Octave **不能**替代 —— Stateflow 是 MATLAB 独有工具箱。先看教程把状态机逻辑与转移条件写清楚（这部分在哪都能练），再去机房实操画图 |

> ⚠️ 本教程操作步骤以 MATLAB R2021b+ 的中英文界面对照给出。不同版本菜单位置可能有差异，**以你机器上为准**；模块名与操作逻辑是一致的。

## 七、学完能做到什么

- ✅ 能说出 Simulink 常用模块与用途，并能搭一个可运行的模型看波形
- ✅ 能讲清 MBD 的 V 模型流程，以及代码生成到烧录进 VCU 的完整链路
- ✅ 能说清 VCU 是什么、有哪些主要功能，以及它在自主驾驶链路里扮演什么角色
- ✅ **能在 Stateflow 里画出车辆运行模式状态机，并仿真验证四种模式切换**
- ✅ 能说清急停最高优先级、模式互斥、失效安全是怎么用状态机结构实现的
- ✅ 能说清线控转向/制动的定义，并讲出好处与代价两面的理解
- ✅ 能按"结论 → 要点 → 落地"的结构把五个重点问题讲成自己的话

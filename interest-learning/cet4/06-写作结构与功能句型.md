# 第06讲：写作结构与功能句型（正文约6分钟 + 练习约4分钟）

## 你将学到
- 三段式怎么切，每段各自干什么活
- 一张能直接套用的功能句型表：开头、理由、举例、建议、结尾
- 让句子出彩的三种结构，以及什么时候该收着用
- 四个最常见的写作错误和对应的自查动作

---

## 1. 三段式：最稳的骨架

写作 30 分钟、不少于 120 词，占总分 15%（整体结构与占比见第 01 讲）。120 词摊到三段，就是每段 40 词上下：

| 段落 | 作用 | 大约词数 | 常用信号 |
|------|------|----------|----------|
| 第一段 | 引出话题并表明立场 | 30~40 | Nowadays / It is widely held that |
| 第二段 | 两条理由各配一个例子 | 60~80 | First and foremost / Take ... as an example |
| 第三段 | 重申观点，给出建议或展望 | 30~40 | In conclusion / Only by ... can we ... |

> 💡 类比：三段式像一次自我介绍——先说你是谁（立场），再说你做过什么（理由），最后说你打算怎么做（建议）。顺序一乱，对方就抓不住你。

## 2. 功能句型表：按用途取用

| 用途 | 可直接套用的句型 |
|------|------------------|
| 引出话题 | With the development of ..., ... has become a heated topic. |
| 表明立场 | From my perspective, ... / I am convinced that ... |
| 给出理由 | Several factors account for this. / The main reason lies in ... |
| 举例支撑 | A case in point is ... / This is best illustrated by the fact that ... |
| 让步转折 | Admittedly, ..., but ... / Despite the fact that ..., ... |
| 提出建议 | It is high time that we took measures to ... |
| 总结收束 | In conclusion, ... / Only in this way can we ... |

> ⚠️ 常见坑：句型是骨架不是装饰，一句里挑一个就够。三个倒装句挤在同一段，反而显得堆砌。

## 3. 三个亮点结构

| 结构 | 写法 | 自造示例 |
|------|------|----------|
| 非谓语开头 | 用 -ing 或过去分词短语当状语 | Walking along the river, I noticed the water had turned grey. |
| 从句嵌套 | 主句带一个定语从句或状语从句 | Those who read widely usually write with ease. |
| 倒装强调 | Only、Not until、Rarely 置于句首 | Only by keeping practicing can you build real fluency. |

用法原则：一段最多一处亮点，先保证句子写对，再考虑写漂亮。

## 4. 四个常见错误

| 错误 | 反面例子 | 改法 |
|------|----------|------|
| 主谓不一致 | The number of students are rising. | 把 are 改成 is；先找主语再定动词 |
| 时态来回跳 | Yesterday I go to the library. | 全篇以一种时态为基准 |
| 中式直译 | Open the light. | 背固定搭配：turn on the light |
| 一句到底 | 整段只有一句，硬撑到 120 词 | 每 3~4 句断一次，用连接词过渡 |

写完留 3 分钟从头读一遍：主语、时态、搭配各扫一次，比多写一句更有用。

## 🎯 动手练习（约4分钟）

1. 打开手机备忘录，计时 40 秒写下三段式骨架：一句立场、两个理由词、一句建议，只写骨架不展开。
2. 从功能句型表里挑 3 句，把话题词换成你自己熟悉的主题（手机、环保、校园生活均可）。
3. 把骨架扩成一段 60 词左右的正文，至少用上 1 个非谓语开头和 1 个定语从句。
4. 读一遍，圈出段里所有动词，逐个确认时态统一、主语和动词一致。
5. 大声读出来数句子，少于 4 句就把最长的那句拆成两句。

✅ 你应该看到：一段 60 词左右的正文里至少 4 个句子、2 处亮点结构，动词时态全部一致。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 三段式 | 立场 → 理由展开 → 重申与建议，各段分工明确 |
| 功能句型 | 按用途取用，一句只挑一个 |
| 亮点结构 | 非谓语、从句、倒装三选一，一段一处 |
| 常见错误 | 主谓一致、时态、直译、一句到底 |
| 自查顺序 | 主语 → 时态 → 搭配，留 3 分钟通读 |

# 第07讲：汉译英段落翻译技巧（正文约6分钟 + 练习约4分钟）

## 你将学到
- 拿到中文先断句、抓主干，别逐字往外翻
- 主语怎么挑：中文省掉的主语，到英文怎么补出来
- 词性转换、增译减译，让译文像英文而非中文的影子
- 四字格三种处理办法，外加按题材分好的主题词表

---

## 1. 断句与定主干
中文是"流水句"：短句靠逗号连着，主语常省略；英文是"形合"：一句话只有一个主干，其余信息靠从句、分词、介词短语挂上去。所以第一步不是翻，而是**断**：按逗号、顿号切成 3~5 个意群（意思完整的小块）。第二步**定主干**：每群只挑"谁、干什么"先翻，修饰成分一律后补。

> 💡 类比：像收拾行李箱：先放大件（主干）压平，袜子毛巾（修饰）塞缝隙；顺序一反，大件就装不下。

> ⚠️ 常见坑：一逗到底，整段用 and 串成长链；或照中文语序逐字搬，前半句还像英文，后半句越翻越中文。

## 2. 主语选择
英文必须有主语，中文却多无主句，照表挑：

| 中文情况 | 英文主语 | 自造例 |
|---|---|---|
| 无主句（"必须重视质量"） | 被动 或 we | Quality must come first. |
| 以地名、时间开头 | 地名/时间直接作主语 | Wuhan lies in central China. |
| "人们认为、大家都知道" | It 作形式主语 | It is widely believed that... |
| 事物作主题（"学校建于1952年"） | 保留作主语 | The school was founded in 1952. |

自查：写完圈出谓语动词，看它前面有没有名词，没有就补一个或改被动。

## 3. 词性转换
中文爱用动词，英文爱用名词和介词。三类最常转：

| 中文习惯 | 转成英文 | 自造例 |
|---|---|---|
| 动词连着来 | 名词 + 介词 | 随着经济的发展 → with the development of the economy |
| "是……的"判断句 | 形容词或分词 | 城市很美 → the city is beautiful |
| 同一动词反复出现 | 换同义名词或代词承接 | 提高水平、改善水平 → improve the level |

拿不准就问：这个动词英文里有没有现成名词？有就优先用名词，句子立刻收紧。

## 4. 增译与减译
增的是英文必须有、中文可省的；减的是中文有、英文累赘的。

| 方向 | 补什么删什么 | 例子 |
|---|---|---|
| 增译 | 冠词、单复数 | 学生 → the students |
| 增译 | 逻辑连接词（因为、所以） | 两个短句用 because 合成一句 |
| 减译 | 范畴词"情况、方面、问题" | 环境污染问题严重 → pollution is getting worse |
| 减译 | 重复主语和套话 | 连说两遍"中国"，第二遍用 it |

## 5. 四字格与主题词
四字格分三种处理：

| 类型 | 怎么办 | 例 |
|---|---|---|
| 并列同义（勤劳勇敢） | 两个英文形容词并列 | hardworking and brave |
| 成语典故（人杰地灵） | 意译意思，不追字面 | a place producing great people |
| 夸张铺陈（美不胜收） | 砍掉修辞，只留事实 | very beautiful |

> ⚠️ 别逐字硬译："三山五岳"写成 three mountains five mountains，整段就站不住。先问它到底在说什么再写。

翻译那段约 140~160 个汉字、限时 30 分钟，占整套材料的 15%（四部分占比见 [01-四级概览与备考规划](01-四级概览与备考规划.md)），题材基本落在下面四类：

| 类别 | 常见主题词 |
|---|---|
| 传统文化 | 书法 calligraphy、剪纸 paper cutting、儒家 Confucianism、丝绸 silk |
| 历史古迹 | 长城 the Great Wall、朝代 dynasty、修建 construct、文物 relic |
| 饮食节日 | 饺子 dumpling、春节 the Spring Festival、习俗 custom、团圆 reunion |
| 社会发展 | 改革开放 reform and opening up、城市化 urbanization、基础设施 infrastructure、人均 per capita |

主题词只练"看到中文写出英文"这一半，反向默写等词汇量补上再说（见 [02-词汇记忆与高频词群](02-词汇记忆与高频词群.md)）。

## 🎯 动手练习（约4分钟）

1. 找一段约 150 字的中文（手机新闻里的文化类短段落；没有就用主题词表自己写三句）。
2. 用竖线切成 3~5 个意群，每群圈出"谁干什么"。
3. 只翻各意群的主干，写成 3~5 个简单句，暂不管修饰。
4. 挑一句做增译：补上冠词或连词，把两个短句合成一句。
5. 从主题词表任选 5 个中文词，只看中文写英文，再对表格核对。

✅ 你应该看到：意群数量和主干句数量一样多，其中至少 1 句含 because / which / with 之类的连接成分，5 个主题词至少写对 4 个。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 断句定主干 | 先切意群，每群只留"谁干什么" |
| 主语选择 | 谓语前面必须有名词：无主句用被动、It 或补主语 |
| 词性转换 | 中文动词优先转英文名词、介词短语 |
| 增译减译 | 增冠词与连词，减范畴词和重复主语 |
| 四字格 | 并列译形容词、成语意译、夸张砍修辞 |
| 主题词 | 按题材分四类，只练中到英的单向输出 |

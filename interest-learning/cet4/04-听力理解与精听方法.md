# 第04讲：听力理解与精听方法（正文约6分钟 + 练习约4分钟）

## 你将学到
- 短篇新闻、长对话、听力篇章三部分各自的脾气和应对重心
- 播放前的几十秒怎么预读选项，提前锁定要抓的信息
- 听的时候抓哪些信号词、笔记只记什么
- 精听五步法，把一小段音频榨干

---

## 1. 三部分特点
四部分结构与占比的完整口径见 [01-四级概览与备考规划](01-四级概览与备考规划.md)，这里只用结论：听力占 35%，共 25 题、25 分钟。

| 部分 | 体量 | 材料特点 | 应对重心 |
|------|------|----------|----------|
| 短篇新闻 | 3 段 7 题（7%） | 导语先行、信息密集，词汇偏时事 | 抓 5W1H：谁、何时、何地、何事、为何、如何 |
| 长对话 | 2 段 8 题（8%） | 一问一答，关键信息会重复出现 | 抓数字、地点、态度与转折 |
| 听力篇章 | 3 段 10 题（20%） | 语速最稳、篇幅最长，多为叙述或说明 | 抓段落主线，以及举例服务的观点 |

## 2. 预读选项：声音还没响就先猜方向
预读 = 播放前把选项快速扫一遍，判断这段大概要问什么。顺序是"先共同，后差异"：

| 选项长相 | 预判方向 |
|----------|----------|
| 几个选项都是地点名词 | 听对话发生的地点 |
| 几个选项都是时间或数字 | 听时间、日期、价格 |
| 几个选项都以 because 开头 | 听原因 |
| 选项长短不一、有一项明显更具体 | 差异词就是落点，重点听它 |

具体动作：① 纵向扫共同词，定方向；② 横向比差异词，圈出落点；③ 在心里默读一遍差异词，耳朵会自动去接。

> ⚠️ 常见坑：逐词读完全部选项，结果还没读完就开始播。改用"共同词 3 秒、差异词 5 秒"，长选项只圈关键词，不读全句。

## 3. 信号词：答案常紧跟在它后面
信号词是说话人给的路标，提示"注意，重点来了"。

| 类型 | 例子 | 提示什么 |
|------|------|----------|
| 转折 | but, however, actually | 后半句才是真话，前半句常是干扰 |
| 强调 | the point is, in fact, especially | 出题人最爱考的位置 |
| 因果 | because, so, as a result | 原因与结果是高频考点 |
| 举例 | for example, such as | 观点比例子本身更重要 |
| 顺序 | first, then, finally | 篇章结构与事件先后 |

## 4. 笔记要点：只记能帮你还原的符号
| 记什么 | 怎么记 |
|--------|--------|
| 数字、时间、人名地名 | 原样写，一个信息占一行 |
| 否定与转折 | ✗ 表否定，but 后面打个箭头 → |
| 趋势与数量 | ↑ 上升、↓ 下降、~ 大约 |
| 其余内容 | 不记，靠短时记忆，笔记只给"听漏了"兜底 |

> ⚠️ 常见坑：埋头写整句，漏掉后面两句话。笔记是补漏网的，不是逐字誊写，竖着记、一格一词，跟不上就先留空。

## 5. 精听五步法
精听 = 拿一小段音频反复听，直到每个词都对上号。判断标准写在最后一列：

| 步骤 | 做法 | 判断标准 |
|------|------|----------|
| 一盲听 | 不看文本整段听 1~2 遍 | 能说出谁在哪做了什么 |
| 二逐句听 | 一句一停写下来，每句至少听 3 遍 | 听不清的词先留空，不猜 |
| 三对照 | 打开文本，标出没听出的地方 | 分成连读、弱读、生词三类 |
| 四跟读 | 模仿语音语调逐句朗读 | 语速能接近原音 |
| 五复听 | 关掉文本再听整段 | 漏掉的部分降到 10% 以内 |

对照时圈出的生词，按 [02-词汇记忆与高频词群](02-词汇记忆与高频词群.md) 的方法归档，这里不重复。

> 💡 类比：精听像校对书稿——盲听是满纸空格的初稿，逐句对照是逐行改错，跟读是朗读定稿，最后复听一遍确认通篇顺下来。

## 🎯 动手练习（约4分钟）
1. 选一段免费音频（BBC Learning English *6 Minute English*，或每日英语听力里的一段短新闻；没有材料就用手机自带录音机录 30 秒中文新闻再自听）。
2. 播放前花 30 秒预读：写下你预测会听到的 3 个关键词。
3. 盲听一遍，用一句话写下大意（谁、在哪、发生了什么）。
4. 挑其中 30 秒做逐句听写，听不清的词留空；对照文稿后，把每个空标成连读、弱读或生词。
5. 关掉文稿复听这 30 秒，数一数还剩几个没听出来。
✅ 你应该看到：30 秒片段的空格从最初 5 个以上降到 2 个以内，且每个空都标好了错因类别。

## 本讲小结

| 概念 | 要点 |
|------|------|
| 三部分特点 | 新闻抓 5W1H、长对话抓数字与转折、篇章抓主线 |
| 预读选项 | 先看共同词定方向，再圈差异词当落点 |
| 信号词 | 转折、强调、因果、举例、顺序之后常跟关键信息 |
| 笔记要点 | 只记数字、专名、否定转折，用符号代替单词 |
| 精听五步 | 盲听 → 逐句 → 对照 → 跟读 → 复听 |
| 课后衔接 | 生词归档走第 02 讲，结构占比看第 01 讲 |
